# 行雨定额

> 一句话：**下雨这件事早就不是「本事」，是「定额」——几寸几分，写在簿子上，按簿子执行。**
> 这一案是「按簿子办事」第一次被人拿住漏洞。

## 一、定额是怎么来的

[[龙族]] 守三族盟约之后，行雨从「族权」变成「职务」：每年、每地、几寸几分，由[[天庭]] 的 [[水部]] 下定额，[[东岳大帝]] 那端对人间收成。

- 定额写在雨簿上，一式两份：水部一份、行雨者一份。
- 改一个字，人间就是一季旱或一季涝。
- 谁都不能多下，也不能少下——**多下也是错**，因为别人的账会跟着乱。

## 二、这一案的经过（四步）

1. **定额下达**：某地该得雨数，写死在簿子上。
2. **执行偏差**：行雨的龙改了点数（在任何版本里，动机都写成「他有理由」——救旱、护人、被求）。
3. **核数对不上**：[[水部]] 复核降雨量、[[东岳大帝]] 核人间收成与寿数，两边数据咬不上。
4. **判**：不是按「造成了多少损失」判，是按**「簿子上的数对不上」**判——违约本身即罪。

## 三、它证明了什么

| 结论 | 说明 |
|---|---|
| 龙族的「不敢」有了具体形状 | 不是怕打，是怕簿子 |
| 制度的刚性不在惩罚重，在**没有裁量余地** | 少一寸和多一寸都是错，判罚一样 |
| [[考功]] 真正在管什么 | 它管的不是「做得好不好」，是「与簿子对不对得上」 |
| 人间的旱涝第一次变成公文问题 | 从此求雨要递文书，不是磕头 |

## 四、后果

- **龙族从此连「好心」也不敢用**：救旱也会错，因为没走文书。
- **求雨的路径变了**：民间求雨 → 地方官报 → [[城隍]]／[[土地]] 转 → 水部下定额 → 行雨。中间每一环都能卡。
- **天庭的分配权再一次显形**：它不生产雨，它只决定雨记在谁的账上、按什么数下。

## 五、写作约束

1. 不写龙族反击成功：这一案的关键是「他没有反抗的理由」。
2. 不写玉帝亲自出场判案：判的是水部与东岳的核数结果。
3. 不写雨数可以事后补批：能补的话整件事就不成立了。
4. 不写具体龙名与地名——写成「某地某龙」，让它是一类事而不是一桩轶闻。

## 已定（2026-11-16 裁决）

- **U-474**：改点数不是一个技术失误，是一念之差：**救旱**。他先下了再说，想着「反正水在天上、多下一点也不至于有人数」。这正是制度要防的那一念——他与雨之间没有中间物。
- **U-475**：判罚是**削职夺封，不再行雨**。不是赔雨、不是罚俸：天庭处理这种事的方式是**把人和职务分开**，让他从此以后只能看着水在别人的簿子上走。这也解释了为什么接定额的龙最守规矩——那个后果不是吃亏，是失去身份。

### 那条龙改了多少、为什么

他改的不是一场雨，是**某个县的三个月**。理由只有一句：那个县旱得厉害，报上去又等不及层层核，他想着先下、回头再补一句说明。

这一念之所以致命，是因为**他与雨之间没有中间物**：只要他动，就会落下来。全天庭的繁文缛节，本质上都是为了在他和雨之间塞进几道手续。

### 罚的是人不是雨

削职夺封之后，那条河由谁来下雨？——**由别处调来的龙兼着**（见 [[行雨体系]]）。天庭从不为一个人留位置，也从不因为少一个人就让某地下不了雨。
