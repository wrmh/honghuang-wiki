# 九曲黄河阵

> 一句话：它不杀人、不困人，**只把人打回原形**——
> 一条线走九曲，每过一弯削一层；出去的人还是那个人，只是修为没了。

## 结构与原理

| 部分 | 作用 |
|---|---|
| 九曲 | 不是迷宫，是**九次过账**（每弯一次，削掉一层） |
| 黄河 | 不是水，是「冲刷」——把修出来的东西刷掉 |
| [[混元金斗]] | 唯一的账笔：削多少由它定，不由布阵人定 |
| 金蛟剪 | 护阵不杀人（剪的是想跑的那一步） |

**核心：它不是战斗，是撤销。** 十二金仙进去，出来还是十二个人，但掉了一档（[[修行境界]] 上退回去）。

## 与其它阵的对照

| 阵 | 处理人的方式 |
|---|---|
| [[诛仙阵]] | 终止（断道/形/神/传） |
| [[万仙阵]] | 淹没（人多到没有命门） |
| [[十绝阵]] | 消耗（拖到有人先死） |
| **九曲黄河阵** | **降级**（不改生死，改档次） |

**四种里只有它给「活着的惩罚」**——所以它比杀更得罪人：被杀是进榜（[[封神榜]]），被削是活着看着自己变了。

## 三条写作约束

1. 不许写成「困阵」：人要能走进走出，只是走一趟就没了。
2. 削掉的不能恢复（[[混元金斗]] 削掉就是没了），故这一阵的后果必须一直拖到封神之后。
3. 不许让布阵人显得狠：三霄摆它，本意是**替兄长出口气**，不是要毁谁。
