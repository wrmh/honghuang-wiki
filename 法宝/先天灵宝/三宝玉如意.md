# 三宝玉如意

> 一句话：它几乎不杀人，因为它只杀**站错了位置的人**。

## 来历

先天灵宝，归 [[元始天尊]]。**它动的是「名分」这一层**：不是杀身，是杀「你算什么东西」。

## 能力与代价

- 能做到：定名分：一句话把对方从「仙」降成「散修」，从「在册」降成「无门」。杀伤面最小，最难防。
- 代价 / 克制：只对「有名分」的人生效；**无名无册者反而伤不到**（这是它在洪荒里杀得最少的原因）。

### 完残与来由

完好。玉色有一道极淡的水线，是开天沉浮留下的，不影响品阶。

## 战史

- 封神前：元始以此定过几回「你算不算阐教弟子」的名分。

## 流转

先天 → 一直归 [[元始天尊]]。

## 相关

- 持有者：[[元始天尊]]
- 对照：[[盘古幡]]（立秩序）、[[封神榜]]（记名录）

## 是什么

[[先天灵宝]]，40 道极品。由 [[混沌青莲]] 的花（未开的苞）所化，现主 [[元始天尊]]。

花是整株青莲上唯一**还没长成**的部位——所以它这一件的能力是「**定**」：点一下，某件还没长成、还在两可之间的事，就被定下来。

| 点在哪 | 定的是什么 |
|---|---|
| 点在人身上 | 这个人的**名分**（谁是弟子、谁是不肖、谁该在榜上） |
| 点在阵上 | 这个阵**算不算数**（[[诛仙阵]] 不归它管：四剑是判决，判决不需要批准） |
| 点在言语上 | 一句话**成不成誓**（所以三教签押那一日，在场的人都得收声） |

## 它为什么杀得最少、又最难防

封神里它真正出手的场合极少，且每回都在关键时刻：

- 破云霄三姊妹那一线：**不是斗法，是「这件事到此为止」**；
- 万仙阵收场：它点的是「截教还算不算一个教」。

挨了它的人往往没受伤，只是**从此不在这件事里了**。这是本库对「圣人出手」的一贯处理：圣人不打人，圣人**改结论**。

## 与 [[盘古幡]] 的分工

同一双手上的两件，一件立法、一件定名：

| | [[盘古幡]]（49 道） | 三宝玉如意（40 道） |
|---|---|---|
| 管什么 | 立规矩（往后怎么走） | 定名分（此刻算不算） |
| 失效场合 | 对杀伐类规则无效（规矩管不了判决） | 对已登记的名字无效（册子上的事它改不动，那要 [[阿鼻]]） |
| 使用者困境 | 立了要有人守，故必须择人而授 | 定了要有人认，故必须讲根行 |

两件合起来才是「阐教」这件事的完整形态：**先定名分，再立规矩。** 这也解释了元始为什么在封神里从头到尾都在「说谁该在榜上」，而不是在打。

四件同源，四种脾气——**同一株青莲没有一个部位是用来杀人的**，这一点是本库刻意留的结构。

## 写作约束

1. **不写它打死过谁**（撞上判决类法宝如 [[诛仙四剑]] 时，它退）。
2. **不写它给谁「加福」**——只定名分，不改气运。
3. **不让它点 [[孙悟空]]**：那块余料不在任何册上，点了没有落点（与 [[乾坤圈]] 砸不进是同一类事）。
4. 与 [[太极图]] 的「分」严格区分：太极图是**把一件事分成两件**，玉如意是**把一件两可的事定成一件**。

## 已定（2026-11-15 裁决）

- **U-235**：没点过自己人。阐教内部的事靠盘古幡的规矩办，玉如意只对外——这也是元始「不清理门户」的结构性原因：他手里的东西只能定对外的事。
- **U-236**：指「名、位、誓」三样，即它管的三种东西。不解释成三块玉，避免变成考据。
