# 先天灵兽

> 一句话：与洪荒凶兽同源不同命——凶兽是「跑出来的」，灵兽是「留下来的」。

## 是什么

开天之后自然化生的第一批兽类里，分出去两支：

| | [[洪荒凶兽]] | 先天灵兽 |
|---|---|---|
| 来源 | 混沌魔神逃入天地者，带混沌之气 | 天地自生，无混沌之气 |
| 本性 | 破坏性，见活物就吃 | 中性，不主动攻击 |
| 与势力关系 | 不入编制，谁都不认 | 可被借力、可被托付（但不能被「收编」） |
| 结局 | 被镇压、被驱逐 | 大多融入山河，成为地理的一部分 |

一句话区别：**凶兽是敌人，灵兽是基础设施。**

## 已知成员

- **巨鳌**：[[女娲补天]] 时被断去四足，用来立四极。它没有反抗，也没有死——四足断了之后沉入东海，此后再未现身。
  「巨鳌」不是名字，是**称呼**：没人知道它叫什么，因为没人在它活着的时候和它说过话。

## 写作约束

- 灵兽**不结盟**：可以被求、被借、被托付，但不会「加入」任何势力。一旦写成结盟，它就成了妖族，整条「兽不入编制」的规矩就破了。
- 灵兽**不主动**：它们不推动情节，只在人需要的时候出现一次。写第二次就俗了。
- 巨鳌的「不反抗」要保留——这是全书少数「强者自愿让出身体」的时刻，与巫族的「肉身即一切」正好相反。
