# 六部

> 一句话：**封神榜填的是名字，六部填的是「你每天做什么」。**

## 六部是什么
[[天庭]] 的第三层，六个职能口：**斗部（兵）、雷部（刑）、火部（火）、水部（雨）、太岁部（年运）、财部（赐福与财）**。

上榜的正神三百六十五位，绝大多数落在六部——**榜给的是位置，六部给的是差事**。

| 部 | 管什么 | 典型座次 |
|---|---|---|
| [[斗部]] | 兵、斗、战阵 | 斗姆、星官 | 
| [[雷部]] | 刑、纠察、天雷 | 雷祖、二十四天君 |
| [[火部]] | 火政、焚邪 | 火德星君 |
| [[水部]] | 雨、江河水政 | 水德星君、龙王对口 |
| [[太岁部]] | 年运、岁星、值年 | 值年太岁 |
| [[财部]] | 赐福、财帛、人间利市 | 财帛星君 |

## 内部结构

```
六部：斗（兵）｜雷（罚）｜火（焚）｜水（量）｜太岁（土）｜财（粮）
  └─ 各部只做本职
       └─ 跨部即越权
```

它最像六条流水线，最不像六个衙门：**每部都只回答一个问题**。

## 力从哪来

| 层 | 管什么 | 权力从哪来 | 命门 |
|---|---|---|---|
| 斗部 | 点兵、发令 | 职务 | 位全能战者半 |
| 雷部 | 点名册才动手 | 册 | 不在册就停手回报 |
| 火部 | 按条文焚山 | 条文 | 不在册者不迁 |
| 水部 | 量水、定水则 | 定额 | 查不出就整条河下压 |
| 太岁部 | 只报不改 | 地脉勘验 | 填假数据以免空着 |
| 财部 | 发赈、收回执 | 账 | 只有发出没有到达 |

## 死穴

1. **每部只回答一个问题**。
2. **跨部即越权**：没有一部能替另一部决定。
3. **六部的错法各不相同**，但都来自「只做本职」。

## 编目控制

- **判断依据**：通行说法（六部）＋本库新立（六部的错法各不相同）
- **异说登记**：见 `## 版本差异`
- **最后校订**：第五元会（2026-11-22）

## 三条硬规矩
1. **六部只会按册办事**：他们是死人，不灵活；「灵活」在任何一部都是失职。
2. **六部之间不越界**：水部不能管雷，火部不能管刑；越界要四天师驳回（见 [[四大天师]]）。
3. **六部没有决策权**：决定「该不该下雨」的是星部与册子，六部只负责「下」。

## 为什么六部全立
因为封神榜之后，**天庭唯一能写清楚的就是「谁在哪一部」**。不立六部，三百六十五个名字就全挤在一张表里，神职戏没法写具体。

## 写作约束
1. 六部出场写「办差 / 走流程 / 按册」，不写「神威」。
2. 不许六部联手做大事：它们连开个会都凑不齐。
3. 不许某人「兼管六部」——天庭最忌讳权聚。
