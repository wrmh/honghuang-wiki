# 白龙马

> 一句话：龙族守了三劫不动，他是那条规矩里唯一走出来的一个——而且是**变成马走出来的**。

## 是什么

西海龙王三太子，因纵火烧了殿上明珠被父告忤逆，判死，后为观音所救，化作白马载唐僧西行。

## 三族盟约下的龙族

[[龙族]] 在 [[龙汉初劫]] 立约：守海眼、镇海疆，**不得出**。所以龙族在巫妖、封神两劫里只能看着，不能动。

他这一走，是龙族第一次有成员「离开岗位」——但方式是**变成一匹马**：不是出征，是服役；不是代表龙族，是被人骑。

| | 龙族 | 白龙马 |
|---|---|---|
| 位置 | 钉在海眼 | 走在路上 |
| 身份 | 守约者 | **违约的豁免形式**（服役抵罪） |
| 代价 | 不能出 | 不能以龙身出 |

## 他和龙族的真正关系

他既不是叛徒也不是英雄，他是**龙族处理内部麻烦的方式**：把一个必须死的子弟，交给一个不需要龙族出面的程序。

所以他在队伍里最有分量的时刻不是救人，是**沉默地承载**：一个族群的全部骄傲，压在一匹马上，一步一步走完了八十一难。

## 与孙悟空

[[孙悟空]] 去过龙宫要宝，见过龙族的软；白龙马是本族的硬，只是硬在了忍耐上。两人几乎不对话——一个抢过龙族的东西，一个就是龙族的东西。

## 写作约束

- **不写成坐骑**。他有判断，只是不能说话（设定上化马后不语）。
- **不写龙族复兴**。他成八部天龙，仍不是龙族的政治代表。
- **把「不能以龙身出」当成他的核心痛苦**，不是屈辱。
