# 二十八宿

> 一句话：**它不是二十八个神，是把天切成二十八格的一张排班表。**

## 一、它是什么

周天切成二十八段，一段一「宿」。每段大约十三度，一格一个人。

它解决的问题只有一个：**「今夜的这一片天，归谁看着」。**

星位是**位置**，不是人（见 [[北斗]]、[[紫薇]]）：所以二十八宿里，有的位空着、有的位一个人兼着、有的位换过三四个人，表的形状一直没变。

## 二、为什么是二十八

按月亮走一圈的站数分的：一夜一宿，二十八夜回到原处。

**这不是天文精度，是排班需要。** 于是它有个很人间的好处——**够用就行**：

- 不需要知道每颗星是什么，只需要知道「这一格今夜有人」；
- 不需要精确到度，只需要切得够均匀，好让人轮流值夜；
- 出了差错也不用改表：改的是人，不是格子。

## 三、四象与七宿

二十八格按方位分成四组，各带七格——东、南、西、北，后世叫四象。原文只当分区用，不当神兽用。

| 组 | 格数 | 用途 |
|---|---|---|
| 东 | 7 | 报春、定农时 |
| 南 | 7 | 报夏、定水利 |
| 西 | 7 | 报秋、定收成与兵期 |
| 北 | 7 | 报冬、定丧祭与闭关 |

**二十八宿真正的产出不是「星」，是「时间表」**——所以它挂在 `天庭历法` 的旁边，而不是兵部旁边。

## 四、三条硬规矩

| 规矩 | 破了会怎样 |
|---|---|
| 不是神格：是职位 | 一写成「下凡的星神」，它就变成了人物，排班表就成了封神册，两套东西混了 |
| 空缺照走：位空着，路照样走 | 一停下来等补人，天象就断档，历法立刻对不上 |
| 分野只认地理，不认王朝改名 | 一朝改地名就重排一次，这套表一年换三回，等于没有表 |

## 五、写作约束

1. 写「表」不写「神」：可以写某宿当值的人，不写某宿的「性格」。
2. 一次只点两三个宿，不全列：全列就是抄字典，不是写小说。
3. 不写二十八宿开会、议事、结盟——**位置不会开会**。
4. 空位要照写：写「那一格今夜没有人」，比写「二十八位齐至」更有力。
5. 与 `周天星斗阵` 的关联只写一句：阵要的是 365 个位置，宿只是其中一段分区的说法。

## 六、关系

- 上层：[[紫薇]]（中天主位）、[[星部]]（排班核期）
- 同类：[[北斗]]（七个位置，管方向与时辰）、[[太阳星君]]、[[太阴星君]]
- 用途：`天庭历法`（报时）、分野（地理分段）
- 对照：[[妖族天庭]] 的 365 阵位（血缘编制）→ 天庭接手后改成「分区长」（程序编制）
- 后果：人间农时、水利、兵期都以它为准；**误一宿，误一季**

## 未定稿问题

- [ ] U-558 空着的宿由谁兼？
  - A 相邻宿兼：一个人看两格，表上写一个名字、空一格——所以「兼宿」是常态
  - B 天庭派散仙临时顶：不入册、只顶夜，顶完就走，事后没人记得是谁
  - C 一直空着：反正夜里那一格没人查，值不值得查是另一件事
- [ ] U-559 二十八宿认不认妖族天庭的旧编制？
  - A 认：表没换，只是换了签字的人——旧编制是「阵位」，新编制叫「宿」，同一个格子两个名字
  - B 不认：新表重排过，旧名只作别名，真正的格线是后来划的
  - C 一半认一半不认：旧位照走，旧名不用——用旧名会被当成「还在替妖族当值」
