# 六魂幡

> 一句话：**它不杀人，它把名字写上去，然后摇——摇够了，那个人就没了。**

## 一、档位与来历

| 项 | 值 |
|---|---|
| 品阶 | [[先天灵宝]]（44 道极品） |
| 系列 | 先天 |
| 来历 | 开天后第一次沉降之物；幡面特殊之处在于**它是一层空的东西**，可以被写 |
| 原主 | [[通天教主]]（截教） |
| 现主 | [[佛门]]（封存，从不用） |

## 二、机制：写与摇

| 步骤 | 做什么 | 关键 |
|---|---|---|
| 一 | 写上名字（最多六个） | 写「名字」不写生辰，认的是册上的那一个 |
| 二 | 摇 | 每摇一次，名字对应的那个人就弱一分 |
| 三 | 摇够 | 人消失，且**不留痕迹** |

四个硬约束（否则它会强到没道理）：

1. **只能写六个**：不是六个一批，是**总共六个位置，写满即止**。
2. **必须是「册上有名」的人**：写不进无相魔神，也写不进没被任何册子记过的人（与 [[阿鼻]] 正相反——阿鼻划掉已有的名字，六魂幡把名字写进它自己）。
3. **摇的人必须知道那个人是谁**：不能只凭一个称谓写。
4. **摇的过程会被察觉**：被写的人会「一天比一天轻」，不是无声无息（对照 [[钉头七箭书]] 的完全无声）。

## 三、它与其它「名字类」法宝的分工

| 法宝 | 对名字做什么 | 结果 |
|---|---|---|
| [[封神榜]] | 收进去 | 有位置，永远在册 |
| [[阿鼻]] | 划掉 | 人活着，册上没有他 |
| [[无相面]] | 从来没写上 | 任何册子都记不到 |
| **六魂幡** | **写进它自己** | 写满即杀，且不留痕 |

四件合起来，是这本书「名字」这条线的全部机制。

## 四、封神里最险的一次

通天在万仙阵之前把六魂幡交给 [[长耳定光仙]] 保管，幡上写的是对方六位最关键的人。

**他没用上。** 因为长耳定光仙在最后一刻把幡带走了（见 [[长耳定光仙]]）：

> 带走比使用更狠——**用一次只是杀六个人；带走，等于这六个位置从此永远悬着。**

这也是本书对「截教之败」最重要的一次处理：**它不是输在打不过，是输在「有人提前算清了结局」。**

## 五、后来

幡随长耳入西方，佛门把它封了，从不用。

**佛门收它不是为了用，是为了不让别人用。** 这与 [[接引]] 的算法一致：收一件东西的成本，低于防它一百次的成本。

## 六、写作约束

1. **不许它真的摇过六次**：全书最多写到「摇到第三下」。
2. **不许它写圣人**：圣人不在这套「被写」的层级上（写了也摇不动）。
3. **不许佛门用它**：封存就是封存。
4. 出场只写「幡上有几个字」「他摇了一下」「那个人今天比昨天轻」。

## 已定（2026-11-15 裁决）

- **U-384**：一个都不是真人：通天写的是「位置」不是「人」——所以就算摇了也未必生效。这让摇幡在伦理上变轻，在效果上变虚。
- **U-385**：没有：封得很紧，连燃灯都不碰。佛门收它只为一个用处——不让别人用。
