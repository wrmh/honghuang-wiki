# 瑶池

> 一句话：**它不是天庭的后花园，是天庭唯一一块「不办公」的地方——所以所有不好在朝会上说的话，都在这里说。**

## 一、它是什么

天上的一处水，一圈园子。水不深，园不大，绕一圈不到半个时辰。

它不在 [[三十三天]] 的衙门序列里：`册府` 在这儿没有窗口，`星部` 不在这儿排班，`南天门` 的凭信在这儿不作数——**进来要的是邀，不是信。**

名义上归 `瑶池金母`。实际上的规矩是：**她不说「请」，谁也不能来；她说了「请」，谁都可以来。**

## 二、为什么它必须在

天庭只分配三样东西：位置、日子、名分。这三样都只能**在朝会上**给，而朝会上说的话，每一句都要入档。

于是天庭有一个结构性的问题：**有些话不能入档。**

- 试探（「你近来如何」其实是「你还站得住吗」）
- 让步（说出口就等于把让步写进册子）
- 托付（一旦入档，受托的人就有了责任，也就有了把柄）

瑶池就是为这三类话准备的：**在这里说的话不入档，因为这里本来就不是办公的地方。**

## 三、蟠桃会

蟠桃会不是宴席，是一次**公开的清点**：

| 层面 | 表面 | 实际 |
| --- | --- | --- |
| 为什么办 | 请各路仙家吃桃 | 一年一度看谁来了、谁没来、谁替谁来了 |
| 席位怎么排 | 按修为、按辈分 | 按**还在不在**——位次可以不动，人可以不在了 |
| 桃子的作用 | 延寿、增修为 | 一个由头：**没有由头，就没人会来** |

所以蟠桃会最要紧的信息不在席上，在**名册与到场名单的差**。这个差，天庭从来不解释；来的人也不问。

## 四、三条硬规矩

| 规矩 | 破了会怎样 |
| --- | --- |
| 进来靠邀，不靠凭信 | 一旦凭信能进，这里就成了第二个南天门，「不入档的话」就无处可说了 |
| 在这里说的话不入档：出了园子就不认 | 一旦入档，试探变成立誓，让步变成条款，托付变成把柄 |
| 水与园都小：装不下太多人 | 一旦能装下所有人，它就成了朝会的分会场 |

第三条是刻意的：**小，是它还能「不入档」的物理前提。**

## 五、写作约束

1. 不写仙气缭绕、不写琼楼玉宇：**写「不大」「不深」「一轮照旧」**，越平常越好。
2. 不写在这里动手：这块地一旦能打，就再也不是「不办公的地方」。
3. 这里的话只写「试探、让步、托付」三类，别写闲谈——闲谈在这儿是浪费，也不像天庭。
4. 蟠桃会要写成**点名**，不写成热闹：热闹是给人看的，点名是给册子看的。
5. 不写 `瑶池金母` 在这里办公、批条子、见客排队——**她在这里只做一件事：决定请不请**。

## 六、关系

- [ ] U-550 蟠桃会请不请「没有位置」的人？
  - A 请：正因为没有位置才要请——请来坐着，比给位置便宜，也更容易收回
  - B 不请：席位就是位置的一种，没有位置就没有席位，所以名单永远比到场短
  - C 请，但不入席：给个偏座、不给名分，来的人自己知道那是什么意思
- [ ] U-551 「在这里说的话不入档」是谁定的？
  - A 昊天定的：他需要一块不入档的地方，否则天庭只有一种说话方式
  - B 瑶池金母定的：她只肯在自己的地方见人，条件就是不记账
  - C 没人定：天庭立起来之前这块地就在，它是**留下来的**，不是被规定的
