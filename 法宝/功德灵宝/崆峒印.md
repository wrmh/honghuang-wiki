# 崆峒印

> 一句话：**它不封神，它"承认"——盖上这方印，一件事就算被立成了规矩。**
> 全书唯一一件靠「教」而不是靠「造」或「杀」攒出功德的法宝。

## 一、档位

| 项 | 值 |
|---|---|
| 品阶 | [[功德灵宝]]（45 道） |
| 系列 | 后天 |
| 功德来源 | 教化：把人族从"能活"教到"知道怎么一起活" |
| 现主 | [[人族]] |

为什么只有 45 道：教化的功德**最慢、最散、最难算清**。它不是一件"事件"，是几百年里一笔一笔攒起来的——天道对这种账最不耐烦，给的分也就最少。

## 二、印盖下去会发生什么

| 盖在 | 效果 | 边界 |
|---|---|---|
| 一部族约 | 从此这部约**算数**（相当于人族内部的"成文法生效"） | 只对人族有效 |
| 一份册籍 | 册上之名被承认为"人"（不是"某族的余脉"） | 不能改天道册子（见 [[封神榜]]、[[生死簿]]） |
| 一道命令 | 命令获得"正当性"，执行者不算僭越 | 不能强人所不能 |

**它给的是"承认"，不是"权力"。** 这一点与[[三宝玉如意]]（定名分）很像，区别是：如意定的是**诸天**的名分，崆峒印定的只是**人族内部**的规矩。

## 三、它与三皇那条线

- [[伏羲]] 给了人族"能算"（见 [[河图洛书]]）；
- [[神农]] 给了人族"能吃"；
- [[轩辕]] 给了人族"能一起活"——**崆峒印是这一段的实物**。

所以它更像"人族的公章"：谁拿着它，谁就能替人族立规矩。这也是它后来不断被抢的原因——**它不是武器，它是合法性**。

## 四、写作约束

1. **不写它能号令诸天**：它连天庭的册子都动不了。
2. **不写它一盖就灵**：盖印之前得先"有人认"，没人认的印只是块石头。
3. **不写它择主**：它认的是"人族共主"这个身份，不认具体某个人。
4. 出场只写"按印/朱痕"，不写宝光。

## 关系

- 造/用者：[[轩辕]] 一脉；现主：[[人族]]
- 同档：[[轮回镜]]、[[定海神针]]、[[九州鼎]]
- 对照：[[三宝玉如意]]（定诸天名分）、[[封神榜]]（天道册子）

## 已定（2026-11-15 裁决）

- **U-306（在谁手里）**：**随[[轩辕]]入葬、封存**。此后人族立规矩不再需要实物——所以后世「得印者正」是一场空谈：印早就不在了，谁都在拿一个不存在的东西给自己正名。
- **U-307（与九鼎是不是一套）**：**曾经是一套**（印立法、鼎划地），后来被人为拆开，正是为了防止一家独大。拆它的人是谁，见未定稿。
