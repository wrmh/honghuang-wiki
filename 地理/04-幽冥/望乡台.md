# 望乡台

> 一句话：**它不是让人怀旧的地方，是让「还在看着」这件事有个了结的地方——全书唯一允许回头的地方，回头的资格却只有一次。**

## 一、它是什么

奈何桥之后、三生石与轮回台之间的一处高台。不高，走十几步就上去了；台上没有栏杆，没有碑，没有灯。

它只办一件事：**站上去，往阳间看一眼。**

看完下来，册上多一行——「某年某月某日，曾看」。这一行不进份例、不进差事、不进审判，从第一次被写上去之后，就再没有判官读它。

## 二、为什么必须是「规定动作」

黄泉路上可以回头，但走不快——那是**忍不住**。

望乡台上回头，是**规定动作**：上来就是为了看，看完就算做完了。

两者差在账上：

| | 黄泉路上回头 | 望乡台上回头 |
| --- | --- | --- |
| 性质 | 忍不住，越看越慢 | 手续，看完即了 |
| 记法 | 不记（判官只问走完没有） | 记一行「曾看」，此后无人再读 |
| 后果 | 到第一殿时答不出话 | 下台时反而答得出话 |

**这条路要把「回去」耗掉；这个台要把「还在看着」做掉。** 两件事不同：前者是念头，后者是一个动作——念头耗不掉，动作可以做完。

## 三、看的是什么

看的是**此刻**的阳间，不是回忆。

台上看见的东西是活的：屋里的灯还亮着、田里的水还在流、有人在你走了之后还在替你说话。也会有看不见的：有的家已经搬空了，有的院子长满了草——**台不保证那边还有什么，它只保证你看得见此刻那边的样子**。

所以台上最常见的反应不是哭，是**站一会儿，然后下来**。

## 四、三条硬规矩

| 规矩 | 破了会怎样 |
| --- | --- |
| 只看一次：上去了就那一次，下来不能重上 | 重上过一次的先例没有——没人试过，因为没人愿在同一个地方待第二次 |
| 只能看，带不走任何东西——连一句话都带不走 | 想带的人下台后说不出话：不是罚，是他自己知道那句带不出去 |
| 只能看阳间，看不见幽冥、看不见轮回台、看不见后面 | 能看见的只有活着的那一侧；**往后不在这个台上** |

第三条尤其要守住：望乡台**不是**一个能看见命运的台，它只是朝着人间开的一个口子。

## 五、写作约束

1. 不写台上有人哭天抢地、不写有人扑倒在地——**这里不演悲剧，只办一道手续**。
2. 台上不写旁观者：后面排队的人看不见别人看见的东西，只看见那个人站着。
3. 不写「他看见家里出了事，于是不肯走」——**看了也不能回去**，这一条不能破。
4. 台上看见的画面只给细节，不给叙事：给「碗没有收」「门开着半边」，不给「他儿子后来怎样」。
5. 不给「再望一次」的例外：全书只允许回头，不允许回头两次。

## 已定（2026-11-18 裁决）

- **U-536** 台上的「此刻」是跟着时辰走的，还是冻在那个人走的那一刻？ → 跟着时辰走：看见的是此刻正在发生的阳间。所以有人正好看见自己家里在办丧事，看完下台一句话不说——**看见的不是回忆，是错过**。

- **U-537** 有没有人上过台之后不肯下来？ → 从来没有。看得越久越明白回不去，自己会下来——这个台不需要人清场，它靠的是「看清楚」本身。
