# 大闹天宫

> 一句话：**点着整座天宫的不是棍子，是「没被请」——名单上没有它，而它刚刚才被告知「你也是有位子的人」。**

## 事件要素

### 一、时间
封神之后约七百二十年，秋。从蟠桃会前一日到被压山下，前后不足一月。

### 二、地点
蟠桃园 → 瑶池（[[瑶池]]·蟠桃会）→ 兜率宫 → 花果山 → 天宫诸门 → 凌霄宝殿外 → 灵山（赌赛）→ 五行山。

### 三、主体
发起方：孙悟空。承受方：天庭（[[斗部点兵]]、[[雷部巡检]]、[[太上老君]]、[[杨戬]]）。见证方：佛门（[[观音]] 在场，只在看）。

### 四、事由
蟠桃会的请帖按册发。齐天大圣府的位子在册上，蟠桃会的名单上没有——**它有位，却没有份**。它问七仙女「请的是谁」，听完就定住了。

### 五、经过
六步。**一、未受邀**：定住七仙女，先去瑶池，路上把蟠桃吃了几个——不是饿，是「你们不给我，我自己拿」。**二、偷丹**：醉入兜率宫，把 [[太上老君]] 的五壶金丹吃了，**这一条后来最要命**（丹是给谁炼的，账上有数）。**三、反下**：回花果山立旗，自称齐天大圣。**六位结义兄弟一个都没来**——不是不讲义气，是他们各自的册上都没有「援助齐天大圣」这一项（见 [[孙悟空]]「花果山结义的另外六位」）。**四、用兵**：[[斗部点兵]] 点十万天兵（李靖、哪吒），输了——不是打不过，是**它的位没有、所以没有阵可破**。**五、二郎**：调 [[杨戬]]。他「听调不听宣」，这次调他，他来了；斗变化、照妖、细犬咬腿，擒住。**六、斩与炼**：斩妖台刀砍雷劈火烧，一概不伤；[[太上老君]] 请入八卦炉，四十九日，它在巽位躲火、被烟熏出火眼金睛，出炉时踢倒丹炉，一路打到凌霄宝殿外，被灵官殿前的执事挡下——**天宫第一次需要「挡」，而不是「拿」。**

### 六、结果
天宫被打坏多处（含斗牛宫），天庭颜面尽失；猴被擒，但**杀不掉**——刀砍、雷劈、火烧，全部无效。最后不是天庭解决的，是**请佛来收**。

### 七、影响
短期：补门禁、补验凭信、加值房（[[南天门]] 三道验）。长期：天庭明白「不在册的强者无法用刑罚处理」——**账上没有对应的格子，罚不下去**。连锁：佛门由此获得一个入场资格：不是帮忙，是**替三界处理了一件天庭处理不了的事**。

### 八、史料备注
原书顺序：蟠桃会未请 → 偷桃偷丹 → 反下天宫 → 天兵征讨 → 二郎擒拿 → 斩妖台 → 八卦炉 → 大闹凌霄 → 请佛 → 压山，本库沿用。「太上老君以金刚琢打中其头」采信，[[金刚琢]] 本书归老君，不归他人。「四十九日」采信。

### 九、定性
灾异（天宫之乱）＋战争（天庭首次对内用兵）。

### 十、关联
前接 [[天庭招安]]；后继 [[五行山镇押]]；并行 [[斗部点兵]]（「位全，能战者半」在这次第一次被验证）；对照 [[封神量劫]]——那一次是分位子，这一次是「位子给了却没给份」。
