# 洪荒凶兽

> 一句话：魔神的一批「没被删干净」的残余——不是输家，是碎片。

## 是什么
[[混沌魔神]] 里**逃入天地、未能成形的部分**（裁决 2026-11-13 单独立条）。

与魔神的分野必须写清：

| | 混沌魔神 | 洪荒凶兽 |
|---|---|---|
| 是 | 开天之前的存在 | 没被删干净、活到开天之后的部分 |
| 有没有主张 | 有：拒绝被排序 | 没有：只想活下去并吃 |
| 有没有组织 | 名义上三千同族，各自为政 | 无，个体汇聚 |
| 为什么会输 | 秩序一旦成立，他们的存在条件就没了 | 从未被认真清剿过 |

混在一条里写，读者会以为「魔神打赢过、留下一支军队」。事实相反：**凶兽不是继承者，是残渣**。

## 沿革

| 时间 | 变了什么 | 为什么变 |
|---|---|---|
| 第一元会 | 凶兽初荡 | 被赶进来的，不是自己长出来的 |
| 第一元会末 | 清剿与地名 | 清完之后才有地名 |
| 第三元会 | 妖庭散后一部分凶兽重出 | 地区发灰，山开始「硬」 |

## 内部结构

```
凶兽（不入族、不入册、不认主）
  └─ 被赶进边缘地带
       └─ 与先天灵兽的区别：一个被赶，一个自己长出
```

它最像一群被赶出去的住客，最不像一群敌人：**它们不是坏的，是没被记的**。

## 力从哪来

| 层 | 管什么 | 权力从哪来 | 命门 |
|---|---|---|---|
| 凶兽 | 占据边缘 | 自身 | 不入册，故无谈判资格 |
| 清剿 | 赶、封 | 天庭与巫族 | 清完即不再提 |
| 边缘地带 | 容纳 | 无人管 | 越清越往外 |

## 死穴

1. **凶兽是被赶进来的，灵兽是自己长出来的**。
2. **不入册，故无谈判资格**。
3. **越清越往外**，边缘地带因此越来越大。

## 主要几支
本书点名三支（其余概称「群兽」）：

- **无相之裔**：[[无相魔神]] 的后身。不肯成形，所以至今没有确定形体——**看得见的是它此刻披的那张皮**。
- **饕餮一脉**：吞噬型，无上限也无底限；越吃越像兽、越吃越不像自己。它与人族的「贪」在词源上会撞上，封神劫之后可作人族内部寓言的来源。
- **混沌之种**：形如浑圆的囊袋，无耳目，行止最慢，是唯一能被巫族当作「东西」而非「对手」的存在。

## 与两族的关系
- **巫族**：视其为荒地里的虫豸，能杀则杀，从不作为战略对象。这也解释了巫族为什么从未建立边疆——**他们的法理不容许承认「有不需要处理的邻居」**。
- **妖族**：部分凶兽被妖族收作镇守或坐骑，但从不入编制。[[周天星斗大阵]] 的 365 个位置从未为凶兽留过一格。
- **人族**：人族出现之后，凶兽才第一次成为「必须被处理的事」——不是威胁升级了，而是终于有人弱小到会怕它们。封神、西游里的诸多妖魔，正脉多可追到此处。

## 为什么它们一直没被清剿
因为它们**不值得被记账**。[[天道]] 的结算是按因果走的，凶兽造成的死亡常常查不到「因」——它吃完就走，不留痕迹，也不承担任何气运。一套只处理「有主张的存在」的秩序，对「无主张的残余」天然失效。

这是本书给「混沌」留的最后一个位置：不是敌人，是**秩序管不到的那部分世界**。

## 不入编制（已定）
凶兽**不能被任何势力真正收编**。不是不想，是收不了：

- 它们没有「归属」这个概念，认地不认主；
- 收编需要给编制、给号令、给赏罚，而凶兽只对「谁更强」有反应；
- 一旦被编进军队，它们的第一反应是把同袍吃掉。

所以洪荒所有势力对凶兽的做法只有三种：**赶走、杀掉、绕着走**。没有第四种。

这也让人族「驱逐凶兽」这件事分量变重了：那不是打赢一场仗，是把一整类存在从「可以共处」变成「只能隔离」——**人族干的是一件没人干成过的事**。
