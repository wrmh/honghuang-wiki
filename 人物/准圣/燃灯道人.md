# 燃灯道人

> 一句话：他是全书最会**等**的人——三教都在赌这一劫谁赢，只有他在赌「这一劫之后谁还需要人」。

## 是什么

阐教元老，辈分极高但不在三清直系里。在 [[封神量劫]] 里他出手不少，位置却始终模糊：**不是教主，不是弟子，是「客卿」。**

| 他有 | 他没有 |
|---|---|
| 极老的资历，谁都得客气 | 一个真正属于自己的位置 |
| 一双看得准的眼 | 一支能听他的话的队伍 |
| 一件给出去的东西（[[天地玄黄玲珑宝塔|玲珑宝塔]] 赐 [[李靖]]） | 一件自己真正的底牌 |

## 「等」这个字

本库把燃灯写成封神里唯一一个**不以胜负为目标**的参与者。他的算法很简单：

> 阐教赢，他是元老；阐教输，他还有别的门可进。

所以他从不下死手、从不押全部、从不把自己摆到「必须赢」的位置上。这不是怯，是**清醒**——他早就看明白：这一劫里所有人争的是「位置」，而位置是可换的，**只有活人能换位置。**

## 后来：他去了西方

封神之后他入了佛门，称燃灯古佛。

本库不写成「背叛」，写成一次**结算后的换场**：

| 阶段 | 他的身份 |
|---|---|
| 封神前 | 阐教客卿：有资历、无基业 |
| 封神中 | 出手但不站死：赢的那边需要有老人撑场 |
| 封神后 | 佛门过去佛：**位置终于只属于他自己** |

与 [[接引]] 的「先赊后还」、[[准提]] 的「出去找」并排看，燃灯走的是第三条路：**带着资历过去，换一个不需要打仗的位置。**

## 与 [[李靖]] 的关系

他赐 [[天地玄黄玲珑宝塔|玲珑宝塔]] 给李靖，是全书一处很小的伏笔：

> 一个没有自己位置的人，最懂「位置」值多少——所以他给的不是法宝，是**一个父亲最后的权威凭证**。

李靖此后一辈子靠那座塔说话。塔在，他就是父亲；塔不在，他什么都不是。（见 [[李靖]]）

## 关系

- [[元始天尊]]：同门不同系。元始用他，但从不把他算进「自己人」。
- [[赵公明]]：封神里正面打过，输赢各有说法；本库不写他夺定海珠（见 [[定海珠]]）。
- [[接引]]、[[准提]]：他后来的同僚。三人关系极冷——**一个是接收方，一个是找人的，一个是自己走过来的。**
- [[李靖]]：受他一件东西，此后一生被这件东西定义。
- [[过去七佛]]：**他不在七佛里**。七佛管旧账，他管授记——「七佛是七本旧账，燃灯是给下一本账写封面的那个」。

## 版本差异

| 说法 | 内容 | 本书 |
|---|---|---|
| A | 燃灯本是燃灯古佛，来阐教是「借住」 | 不采用：他后来过去的，不是先来的 |
| B | 他在封神里被赵公明打得没法还手 | 部分采用：确实吃过亏，但本库写成「他不肯拼」 |
| C | 他夺了赵公明的定海珠 | 不采用：与 [[定海珠]] 的流转裁决冲突 |

## 写作约束

1. **不写他背叛阐教**：他没有背叛，他只是**换了一个不再需要打仗的地方**。
2. **不写他谋算全局**：他是看准了才动，不是布了局。
3. 他的台词温和、留有余地——**一个从不把话说死的人**。
4. 不让他出现在 [[西游量劫]] 主线里，最多一句「过去佛不管现在的事」。

## 已定（2026-11-15 裁决）

- **U-261**：封神之后才决定的。他看见阐教赢了却也没有他的位置，才走的——不是早有预谋，是结算之后才发现自己不在任何一份名单上。
- **U-262**：没有。一前一后隔着几百年，两个从东方过去的人从未照面。
