# 四海龙王

> 一句话：不是四个王，是**四份岗位说明书**。

## 它们是什么

[[龙族]] 在龙汉之后退居四海，祖龙是共主，四海分封而治。分封的结果不是四个小朝廷，是四个位置：

| 位次 | 海 | 王 | 这个位置真正负责的事 |
|---|---|---|---|
| 第一 | [[东海]] | 敖广 | 祖庭、海眼，以及「祖龙还在」这件事本身 |
| 第二 | [[西海]] | 敖闰 | 行雨核得最严的一段，与族内最不能出事的一支 |
| 第三 | [[南海]] | 敖钦 | 与落伽山（`观音`）交涉，管文书 |
| 第四 | [[北海]] | 敖顺 | 名义上的王，由天庭指定，人多半常驻东海 |

位次按**谁最不能出事**排，不按海的大小排（见 `西海`）。

## 为什么是「岗位说明书」不是「王位」

- 四王之间**没有上下级**。东海是祖庭，但东海龙王不能给西海下命令；一件事要四海一起办，只能靠「祭海的先后」这种软规矩。
- 他们也不能改自己的位置：能做什么、能走多远、能收多少雨，全在盟约与定额里写着（见 [[三族盟约]]、[[行雨体系]]）。
- 所以龙族的王更像「守门的人」：**权力是"不许出去"的范围，不是"能管什么"的范围。**

## 一次典型的四海公文

西海核出雨数不对 → 报东海 → 东海转南海（南海有文书之能，要写成能过两套册子的样子）→ 南海起草 → 回报东海 → 东海以祖庭名义发往天庭。

一件在西海发生的事，走完四家，走的不是权力链，是**手续链**：每转一手，多一道存档，就少一次被追问。

## 写作约束

1. 写四王一律写「他们怎么把一件事做成一纸文书」，不写调兵。
2. 四王彼此客气，客气到底下是「谁也不想先开口」。
3. 敖顺（北海）几乎不出场：他的出场方式通常是「册上写了，人不在」。
4. 不要写「龙王震怒」。龙族震怒的方式是把账做平。

- [ ] U-503 东海龙王敖广与祖龙是同一个人吗？
  - A 是：祖龙在海眼养伤，对外仍称东海龙王，位子与人是同一个
  - B 不是：祖龙是共主，敖广是代管东海的人，祖龙一旦现身，东海要还位
  - C 说不清：龙族内部两种说法都有，看谁在说
- [ ] U-504 王位怎么传？
  - A 血统：父死子继，西海三太子案正是「本该继位的人被交出去」
  - B 祖龙指定：四王每元会到东海一次，位子由祖龙一句话定
  - C 不传：位置一直空着，由族老轮流值守，谁也不正式坐上去
