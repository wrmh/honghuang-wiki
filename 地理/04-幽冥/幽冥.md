# 幽冥

> 一句话：洪荒所有东西最终都往下走，**幽冥就是「下」的尽头**。它原本只是一个空腔，直到 [[后土]] 把自己填了进去。

## 它是什么

洪荒地下最深处的一层空腔，位于大陆之下、九幽之底。开天时它是「分离」留下的剩余空间——天地分开，中间那层被挤出去的气与渣往下沉，沉到底就是九幽。

开天之后很长一段时间里，**幽冥是死的**：有死气，没有秩序。亡魂往这里来，不来也不影响什么，因为那时候死者不进账。

## 三段与十二站

幽冥的地理是**一条从浅到深的线**，深浅＝可选择的多寡。整条线上有十二个点，每个点只解决一件事（流程见 [[地府]] 第五节）：

| 段 | 站点（由浅到深） | 这一段在做什么 |
|---|---|---|
| **上段｜入口** | 鬼门关 → 黄泉路 → 枉死城 | 收进来，分辨"该不该现在办" |
| **中段｜城与审** | 酆都城（十殿驻地）→ 孽镜台 → 十八层地狱 | 把账记在哪一类、要不要先清 |
| **下段｜过渡与出口** | 忘川河 → 奈何桥 → 孟婆亭 → 三生石 → 望乡台 → 六道轮回台 | 减掉前尘、最后一次回头、然后出去 |

**为什么是这个顺序**：越往下，亡魂能用来讨价还价的东西越少。到轮回台时已经什么都不剩了——**幽冥不是靠暴力让人服从，是靠流程。**

几个点的地理细节：

| 站点 | 位置与形态 |
|---|---|
| 鬼门关 | 阴阳分界，一道关不是一扇门；过了它才归册子管 |
| 黄泉路 | 一条自地脉渗下的暗河旁的旱路，沿途生彼岸花 |
| 枉死城 | 黄泉路尽头偏侧的一座城，收「账没结清」的，**暂不审判** |
| 酆都城 | 幽冥主城，十殿驻地；不是宫殿，是**十张桌子十本册子** |
| 孽镜台 | 城中一侧的台，照一生善恶；它不判，只让人自己看见 |
| 十八层地狱 | 城下，分层向下；在十殿辖下但独立于轮回之外 |
| 忘川河 | 中段一条**弱水**，河水锁魂；岸上立三生石，记三世因果 |
| 奈何桥 | 跨忘川，分三层（善上／善恶中／恶下）；桥上另有孟婆亭 |
| 望乡台 | 桥后一处高台，最后一次眺望阳间，**全书唯一允许回头的地方** |
| 轮回台 | 最深处，六道入口，后土所化，**不说话的裁判** |

再往侧边是**血海**：一片红色的、不上不下的海，冥河老祖的地盘。血海与轮回台的关系是本书刻意留的一条缝——**轮回管「该去哪」，血海管「不想去哪」**。不愿入轮回的，沉进血海。

## 一条例外的道口：阿修罗道

六道的道口都在轮回台上，只有**阿修罗道**的道口在**血海侧**（见 [[六道轮回]]）。

这条缝的作用：

1. 冥河因此**不需要跟任何人换**——他有一条自己的道口，所以他能全书不站队（见 [[冥河]]）；
2. 「不入轮回者」有了去处，而它**不在天道直辖的那张表上**；
3. 地府也知道这件事，但管不了——**因为它不在幽冥的册子里，它在血海里。**

## 谁在维持边界：酆都大帝

[[六道轮回]] 是**概念存在，没有实体**——它不是一个能走进去的地方，是一套规则。真正的「地方」是幽冥，而幽冥的秩序由**阴曹地府**维持，出面的是**酆都大帝**。

所以边界这件事要分层说清楚：

| 层 | 归谁 | 管什么 |
|---|---|---|
| 轮回（规则） | [[天道]] | 转不转、通不通 |
| 幽冥（地方） | 阴曹地府 / 酆都大帝 | 谁进哪一道、谁在门口闹事 |
| 血海（侧翼） | [[冥河]] | 他自己那一摊，不入账 |

酆都大帝的位置因此很微妙：他不是最强的，但他是**唯一有权在幽冥里说「不」的**。冥河守血海、天道管规则，中间那块「人间的账要在这儿落笔」的地方，是他管。

写作上：**不要写后土在幽冥办公**。她在轮子里，不在衙门里。

## 它为什么是「天地账本」

[[六道轮回]] 立起来之前，洪荒只有「生」这一个方向：活着的人争气运，死了就是没了，死者的气运直接消散回天地。

轮回立起来之后，死者的气运动会**回来**：入轮回、转世、重新进账。所以幽冥不是慈善设施，是**结算系统**——它让「欠的」有地方记，「还的」有路径走。

这也是巫族真正的死因（见 [[巫族]]）：他们主张的是血统合法性，而轮回把合法性换成了功德。**巫族不是被打败的，是他们那套道理过期了。**

## 归属：为什么归天道

后土以身化轮回，但她化进去的只是「身」，轮回的**规则**归属天道。所以：

- 天道管规则（谁能进哪一道、什么时候清算）
- 后土管执行（她判，但不说话、不改规则）
- 任何势力都**不能占有**幽冥——鸿钧不能，天庭不能，佛门也不能

这条是硬约束：一旦有人能占有幽冥，就等于能改生死，量劫立刻失去意义。

## 与其他地理的关系

- [[不周山]]：不周山接地，折了之后地面塌陷，九幽的入口从「一处」变成「多处」——这是后世「地府有多个入口」的物理来源
- [[东海]]：不相通，但性质互为镜像（两个「进得去出不来」的地方）
- [[域外]]：**不通**。域外是天道管不到的地方，幽冥恰恰是天道管得最死的地方
- [[三十三天]]：上下两极。天上管「谁在上面」，地下管「谁回得来」
