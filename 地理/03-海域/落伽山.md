# 落伽山

> 一句话：它不是一个道场，是**一个收件地址**。

## 它是什么

南海东部一座小岛。山不高，没有灵脉，没有矿，没有洞府——岛上只有三间屋、一片竹、一口井，和一条从滩头上来的石阶。

按灵气的标准衡量，这是四海里最不值钱的一块地。`南海` 里比它肥的礁有几百处。

## 为什么它不是道场

[[观音]] 一年在这里待不满一个月（U-427 已定）。她本来就没有固定的地方——`灵山` 是治所，落伽山不是。

所以「岛是真的，常住是假的」。真要按道场的标准算，这里连门都没有：没有山门、没有知客、没有护法。

## 它真正的作用：收信

洪荒所有要送到观音手上的东西——求告、文书、一支香、一句传话——都往这座岛上送。

原因很朴素：**她本来没有地址，可总得有一个地址。** 神佛与人之间的距离，最后落成一个具体的门牌。

收信的不是修行人，是一个凡人的老妇。她不懂经文，也不问来处，做的事只有一件：**把送来的东西放进屋里，告诉他「送到了」。**

| | 一般道场 | 落伽山 |
|---|---|---|
| 收什么 | 香火、供奉、弟子 | **信** |
| 谁在 | 门人、护法 | 一户凡人 |
| 有没有回音 | 有（显灵） | **基本没有** |
| 归谁管 | 本门 | 龙族送补给，佛门不认领 |

## 龙族在这里唯一的一笔支出

岛不在龙族册上（见 `南海`），但龙族每年往岛上送一次补给——米、盐、灯油。

理由不是慈悲，是账：**「免得岛上没人，信就落进海里。」** 一封信落海，此后就要有人来解释它为什么没送到。

所以这是龙族在南海北部唯一一笔不算亏的支出：一年一次船，换一年不用解释。

## 写作约束

1. 不写观音在岛上显灵。她可以来，但不在这里办事——办事在`灵山`，在路上，在别人家里。
2. 不写宝殿、法会、香火鼎盛。这里一旦热闹起来，「没有固定地方」这条设定就塌了。
3. 写落伽山一律用三个动词：**送到、收到、没有回音**。
4. 岛上那户人家不修行、不求什么，也不因此得道——他们的作用是让「送到」这件事有个落点。

### 收信的人是偶然的（U-505 C）

没人安排。第一户人家在岛上住下就没走——之前岛上没人，之后也没人赶。

于是落伽山从「一块石头」变成「一个地址」，中间**没有一步是设计出来的**：观音开始往这儿送东西，是因为这儿已经有人收；那户人家还在，是因为观音还在送。

这件事在整个设定里的位置：观音是洪荒第一个**有固定投递点**的神。不是因为佛门建了道场，是因为一个凡人在一个错误的地方住对了。

写作约束：这户人家不知道自己为什么会在这儿；不写「命定」「有缘」。

### 信收着，从不打开（U-506 A）

一箱箱码在屋里，从进门那一箱到最新那一箱，**一封都没开过**。

不是不敬，是权限：开封等于处置，处置要先回答「谁有权代她处置」。岛上没有这个人。所以箱子只会越来越多，屋子一直在加。

于是岛上真正在长的是屋子。屋子比信重要——汛期先垫箱子，再垫屋顶。

与 [[授记]]「菩萨没有开口权」互为表里：她连自己的信都不能拆，因为要拆，就得先替一个还没到的结果说话。

写作约束：不写信的内容。这屋里所有信都可以是任何东西，写出来就窄了。

### 一次都没有（U-507 B）

「有人等到了」这件事，**一次也没发生过。**

不是因为她不回应，是因为回应从不落在这一点上：求的东西若成了，成在别处（一场雨、一个人活下来、一件事没发生），没人会把它归到这座岛上；若不成——那就是没等到。

所以岛上老妇的工作天然没有结果。她的存在不是为了让谁等到，是为了让「送到」这件事本身有一个落点。

一句可以用的写法：「**她一生都在替一个人说『送到了』，从没替任何人说『他来了』。**」

与 [[不在册]] 呼应：她不在任何一本册上——不在龙族册、不在佛门册、不在天庭册。所以她能收；也正因如此，她永远等不到一个能回报她的东西。
