# 七宝妙树

> 一句话：它不砍不砸，只做一件事——**刷**。刷一下，你先前的那个「样子」就没了。

## 是什么

[[先天灵宝]]，44 道极品。由 [[混沌青莲]] 最大的一片莲瓣所化，现主 [[准提]]。

它是全书唯一一件**下手对象不是人、而是「人身上的构成」**的法宝：

| 被刷的东西 | 结果 |
|---|---|
| 兵器、法宝 | 从手里脱出去（不是被夺，是「不再在手里」） |
| 五色神光这类**天生的**神通 | 光散，人现形 |
| 借来的加持、护体法门 | 一层一层被揭掉，像剥 |
| 已经成形的躯体 | **不散，只是不再是那个形状** |

所以它刷不「死」人——它刷的是**资格**。挨过它的人多半还活着，只是从此不再是自己那个样子。

## 为什么它专克「天生」的东西

这一条接 [[先天灵宝]] 的分档逻辑：**先天之物都是「本来如此」，没有来路可查。** 而青莲是洪荒一切「本来如此」的源头之一（见 [[混沌青莲]] 解体谱）。

同一个源出来的东西，对同源之物有天然的支配关系：

> 树知道瓣该怎么长，所以也能让它不这么长。

这也是它刷得动 [[孔宣]] 的五色神光、却刷不动 [[诛仙四剑]] 的原因：四剑是**判决**，不是「构成」——它没有「原样」可以被改回去。

## 与准提的关系

[[准提]] 手里能用的东西不多。西方贫瘠，没有粮、没有地、没有编制，**只有一张嘴和这件树**。

分工极清楚：

- 接引负责「接」——把账接到西方；
- 准提负责「找」——出去把人找回来；
- 七宝妙树负责「剥」——**先把人身上那层「他原来是谁」剥掉，人才肯走。**

所以西游里那些「放下屠刀」的场面，本库的处理是：不是顿悟，是**先被刷过一次**。

## 与 [[三宝玉如意]] 的对照

同一株青莲的两片，一件主「定」，一件主「去」：

| | [[三宝玉如意]]（花，40 道） | 七宝妙树（瓣，44 道） |
|---|---|---|
| 动作 | 点一下 | 刷一下 |
| 对什么 | 名字、名分、位置 | 形体、神通、加持 |
| 结果 | 你**被定在**某处 | 你**从**某处被剥下来 |
| 失败时 | 点不动的人，是本来就不在册上的人 | 刷不动的东西，是没有「原样」的东西 |

两件都是「不杀人的法宝」，这在本库的封神里比杀人的更管用——**封神要的是把人挪走，不是把人杀掉。**

## 写作约束

1. **不写它刷散魂魄。** 它刷的是形体与资格，魂魄归 [[六道轮回]] 管。
2. **不写它一次性刷掉一群人**（那是 [[混元金斗]] 的活）。
3. **不让它刷 [[无相面]]**：无相面没有「原样」，两件撞上等于空过。
4. **不解释「七宝」是哪七样**——解释清楚就变成考据，本库不需要。
