# 天庭

> 一句话：**它不是[[妖族天庭]]的延续，是它的接手人**——同一份岗位表，换了主人，也换了性质。
> 这一条先定**框架**（谁在哪一层、权力从哪来、不管什么），没定的都进末尾的「未定稿问题」。

## 〇、先分清两个「天庭」

全书最容易写混的一处，先把两张表摆开：

| | [[妖族天庭]]（帝俊的） | **天庭**（昊天的） |
|---|---|---|
| 本体 | 血缘王朝 | **程序官僚** |
| 谁是主 | [[帝俊]]／[[太一]] | [[昊天上帝]] |
| 位置怎么来 | 血统给的（365 星君＝365 阵位） | 册子给的（[[封神榜]] 上榜即归位） |
| 人能不能换 | **不能**（位置挂在人身上） | **能**（位置在，人可换） |
| 兵源 | 妖族全族 | 三教死者的名字 |
| 命门 | 血缘不可补，少一个就崩 | **缺编**：没人上班，规矩就执行不了 |
| 结局 | 倾覆（巫妖量劫） | 满编（封神之后），此后长期在场 |

一句话记：**妖族天庭是「一群有血缘的强者占住了岗位」，天庭是「一套岗位找人来坐」。**

它从妖族天庭手里只接了一样东西：那张 **365 星位的岗位表**（见 [[妖族天庭]]「政权即阵法」一节）。不接人、不接血脉、不接旧主。而这张表自带一个难题——**编制不满，天庭就运转不了**，这正是 [[封神量劫]] 的直接起因。

                    │
【3 职能部】   ┌────┼────┬────┬────┬──────┐
            斗部  雷部  火部  水部  太岁部／财部
           （兵）（刑）（火）（雨）（年运／赐福）｜是否全立，见 U-440
                    │
【4 地方末梢】 ┌────┼─────┐
             城隍  土地   山神／河伯｜层级，见 U-441

**读法**：上面三层（0–2）**定规矩**，下面三层（3–5）**办规矩**。天庭的毛病是——定规矩的人多，办规矩的人不够用。

## 二、六层各是什么

| 层 | 谁 | 管什么 | 权力从哪来 | 命门 |
|---|---|---|---|---|
| 0 主位 | [[昊天上帝]] | 发位置、批文书、定名分 | 天道授权（鸿钧合道后不需要人盯，规矩自己办） | **没有战斗力**：他一动手，天庭就变成「能打的势力」，而它是机构 |
| 1 中枢 | 星部／册府 | 星部校 [[天庭历法]]（时间）；册府管名册（位置） | 编制内、可替换 | 星部一停日子就漂；册府一漏名字就错 |
| 2 帝级分掌 | [[紫微]]／[[勾陈]]／[[后土]]／南极长生 | 各掌一类 | 册子给的位置 | **这层是从妖族天庭原样搬来的**：三位旧编制、一位新的，混着坐 |
| 3 职能部 | 斗／雷／火／水／太岁／财 | 兵、刑、火、雨、年运、赐福 | [[封神榜]] 上榜归位 | 全是「死人的名字」，**只会按册办事，不会变通** |
| 4 地方末梢 | 城隍／土地／山神／河伯 | 收香火、报账、管一地 | [[册封]] 给的承认 | 靠 [[香火]] 养；香火断了位子还在，人却懒了 |
| 5 派驻与外部 | [[东岳大帝]]／太白金星／四大天师 | 地府门口签字、传旨、管文书 | 昊天直接派 | 派驻的人**只签一头**，签不了别人的账 |

## 三、它靠什么活着：不生产，只分配

天庭不产气运、不产功德，它**分配**三样东西：

| 卖什么 | 怎么卖 | 谁记账 |
|---|---|---|
| **位置** | [[封神榜]] 上榜即归位；散仙给名不给册 | 册府 |
| **日子** | [[天庭历法]] 定节气、行雨、巡狩 | 星部 |
| **名分** | [[册封]] 只给承认，不给权力 | 昊天亲批 |

香火是人间的记账动作，经它核过（见 [[香火]] 四种收法）；功德它年年刮一笔，还握着「这笔记给谁」的分配权（见 [[功德]]）。

所以它穷到要刮香火，却谁也不敢得罪它——**不是因为强，是因为它在册子那一头。**

## 四、它不管什么（四条最容易被写错）

1. **不管生死**：生死归 [[生死簿]] 与 [[地府]]，它只在门口签「确实到期」。
2. **不管轮回**：[[六道轮回]] 归天道直辖，[[后土]] 只维护不使用；天庭连边都摸不着。
3. **不管修行**：境界是人自己修出来的（见 [[修行境界]]），天庭只发「金仙以上」那种**位置**。
4. **不判对错**：它执行规矩，不裁定规矩。规矩在鸿钧合道之后**自动运行**（见 [[天道]]），天庭只是跑腿的。

## 五、命门与三步解法（它的力量曲线）

**缺编**是结构性弱点。三步解法一步比一步被动：

1. **封神**：用位置换命，把死者的名字填进岗位（[[封神量劫]]）；
2. **关门**：[[绝地天通]] 一断，人上不来，只能靠册子招人；
3. **走程序**：到 [[西游量劫]] 连「派人」都做不到，只能**出文书**——文牒一批，剩下靠佛门自己走（见 [[八十一难]] 二组「官面」）。

**从「缺人就补」到「只能批条子」，这就是它全书的力量曲线。**

## 六、写作约束

1. **不许它有战斗力。** 它没有能打的人，只有能签的字。
2. **不许两朝的人混用。** [[帝俊]]、[[太一]]、[[白泽]] 属妖族天庭；[[昊天上帝]]、[[东岳大帝]]、星部属天庭。
3. **不许[[昊天上帝]]出手。** 他的权力形状是「签字」，不是「斗法」。
4. **补编只能靠 [[封神榜]]。** 不许用别的东西填天庭的位置。
5. **不许写成暴政。** 它不压迫，它**办事慢**——慢才是它可怕的地方。
6. **不许让职能部「灵活处理」。** 上榜的神是按册办事的死人，越灵活越不像天庭。
7. **未定的位置先不点名加链接。** 瑶池金母、册府、南极长生、太岁部、财部、太白金星、四大天师、城隍、土地都还没立条，正文里只写纯文本等定稿。

## 未定稿问题

- [ ] U-437 王母（瑶池金母）要不要作为「主位的另一半」写进框架？与昊天是并列还是从属？
  - A 并列：一个管神道名册，一个管仙道女仙与蟠桃，两个都是主位
  - B 从属：她在天庭里但不管编制，只管瑶池与女仙（像一个挂靠的独立机构）
  - C 不进框架：天庭只有昊天一个主位，王母留到西游再出场
- [ ] U-438 「册府」要不要单独立条（管名册的那个机构）？
  - A 立条：它是天庭的「人事处」，与星部（历）对称
  - B 不立条：名册就是 [[封神榜]] 本身，多写一个机构反而绕
  - C 并入星部：一个机构管历与册，叫「星册府」
- [ ] U-439 「四御」这一层成不成立（紫微／勾陈／后土／南极长生）？
  - A 成立：四御是从妖族天庭原样搬来的旧层，天庭不得不留
  - B 不成立：只接手了紫微与勾陈，后土独立、南极长生不设
  - C 成立但不叫「四御」：天庭没这个称呼，只是「四个帝级位子」
- [ ] U-440 职能六部要不要全部立条（斗／雷／火／水／太岁／财）？
  - A 全立：六部各一条，上榜者的去处就具体了
  - B 只立雷部与斗部：其余只在表里出现，不单独立条
  - C 只留一张「六部表」放本条内，不单独立条（避免六条空架子）
- [ ] U-441 地方末梢的层级：城隍与土地是上下级，还是各管一摊？
  - A 上下级：城隍管城、土地归城隍，山神河伯再归土地
  - B 各管一摊：城、乡、山河三套并行，互不隶属
  - C 只有城隍是神职，土地山神是「地方自发祭祀」，天庭事后追认
- [ ] U-442 派驻与外部那三个位子（太白金星／四大天师／传旨系统）要不要立条？
  - A 立太白金星：使者位太常用，缺了没法写「下旨」
  - B 立四大天师：文书系统比使者更能解释「为什么办事慢」
  - C 都不立：只在本条写一句「有使者与文书系统」，不点名
- [ ] U-443 帝级分掌里的「南极长生」是不是寿数之神？若是，他与 [[东岳大帝]] 的「核寿数」怎么分工？
  - A 南极掌「该给多少」，东岳掌「是不是到期」——一个定数，一个核数
  - B 南极不管寿数，只管「长生」这件事（修行侧），与东岳无关
  - C 南极长生不立条，寿数全交给东岳与 [[生死簿]]
- [ ] U-444 天庭有没有「太子／储君」这个概念？
  - A 没有：天庭是机构，位置不是血统传的
  - B 有名义上的：某个位子被视为储位，但从未启用
  - C 有且是隐患：妖族天庭就是血缘王朝，天庭最怕被人看出它也想要血统
- [ ] U-435 天庭有没有「文官」这一层（不作战、只管账的神）？
  - A 有：星部与判官那一类就是文官，只是不单独立条
  - B 没有：天庭所有神职都带一点执行力，纯文官不存在
  - C 曾经有，封神时被三教的武职挤掉了
- [ ] U-436 天庭与[[妖族天庭]]之间，有没有人「两头都当过差」？
  - A 没有：妖族天庭的人死绝或散了，编制是重新填的
  - B 有极少数：旧星君残部被收编，但名字重写过
  - C 有，且是隐患：这些人记得旧天庭怎么运转
