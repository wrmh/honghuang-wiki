# 阴德

> 一句话：**功德是做成的事被记在天上，阴德是没人看见的事被记在地下——同一件好事，走进两个本子就是两笔账，而且这两笔不能互换。**

## 一、它是什么

阴德不是「暗中的功德」，是**另一套记账主体**：功德由 `册府` 记（天体、天道、因果那一侧），阴德由**地方**记（`城隍` 的私簿、`土地` 的口传、判官听来的那几句）。

| 对照项 | 功德 | 阴德 |
|---|---|---|
| 谁记 | `册府`、开天那一侧的算法 | `城隍`／`土地`，人手记，会抄漏 |
| 记什么 | 做成的事（有结果、有公开的因果） | 没被看见的事（没有结果，也没有见证人） |
| 什么时候入账 | 事成之后 | 人死之后，`孽镜台`／判官那一站才补上 |
| 能不能换修为 | 能（功德成圣、功德灵宝） | **不能**——它换不了名分，只换「怎么过」 |
| 破了会怎样 | 账在册上，赖不掉 | 记的人一死／一调，这笔就没了 |

核心判断：**天上那本账只记得住「发生过的事」，记不住「没被知道的事」；后者如果不记，就真的不存在了——所以才有阴德。**

## 二、时序：这个词很晚才有

**「阴德」不是开天就有的东西，它是 `后土` 身化轮回、地府那一套结构立起来之后，才被明文写下来的。**

在那之前，做了没人看见的好事，人心里是知道的——**冥冥之中有所察觉**：觉得这一支活得顺、觉得那家人后来没出事、觉得亏心的人最后都撞上了。没有人记账，也没有「阴德」这个词；**察觉是真的，账还没有。**

| 阶段 | 有没有这回事 | 有没有这个词、这个账 |
|---|---|---|
| 后土身化轮回之前（开天—巫妖劫） | 有：好事照样在因果里算 | **没有**：只有「冥冥之中」四个字，说不清是什么在算 |
| 地府立起、十殿开始运转 | 有：账开始落到纸上 | 起先只在 `城隍` 私簿的最后一页，不呈天庭 |
| `轮回台` 分通道、判官加「此人有旧账」 | 有：开始能换「怎么过」 | 才有「阴德」这个叫法与用法 |

写早期的时候要守住一条：**那时候的人不知道自己被记着。** 他们只会说「祖上积了德」「这家人命好」，说不清是谁在算；谁要是张口就说「阴德换寿数」，那个人要么活在地府立起来之后，要么在胡说。

## 三、谁在记，记在哪

- **`城隍`**：一城一本私簿。写「某年某月，某人在某处做了某事，无人见」，字很小，写在簿子最后一页——那一页不呈天庭，`考功` 也不核。
- **`土地`**：不写字，只记人。一个土地爷记得住三代人做过什么事，死后 `黄泉路` 上有人问起，他就答一句；答过就忘。
- **判官**：不问阴德，只听。阴德不构成判词，只在判词末尾加一句「此人有旧账」，`轮回台` 分通道时用得上。
- **`册府` 不知道**：不是被瞒着，是它没有这一栏。三本主册写位置、份例、对账，**没有一格留给「没人看见的好事」**。

**记漏了能补，只有一次。** `城隍` 死时交接，接任的人翻到私簿最后一页，看到那一行没写全的，可以补报；补报要报给 `四大判官`，判官认了才算。但补一次要等一个元会（129600 年）——所以「补上」这件事，几乎总是补给别人看的：**当事那一代早走完了。**

## 四、它真正能换什么（不能换什么）

| 能换 | 怎么换 |
|---|---|
| 寿数（阳间那几年） | `东岳大帝` 只签阳间到期；阴德厚的人，到期前会被地方「缓报」一次，缓一次一年 |
| 减时长（十八层地狱） | 不是抵罪，也不改判成哪一层：该下的层不变，**待的日子短一些**——阴德从不改变「判成什么」，只改变「多久」 |
| 托生的先后 | 不改通道：`轮回台` 六道同时开，阴德只让他在**自己那一条道上**排得靠前些，改不了是哪一条 |
| [[余荫]]（子孙） | 记在姓上不记在人上，**补的是家族不是人**（见 `里社`） |

| 不能换 | 为什么 |
|---|---|
| 修为、境界 | 那是「被允许欠多少」，阴德不改变欠条 |
| 名分、果位、官职 | 那些要走 `封神榜签押` 或 `授记`，没有一格是给「无人见」的 |
| 抵掉功德的欠 | 两本账不对冲；功德欠着的，阴德再多也不平 |

## 五、三条硬规矩

| 规矩 | 破了会怎样 |
|---|---|
| 不能自己申报 | 一说「我做了好事」，它就从「无人见」变成「有人见」，当场降格为普通的因果，进不了阴德这一栏 |
| 不能转让、不能继承（除 [[余荫]] 那一条） | 一转让就变成可交易的功德，地府立刻多出一门生意 |
| 不能拿来跟天庭讲价 | 天庭那本账上没有这一栏，拿它去讲价＝拿一本对方不认的册子去对账 |

## 六、写作约束

- 不写「善有善报」的即时兑现——阴德的回报恒在**事后**、恒在**人间**、恒由**别人**承受。
- 不写地府像法院一样审阴德；它只是**记得**，记得的方式是「某一页最后一行」。
- 不许让主角靠积阴德升级：阴德换不了境界，这是本书制度线的一条地基。
- 写「无人见」时，要写清没有谁看见——不是省略，是要让读者知道这一笔真的只存在于一本私簿上。

## 七、已定（2026-11-19 裁决）
