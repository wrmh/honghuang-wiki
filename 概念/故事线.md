# 故事线

> 一句话：洪荒不是五段故事，是**一条从开天到西游的连续因果链**——每一环都是上一环没结清的账。

## 这条线怎么读

三段，九个阶段：

- **成形**（开天 → 洪荒初生）：天地有了，但没有秩序。这时候留下的东西是**材料**（灵脉、地脉、肉身、法宝）。
- **立规**（龙汉 → 六圣成圣）：谁定规矩、谁执行、谁记账。这一段结束时，洪荒的权力被切成六份。
- **结账**（巫妖 → 封神 → 西游）：三笔大账依次清算。清算的方式不同，但账本是同一个。

读法上有一个硬要求：**不许把某一劫当成独立故事**。四劫是同一笔气运账的四个账期，开天是本金（见 [[索引]] 二、因果接口）。

## 第 4 段：六圣成圣（本库口径）

这一段是整条线最容易被跳过的，因为洪荒叙事通常只写「四劫」。但**没有六圣，巫妖劫没人能收场，封神劫没人能签押**。

### 时间点：龙汉之后、巫妖之前

为什么必须在这里：

- 六圣之一起码要有东西可分、有账可认——**分宝岩是前提**，而分宝岩在龙汉末尾；
- 巫妖劫里女娲已是圣人（所以能补天、能代偿），说明成圣早于巫妖；
- 封神要靠三教签押，说明三教在封神之前已经成型。

### 成圣的唯一条件：认领一笔没人认的账

按 [[修行境界]]：「准圣 → 圣人卡的是**记账**」。所以成圣不是修到顶，是**接下一笔此前无主的账，并用自己的一生去还它**。

| 圣人 | 成圣方式 | 接下的账 | 代价（结构性缺陷） |
|---|---|---|---|
| [[女娲]] | 造人 → 功德 | 「受造之物该按什么标准活着」——她把合法性从血统换成功德 | 从此不能替人族做决定，只能代偿（补天耗掉气运即此） |
| [[太上老君]] | 立人教 → 道统 | 「名分由谁来定」 | 太极图只分不合 → 不能立教规、不能执行家法 → 人教只能「谁来了都行」 |
| [[元始天尊]] | 立阐教 → 道统 | 「规矩由谁来立」 | 盘古幡只立不行 → 必须择人而授，规矩要靠可查证的人守 |
| [[通天教主]] | 立截教 → 道统 | 「没人给活路的那些人谁来收」 | 有教无类＝扩张而非慈悲 → 人最多、位置最少，必败 |
| [[接引]] | 发愿「接」→ 愿力 | 「在别处算不清的人往哪放」 | 西方无粮，只能给位置不给饭 → 扩张只能「先赊后还」 |
| [[准提]] | 发愿「找」→ 愿力 | 「谁来把人找来」 | 圣人里最不要脸，因为他必须主动开口 |

六人合起来才是一套完整的权力：**造（女娲）、定名（老子）、立法（元始）、收容（通天）、接人（接引）、找人（准提）**。缺一条，洪荒的账就没有闭环。

### 一个必须说清的例外：鸿钧不算六圣

[[鸿钧]] **不是成圣，是换位**：从棋盘上的一枚子，变成棋盘本身（合道）。所以他不在六圣之列，也不参与六圣的分工——他只在六圣打成一团时出面（万仙阵之后带走通天即此）。

### 这一段留下的三个后果

1. **权力切成六份，且六份都不完整**——这是封神量劫的发动机（见 [[三清]]：三清不可能联手，因为联手等于承认谁都不是正主）。
2. **「代为偿还」成为合法动作**：圣人不能下场，但可以代偿（女娲补天是第一次，封神「圣人不入杀劫但可代偿」是制度化）。
3. **人的位置被确定**：六圣分工里没有「人族自己」这一项 → 人族此后所有努力（[[伏羲]] 算卦、[[神农]] 尝草、[[轩辕]] 编秩序）都是在争取一个六圣体系里不存在的位置。

## 六个真正的转折点

不写大事记，写**结构变化**——每一处之后，洪荒的运行规则都变了：

1. **斧碎三件**（降档为先天至宝）：混沌至宝从此不存在，50 道变成 49 道。
2. **三族盟约**：三族不是被打败的，是被**职能**绑死的（龙守海眼、凤守火山、麟镇裂口）。
3. **鸿钧合道**：秩序有了执行者，但没有立法者——所以后来的规矩都要「签押」才生效。
4. **六圣成圣**：权力切成六份，谁都不完整。
5. **天柱折**：绝地天通，凡人不再能自己上去，飞升变成三条被管制的路（见 [[人族]]）。
6. **榜满编**：位置成了稀缺资源，此后一切争夺都是争位置（见 [[封神榜]]）。

## 每一环的缺口（还没写透的地方）

- **洪荒初生段**：[[洪荒凶兽]] 只有一条，凶兽时代的规模、灵兽的分布都没写实。
- **六圣成圣段**：[[准提]] 尚未立条（只在 [[接引]] 里出现）；六人成圣的先后顺序还没排定。
- **巫妖段**：十二祖巫只点了几位（[[玄冥]]、[[天吴]]、[[烛九阴]]、[[蓐收]] 仍无正文）。
- **封神段**：[[三宝玉如意]]、[[青萍剑]]、[[七宝妙树]]、[[红绣球]]、[[山河社稷图]] 等青莲碎片多为空链。
- **西游段**：佛门内部结构（谁管谁）尚未成条。

## 写作约束

- **不许跳环**。写巫妖时必须交代六圣已经成圣；写封神时必须交代榜的制度来源。
- **不许把某一劫写成独立故事**。每篇开头都要能接上上一环的账。
- **时间用「元会」粗算，不写死年份**（一元会＝129600 年，对账用；叙事里只说「第几元会」或「数万年」）。
- **不写盘古复生、不写圣人联手、不写量劫被打断**。
