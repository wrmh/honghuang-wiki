# 打神鞭

> 一句话：它**只打榜上有名的人**——
> 打不着无名之辈，也打不着不在册的神；所以它其实不是武器，是**一支会疼的笔**。

## 机制

| 对象 | 结果 |
|---|---|
| 榜上有名、尚未归位者 | 打得到，且疼（因为打的是「你早晚要来」这件事） |
| 无名之辈（凡人、散仙） | 打不着——从鞭子上滑过去 |
| 已在册的神（[[天庭]] 正神） | 打不着（已经归位，账已结） |
| 圣人 | 打不着（不在任何册子上） |

**「只打榜上有名的人」是它唯一的能力，也是它全部的意义**：它让「你已经在名单上了」这件事变得可以感觉到。

## 为什么 40 道（极品后天灵宝）

- 它是**造出来的**（[[元始天尊]] 手制），故属后天。
- 它只对一本册子有效，作用面比 [[阿鼻]]（能划任何名字）窄得多——**面越窄，道数越少**（与 [[红绣球]] 32 道同理）。
- 到不了 42 道的炼制上限，因为它不是靠「炼」堆上去的，是靠「仿」——**仿的东西永远差一点**。

## 与其它「名册类」法宝的对照

| 法宝 | 对名单做什么 |
|---|---|
| [[封神榜]] | 写（谁上） |
| [[阿鼻]] | 划（把名字划掉，留空行） |
| [[无相面]] | 不写（让名册上没有你） |
| [[六魂幡]] | 写位置再摇 |
| **打神鞭** | **打（让「你在册上」这件事疼起来）** |

**五件合起来：能写、能划、能不写、能摇、能打。** 打神鞭是唯一一件**不打人、只打账**的。

## 三条写作约束

1. 不许它打赢任何一场硬仗：它的作用是「让对手知道自己已经在名单上」，一慌就输了，不是被打败的。
2. 不许它打出致命伤：疼而不死——死了就归位了，反而省事。
3. 拿它的人必须是「抬不动笔的人」（见 [[根行]]、[[姜子牙]]）：他自己不在榜上，才能替榜办事。

## 已定（2026-11-15 裁决）
- **U-409**：天书本来就这样：元始只是照着仿，仿不出多余的东西——四十道里「认名」那一条不是他加的。
- **U-410**：打过很多次，但一次也没打死。它的性质决定了这个结果：疼而不死，死了就归位，反而省事。
