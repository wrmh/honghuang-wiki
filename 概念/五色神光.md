# 五色神光

> **五色神光不判对错，只判「能不能被拆开」。**
> 它动的不是规则，是**构成**：把一件东西拆回它由什么拼起来的那一刻。所以它对「有构成的东西」几乎无敌，对「只由规矩成立的东西」毫无办法。

## 一、是什么

[[孔宣]]的本相是孔雀，五色神光是他尾羽所化的五色毫光，青、黄、赤、白、黑，对应五行与五方。

它不是法术、不是法宝、不是神通里常见的那种「打出去」——**它是把对手的存在方式换回去**：

| 对手的状态 | 五色神光的处理 |
| --- | --- |
| 一件法宝 | 刷落——从「正在起作用的宝」退回「一块材料」 |
| 一个化身本相能压人的存在 | 打回本相——你本来是什么，就被摁回什么 |
| 一道以名分、誓言、册子成立的规矩 | **无效**——它没有构成可拆 |
| 一个人（凡人、修士） | 刷落其护身之物与护体之气，本人不受根本损伤 |

## 二、为什么它不算「规则」

全书里对规则下手的东西很少，且各有其层：

| 层级 | 代表 | 动的是什么 |
| --- | --- | --- |
| 名册 | [[阿鼻]]、[[无相面]]、[[封神榜]] | 名字能不能被写上、被划掉 |
| 名分 | [[三宝玉如意]] | 一个位置算不算数 |
| 秩序 | [[盘古幡]]、[[太极图]] | 规矩怎么立、怎么分 |
| **构成** | **五色神光**、[[七宝妙树]] | **一件东西由什么拼起来** |

层次越低越「硬」，也越「窄」。五色神光在最低一层，所以它对法宝近乎无解，对天条的判词则完全使不上力——**它拆得开东西，拆不开条文**。

## 三、唯一的克星：七宝妙树

同源相克。[[七宝妙树]]是[[混沌青莲]]的花瓣所化，五色神光是孔雀尾羽所化：**一个剥「加持与资格」，一个剥「构成」**，两者干的是同一件事的不同高度。

所以[[孔宣]]只被一件东西克过：西方二圣拿七宝妙树刷他。这不是实力差距，是**出身差距**——他的光来自「一只鸟长出来的东西」，对方的花瓣来自「开天之前的那朵」。

## 四、它为什么后来「不算他的了」

孔宣被收编之后，五色神光仍在，只是**不再属于他自己**：光还在他尾上，用不用、什么时候用，不由他定。

这也是西方肯收他的真正理由：他们要的不是一个人，是**一种能把别人的构成拆开的工具**。[[接引]]收的是账，[[准提]]收的是人——这次他们收的是一道光。

## 五、与[[阿鼻]]的对照（名册 vs 构成）

| | 阿鼻 | 五色神光 |
| --- | --- | --- |
| 动的是 | 名字 | 构成 |
| 对法宝 | 无意义（法宝没名字） | 刷落 |
| 对上榜者 | 留下填不进去的空行 | 无效 |
| 谁最怕它 | 一切靠「在册」活着的人 | 一切靠「有形状」活着的东西 |

## 六、写作约束

1. **不写它「无敌」**——它的边界必须永远清楚：条文、名册、纯规则，一律无效。
2. **不写它被复制**——五色神光是本相外化，别人学不会，也不许出现「仿制的五色神光」。
3. **不写孔宣用它翻盘**——他被收编之后再没为自己用过一次，这条一旦破，全书「被收编者」的处境就假了。
4. 每次出现都只写「刷落／打回本相」两个动作，不写光效颜色变化之类的描写。
