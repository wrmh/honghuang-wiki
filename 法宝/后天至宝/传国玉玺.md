# 传国玉玺

> 一句话：**它不是一件兵器，是一枚「批准」的印——盖下去，就有一笔气运被支出去。**

## 一、它是什么

[[龙气]] 是账，玉玺是**唯一能把账支出去的手续**。没有龙气，玉玺只是一块玉（末代皇帝就是这样：印在手里，盖下去什么都没有）。

## 二、三条性质

1. **认名分不认人**：谁被认作共主，谁就能盖；同一个印换手，效用不换。
2. **每盖一次，账上留一笔「支」**：不是消耗品，是欠条——支多了，下一次盖不动。
3. **不能伪造、不能复制**：不是因为它难刻，是因为「受命于天」这四个字只能被承认一次。

## 三、与其它法宝的区别

| | 本库的做法 |
|---|---|
| 与 [[屠巫剑]] 比 | 剑是杀出来的档位，玺是认出来的档位 |
| 与 [[天地玄黄玲珑宝塔]] 比 | 塔护一人不败，玺护一国之主，护不住那国的百姓 |
| 与 [[公器]] 比 | 公器认位置，玺认**名分**；位置能换人，名分只能重立 |

## 四、写作约束

1. 不许把玉玺写成万能的护身符：它挡得住一击，挡不住一场战争。
2. 每次动用写清「支了一笔」，并让后面某件事变难（调不动兵、赈不下去）。
3. 国亡之前玉玺可以先丢——**先丢印，再丢国**，比反过来更有力。
