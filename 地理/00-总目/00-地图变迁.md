# 地图变迁

> 一句话：**总图只画形状，分图画里子。** 一张图塞进所有东西只会挤成一团，所以这里分成两套：**总图（五个时点）× 分图（五个空间层）**。

## 这份文件怎么用

| 你要做什么 | 看哪一节 |
|---|---|
| 画一张「洪荒长什么样」的全景图 | 一、总图（T0–T4，只画形状） |
| 画某一层的细节图（只画陆地、只画天上…） | 二、分图（五张，按 `地理\` 的空间层） |
| 查某个地方哪年出现、哪年没了 | 四、地名总表 |
| 查某个地方该出现在哪张图上 | 四、地名总表的「画在哪张图」列 |
| 陆地以后要拆成四大洲 | 三、陆地什么时候拆 |

**总图与分图共用一个色板**，所以拼起来像同一套地图集；但**总图不许出现地标**，地标一律下沉到分图（这是本节最重要的一条规矩）。

## 一、总图：只画形状

### 1.1 总图约定

| 项 | 规定 |
|---|---|
| 画幅 | 16:9 横构图，1920×1080 |
| 视角 | 正上方略斜俯视（约 30°），**不用透视灭点**，保持类地图感 |
| 方位 | 上北下南左西右东，四角有方位罗盘 |
| 构图 | 竖向三段式：上缘 12% 天界示意带，中部 76% 地表，下缘 12% 九幽示意带 |
| 总图**只许画** | 天带的层数／大陆的整体轮廓／环海或四海的分布／九幽带的状态（空腔或成界）／四角的域外暗雾／不周山断柱的截面／东南海面的楔形 |
| 总图**不许画** | 山、宫、殿、岛、炉、崖、塔、人、旗、纹章——**地标一律下沉到分图** |
| 允许的锚点 | 最多三个：不周山（柱／断柱）、昆仑（一处山结）、东海海眼（一点微光）。其余全部留白 |
| 地表色板 | 土黄 `#C8B08A`、灵脉青绿 `#7FD1C1`、焦土 `#6B4A3A`、凶兽荒野 `#8C8577` |
| 海色板 | 深海 `#2E5C7E`、浅海 `#4A8FAE`、被淹古陆 `#1F4459` |
| 天界色板 | 半透明蓝紫 `#8FA9D9`（40% 不透明度） |
| 九幽色板 | 紫黑 `#2A2233`、血海 `#7A2B33` |
| 标注 | 白描细线 1px、深色描边、`#F2E9D8` 字形，中文地名，字号统一（总图最多标 8 个地名） |
| 风格 | 手绘古籍地图 + 现代信息图混合：留白多、线条细、无写实材质 |
| 禁忌 | 不画人物、不画光效爆炸、不用卫星图质感、不加伪英文标注 |

**变化表达法**：同一帧里，本时点**新增**的东西用亮线勾边，**消失**的东西用虚线残影 + 小字「已毁」，**改变**的东西在旁加 `↳` 注释。五张并排看就是一条干净的演化链。

### 1.2 总图 T0 开天初成（[[开天辟地]] 之后）

**一句话**：一整块大陆，一根柱子，一圈海，天只有一层，地下是空的。

| 元素 | 方位 | 相对大小 | 状态 |
|---|---|---|---|
| 古大陆（未分裂） | 正中 | 占中部宽 70% | 完整，无裂缝 |
| 撑天柱（[[不周山]]） | 大陆正中 | 顶到天带的一条竖柱 | 撑天，通天 |
| 山结（[[昆仑]]） | 正中偏西 | 一处高亮山结（**只画结，不画山形**） | 龙脉之源 |
| 环海（四海未分） | 环绕大陆 | 环带宽 30% | 完整闭环，无海眼 |
| 天 | 上缘天带 | 单层薄带，无分层线 | 完整可用 |
| 九幽 | 下缘九幽带 | 一片无结构暗区 | **空腔**，未成「界」 |
| [[域外]] | 四角之外 | 只画边缘一圈暗雾 | 不入图 |

**生图提示词**

> 古籍风格世界地图，16:9 横构图，正上方 30 度斜俯视，无透视灭点。竖向三段式：上缘 12% 为半透明蓝紫色单层天穹薄带（无分层线），中部 76% 为土黄 #C8B08A 的一整块完整古大陆，下缘 12% 为紫黑 #2A2233 的无结构暗区。大陆正中央立一根直通天带的光滑石柱，柱顶接触天带；大陆正中偏西有一处青绿 #7FD1C1 发光山结，自山结向东北与正南各延伸一条细发光脉络。大陆外围是一整圈闭合的深海 #2E5C7E 环带，带宽约画面 30%，环带中有浅海 #4A8FAE 过渡。四角各一枚小罗盘与方位字。画面只画轮廓与相对位置，不画任何建筑、山形、岛屿与人影。留白多、线条细、无写实材质。地名白描细线标注，字色 #F2E9D8。

### 1.3 总图 T1 龙汉之后（[[龙汉初劫]] 之后）

**一句话**：大陆还完整，但西边烧掉一条，正中多了一块分宝的石头。

| 形状级变化 | 怎么画 |
|---|---|
| 西部焦土带 | 大陆西侧一条南北向 `#6B4A3A` 焦色带，边缘不规则，**不画西边有多少山** |
| 分宝岩 | 一块石头，不给形状细节，只在图上标一个点 |
| 天 | 仍然单层 |
| 九幽 | 仍然空腔 |
| 三族岗位 | **总图不画**（下沉到分图·陆地 / 分图·海域） |

### 1.4 总图 T2 巫妖之后（[[巫妖量劫]] 之后）

**一句话**：柱子断了，大陆裂成四块，海灌进来，地下终于有了「界」。**这是全图集唯一一次结构性改变。**

| 形状级变化 | 怎么画 |
|---|---|
| 柱断 | 正中柱体**画截面**（深灰岩层＋不规则断口），上半截倒向西北，只画倒伏的一小段 |
| 裂四块 | 大陆沿四条龙脉裂成四块，裂缝用**细直暗线**（不画峡谷宽度） |
| 海侵 | 东南一侧海面抬高约 3% 画高，海水成楔形渗入裂缝 |
| 天 | 天带整体倾斜（见七、天倾西北画法） |
| 九幽 | 由暗区变成**有结构的分层带**（三层细线即可，不画十二站） |
| 焦土 | 九片焦土只画成「一串点」，不给具体形状 |

### 1.5 总图 T3 封神之后（[[封神量劫]] 之后）

**一句话**：地在 T2 之后基本不动了，动的是天——天带第一次有了层。

| 形状级变化 | 怎么画 |
|---|---|
| 天带分层 | 天带内侧加 3–4 条**极细横向线**表示 33 重（不画 33 条，画 4 条示意），并加一条封条似的浅金线表示「绝地天通」 |
| 地 | 沿用 T2，只许改颜色深浅，不许改轮廓 |
| 海 | 沿 T2，四洲岛链未成形 |
| 九幽 | 沿用 T2，结构带加一条竖线（表示「册子」已齐） |

### 1.6 总图 T4 西游定型（[[西游量劫]] 之后）

**一句话**：地图定稿。四洲定型，四海各归其位，天上地下都不再变。

| 形状级变化 | 怎么画 |
|---|---|
| 四洲定型 | 裂缝边缘圆钝（不再尖锐），外围出现细小岛链 |
| 四海 | 环海彻底断开成四片，各自有名字 |
| 一条路线 | 从南赡部洲向西北画一条**虚线**（取经路，只画线不画站点） |
| 天／九幽 | 沿用 T3，不再变化 |

## 二、分图：按空间层各画一张

### 2.1 分图约定

| 项 | 规定 |
|---|---|
| 一张图只画一层 | 陆地分图里**没有天带、没有九幽带**；天上分图里地面只留底部一条薄边作方位参考 |
| 画幅 | 平面层（陆地、海域、域外）用 16:9；流程层（幽冥）用 4:5 竖版；剖面层（天上）用 16:9 并在上方加一条竖向剖面 |
| 视角 | 平面层：正上俯视或有轻微倾斜；剖面层：横向剖面，标注重数 |
| 详细度 | 分图**比总图细**：地标、界线、编号点、区块名都可以画 |
| 命名 | 与目录一致：`地理\01-天上\` 对应「分图·天上」，以此类推 |
| 色板 | 与总图共用；分图可用同色系加深一档做层次 |
| 禁忌 | 分图也不画人物；不跨层（天上分图不解释地下） |

### 2.2 分图·天上（`地理\01-天上\`）

**画什么**：[[三十三天]] 的分层、[[天河]]、星辰带、治所。

| 区块 | 画法 |
|---|---|
| 天带剖面（上半） | 一条竖向剖面，从下往上画 4 条分级线，标「一重／十二重／三十二重／三十三重大罗天」；**只标 4 个刻度，不画 33 格** |
| 玉京（第三十二重） | 剖面上一个方框，标「治所」 |
| 大罗天（第三十三重） | 最上一层留白，标「不入重数」 |
| [[天河]] | 下方平面里一条横向水带：两岸浅金 `#E8D9A0` 三层渐变（罡气岸），水面近黑 `#1B2A33` **无反光** |
| 星辰带 | 平面里 365 个极小的点，**不逐个标名**，只标紫微、北斗、太阳、太阴、勾陈五个 |
| [[紫霄宫]] | **不画在这张图上**（在域外，见分图·域外），只在图角加一行小注 |

**生图提示词**

> 古籍风天界分层图，16:9，横向剖面加平面混合。上半部为竖向天界剖面：自下而上四条细金线分隔出四个刻度区，标注「一重／十二重／三十二重／三十三重」，第三十二重内画一个方框表示玉京治所，最上一层大面积留白。下半部为平面星空示意：深蓝 #1F4459 底，散布细小星点，只对五个亮点做白描标注；中部横贯一条水带，两岸三层浅金 #E8D9A0 渐变，水面近黑 #1B2A33 且无反光。画面不画宫殿群、不画人物、不画光效。留白多、线条细。

### 2.3 分图·陆地（`地理\02-陆地\`）

**画什么**：四洲（或未分裂大陆）、山脉与水系、所有陆地地标。**这是地标最多的一张，也是最早需要拆图的一张。**

| 区块 | 画法 |
|---|---|
| 大陆／四洲 | 只画陆地边界与裂缝，不画环海细节（海属分图·海域） |
| [[昆仑]] | 山基一处、山体一道、山顶石台一点，标「根」 |
| [[不周山]] 残址 | 断柱**截面**＋西北侧崩口＋脚下炼石炉址（五色残渣画成五色细点） |
| [[麒麟崖]] | 一道横向断崖（方圆百里、高百丈），崖下一道**极细竖缝**（不画成峡谷） |
| [[不死火山]] | 大陆正南端，山口一格近白高亮，外圈极细浅金界线 |
| [[盘古大殿]] | 一块**平的**石台＋十二个柱位呈环状＋中心凹坑；**不画殿宇、不画屋顶** |
| 四极 | 四角各立一根短柱，柱头完整，不与大陆相连 |
| 九片焦土 | 串状分布，黑而硬、带玻璃化裂纹 |
| 夸父倒地 | 干裂高地，黄白多边形龟裂、缝里无草 |
| 巫族旧地 | 无主空地：兽道＋残存图腾柱，**不画废墟** |
| 三族岗位 | 见五、三族岗位统一画法（此处只画麒麟崖与不死火山两处） |

**生图提示词**

> 古籍风陆地地图，16:9，正上略斜俯视，**全幅只画陆地，不画天空与地下**。土黄 #C8B08A 大陆为主体，四块大陆由四条细直暗线分开（若画分裂前则为一整块）。中部偏西一处山结并向上收成石台；正中一根断裂石柱的横截面朝上，倒伏的一小段指向西北，柱脚有石台与五色细点残渣。中土一道横向断崖，崖下一道极细竖缝。正南端一座山体，山口一格高亮，外圈一道极细浅金界线。一块平坦石台上有环状排列的十二个小柱位与中心凹坑，不画殿宇屋顶。西南与东北各有一处干裂灰白高地，东南九处小而硬的黑色焦斑。四角四根短柱。画面不画海、不画天、不画九幽、不画人物与旗帜；界线内不插旗。留白多、线条细、无写实材质。

### 2.4 分图·海域（`地理\03-海域\`）

**画什么**：[[东海]] 的三层、[[东皇钟]] 封的海眼、龙族岗位、蓬莱三岛、四海分布。

| 区块 | 画法 |
|---|---|
| 海域范围 | 只画水，陆岸画成一条**边界线**（不画陆地内部） |
| 浅海带 | 近岸一圈浅海 `#4A8FAE` |
| 渊层 | 一圈更深的 `#2E5C7E`，标注「水晶宫」为一个方点 |
| 海眼 | 一处**不可打捞的深点**：同心圆三层加深到 `#1F4459`，中心一点微光（东皇钟在此，但**不画钟**） |
| 龙族界线 | 极细浅金 `#E8D9A0` 一圈，界内不插旗 |
| 蓬莱三岛 | 三粒极小的浮岛点，**不给确定位置**（用三个虚线圈） |
| 四海 | 四条断续分界，各标一名 |

**生图提示词**

> 古籍风海域图，16:9，俯视，**全幅只画水**，陆岸仅一线边界。近岸一圈浅海 #4A8FAE，向内一圈深蓝 #2E5C7E，再向内一处三层同心圆加深至 #1F4459，圆心一点极微白光（不画器物）。深区中一个方点标注为宫殿所在。一圈极细浅金 #E8D9A0 界线环绕宫域，界内无任何旗帜与纹章。画面上有三粒极小的浮岛点，各用虚线圈示意位置不固定。四条断续分界线把水域分成四片并各标一名。不画船、不画人物、不画浪花特效。留白多、线条细。

### 2.5 分图·幽冥（`地理\04-幽冥\`）

**画什么**：[[幽冥]] 的十二站流程、血海侧翼与阿修罗道口、[[轮回盘]] 所在。

| 区块 | 画法 |
|---|---|
| 画幅 | 4:5 竖版，**流程自上而下**（不是地图，是流程图地图） |
| 上段（入口） | 阳间边缘→鬼门关→黄泉路→枉死城，一条向下主干道 |
| 中段（城与审） | 酆都城（方框群，**不画殿宇细节**）→十殿（十个并列小格，只标序号）→孽镜台（一个圆点） |
| 下段（过渡与出口） | 忘川→奈何桥（一条横线）→孟婆亭（一点）→三生石／望乡台（两点）→[[轮回盘]]（同心圆，只画「在转」的弧线） |
| 十八层地狱 | 主干道**侧边**一组竖向层线，标注「清账区，不复入流程」 |
| 血海 | 画面一侧（左）独立的暗红 `#7A2B33` 区块，与主流程**只用一条虚线相连** |
| 阿修罗道口 | 血海内侧一个开口，标「唯一绕过分流的道口」 |

**生图提示词**

> 古籍风地府流程图，4:5 竖版，从上到下排列。深紫黑 #2A2233 底。顶部一道细线表示阳间边界，向下一条主干道经过一座门形、一条长路、一座方框城；城内十个并列小方格，标序号；再向下一条横线为桥，桥侧两点，最底一组同心圆弧线表示一个不停转动的盘。主干道左侧一幅竖向分层线组，标注为另一系统。画面左侧独立一块暗红 #7A2B33 区域，与主干道之间仅用一条虚线相连，该区域内侧有一个开口。不画人物、不画鬼怪、不画火焰地狱景象、不画光效。留白多、线条细。

### 2.6 分图·域外（`地理\05-域外\`）

**画什么**：域外的雾、[[紫霄宫]]、[[柳庭]]、「门」。

| 区块 | 画法 |
|---|---|
| 底 | 一片没有地形的暗雾（`#2A2233` 到黑的渐变），**不画大陆轮廓** |
| 门 | 一道极细的竖缝（在内侧边缘），按四个状态画：关闭／开一条缝／开到最大／重闭（四张小图并排） |
| [[紫霄宫]] | 一座贴在边界内侧的宫殿剪影，**只画轮廓不画细节**（它是一座建筑，唯一在域外有形的建筑） |
| [[柳庭]] | 雾里一处极淡的**垂丝纹理**（不画树冠、不画门阶、不画人影） |
| 禁忌 | 不画星空、不画混沌漩涡、不画光柱 |

**生图提示词**

> 图中只有雾与两处极淡的痕迹：16:9 横构图，深紫黑到黑的渐变背景，没有地形轮廓。画面内侧边缘一道极细竖缝，左侧另并排三张同尺寸小图，分别表示同一道缝的开合程度。内侧边缘另有一座只画轮廓线的宫殿剪影，无窗无门无细节。远处雾中一处极淡的垂丝纹理，像一层垂到地面的丝线，不画树冠。不画星空、不画漩涡、不画光柱、不画人物。留白极多、线条极细。

## 三、陆地什么时候拆成四大洲

**触发条件（满足任一即拆）**：

1. 陆地层的地标超过 **12 个**（现在已 8 个，接近上限）
2. 某一块洲自己有 **3 个以上**词条
3. 要画某洲的独立战役或独立地图

**拆法**：

| 步骤 | 怎么做 |
|---|---|
| 1 | `分图·陆地` 保留一张「四洲关系图」：只画四块洲的相对位置、裂缝、各洲名字，**不画任何地标** |
| 2 | 另拆四张：`分图·陆地·东胜神洲`／`南赡部洲`／`西牛贺洲`／`北俱芦洲` |
| 3 | 每洲按键在纵广比：北俱芦洲 40 : 东胜神洲 36 : 西牛贺洲 32 : 南赡部洲 28（万里）定画幅宽度 |
| 4 | 地标跟着它所在的洲走（[[昆仑]]→南赡部洲／[[不周山]] 残址→西牛贺洲与南赡部洲交界／[[麒麟崖]]→中土即南赡部洲北部／[[不死火山]]→北俱芦洲南缘／[[盘古大殿]]→西牛贺洲） |
| 5 | **总图不变**：总图本来只画形状，拆图只影响分图 |

**拆图不是删图**：四洲关系图永远保留，因为它回答的是「它们怎么分开的」，而四张分图回答的是「分开了以后里面有什么」。

## 五、三族岗位统一画法（分图·陆地 与 分图·海域）

三族盟约之后，三族各被钉在一个**岗位上**，领袖各守一处，从此都是「位置」，不是「势力」。三处画法必须统一成**岗点位**：

| 族 | 栖息地 | 领袖 | 最终去处 | 画在哪张图 |
|---|---|---|---|---|
| [[龙族]] | 东海渊层·水晶宫 | [[祖龙]] | 镇东海海眼（与 [[东皇钟]] 照面后各自收手） | 分图·海域 |
| [[凤族]] | 南方 [[不死火山]] | [[元凤]] | 退守不死火山，以火为界 | 分图·陆地 |
| [[麒麟族]] | 中土 [[麒麟崖]] | [[始麒麟]] | 压在崖下那条裂口上；每元会只有稳定期由族人代镇 | 分图·陆地 |

**统一画法（三处一致）**：

1. 每处一圈**极细浅金界线**（`#E8D9A0`，1px），界线之内是岗位范围，之外不画该族痕迹。
2. 界线上**不画旗、不画纹章、不画人影**——岗位不插旗。
3. 都不画建筑群：海眼只画一点微光、火山只画山口一格高亮、麒麟崖只画断崖接一道竖缝。
4. 界线之外的影响痕迹（海浪暗纹、焦土带边缘、干裂高地）画淡一档。
5. T1 起固定；T2–T4 只许改地貌，不许改这三处界线。

**为什么必须这么画**：盟约把三族从「争天下的一方」变成「三个岗位」。地图上若还画成三个王国，读者会一直等他们出手；画成三处岗点位，一眼就明白——**他们不是不出手，是不能动。**

## 六、「天倾西北、地陷东南」怎么画（T2 起统一改法）

| 画法 | 怎么画 | 读起来像什么 | 采不采用 |
|---|---|---|---|
| **A 倾斜** | 天带整体西北高、东南低，倾角 3–5°；西北留一处「下垂」（断柱塌下来的一小段）；同时**东南海平面抬高**，海水成压向东南的楔形 | 天往西北抬、水往东南灌；世界是「斜的」 | **采用** |
| B 破洞 | 天带水平，西北开一个人为豁口，天光漏下来 | 天幕被砸掉一块，像屋顶破洞 | 不采用 |

**为什么不用 B**：破洞会把「天倾」读成「天塌」，还会引出「洞里为什么不往外掉东西」这类收不了尾的问题。断的是**柱子**，不是天幕。

**A 的落地参数**：

- 天带左上角比右上角高约 **4%** 画高，形成自左上向右下缓降的斜线。
- 斜线在西北（不周山原址）有一处约 **2% 画宽**的下垂缺口，缺口内是断裂柱体截面（深灰岩层＋不规则断口），**不画云、不画光柱**。
- 海平面：东南比西北高约 **3%** 画高，海水沿四洲裂缝向内渗入，成楔形浅色水带。
- 四部洲按真实纵广反推：北俱芦洲 40 / 东胜神洲 36 / 西牛贺洲 32 / 南赡部洲 28（万里），按「大陆总宽占 70%」分配像素宽度。
- 颜色不变；倾斜只改**位置与角度**，不改配色。

**用在哪**：总图 T2–T4（画天带倾斜与海面楔形）；分图·陆地（画裂缝与楔形水带，但不画天带）；分图·天上（画天带的倾斜剖面）。

## 七、标注清单（按图分组）

### 7.1 总图（T0–T4）只标这些

最多 8 个地名：古大陆／四部洲（或环海）／不周山／昆仑／东海（或环海）／幽冥／域外／天河。**其余一律下沉**。

### 7.2 分图·陆地

- **四极**（[[女娲补天]] 断鳌足所立）：四角各一根**临时支撑**，柱头完整，不与大陆相连，比天柱矮。与正中断柱区分：断柱要画**截面**。
- **不周山残址与炼石炉**：断柱脚下画**炉址**（石台、鼎痕、五色残渣细点），炉已冷。
- **共工撞山点**：断口朝**西北**，画在山体西北侧崩口，不是山顶缺一块——柱子从中段折断，上半截倒向西北。
- **巫族旧地**：画成「无主的空地」，不画废墟（巫族没有城，只有驻地），只画兽道与残存图腾柱。
- **夸父倒地处**（[[夸父逐日]]）：黄白多边形龟裂高地、缝里无草，与射日的九片焦土区分：**焦土黑而硬、有玻璃化裂纹；干裂高地黄白而碎。**

### 7.3 分图·天上

- 天河两岸三层浅金罡气，弱水本体近黑且**不反光**。
- 星辰带只标紫微、北斗、太阳、太阴、勾陈五个，其余 360 个点不标名。

### 7.4 分图·幽冥

- 十二站按流向自上而下排，**每一站都在减少选择**，所以图上只画「站与站之间的连线」，不画岔路。
- 十八层地狱画在主干道侧边，与主线**不连通**（它独立于轮回之外）。
- 血海只画一条虚线连到主流程，阿修罗道口开在血海内侧。

### 7.5 分图·域外

- 门的四个状态并排四格（关闭／开缝／全开／重闭），因为「门的开合」是域外唯一会变的东西。
- 紫霄宫只画轮廓剪影：它是域外唯一有形的建筑。
- 柳庭只画垂丝纹理：无门无墙无匾，画上就说明「这不是一个可以走进去的地方」。

## 写作约束

1. **总图不许画地标**：一画就挤，一挤就回到「全塞一张图」的老问题。
2. **分图不许跨层**：陆地分图不解释天上，天上分图不解释地下。
3. **每一章只改一张图**：改总图的是「时代变了」，改分图的是「这一层多了个地方」。
4. 新增一个地标，先问「它在哪一层」，再问「要不要拆四大洲」，最后才动图。
