# 十绝阵图

> 一句话：**它不是阵，是次序——十座阵怎么轮，谁拿着图，谁定下一座开哪一座。**

## 一、图与阵的区别

[[十绝阵]] 是十座阵；**十绝阵图是「怎么排」**。

| | 阵 | 图 |
| --- | --- | --- |
| 是什么 | 一个地方（布好就固定在哪儿） | 一个次序（决定下一座开哪个） |
| 谁定 | 布阵的人 | 拿图的人 |
| 破了会怎样 | 那一座失效 | **十座同时乱** |

所以截教真正的家底不是那十座阵，是这张图：**十座阵谁都会布，轮着用的次序只有一张。**

## 二、为什么要轮

截教在封神那两阵里从来没打算打赢。

打不赢，就只能拖。而「拖」的技术问题只有一个：**同一座阵连开三天，就被人摸熟了。**

次序按「拖什么」排：先拖体力、再拖耐心、再拖判断、再拖心性、最后拖名声。排在前面的阵伤人，排在后面的阵逼人自己先动。这不是布阵的次序，是**被消耗的次序**——所以阐教能撑到最后才崩。

于是需要轮：一天一换、三天一小轮、九天一大轮。图就是用来记这个的——不是记阵怎么布，是记**什么时候该换、换哪一座、换的时候哪一处会露空**。

它也不是谁私藏的：布阵那天由通天当众交给十个阵主，一人一页。所以它不神秘——它更像一份公文。而公文是会缺页的。

## 三、破阵的真正方式是断次序

打碎一座阵没有用：下一座照开。

所以每破一阵必须**杀阵主**。杀的不是战力，是「下一阵该开哪座」的那个决定——阵主一死，图上的次序就断了一节，后面几座阵等不到指令，会自己开、自己乱。

**十绝阵在史书里写成「十阵」，其实只轮了不到十轮就乱了。** 乱的开始，是第一个阵主死掉的那天。

## 四、这张图后来去哪了

阵主死光之后，图留在截教。

它还在，纸也没烂，可**没人按它排了**——因为要按它排，得先凑齐愿意布阵的人，而愿意布阵的人已经不在了。

所以这张图后来只是「一件东西」：`册府` 不记它（它不是法宝），`截教` 也不再提它。**一张图失去用途之后，比一张废纸更像一张废纸。**

## 五、写作约束

1. 不写图上画的是什么符、什么纹；只写「翻到第几页」。
2. 破阵必须写成「杀阵主 → 次序断」，不许写成「找到阵眼打碎」。
3. 不许让任何人凭这张图翻盘——它的用途已经随人一起没了。
4. 十座阵的名字只在 `十绝阵` 那篇里列，本篇不复述表。
