# 姻缘

> 一句话：**姻缘是一根线的账，不是一本册的账——册上写「谁是谁的人」，线上写「谁认得谁」。**

## 一、它与「册」无关

这是本库最容易写错的一处，先分清：

| | 册（[[册府]]） | 线（本页） |
|---|---|---|
| 写什么 | 名分、位置、份例 | 谁与谁系上了 |
| 谁记 | 天庭、地府、佛门各自的册子 | 只有一个人记：[[月老]] |
| 能不能改 | 能（改一笔、划一笔、补一页） | **已成的不改**，断的只留疤 |
| 认不认人 | 认位置不认人 | 认人，不认位置也不认名分 |

**所以「册上是王妃」和「线是空的」可以同时成立。** 帝辛把 [[妲己]] 写进后妃册，只是把她放进了他那一栏；线要两端都系上才算——他没牵，牵不上，也从没打算牵。

反过来也成立：册上什么都没写的人，线可能早就系上了。

## 二、两根线，一条路

本库的姻缘只有两种成立方式，没有第三种：

1. **[[月老]]的红线**（常规路径）：一人一根，两端都系 = 成；只系一端 = **挂着**（这是「单身」的机制解释）。
2. **[[女娲]]的[[红绣球]]**（命定路径）：落中即天地认，线自断、簿记一笔；不落则不改任何东西。**至今一次没落**。

> 绣球那条路一直空着，本身就是设定：天地从没给过谁「命定的姻缘」。所有成双的，都是别人替他牵的、或者他自己求来的。

## 三、红线四条规矩

1. **一线一人**：一个人一根，不能同时挂两根（要挂第二根，先得把第一根断开）。
2. **两端才成**：一端系上叫「挂着」，两端都系才叫「成了」。挂着的人数远多于成了的人——这是洪荒的常态，不是例外。
3. **已成的线不改**：[[月老]] 自己也不能改。唯一能改它的是绣球落中（线自断）。
4. **断线留疤**：可断（外力断、自断都算），疤留一生、不消。重系要「赔」一样东西给月老（他从不说是哪一样）。

## 四、三种状态，三种读法

| 状态 | 线上是什么样 | 本库的说法 | 对原创层意味着 |
|---|---|---|---|
| 已成 | 两端都系 | 有归属 | **不可攻略**（褒姒、长孙皇后） |
| 挂着 | 只有一端 | 单身 | **可攻略**（妲己、西施、王昭君、赵飞燕、貂蝉、甄宓） |
| 断过 | 一端 + 一道疤 | 单身，但带「旧」标记 | 可攻略，关系档要带「旧」 |

## 五、写作约束

1. **不许让册决定姻缘**：任何人说「你名分在我这，你就是我的人」，都只是册上的话；线系没系上，得单独回答。
2. **不许写「姻缘天定」**：绣球一次没落，本库没有天定姻缘这一回事。
3. **不许让月老改已成的线**：他没有这个权限，天庭也没有。
4. 写到「成亲」时，先问一句：**线是谁系的？** 答不出来就是还没想清楚。

## 关系

- [[月老]]：唯一记这根线的人；[[红绣球]]：另一条至今空着的路。
- [[册府]]：册的体系（与线互不相干）；[[不在册]]：连册都没有的人，线照样可以系。
- 原创层接口：[[好感度]]（数值）、[[亲密关系]]（档位）、[[可攻略名录]]（准入）。
