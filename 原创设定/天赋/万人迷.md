# 万人迷

> 你不需要做什么，所有人就先喜欢你三分。

## 一、效果

| 项 | 值 | 说明 |
|---|---|---|
| 初始好感度 | **20** | 从没见过你的人，一见面就是 20（正常为 0） |
| 正向增速 | **×1.5** | 所有加分乘 1.5，向上取整 |
| 负向变动 | ×1（不变） | 得罪人不会变轻 |
| 上限 | 不变 | 仍然是 +100 |
| 衰减 | 不变 | 每 30 天仍回落 1 点 |
| 亲密阈值 | 不变 | 关系不会因此更早建立 |

**一次典型往来**：初见 20 → 帮一次忙 20+3 = 23 → 说错一句话 23-2 = 21。

## 二、代价（必须写出来）

1. **「先喜欢」会被读成「有意思」**。你没做什么，对方自己长出期待；期待落空时，掉得比涨得快（这一条不改数值，改的是对方的解读）。
2. **旁人看得见**。同一件事你做和别人做，旁人会说你会来事——于是你的功劳总有一半被记成脸。
3. **二十点是借款不是本金**。从 20 掉到 0，等于把「喜欢」收回去了；没有天赋的人从 0 开始，不会经历这种落差。

## 三、破法

- **看见真面目**：同一个人连续三次看到你做出与「讨喜」相反的事（当众拒绝、见死不救、算计熟人），初始 20 失效，此后按正常算。
- **对他无效**：无心的造物、机关、傀儡；以及「天庭」「妖族」这类复合体（它们没有好感度）。
- **已有记录不覆盖**：已经见过你的人不会因为你后来得了天赋就 +20；天赋只管「第一次」。

## 四、写法约束

1. 不许写成「所有人都爱你」——写「所有人一开始都愿意听你说话」。
2. 不许用它解围：它不改变判断，只改变态度；该杀你的还是杀你，只是会多问一句。
3. 必须演出「高开低走」的那种尴尬：别人比你先热，你接不住。
