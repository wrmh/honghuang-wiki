# 准圣

> 一句话：**准圣不是「快要成圣」，是「有一条自己的道、但那本账还没人认」。**

## 一、它在阶梯上的位置

见 [[修行境界]]：凡人 → 引气入体 → 炼气化神 → 炼神返虚 → 炼虚合道 → 地仙 → 天仙 → 玄仙 → 金仙 → 太乙金仙 → 大罗金仙 → **准圣** → 圣人。

准圣紧挨圣人，但**卡的不是修为，是记账**。

## 二、准圣与圣人的真正差别

| 项 | 准圣 | 圣人 |
|---|---|---|
| 有自己的道 | **有**（没有就成不了准圣） | 有 |
| 能影响规则 | 能影响一域 | 能立规则 |
| 被天道承认 | **没有** | 有（认领了一笔没人认的账） |
| 会不会死 | **会**（可以被打死） | 不会（可代偿不可抹除） |
| 能不能下场 | 能 | 不必下场 |

**差的那一步是「承认」，不是「力量」。**

## 三、为什么准圣这么多，圣人只有六个（外加一个换位的）

因为天道要的不是「谁更强」，而是**「谁把那笔没人认的账认下来」**。

六圣各自认了一笔：[[女娲]] 认了「受造之物该按什么标准活着」，[[太上老君]] 认了「名分由谁定」，[[元始天尊]] 认了「规矩由谁立」，[[通天教主]] 认了「没人给活路的谁来收」，[[接引]] 认了「接」，[[准提]] 认了「找」。

准圣们的道都成立，但**都不是一笔没人认的账**，所以卡住了。这不是运气差，是**名额本来就只有那几个**。

## 四、准圣的三种活法

| 活法 | 例子 | 结局 |
|---|---|---|
| 继续磨那条道 | [[冥河]]、[[镇元子]] | 永远不够，因为不缺他这一笔 |
| 用别的东西补（气运、法宝、编制） | [[帝俊]]、[[太一]] | 补到最后发现补的是别人的账 |
| 干脆不管，做自己的事 | [[红云]] | 死在自己让出去的位置上 |

## 五、准圣为什么是全书最惨的一档

- 有圣人的眼界，没有圣人的免死
- 有大罗的战力，没有大罗的退路（大罗可以不管事，准圣一旦退，道就散了）
- 一旦死，**道就断了**，跟凡人死没本质区别

[[十二祖巫]] 那一批全是这一档的证据：他们的道（血统）成立过，但没人认，所以他们**会死**。

## 六、写作约束

1. **不许把准圣写成「圣人的弱化版」**：他们的差别是承认，不是强度。
2. **不许准圣打赢圣人**：可以打到圣人「不得不代偿」，但杀不死。
3. **不许写「晋升圣人」的过程**：圣人不是升上去的，是被认领的（见 [[故事线]] 六圣成圣一节）。
4. 一个准圣出场，先写**他那条道是什么**，再写他打不打得过。
