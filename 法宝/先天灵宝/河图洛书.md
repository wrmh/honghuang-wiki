# 河图洛书

> 一句话：洪荒唯一一件**「算」出来的灵宝**——它不打人，它算。算得准的时候，三百六十五个星君能各就各位；算不准的时候，整座天庭一起崩。

## 能力

三件事，按重要性降序：

1. **推演周天**：把混沌中散乱的星辰排成可管理的秩序。没有它，星辰就只是光点；有了它，才有「周天三百六十五度」这个可被管理的数字。
2. **定方位**：[[周天星斗大阵]] 的阵图由它排。三百六十五个阵位、每个阵位接哪颗星，全靠河图洛书实时计算。帝俊主阵，实际是**在执行它的算果**。
3. **窥数**：短程预判。看得见「下一步」，但看不见「下一步之后」。

## 代价

河图洛书不消耗法力，消耗**确定性**。

- 每推演一次，就把一种可能性钉死。钉得越多，可选的路越少。
- 帝俊拒谈三次，底气和枷锁是同一个东西：河图洛书算出了「谈判必输」，所以他谈不了。**能算的代价，是不能不算。**

这是本书对这件法宝的核心处理：它不是增强器，是**提前消耗未来的机器**。用它越久的人，越难做出「不合算但仍然正确」的选择。

**「消耗确定性」长什么样**：不是头痛、不是吐血，是**决策变慢**。

具体的可观察表现（写帝俊时直接用）：

- 同一条战报要核对三遍才肯动，等核完，战机已经过去了。
- 越到后期越只信「算出来的」，不信「看不出来的」——近臣提出的判断若与卦象不合，他一律按卦象走。
- 巫妖终战那天他做的每个决定单独看都对，连起来看是「每一步都晚半拍」。

这就是代价的实体：**它不是夺走他的能力，是夺走他「敢不敢不算就动手」的那部分**。周天星斗之败，账要记在这里一部分。

## 克制

河图洛书有一个硬缺陷，而且正是巫族打中它的地方：

> **它只对「有结构的东西」有效。星图是结构，阵法是结构，军队是结构；一个没有结构、只有一具身体的对手，它算不出来。**

[[都天神煞大阵]] 召盘古真身，十二祖巫合为一物——那不是十二个目标，是一个。河图洛书能算出「十二个祖巫各在何处、如何逐个击破」，算不出「一个盘古下一步往哪砸」。

**这就是巫妖量劫胜负手的真实机制**：不是妖族变弱，是妖族的最强工具在对手面前直接失效。周天星斗大阵的精确性，遇上一个整体行动的对手，反而成了累赘——每一步都要算，算完已经被砸到。

## 仿制品为什么单独立不了条

后世仿制的河图洛书不止一件：材料、手法、成品的品阶各不相同，有的是玉片，有的是骨甲，有的干脆是画在纸上的图样。**它们不是「第二件河图洛书」，是各自另一件东西**。

所以本书不给仿制品立条目，只在需要时作为情节道具出现，且必须满足两条：① 明确说清「这是仿的」；② 仿品的一切能力都比正本低一档以上（算得慢、算得浅、要人喂数）。

正本只有一件，且永远只有一件。

## 与东皇钟的分工

| | [[河图洛书]] | [[东皇钟]] |
|---|---|---|
| 功能 | 算（排布、推演） | 镇（定序、压制） |
| 持有者 | [[帝俊]] | [[太一]] |
| 代价 | 消耗确定性，路越走越窄 | 消耗道行，气运越漏付得越多 |
| 失效条件 | 对手无结构 | 对手之力超过钟的镇压上限 |

两件合起来才是完整的妖族秩序：**算得准 + 压得住**。缺一件，天庭就退回散修集合。这也是为什么两位共主必须同进同退——分开就是两个残废。

## 来历与归属

**巫妖劫之后的归属**（裁决 2026-11-13）：巫妖劫结束、[[女娲]] 接任妖族之主后，她把本宝**借**给 [[伏羲]] 使用——借而非赠：宝属妖族，人属人族，这层「借用」正是巫妖→封神的关键接口。

伏羲身后，本宝归还妖族，随女娲隐于三十三天外，封神劫不再出现（本书自定，与 [[巫妖量劫]] 结局一致）。所以封神里若有谁拿出「河图洛书」，那不是本书的正本。

开天瞬间成形，与 [[东皇钟]] 同批落定（[[开天辟地]] 一节），但**不是神斧碎片**，是开天时「数」这一层被分离出来时自己凝成的。[[龙汉初劫]] 后分宝岩分配，归妖族，由帝俊持有并录入天庭制度——**它从一件法宝变成了国家机器的一部分**，这是妖族与其他势力最大的不同。

太一陨落后下落不明（见 [[太一]] 未定稿问题）。本书暂定：随天庭倾覆散佚，后世出现的河图、洛书为残卷摹本，不再具备推演周天的完整能力。

**出身补一句**：它是 [[混沌青莲]] 的一片莲瓣所化（系列：先天，四十道）。这解释了它为什么「只算有结构的东西」——莲瓣是青莲最外层的那一圈，管的是**形**，不管**实**。
