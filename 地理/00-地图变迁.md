# 地图变迁

> 一句话：洪荒的地图不是背景板，是**五次事故的现场照片**。每一劫都在上面留下了一道改不掉的痕。

## 这份文件怎么用

1. **要画图**：直接复制每节的「生图提示词」到任意 AI 绘图工具（Midjourney / 即梦 / SDXL 都行），五张图共用同一套「通用约定」，所以五张能拼成一条时间线。
2. **要查方位**：看每节的「元素表」，方位词一律按「上北下南」。
3. **要查某个地方哪年出现、哪年没了**：看文末「地名总表」。

## 通用约定（五张图必须一致）

| 项 | 规定 |
|---|---|
| 画幅 | 16:9 横构图，1920×1080 |
| 视角 | 正上方略斜俯视（约 30°），**不用透视灭点**，保持类地图感 |
| 方位 | 上北下南左西右东，四角有方位罗盘 |
| 构图 | 竖向三段式：上缘 12% 为「天界示意带」，中部 76% 为「地表」，下缘 12% 为「九幽示意带」 |
| 比例 | 大陆占中部宽度 70%，环海占 30% |
| 地表色板 | 土黄 `#C8B08A`、灵脉青绿 `#7FD1C1`、焦土 `#6B4A3A`、凶兽荒野 `#8C8577` |
| 海色板 | 深海 `#2E5C7E`、浅海 `#4A8FAE`、被淹古陆 `#1F4459` |
| 天界色板 | 半透明蓝紫 `#8FA9D9`（40% 不透明度） |
| 九幽色板 | 紫黑 `#2A2233`，血海 `#7A2B33` |
| 标注 | 白描细线（1px）、深色描边、`#F2E9D8` 字形，地名用中文，字号统一 |
| 风格 | 手绘古籍地图 + 现代信息图混合：留白多、线条细、无写实材质 |
| 禁忌 | 不画人物、不画文字漩涡、不画夸张光效、不用写实卫星图质感、不加伪英文标注 |

**变化表达法**：同一帧里，本时点**新增**的东西用亮线勾边，**消失**的东西用虚线残影 + 小字「已毁」，**改变**的东西在旁加一个 `↳` 注释。这样五张图并排看，就是一条干净的演化链。

## T0 开天初成（[[开天辟地]] 之后）

**格局一句话**：一整块大陆，一根柱子，一圈海，天只有一层，地下是空的。

| 元素 | 方位 | 相对大小 | 状态 |
|---|---|---|---|
| 古大陆（未分裂） | 正中 | 占中部宽度 70% | 完整，无裂缝 |
| [[不周山]] | 大陆正中 | 高度画成「顶到天带」的一条竖柱 | 撑天，通天 |
| [[昆仑]] | 正中偏西 | 大陆内一处高亮山结 | 龙脉之源，尚无宫观 |
| 环海（四海未分） | 环绕大陆一圈 | 环带宽 30% | 完整闭环，无海眼 |
| 天（一层穹顶） | 上缘天带 | 单层薄带，无分层 | 完整，可用 |
| 九幽 | 下缘九幽带 | 一片无结构暗区 | **空腔**，有死气无秩序，未成「界」 |
| [[域外]] | 画面四角之外 | 不画，只用边缘一圈暗雾示意 | 混沌，不入图 |

**生图提示词**

> 古籍风格世界地图，16:9 横构图，正上方 30 度斜俯视，无透视灭点。竖向三段式：上缘 12% 为半透明蓝紫色天穹薄带（单层、无分层线），中部 76% 为土黄 #C8B08A 的一整块完整古大陆，下缘 12% 为紫黑 #2A2233 的无结构暗区。大陆正中央立一根直通天带的石柱（不周山），柱身有细密刻痕，柱顶接触天带；大陆正中偏西有一处青绿色 #7FD1C1 发光山结（昆仑），自山结向东北、南、北各延伸一条细发光脉络（龙脉）。大陆外围是一整圈完整闭合的深海 #2E5C7E 环带，带宽约占画面 30%，环带中有均匀的浅海 #4A8FAE 过渡。四角各有一枚小罗盘与方位字「北 南 西 东」。地名白描细线标注，字色 #F2E9D8。画面留白多，线条细，无写实材质，无人物，无光效爆炸。

## T1 龙汉之后（[[龙汉初劫]] 之后）

**格局一句话**：地图整体没变，只在西边烧出了一道口子——而那一道口子决定了后面三劫的全部走向。

| 元素 | 方位 | 变化 |
|---|---|---|
| 古大陆 | 正中 | 不变（尚未分裂） |
| 西方灵脉断口 | 大陆西部 | **新增**：一条自西北向西南的焦土带 `#6B4A3A`，脉络在此处断裂发黑 |
| 西方焦土区 | 西部三分之一 | **新增**：土色由黄转灰褐，灵气脉络消失 |
| 分宝岩 | 焦土带东侧边缘 | **新增**：一处孤立岩台，岩上无光 |
| 其余区域 | —— | 不变，气运脉络在别处反而变粗（气运总量恒定，西方漏掉的从别处溢出） |

**生图提示词**

> 沿用 T0 全部构图、视角、色板与三段式比例。唯一变化集中在西部：自西北向西南横贯一条宽约大陆宽度 1/4 的焦土带，颜色 #6B4A3A，纹理干裂；原本通向该带的青绿色 #7FD1C1 灵脉在此处齐齐断裂，断口发黑并晕开。焦土带东侧边缘有一处孤立浅灰岩台（分宝岩），岩台无发光。焦土带以外的大陆其余部分灵脉变粗变亮（用加粗的 #7FD1C1 发光线条表现），与西部的枯败形成对比。云层与光效一律不加。地名标注在焦土带边缘加一行小字「灵脉已断」。整体仍是同一张地图，只换西部一块。

## T2 巫妖之后（[[巫妖量劫]] 之后）

**格局一句话**：柱子折了，大陆裂成四块，海漫上来，地下第一次有了「界」。

这是全部五张图里变化最大的一张，也是**只有这一张需要重画大陆轮廓**。

| 元素 | 方位 | 变化 |
|---|---|---|
| [[不周山]] | 原大陆正中 | **已毁**：画成折断的残柱，上半截倒在西北方，柱基周围是放射状裂谷 |
| 古大陆 | —— | **已分裂**：沿龙脉裂为四块（见下），四块之间是深不见底的裂缝（画成黑色断层线） |
| [[四部洲]] · 东胜神洲 | 东 | 新：灵气最盛，青绿脉络最密 |
| 四部洲 · 南赡部洲 | 南 | 新：土黄为主，脉络稀，村落纹理密集 |
| 四部洲 · 西牛贺洲 | 西 | 新：含 T1 的焦土带，整体灰褐，只有极少数脉络 |
| 四部洲 · 北俱芦洲 | 北 | 新：灰白荒野 `#8C8577`，无脉络，点缀兽形阴影（不画具体动物） |
| 四海 | 外围 | **扩张**：海面向内推进，环带由 30% 增至 38%，古海岸线用 `#1F4459` 画出被淹的浅色残影 |
| 天 | 上缘天带 | **倾斜**：天带整体向左（西）倾斜约 3 度，天带上出现一道由上向下的裂口对应折柱 |
| [[东海]] 海眼 | 东海最深处 | **新增**：一处漩涡状深色圆眼 |
| [[幽冥]] | 下缘九幽带 | **成界**：暗区第一次出现结构——一条暗河（黄泉）、一片红色 #7A2B33 侧海（血海）、中央一座发光台（轮回台） |
| [[昆仑]] | 西牛贺洲与南赡部洲之间的脊线 | **位移感**：不再是大陆正中，而是两洲分界的高处 |

**生图提示词**

> 沿用 T0 的视角、三段式构图与色板，但大陆轮廓改为四块。正中偏北为折断的石柱残基，上半截石柱倒向西北、断口粗糙；残基四周是放射状黑色裂谷。四块大陆沿裂缝分开，裂缝为纯黑断层线，宽窄不一，走向沿灵气脉络。东侧大陆青绿 #7FD1C1 脉络最密（东胜神洲）；南侧大陆土黄为主、脉络稀疏、点缀细小聚落点（南赡部洲）；西侧大陆整体灰褐并含一条焦土带（西牛贺洲）；北侧大陆灰白 #8C8577 无脉络、有模糊兽形阴影（北俱芦洲）。外围深海环带由 30% 扩至 38%，大陆边缘有一圈更暗的 #1F4459 带状残影表示被淹的古海岸。上缘天带整体向西倾斜约 3 度，并在折断石柱正上方出现一道竖向裂口。东侧海域最深处画一个深色漩涡（海眼）。下缘紫黑九幽带第一次出现结构：一条暗河、一片 #7A2B33 红色侧海、正中央一座发光圆台。地名标注用「↳ 已毁」标注不周山。禁止写实灾难插画风格，保持地图感。

## T3 封神之后（[[封神量劫]] 之后）

**格局一句话**：地面格局不动，天上被封死了——地图第一次出现「不能去的地方」。

| 元素 | 方位 | 变化 |
|---|---|---|
| 四部洲 | —— | 不变（T2 轮廓沿用） |
| 天带与地面之间的通道 | 折柱正上方 | **已封**：T2 那道裂口被一道横向封条覆盖（画成一条横贯天带的暗金细线） |
| [[三十三天]] | 上缘天带 | **分层**：原本单层薄带改为可见的细横线分层（约 6–8 条细线示意 33 重），第三十二重有一条高亮短线（玉京所在） |
| 天庭 | 天带内 | **新增**：天带中一处小型宫殿群符号 |
| [[昆仑]] | 两洲分界脊 | **新增**：山腰一处宫观符号（玉虚宫） |
| [[幽冥]] | 下缘九幽带 | **新增**：入口变多——地表与九幽带之间出现数条虚线连接（原来只有一条） |
| 人间 | 南赡部洲 | **新增**：聚落点更加密集（人族扩张） |

**生图提示词**

> 沿用 T2 的大陆轮廓、裂缝、四海扩张与下缘九幽带结构，不改变任何地面地理。上缘天带改为可分辨的细横线分层（6 至 8 条极细横线，暗示三十三重叠加），天带中部偏西出现一组小型宫殿群符号，第三十二层位置用一条亮色短线标出。T2 中折柱正上方的竖向天裂口被一条横贯天带的暗金色细线封住，画成「封条」形态。地面与天带之间不再有任何向上的连线。地表新增两类细节：昆仑所在的分界脊上出现一处宫观符号；南赡部洲聚落点密度明显最高。下缘九幽带中，地表与九幽之间原本一条连接改为五至六条细虚线。整体仍是同一张地图的「只增不改」版本，禁止出现升天光柱等特效。

## T4 西游定型（[[西游量劫]] 之后）

**格局一句话**：格局定型，此后不再变。四块地、两处不能去、一条从西往东的路。

| 元素 | 方位 | 变化 |
|---|---|---|
| 四部洲 | —— | 定型，轮廓不再变 |
| 西牛贺洲 | 西 | **已恢复部分**：焦土带边缘出现新生细脉络（佛门东渐带来的灵气回流） |
| 东胜神洲 | 东 | **已边缘化**：脉络依旧最盛，但无势力符号（无人重建秩序） |
| [[幽冥]] | 下缘 | 定型：结构完整，血海与轮回台的边界线清晰 |
| 三十三天 | 上缘 | 定型：分层固定，封条仍在 |
| 路线 | 自西向东 | **新增**：一条自西牛贺洲东部穿过裂缝、横贯南赡部洲、指向东胜神洲的细虚线（佛门东渐的路线，非道路） |

**生图提示词**

> 沿用 T3 全部构图与分层天带、封条、九幽结构与四洲轮廓。唯一新增：西侧大陆的焦土带边缘出现数条极细的青绿色新生脉络（自东向西渗入）；自西侧大陆东部起，穿过裂缝、横贯南侧大陆、指向东侧大陆，画一条细虚线（点划线），虚线不加箭头以外的装饰。东侧大陆保持脉络最密但不加任何建筑或势力符号。下缘九幽带中，红色血海与中央发光圆台之间加一条细边界线。整体色调比 T3 略回暖（西部焦土区颜色由 #6B4A3A 提亮到 #7A5747）。保持地图感与留白，禁止添加人物、取经队伍、云彩、光晕。
