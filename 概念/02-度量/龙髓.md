# 龙髓

> 一句话：**它是龙脉在最好的时候掉下来的那一节骨头——盛世的髓，乱世才用得上。**

## 一、它是什么

[[龙脉]] 长到九里以上，脉眼外侧会慢慢结出一节硬物，色如旧玉、纹理顺着脉走，敲之有声。

按本库的取名：不叫「结晶」叫**髓**。理由是它像牙、像骨刺——**长在活物上、掉下来是脱落、不是产出**。所以它是「掉了什么」，不是「挖出什么」。

一个人间说法叫「龙髓石」，因为落地之后像石头；正式名只叫龙髓。

## 二、它怎么来的

| 环节 | 规矩 |
|---|---|
| 何时结 | 脉长 ≥9 里，约**百年一节** |
| 长在哪 | 脉眼外侧，不在地表——要开山才看得见 |
| 谁去采 | **盛世没人采**：采它等于承认它会断，是忌讳；所以库存多是别人替你存的 |
| 脱落 | 脉一旦掉到 8 里以下，髓**不再生长**；已有的髓不坏，但也不会再有第二节 |

所以最残忍的一句话是：**有髓的皇朝，往往已经不在了。** 髓留在山里的那段，后来归了别人。

## 三、怎么用

1. **同脉之髓**才有效：只能插回自己那一段龙脉的脉眼。
2. 异脉之髓**排异**：脉不长，反而缩一里——这是盗髓者常犯的错，也是本库最省事的惩罚。
3. 嵌进去即**化**，不可再取。
4. 修的结果：一节髓修 **1–2 里**——足够把断脉从 0 救回「**可维持**」（1–2 里），**修不回鼎盛**。
5. 代价不当场付：修完的十年内，脉会**掉得比原来快**（等于提前用了明天的年成）。

## 四、谁知道这件事

- **钦天监与工部**：知道脉眼在哪，但**不公开**——公开等于告诉别人怎么断。
- **[[地府]] 的东岳一系**：不传这件事，只记「某年某地开过一次山」。
- **[[佛门]] 的香火院**：不碰龙脉，因为「替人算命数」与「替人记香火」不能兼。
- **散修与江湖**：只信传说，多半挖错地方，白毁一段山。

## 五、写作约束

1. **不许把它写成力量来源**：龙髓不能吃、不能炼、不能随身带出战场，它只能修脉。
2. 一颗髓只能救一朝**一次**——同一朝用第二颗，要写清代价（掉得更快）。
3. 抢髓的戏要写「运输」：它不能放进储物袋里随便带（脉髓离脉会「失水」，重量逐年增），所以运髓是漫长、笨重、可被截的事。
4. 不许写成「得髓者得天下」——它只续命，不长气。
5. 结局两种：**救了但再也回不去**（多数），或**救不回**（髓插进去、脉还是断，因为民心已经没了）。
