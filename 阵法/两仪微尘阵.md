# 两仪微尘阵

> 一句话：**它不杀人，它把人放在错的那一半——进来的人永远差半步。**

## 一、它是什么

阐教用来守门的一座阵，`太乙真人` 布过。

它做的事只有一件：**把一段地方分成两半**——两仪。人走进来，只落在其中一半里；阵的另一半，就在他旁边，与他隔着一层看不见的缝。

**阵里没有杀伤。** 走进去不流血、不受伤、不迷路；只是每一件想做的事，都差半步。

## 二、为什么难破

不是强度问题：

| 一般阵的破法 | 这一座阵 |
| --- | --- |
| 找到阵眼，打掉它 | 找到了也没用：阵眼就摆在那条缝上，看得见，跨不过去 |
| 用更大的力硬打 | 你打的那一半，不是他站的那一半 |
| 一一对应地破 | 你每动一次，**错位就重新分一次** |

所以它最磨人的地方不是「打不过」，是**每一次出手都对，却都不是这一次该对的**。

## 三、破法：不破阵，破「分」

唯一有效的办法是让两半**重合**：

1. 两个人同时从两边进——各站一半，那一瞬间缝就合上了；
2. 或者有一个能**同时站在两边**的人（本书里这种存在极少，且都不属于阐教之外）；
3. 或者让它自己散——它靠「分」维持，分到极细（微尘）就散了，但散之前没人等得到。

第二条与 [[太极图]] 是同一个道理：**能「分」的东西，只有能「合」的人治得住。** 太极图分的是「一切」，这座阵借的正是同一个字。

## 四、三条硬规矩

| 规矩 | 破了会怎样 |
| --- | --- |
| 只守不攻：阵里没有任何杀伤 | 一旦能伤人，它就变成杀阵，阐教守门的分寸也就没了 |
| 不能移动：分是钉在地上 | 能搬走的阵就是法宝，不是阵 |
| 阵眼在那条缝上：看得见，跨不过 | 阵眼不是弱点，是这道阵的**边界本身** |

第三条决定了它的用法：**它守的是「一段路」，不是「一个人」。** 所以它常被用来封住一个不该出去的人，而不是用来困住一个该被抓的人。

## 五、写作约束

1. 不写阵中打斗的华丽：写**差半步**的重复——每一次都像第一次走。
2. 不写「阵破了」的爆裂场面：它散起来像尘落，不像它破。
3. 阵内时间感要写成「每一步都是新的第一步」：因为每次错位都重新分一次，走过的路不算数。
4. 不写被它困住的人发疯、绝望：它的可怕在于**让人一直觉得自己差一点就行**。
5. 与 [[诛仙阵]] 对照着写：那边是「规则不通用」，这边是「位置不通用」——都不是靠力气破的。

## 六、关系

- 布阵者：[[太乙真人]]（阐教守门）
- 同源：「分」这一面，见 [[太极图]]
- 对照：[[诛仙阵]]（规则不通用）、[[十绝阵图]]（次序断一节阵自乱）
- 上下游：封神量劫中用于封锁，不出战
- 性质：**守门阵**，不是杀阵

- [ ] U-546 那两半分的是什么？
  - A 阴阳：一半属阳、一半属阴，所以活人只走阳那一半，死物落阴那一半
  - B 在册／不在册：一半是册子上写得出来的，一半是写不出来的——所以被它困住的人，出来之后常常「查不到」
  - C 活／死：一半是给还活着的，一半是给已经死了的；跨错一步，人就在那一瞬间既不算活着也不算死了
- [ ] U-547 阵眼有没有人守？
  - A 没有人：阐教不设守阵人，因为阵眼本身就是缝，谁靠近就跨不过去
  - B 有：`太乙真人` 的弟子守在一旁，只负责「报」，不负责「打」
  - C 阵眼是一口井：井里是另一半的样子，谁往里看一眼就会站到另一边去
