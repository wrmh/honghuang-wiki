# 盘古

> 一句话：他不是英雄，是**一次性的工程机械**——开天、撑天、然后成为天地本身。洪荒所有的资源分配，都是他尸体的分配。

## 来历

生于混沌之中，是[[混沌魔神]]里唯一一个「不满足于在混沌里活着」的存在。其余魔神把混沌当作居所，只有他把混沌当作材料。

他没有师承。洪荒后来的一切道统（三清、[[鸿钧]] 一脉）追溯上去都到他这里就断了——**他是全库唯一一个没有来处的人**。

## 立场与诉求

- 要什么：一个「有上下、有始终」的世界。这是他和所有其他魔神的根本分歧。
- 怕什么：虚无。混沌里没有时间，也就没有「发生过什么」，活着等同于没活过。
- 与谁对立：[[混沌魔神]]。他们要维持混沌，他要终结混沌。

## 在量劫中的作为

- **持斧开天**：一斧分清浊，天地始分。这是全库唯一一次「直接修改物理层」的操作。
- **撑天一万八千年**：天地有合拢之势，他以身体撑住，天日高一丈、地日厚一丈、他日长一丈。撑到定型。
- **力竭身殒**：不是被杀，是耗尽。这一点很重要——**没有敌人能杀盘古，只有开天这件事能杀盘古**。
- **身化万物**：见下节。他死后没有「遗产纠纷」，因为他的遗产就是整个世界。

## 身殒化万物（资源分配表）

**① 死后没有残念**（裁决 2026-11-13）。盘古死得干净：元神化三清、精血化 [[巫族]]、脊梁化 [[不周山]]、双目化日月、呼吸化风云——**全部一次性分配，不留意志、不留执念、不留复活伏笔**。

这条是硬约束：全书不允许出现「盘古残念苏醒」「盘古意志考验某人」这类桥段。一旦允许，开天这件一次性事件就会被稀释成连续剧，而「开天」之所以重，正因为它不可重复。

顺带划清一条界线：[[罗睺]] 一线处理的是「盘古开天时被删掉的那个状态」，**不是**「盘古遗产」。两者别混。

**② 开天神斧的来源：混沌中天然生成**（裁决 2026-11-13），不是盘古炼的。斧先于盘古存在，盘古只是「拿得动它的那一个」。这也解释了斧碎之后为什么能变成三件至宝（见 [[混沌至宝]]）：它本来不是被造出来的东西，所以也不按「造物」的规则碎。

这一步是全库最硬的一次性设定，后续四劫的所有「资本不均」都从这里开始：

| 身体部分 | 化为 | 谁因此获得资本 |
|---|---|---|
| 脊梁 | [[不周山]]（天柱） | 无主，后被 [[共工]] 撞断 |
| 元神 | 三清：[[太上老君]]、[[元始天尊]]、[[通天教主]] | 道门（继承「解释权」） |
| 精血 | [[巫族]] | 巫族（继承「肉身」） |
| 双眼 | 日月 | 妖族（占据星空，后成 [[妖族天庭]]） |
| 血液 / 肌肉 / 毛发 | 江河 / 田土 / 草木星辰 | 万族（继承「地」） |
| 开天神斧（碎） | 太极图 / 盘古幡 / 混沌钟（[[东皇钟]]） | 三清二件、妖族一件（继承「法宝」） |

**这张表就是洪荒的不平等条约**：巫族拿肉身、妖族拿法宝与星空、道门拿解释权，谁都没拿到全部。任何一族的崛起，都是在这张表的缝隙里长出来的。
