# 小周天阵

> 一句话：**它不是一座阵，是一班人——阵没坏，只是人没到齐。**

## 一、它是什么

天庭照着妖族天庭的 `周天星斗大阵` 重制的简化版。

原阵要三百六十五位星君，一位守一个星位，少一个就露一处空；天庭凑不出三百六十五个能打的，于是按 `二十八宿` 的格子重制：**二十八人，一人守一宿，阵转一圈是一月。**

| | 周天星斗大阵 | 小周天阵 |
|---|---|---|
| 人数 | 365 | 28 |
| 阵眼 | `东皇钟`（固定，在中心） | 无固定阵眼：**阵眼随当值的那一宿移动** |
| 怎么算在阵里 | 星位对上就行 | 人要**站上去**，站上去才算 |
| 散了怎么补 | 补一个人 | 补不上：人不是星，不能替 |

它是本书里第一座**活阵**：前面几座（`诛仙阵`、`九曲黄河阵`、`两仪微尘阵`、`十绝阵图`）都是「摆在哪儿就在哪儿」的死阵，靠的是规则与位置；这一座靠的是**人在场**。

## 二、它真正在管什么

它管的是「天庭到底能不能打」这个问题——而答案是：**能摆出来，摆不出来多久。**

- **要人手。** 二十八个人各站一宿，站上去阵才转；缺三个人，阵转不满一圈，自己就散了。
- **要能打的人。** `斗部点兵` 的结论是「位全，能战者半」：位子都有人，能打的一半不到。小周天阵照着二十八宿的名册叫人——来的是**位置上的人**，不是**能战的人**。
- **阵眼会动。** 当值那一宿就是阵眼，所以破阵者找不出「打哪儿一下就行」的那个点：打完这一处，阵眼已经挪到下一宿。

所以它的实战记录很难看：**启阵六次，撑满一圈的一次也没有。**

## 三、三条硬规矩

| 规矩 | 破了会怎样 |
|---|---|
| 不能替位 | 谁也不能替别人站：站着的那一位不是「位置」，是那个人 |
| 不能连值 | 一个人顶两宿，阵会「卡」在中间转不动——**亮度够、进度不够** |
| 启阵必须报 | 启阵要报 `斗部`，因为一旦散在半圈，那半圈的星位会跟着错乱一整月 |

## 四、写作约束

1. 写「到齐没有」比写「打得怎样」重要：这一座阵的戏眼在点名。
2. 不写阵光冲天的壮观：写二十八个人站在各自的石台上，有人手抖、有人喘。
3. 散阵要写得难看：不是轰然崩塌，是一处一处暗下去，像灯油烧完。
4. 不写它打赢过：它能撑住的最长一次，是撑到第十四宿。

## 五、未定稿问题

- [ ] U-576 二十八宿里那几位「不能战」的，天庭为什么不换？
  - A 换不了：位是封神榜上填的，换位要走 `封神榜签押`——条款不能改，宁可位错着
  - B 换过，换上去的更差：试过三次之后，斗部不再提
  - C 不能换的只有三个，其余都是兼位（`公器` 那条：兼位的人能同时管两件）
- [ ] U-577 小周天阵散在半圈，那半圈会怎样？
  - A 会错：那一月的星位与历法跟着偏，`星部` 要花一个元会校回来
  - B 不会错：散阵只是人散了，星位归 `星部` 管，与阵无关
  - C 会错一点点：偏的是「当值」，不是星位——所以错的是值班表，不是天
