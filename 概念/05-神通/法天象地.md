# 法天象地

> 一句话：**它不是变大，是换尺子——把「一个人」按「一座山」来量，于是山成了台阶。**

## 一、它换的是单位，不是大小

外面常说「法天象地就是变高变大」。在这本书里不是。

| | 普通战斗 | 法天象地 |
| --- | --- | --- |
| 按什么算 | 一个「人」 | 一段「地形」 |
| 山是什么 | 障碍、屏障、可以搬 | 台阶、垫脚石、可以蹬 |
| 一条河是什么 | 天险 | 一条线 |
| 谁打谁 | 人对人 | 地形对地形 |

**所以它真正的动作是：把自己从「人」那一栏挪到「地形」那一栏。**

这也解释了它为什么看起来那么夸张：不是他变强了，是**量他的那把尺子换了一把**。

## 二、战场上为什么几乎没人用

换了尺子，双方的招式同时失效：

- 他打不着人——人太小，在那个单位上不成立；
- 人也打不着他——人太硬，被算成了地形的一部分；
- 于是两边都在打「不存在的东西」。

所以法天象地只出现在三种场合：**拆城、挡水、搬山**。它不是用来杀人的，是用来改地形的。

谁在战场上用它，谁就是在说：**这一仗我不打算按人的规矩打。**（这句话在洪荒里是很重的表态。）

## 三、代价：出来时要记得自己原来多大

换尺子容易，换回来难。

换回来只需要一件事：**记得自己原来多大**。

记不住的人，就回不去了——不是变不回来，是**不知道该变回多少**。他会一直以那个单位存在，直到被别的东西按地形算进去：一座无名的山、一段隆起、一片「还在长的地」。

这也接上了 `太岁动土` 那一笔：地脉册只写「**已成的形**」。这些回不去的人，正是「已成的形」里最说不清的一类——他们不生、不长、不裂，只是在那里，占着一个位置。

## 四、谁能用，谁不需要用

- **大罗金仙以上**：能换，但要付上面那个代价。
- **十二祖巫**：不需要换。他们本来就在那个尺子上——祖巫出手不是「变大」，是**一直就那么大**，只是平时收着。
- 这也是巫族看不起人族修士的一个理由：**「你们得先把自己变成另一样东西才敢打。」**

## 五、写作约束

1. **不写「金光万丈、顶天立地」**之类的变身描写。写**参照物的变化**：山矮下去了、河变细了、云在他腰上。
2. 每次使用必须写明用途（拆/挡/搬），不许用来单挑。
3. 不写「变回来以后毫发无伤」——换过一次的人，此后看东西会先看「它多大」，这是留下的毛病。
4. 不许出现「法天象地 + 其他神通叠加」的写法。
5. 回不去的人只以地名出现，不给名字、不给回忆。
