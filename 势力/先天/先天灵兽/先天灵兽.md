# 先天灵兽

> 一句话：与洪荒凶兽同源不同命——凶兽是「跑出来的」，灵兽是「留下来的」。

## 是什么

开天之后自然化生的第一批兽类里，分出去两支：

| | [[洪荒凶兽]] | 先天灵兽 |
|---|---|---|
| 来源 | 混沌魔神逃入天地者，带混沌之气 | 天地自生，无混沌之气 |
| 本性 | 破坏性，见活物就吃 | 中性，不主动攻击 |
| 与势力关系 | 不入编制，谁都不认 | 可被借力、可被托付（但不能被「收编」） |
| 结局 | 被镇压、被驱逐 | 大多融入山河，成为地理的一部分 |

一句话区别：**凶兽是敌人，灵兽是基础设施。**

## 三条判据：什么才算先天灵兽

不是「长得好看的兽」，也不是「没有主的兽」。三条同时满足才算：

| # | 判据 | 反面（不算） |
|---|---|---|
| 一 | **天地自生，不带混沌之气** | [[洪荒凶兽]] 是混沌魔神逃入天地时带进来的，带气，所以算凶兽 |
| 二 | **不入族、不入册、不认主** | 认了主的算坐骑或家神；聚成族、认了名分的算妖 |
| 三 | **只在需要的时候出现一次** | 反复露面、参与战事的，已经被人当兵用了，算妖或算神 |

判据的对齐说法：**凶兽是被赶进来的，灵兽是自己长出来的，妖是后来愿意站队的。**
同一片天地里长出来的东西，只因为「认不认编制」分了三种命。

## 它们在第一元会里做什么

第一元会的三族还没有共同的规矩（见 [[洪荒初生]]：无册、无位、无欠条），灵兽在这个空白里各留了一样东西，后来都成了制度的地基：

| 灵兽 | 留下的那一样 | 后来长成了什么 |
|---|---|---|
| 夔牛 | 一声不必解释的雷 | [[雷部巡检]]：雷必须有人负责 |
| 獬豸 | 一次不给理由的撞 | [[考功]]／判词：判必须写得下来 |
| 陆吾 | 九道「到这儿为止」 | [[南天门]]：先有界，才有门 |
| 重明鸟 | 一块没有用处的木牌 | [[名声]]／[[野祀]]：有人替你说话 |
| 九色鹿 | 一笔记不上的善 | [[阴德]]：地下的那本账 |

写法上注意一件事：**它们谁都没有「参与」第一元会的历史，它们只是留下了痕迹。** 第一元会的戏是巫、妖、人三族的，灵兽是背景里那几样东西——写它们的时候不要让人去和它们对话、谈判、结盟。

### 巨鳌

它已单独立条：见 [[巨鳌]]。这里只留一句——**它一生只出场两次：第一元会自己沉下去顶住地脉，[[女娲补天]] 时被借走四足。**

## 写作约束

- 灵兽**不结盟**：可以被求、被借、被托付，但不会「加入」任何势力。一旦写成结盟，它就成了妖族，整条「兽不入编制」的规矩就破了。
- 灵兽**不主动**：它们不推动情节，只在人需要的时候出现一次。写第二次就俗了。
- 巨鳌的「不反抗」要保留——这是全书少数「强者自愿让出身体」的时刻，与巫族的「肉身即一切」正好相反。
- **不许给灵兽「立场」**：它们不站队、不评价、不保佑谁。写它救人不写它怜悯，写它撞物不写它正义。
- **不许让灵兽进战场**：一旦它替某一方出手，它就从「基础设施」变成了「盟友」，那 [[妖族天庭]] 与灵兽的分类就塌了。
- **每只灵兽只写一次高光**：第一次出现是它的一生，后面所有提及都只能是「留下过什么痕迹」。
