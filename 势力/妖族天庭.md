# 妖族天庭

> 一句话：洪荒第一个中央政权，也是第一个「政权即阵法」的政权。

## 是什么

[[帝俊]] 为帝、[[太一]] 为东皇，统御妖族所建的中央政权。它不是部落联盟，是**有编制、有职守、有历法**的王朝——在洪荒这个还靠血缘和拳头说话的时代，这是全新的东西。

## 政权即阵法

妖族天庭最关键的一条设计：**行政编制与军事编制完全重合**。

周天星斗大阵有 365 个阵位，天庭就设 365 位星君，一位对一位。星君平时管星辰运转与历法，战时就是阵位。

| 好处 | 代价 |
|---|---|
| 一道命令直达阵位，反应极快 | 不能抽调：调走一位，阵就缺一角 |
| 平时就在练阵，不用临时集结 | 不能裁撤：裁了阵就转不起来 |
| 权力与战力同一套系统 | 不能补人：星君须天生对应星位，**补不上** |

所以妖族天庭是洪荒历史上**效率最高、韧性最差**的政权：它没有腐败、没有内耗、没有派系——也因此没有任何缓冲。

## 与巫族的对照

| | 巫族（[[十二祖巫]]） | 妖族天庭 |
|---|---|---|
| 结构 | 血缘：十二祖巫 | 编制：三百六十五星君 |
| 冗余 | 无（少一个就崩） | 有（缺几个还能转） |
| 弹性 | 无（不能换人） | 无（不能换人） |
| 死穴 | 关键位不可替代 | **每一处都不可替代** |

两套结构各有一个死穴，而它们恰好互相打中了对方的死穴。

## 它其实管得很好

这一点必须写清楚，否则妖族天庭会被写成暴政，而暴政解释不了它为什么能撑一劫。

它做的事：定历法、序星辰、编族类（连人族都被编进去当「万灵之一」）、维持天地秩序。**在巫妖量劫之前，洪荒是有秩序的，而那个秩序是妖族天庭给的。**

它的失败不是因为它坏，是因为**它的秩序只对「可以编号的东西」有效**——而 [[都天神煞大阵]] 召出来的东西，编号不了。

## 巫妖量劫里的三步崩塌

1. **首战失利**：[[河图洛书]] 算不出盘古真身的整体动作（详见 [[河图洛书]] 与 [[巫妖量劫]]）。
2. **内部失序**：帝俊与太一争执动手，随后认清「现在打没有用」而停手——这是它唯一一次内耗，也是最致命的一次：**它花了时间，而时间是要还的**。
3. **决战**：十二祖巫缺一（后土已去），帝江被东皇钟钉住移动，太一陨落，钟坠东海海眼。

## 遗产：编制这个概念活了下来

妖族天庭塌了，但它发明的「编制」没有死：

- 三百六十五星君的阵位表，成了此后天庭的**职位表**。
- [[昊天上帝]] 接手天庭时，接的不是妖族的势力，是**妖族留下的那套编制**——以及「编制不满就运转不了」这个难题。
- 这正是 [[封神量劫]] 的直接起因之一：天庭缺编整整一劫，只能去三教那里要人。

**妖族天庭真正的遗产不是仇恨，是一份没人能填满的岗位表。**

## 写作约束

- **不写成暴政**。它管得好，问题在结构。
- **不写复兴**。妖族此后没有政治实体（九尾一族散入人间，白泽一脉归隐）。残部可以有个体，不可以有朝廷。
- **不与封神天庭混为一谈**。一个是血缘王朝，一个是程序官僚；同名，不同物。
