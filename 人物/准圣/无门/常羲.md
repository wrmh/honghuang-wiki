# 常羲

## 导语

月母，太阴星的守星者。**月位是全书唯一从头到尾没被压缩过的位子**——因为打月亮没有收益；她守着一个没人抢的东西，也因此一直留着门。

## 人物要素

### 一、基础标识
- **姓名**：常羲｜**性别**：女
- **生辰**：第一元会（月之精自生）｜**出身**：太阴星自己养出来的一点精
- **现居**：太阴星（闭门不出）｜**族属**：妖族（月精）

### 二、外貌体征
172cm，三围 90 / 63 / 93。细部见 `## 外貌`。

### 三、性格气质
柔、静、留门。处事：不承诺，不拒绝。情绪：平。气场：凉，让人说话也放轻。

### 四、身份背景
月母、太阴星之主。家庭：[[羲和]]（同一副骨相）、十二月（同十日来历）。关键经历：出精 → 帝俊强索 → 闭门 → 收留 [[嫦娥]]。

### 五、能力喜好
擅长御月、调暗、出月精。爱好：听夜里的事。习惯：赤足（指节凉）。价值观：名字在你嘴上，怎么叫随你。好恶：厌被代言。

### 六、言行特征
轻，句子软。口头禅「随你」。肢体：说话时袖口拢着。行为模式：先让人说完。

### 七、状态与关系
当下：闭门，收留嫦娥。关系：[[羲和]]、[[嫦娥]]。诉求：让月亮照该照的地方。

### 八、补充标签
- **闪光点**：永远留一条门。
- **缺点**：不肯表态。
- **标志性事件**：把月亮调暗一次，放走溃散的妖军。

## 外貌

### 一、与羲和：同一副骨相

两个人站在一起，第一眼会被认成**双生**——不是一模一样，是**骨相是同一副**：额线、颧骨、下颌收法、鼻梁高度、鼻头形状、唇线弧度全对得上。差别只在**颜色、体温、和眉尾的方向**。

洪荒里的说法是「**盘古的双眼本是一对，从一对眼里长出来的两个人，骨相自然一样**」。她们自己不提。两个人拢头发的手势一模一样，方向相反：常羲用左手替羲和拢。

**唯一一次被认错**：妖族立朝那年朝会上，有星君把她认成羲和，跪下就报日轮的事。她没有纠正，只说了句「她是我姐姐」——其实谁先成形没人知道。[[帝俊]] 后来把这句话拿去当「二妻」说法的第一块砖，她也没有反驳。

### 二、头面

标准的鹅蛋脸，线条比羲和软，下颌收得圆一些；**眉淡而长，眉尾自然垂着**（羲和是向上挑的），所以看起来总像刚醒。皮肤是冷白，白得透出一点青，眼底一层淡青——**不是病，是不常睡在白天**。

眼睛是**月白近灰**：瞳色很浅，睫毛长且密，垂眼时像盖了一层薄霜；看人时不逼视，只是安静地看着，看得久了对方会自己把话说完。鼻梁细、鼻头小；唇色浅，常是抿着的。

**同样的长度、同样的挽法，羲和那边是熔金。**

**头发**：极细的银白，几乎不带亮，像霜落在丝上；长度到腰，发质软得几乎立不住。梳得极松：只在脑后松松挽一个髻，用一根**素银簪**别住，簪子插得浅，走快了会掉。风一吹就散下来，她也不拢——**散了就散了，她从不因为头发被看见而躲**。发梢是凉的，碰一下像触到月下石阶。拢头发的手势是从左往右（与羲和正相反）；两人并排时，一金一银，一热一凉。

### 三、身形

身高 **174 cm**（与羲和同高——这是最容易认错的地方），身形清瘦，肩窄，脖颈长；站在那里几乎不出声，衣服垂下来的褶皱都很少动，重心却和羲和一样压得低。

三围 **90 / 63 / 93**（羲和 95 / 65 / 97，差在几处，不必一致）。手脚都凉，指尖常年比别处低一度；和羲和并肩站时，中间那道温差比长相更能说明谁是谁。

### 四、服饰与妆造

**衣服**：素银灰长衣，交领，宽袖，料子薄到能透光，动起来像一层雾；外面一条霜色披帛，缠在臂上不系紧，走一步松一分。腰间一条霜色绦带，只打一个活结——**她随时可以走**。脚上赤足，脚踝细，走路几乎踏不出声。

**妆造**：几乎没有妆。唯一的讲究是眉梢扫极淡的一点冷银，夜里在月光下才看得见。

### 五、特殊标记

- 指节凉：碰过的水面会结一层薄霜，霜的形状是细密的针。（羲和对应的是一碰就留下金色痕的石头。）
- 呼出的气在暖处也看得见，很淡。
- 她坐过的地方，席子过一会儿会凉下来。
- 说话时会停很久——不是在想词，是在听。
- 极少数时候，眉心会浮起一道极淡的银线，一闪就没（朝会上被认错那次浮过，没人看清）。

### 六、气质与神态

**她轻。** 声音轻、脚步轻，连拒绝都很轻。

- 先说「你坐」，再说别的；给茶、给看星、给听，但从不说「我帮你」。
- 不承诺，也不拒绝：答话常用「可以」「记下了」「随你」——**都是不欠人的说法**。
- 听得比说得多；别人急的时候她不劝，只等。
- 从不在人前显出难过；难过的时候她会去看月亮的背面，回来时眼睛更浅。
- 对羲和例外：会笑一下，会伸手替她把散下来的头发拢到耳后。

### 七、写作忌处

1. 不许写成圣女、不许写成「温柔得没有脾气」：她的温柔是**不干涉**，不是顺从。
2. 不许写悲情：她不是受害者，她只是懒得争。
3. 不许写她被帝俊打动，也不许写她恨帝俊——她连提都不提。
4. 不许写她的月亮能救人：她能给的只有暗，暗只让人看不见，不让人活。
5. **不许把她和羲和写成一模一样**：相像是骨相；颜色、体温、眉尾方向、眼睛一亮一暗，任一项都能分出。
6. 不许写她们互换身份骗人：体温与眼睛对不上，会被当场认出。
7. 不许写「她们是同一个人的两面」——两个来源、两段经历、两副脾气。

## 与既有词条的边界

- **不是嫦娥的婆婆**：两人是收留关系。
- **不许写她与羲和敌对**：她们同一副骨相。
- **不许写她交权**。
