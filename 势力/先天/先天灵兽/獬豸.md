# 獬豸

> 一句话：**它能判，但它不给理由**——而这正是天庭最终没有用它来判案的原因。

## 是什么

形如羊，青身，**额上一角向前**——那角不长在头顶，长在眼睛之间偏下的地方，像是从「看」里伸出来的。

它遇着不直的东西会去撞，遇着直的就不撞。它不叫，也不咬。

## 它与「判官」的分别

| | 獬豸 | 判官 |
|---|---|---|
| 判据 | 撞或不撞 | 册子上有没有这一行 |
| 说不说理由 | **不说** | 必须写 |
| 能不能上诉 | 无从上诉（没人知道它为什么撞） | 可以（附页记情形） |

后世执法者戴「獬豸冠」，戴的其实是**它不给理由的那种威风**；而天庭选的是判官，因为**没有理由的判，账上写不下去**。

## 第一元会：撞住的那一只

第一元会，它在荒原上撞住了一只正在长的凶兽。

凶兽没死，也没流血——只是**不能动了**。它站在那里，一天天长回去一点，最后长成了一段山脊。

所以后来的人说某一段山「形状不太对」，说的是那件事：**一段本来会跑的东西，被撞成了地。**

那次之后獬豸再没撞过第二次。有人说它撞完就懂了：**撞住一个，等于替它选了一种形状。**

## 写作约束

1. **不许让它说话、也不许让它「点头示意」**：它的判断只能用撞或不撞表示。
2. **不许写成神判**：它是兽，不是法。写谁拿它当「天意裁判」，都要写那人后来发现自己错了。
3. **不许它被驯养**：可以「跟着」某个人走一段，不能「归他」。
4. 每次写它，必须留下一个**代价**：被撞的东西换了一种形状（山、石、枯树），从未「恢复了原样」。

## 关联

- [[考功]]：能判但要写理由的那一套，是它的反面。
- [[仙凡之别]]：判词只写「不得做什么」而不写「当如何」，就是「不给理由」被制度化的结果。
- [[四大判官]]：接手的正是它不肯做的事。
