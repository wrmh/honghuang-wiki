# 轮回镜

> 一句话：**它不判案，它只把账本翻给你看。**
> 镜子照出来的是「你欠了什么」，不是「你该受什么罚」——罚是判官写的，账是镜子给的。

## 一、档位

| 项 | 值 |
|---|---|
| 品阶 | [[功德灵宝]]（44 道） |
| 系列 | 后天 |
| 功德来源 | 立[[六道轮回]]（后土那笔功德的**副产物**） |
| 现主 | [[地府]]——判官执用，不是后土的私物 |

为什么只是功德灵宝而不是至宝：**它只"看"，不改任何东西**。功德至宝动的是位置（生死、名分、去处），它动的只是"知道"。

## 二、照什么、不照什么

| 照得出 | 照不出 |
|---|---|
| 这个人身上的因果连线（谁欠谁、欠多少） | 他心里怎么想 |
| 这条魂该走哪一道（按账，不按善恶） | 他"值不值得"原谅 |
| 某件事把账转给了谁 | 未来会怎样 |

**它照的是"账"，不是"人"。** 所以判官看它的时候，看的是册子与镜子对不对得上——对不上，说明有人在改册子。

## 三、为什么地府离不开它

- [[生死簿]] 记「谁死了、去哪了」，是**账本**；
- 轮回镜照「这一笔为什么是他」，是**凭证**；
- 两者对上，分流才能做；对不上，就得往上查（这一般意味着有人动过名册）。

它是地府内部**唯一能发现造假的工具**——所以它比任何一件杀伐法宝都让"想改命的人"头疼。

## 四、写作约束

1. **不写它显示画面、播放生平**：只写"镜面上现出几条线"。
2. **不写它能改命**：它只照，改是[[阿鼻]]与册子那一路的事。
3. **不写后土用镜审人**：她不用它，判官用。
4. 每次出场只写"对上／对不上"。

## 已定（2026-11-15 裁决）

- **U-308（照到不该在册的人）**：**空镜**——什么也不显示。比报错更可怕：判官只能上报，而上报之后通常没有下文。
- **U-309（照出「没有账」的人）**：两种都有——[[无相魔神]]那一路（名册上从没有他）与补天余料化成的[[孙悟空]]（不在任何册子上）。前者是「从未被写」，后者是「写的时候没有那一栏」。
