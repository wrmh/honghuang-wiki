# 值日功曹

> 一句话：**一个位置比一个人更容易出错**——因为位置没有记忆。

## 它们是什么

天庭有几十个「按日轮值」的位置，最典型的两个是值日与功曹：

| | 值日 | 功曹 |
|---|---|---|
| 干什么 | 报时辰、开门、给当天的事盖当天的印 | 传令：把一纸文书送到该到的地方 |
| 一天一换 | 是 | 是 |
| 需要修行吗 | 不需要（**斗部点兵**里那几个不需要能打的位） | 需要一点脚力，不需要能打 |
| 出错会怎样 | 全城跟着错 | 文书晚到，事就晚办 |

[[大羿射日]] 里「留一个太阳」那句话，落地就是**给值日这件事留一个位置**：天不能没有时间，而时间必须有人报。

> 名字上有一点要留意：**「值日」这个词在册上先属于 [[太阳星君]]**——太阳每天出一次，就是最原始的值日。天庭后来设的那些轮值位，借的是这个词，不是这个神。

## 这个位置为什么比人更容易出错

天庭的规矩是「换位不换人、换人不换位」——值日这个位置一天一换，人走了，位置留着。位置没有记忆，于是：

- 上一任知道的（哪口钟晚过一刻、哪段路雨后不好走），**不会写进下一个人手里**；
- 规矩只写好「该做什么」，没写「曾经错过什么」；
- 所以同一个错，可以每一年由不同的人各犯一次，谁也不觉得是自己的。

## 一次报错：全城晚开一次门

**第五元会某一日，值日报错了时辰。**

经过很平常：那日云厚，日晷看不见，更漏被人碰歪了一格。值日按更漏报了，报早了一刻。

后果按顺序落下来：

| 序 | 谁 | 做了什么 |
|---|---|---|
| 1 | 南天门 | 按报来的时辰开门，早了一刻 |
| 2 | 早朝的队列 | 人还没齐，门已开了 |
| 3 | 一位排在队末的神职 | 差一步没赶上点名，当日位同空着 |
| 4 | 册府 | 记「该位当日在朝」，其实是空着 |

第四步是全部：**错的不是时辰，是册子上开始有一行不实的话。**

处置：此后值日要**两个人对时**——一个看漏，一个看晷，报出去之前互相对一遍。没有惩罚，因为错不在人；也没有改正，因为改不了已经记下的那一行。

## 写作约束

1. 写值日功曹一律写**流程**，不写战斗力，也不写他们抱怨。
2. 这个岗位的悲剧不来自压迫，来自**可替换性**：做得对，没人记得；做错了，位置记得。
3. 不写「某个值日升了职」。这个位置没有升迁路径，终点就是「明天换人再来一遍」。
