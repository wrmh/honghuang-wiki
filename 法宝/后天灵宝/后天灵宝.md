# 后天灵宝

> 一句话：**开天之后才被造出来的东西。** 它们可以很好用，但**炼到 42 道就到顶**——再往上的七道不是能焊出来的，是拿功德换出来的（见 [[后天至宝]]，又叫功德至宝）。

## 是什么

[[先天灵宝]] 那张总纲页里的第四档（系列＝后天）。本页只收这一类，不重复总纲的判定规则。

判定只有一条，看**材**不看威力：

| 问 | 是 → 后天 | 否 → 去查别档 |
|---|---|---|
| 它在开天之前就存在吗？ | 否 | 是 → [[先天灵宝]] 或 [[混沌灵宝]] |
| 它是被谁"做"出来的吗？ | 是 | 否 → 它可能是碎片（碎片也属它原来的系列） |

## 为什么这一档最重要

因为四劫的走向，全在「后天」这一档里被改写：

| 势力 | 靠什么 | 属哪档思维 |
|---|---|---|
| [[妖族天庭]] | 编制：365 个不可替代的位置 | 先天思维（位置是给定的） |
| [[巫族]] | 血脉：12 个不可替代的祖巫 | 先天思维（能力是生来的） |
| [[人族]] | 造东西：指南车、历法、律令 | **后天思维（把能力外包给物）** |

一句话：**先天靠继承，后天靠制造。** 人族之所以能在一堆先天大能之间活下来，靠的就是这一档。

## 体系约束

1. **后天之物的炼制上限是 42 道。** 42 之后那七道不是炼出来的，是拿功德换的——换成了就叫 [[后天至宝]]（功德至宝），换不成，就永远停在 42。
2. **后天之物可以复制。** 这是它与先天最实用的区别（[[指南车]] 造了三辆）。
3. **后天之物坏了能修**：先天碎片不可再生，后天可以重造。
4. 不为单件后天法宝解释「为什么不更强」——**弱就是它的规定**。

## 写作约束

1. 任何一件后天法宝出场，都要能回答「谁造的、为什么造」。
2. 不把后天写成「劣等」：它的价值在**可复制**，不在强。
3. [[后天至宝]]（功德至宝）一档至今为空——不是凑不出来，是**没人愿意拿一大笔功德去换一个位置**；本页不硬凑实例。

## 已定（2026-11-15 裁决）

- **U-275**：后天灵宝的炼制上限是 42 道；要推到 49 道必须消耗大量功德，所以「后天至宝」在本库又叫「功德至宝」——它不是炼出来的，是拿功德换出来的。
- **U-276**：算。只要够 1 道禁制就入档，指南车 18 道即是例；凡人造的器物只要上了禁制，就属于这一档。
