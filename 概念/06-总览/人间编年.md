# 人间编年

## 一句话

**第四元会一共十二会：封神占三会，剩下九会把「夏到唐初」一次走完**——所有朝代的时间都换算成「第几会第几运第几世」，再括注真实纪年。

## 为什么要把人间拉长

第五元会的西游锚在**真实历史的唐初（贞观）**。既然第五元会从贞观开始，第四元会就必须把「夏 → 隋末」全部装下。不装，西游的时间就悬空。

## 换算口径

一元会＝12 会＝129600 年；一会＝30 运＝10800 年；一运＝12 世＝360 年；一世＝30 年。

元会内第 N 年 = （会−1）×10800 +（运−1）×360 +（世−1）×30 + 1。

## 五条读法

1. **封神是主戏**：第 6–8 会三会连打，从入宫到封榜，中间没有别的朝代插进来。
2. **乙丙两幕是骨架**：第 9–12 会只给「哪一朝靠什么坐稳」，一场仗不细写。
3. **人间戏在人物条目里**：骨架上的血肉靠 `人物\凡人\` 补（美女、文人、皇帝、将领），不靠事件条目堆。
4. **不写宋以后**：第五元会的西游从贞观开始，宋元明清不在本库的人间编年里。
5. **朝代名不进标题**：事件标题写「事」（秦并天下、隋亡唐兴），写成「秦朝」「唐朝」就会和势力目录混。

## 写作约束

1. 时间一律写成「第四元会第 N 会第 X 运第 Y 世（元会内第 Z 年）」，真实纪年只作括注。
2. 一个朝代只回答一个问题：**它靠什么坐稳**；答不出来的朝代不写事件，只写人。
3. 不许让神仙直接干预人间更替（封神之后天庭只盖章，见 [[天命]]、[[绝地天通]]）。
4. 凡人与仙凡之别：涉及婚配与子嗣一律回 [[仙凡之别]]。
