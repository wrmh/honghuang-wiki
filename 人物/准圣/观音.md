# 观音

> 一句话：佛门里**唯一跑外勤的那个**——
> 接引等人来、准提出去找、地藏守住一处，只有她**在路上**。

## 一、她在体系里的位置

| 环节 | 谁做 | 做什么 |
|---|---|---|
| 找人 | [[准提]] | 走出去看谁值得收（体面最差的一环） |
| 收账 | [[接引]] | 接一笔在别处结不了的账 |
| 守一处 | [[地藏]] | 一个永久据点，不动 |
| **对接与转运** | **观音（本条）** | **把「找来的」和「收下的」接上**，还要跟外面的人打交道 |

**四方分工的关键：她是唯一需要「被外人接受」的那一个。** 所以她在书里最像人：会商量、会变通、会先给对方好处。

## 二、她做的事：对接

西游里她不是打手，是**接口**：

1. **对天庭**：取经这件事要有官面上的名目，她去谈（见 [[天庭历法]]、[[八十一难]] 二组「官面」）。
2. **对地方**：哪一段路谁签字、谁放行，她提前铺。
3. **对队伍**：她给的不是力量，是**在关键处出现一次**——每次都只解决一件事。
4. **对佛门内部**：把沿途收下的人与账送回 [[灵山]]，不进自己名下。

**核心设定：她的作用不是「救」，是「接」。** 救是功德，接是手续；功德会记在她头上，接不会。

## 三、为什么她不立在册子上

- 佛门的果位表里，她的说法永远比实际低——因为她做的事**不能写在册子上**（一写就成了「佛门干预人间」）。
- 这与 [[东岳大帝]] 处境相反：东岳是**位置清晰、签不了账**；她是**能签账、位置说不清**。
- 全书不写她的道场（南海只是传说），因为**她本来就没有固定的地方**。

## 四、与几位对照

| 人 | 走的是哪一条 |
|---|---|
| [[地藏]] | 不走（守住一处） |
| [[长耳定光仙]] | 自己走过去（换名字） |
| [[孔宣]] | 被打服（换自由） |
| **观音** | **一直在路上（换的是「被外人接受」）** |
| [[九尾]] | 变成别人（换身份） |

**四种走法都换掉了自己身上的一样东西**，观音换掉的是「一个固定的身份」。

## 五、三条写作约束

1. **不写她打斗**：全书她一次不亲自动手，只「出现一次，事情就办成了」。
2. **不写她的来历**：来历一写实，她「没有固定身份」这条设定就塌了。
3. **不许她替人担因果**：她只接手续，不代偿（代偿是圣人的事，见 [[因果]]）。

## 六、从慈航到观音

她在阐教时叫慈航道人，[[十二金仙]] 之一，道场在南海落伽山。封神之后入了佛门，成了观音。

这条线值得单写一节，因为**它不是「改投」，是「同一套本事换了一本册子」**：

| | 慈航道人（阐教） | 观音（佛门） |
|---|---|---|
| 算什么 | 十二金仙之一，排得进座次 | 菩萨，果位另算（见 [[果位]]） |
| 管什么 | 应劫、助周 | 对接、外勤、度人 |
| 册子 | [[封神榜]] | 佛门自己的名册（不上天） |
| 落伽山 | 道场 | 收件地址（见 [[落伽山]]） |

**她带过去的东西只有一样：落伽山。** 道场是阐教给的，地址是她自己的——所以她入佛门之后，佛门有一个「在外面跑的人」，而阐教少了一个「排得进座次的人」。

### 她一直是女子：扮男相与卸下伪装

**慈航道人从一开始就是女子**——不是「男身变女身」，也不是「本来没有性别」。这条线里没有变形、没有换身，只有一层**伪装**与一次**卸下**：

| 时期 | 示人的样子 | 为什么 |
|---|---|---|
| 阐教（慈航道人） | **男相**：束发戴冠、交领道袍、眉描粗一档、声线压低、行走收着腰 | 那时女身在那一套秩序里立不住——不是不许进门，是**写不进册子**：座次、执事、应劫的名单都按男身排 |
| 佛门（观音） | **女相**：散发、月白长衣、不描眉、不压声 | 佛门收的是「来处」，不问「相」；她把那身男装脱了，从此不再装 |

- **[[元始天尊]] 看透过，没揭穿。** 他要的是「阐教有排得进座次的位」；多一个女身就多一道要解释的事。他选了不说，也从不因此少给她一件差事。
- **同门里没有人知道**——不是他们笨，是没人往那上面想：她太不像「需要被照顾的那种人」。
- 所以「从慈航到观音」不是改投，也不是改性：**是把一件穿了很久的衣服脱下来。**
- **写作铁律：不许写成「男变女」**；不许写「原来是男人」；不许写身体。她的性别从头到尾只有一个答案，要写的只有「装」与「不装」。

## 外貌

### 一、头面

脸是长圆的脸，下颌的线收得柔，颧骨很低——**这是一张不设防的脸**，所以谁都能对她把话说完。肤色是极浅的暖白，不施粉也透着一层薄红。

眉是远山眉，弯而长，眉尾几乎不必画；眼睛是浅褐色的，眼白干净，上眼睑压得低一点，看人的时候像垂着眼——**她其实一直在看，只是不抬眼**。鼻梁细，鼻头小而圆；唇薄，唇色是天然的淡粉，说话时几乎不见唇形变化。

耳朵比常人略大一点，耳廓上多一道浅浅的折——**这是她身上最像「她」的地方**：菩萨听人说话，不是用眼睛。

头发是黑的，中分，极顺，梳得一丝不乱，挽一个松而低的髻，用一根素木簪别住；鬓边总有一缕不肯服帖，风一吹就散。

### 二、身形

身高 **174 cm**，三围约 **88 / 62 / 92 cm**。极瘦，肩窄，脖子长，锁骨清得像两道细线；手长，指细，指甲修得短而圆。

她站着的时候重心很稳，背略向前倾一点——那是常年「往前递东西」的姿势：递一句话、递一个人、递到门口。

### 三、服饰与妆造

**衣服**：月白的交领长衣，料子软而垂，走动时下摆不起风；外罩一件**旧的青灰褙子**——那是阐教时的旧物，边角磨白了也不换，她说「穿着顺手」。

腰上不佩玉，只挂一枚**竹牌**，牌上刻着「落伽山」三个字，磨得发亮：**那是她的地址，也是她的凭信**。

**妆造**：几乎没有妆。眉不描，唇不点，脸上一层极淡的香粉（闻不出来，只在近身时有一点点）。发间只有那根素木簪，不加珠花。

**礼佛时的换法**：外面加一件灰褐的缦衣，袖口收窄；手里托一只**净白的小瓶**，插一枝鲜杨柳——柳是每天现折的，枯了就换，不供着。

**阐教时期的那一身（已脱下的）**：青灰道袍、玄色束带、束发玉冠，里面用一条布带把胸束平，肩上垫两层衬——**为的是在册子上像「一个少年道人」**。她不贴假须，宁可被当成年纪小；说话时刻意慢半拍、把尾音压下去。**那件旧褙子就是那时留下的**，所以袖子磨白了也不换——脱得下男装，脱不下这一件。

### 四、特殊标记

左手腕内侧有一道极浅的旧痕，像被什么勒过很久，颜色比周围淡一点——是当年握剑握出来的，入了佛门也没消。

右耳后有一粒极小的朱砂痣，她自己不知道；靠得极近的人才看得见。

### 五、气质与神态

**「听」是她的本能，也是她的武器。**

- 别人说话时，她会微微侧头，把那一侧的耳朵递过去——这个动作她做得很自然，被看的人会不自觉把话说深一点。
- 说话极慢，句子软，常用「嗯」「是这样」接住；**她从不答应什么**，也从不拒绝，只把人送到门口。
- 她笑的时候眼睛几乎不动，只是眼尾软下来一点；真被问住了会先低头看自己的手。
- 走路的步子轻，进门前会先停一下——不是犹豫，是听里面有没有人。
- 身上没有香火气，只有一点皂角和旧布的味道。

### 六、写作忌处

1. 不许写她「显灵」「度化」「金光万丈」：她的作用是**把路指出来**，不是替人走。
2. 不许写成慈眉善目的老太太，也不许写成冷面菩萨：她是**温和但有距离**。
3. 不许让她承诺任何事——她的台词里不该出现「我会帮你」。
4. **不许写「男变女」**：她一直是女子，只在阐教扮过男相。禁止变形、换身、身体改造，也禁止写「其实是男人」——这是本书的死线。

## 已定（2026-11-15 裁决）

- **U-426（果位）**＝与 [[地藏]] **并列**：两人是佛门里唯二「位置说不清」的。理由：地藏是因为「永远不走」所以排不进果位表，观音是因为「永远在路上」所以她的名字总在册子的边上——一个不能排、一个来不及排。
- **U-427（南海）**＝**照原著**——南海普陀山（珞珈山）确有这一处，是海上一座小岛；但加一条：**她一年待不满一个月**。岛是真的，常住是假的：她本来就没有固定的地方，岛只是「信众知道往哪送信」。
