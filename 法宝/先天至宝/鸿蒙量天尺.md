# 鸿蒙量天尺

> 一句话：**它能"除万法"，也能量一段距离——量完之后，那段距离就不算数了。**
> 与[[天地玄黄玲珑宝塔]]齐名的另一件**先天功德至宝**，走的是相反的路：塔守，尺攻。

## 一、档位与来历

| 项 | 值 |
|---|---|
| 品阶 | [[先天至宝]]（49 道） |
| 特殊类别 | **先天功德至宝**（见 [[后天至宝]] 末节） |
| 材料 | [[玄黄之气]] 中的**鸿蒙玄黄之气** |
| 功德来源 | [[盘古]] 开天功德（三清所化，故能分到） |
| 现主 | **无主**（这一件是本书对"有说无主"的处理） |

## 二、能力：除万法与置距

| 用法 | 效果 | 代价 |
|---|---|---|
| 除万法 | 把一段范围内的"法术"整层抹掉 | 抹掉的那一层，此后不再属于这个世界 |
| 置距 | 量定一段距离，使攻伐**落在它想落的地方** | 量一次，尺上留一道痕 |
| 杀伐 | 可杀人不沾因果 | 与玄黄宝塔同源，故也同享"位置" |

**它的攻击力在[[盘古幡]]之下**——这是刻意的：幡管"立"，尺管"除"；立的东西没有上限，除的东西总有边界。

## 三、为什么它无主

三件[[混沌至宝]]都不设主人（见其条目）；两件先天功德至宝里，宝塔认老子，尺**谁也没认**。

本书的解释：**尺是"量"的东西，量的人一旦定下来，世界的尺寸就定了。** 天道不容许这件事——一个能自己决定"哪里算哪里"的人，等于第二个立法者。

所以它被留在没人找得到的地方：**"无主"不是巧合，是天意的分配。**

## 四、写作约束

1. **不许它被谁"捡到就用"**：全书只能出现"没人找得到"，不能出现"某人得了它"。
2. **不许它用来救人**：尺是杀伐与秩序的东西，救人要么用塔，要么用功德。
3. **不许它和宝塔对轰**：两件同源，真打起来是同归于尽，所以全书不让它们照面。
4. 出场只写"量"与"除"两个动作，不写尺上有多少刻度。
