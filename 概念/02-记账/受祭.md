# 受祭

> 一句话：**香火是预收，受祭是履约——收了不说话，就是欠着。**

## 一、它是什么

`香火` 是人间的记账动作：点一次、说一句、供一份，册上就多一笔。

那笔账的另一头，就是受祭：**神收下之后，得回点什么。**

问题在于神没有「回」的手段——不下雨不归他、收成不归他、生死不归他（天庭只分配位置、日子、名分）。于是受祭的回法只有四种，而其中三种都不算回。

## 二、四种回法

| 回法 | 实际是什么 | 记账上算不算履约 |
|---|---|---|
| **风雨** | 按 `行雨定额` 的簿子下，与他求不求无关 | 不算——他只是恰好在同一个故事里 |
| **收成** | 归地、归人、归 `山神河伯` 的地脉册 | 不算——他连账都碰不到 |
| **护佑** | 换成差事：把香火折算成这一带的「名额」（多一户在册、少一次清剿） | 算——这是唯一他能真正做的事 |
| **沉默** | 什么也不回，账一直挂着 | 不算，但也不清 |

**沉默是最常见的回法，也是最贵的。** 因为挂着的那一笔，会在下一次 `考功` 时被翻出来：不是罚你，是「这一位香火多、回得少，是不是该换人」。

## 三、三条硬规矩

| 规矩 | 破了会怎样 |
|---|---|
| 不承诺具体 | 一旦说出「保你三年丰收」，这笔就变成了 `愿力`——愿力不结清就一直挂在天上，神先被这笔空话拖死 |
| 不能超额 | 多收多欠，所以土地庙宁可小、宁可破：庙小，账小，好还 |
| 不能自己宣布「应了」 | 宣布的人是祭司，不是神（见 `天命` 的传播环节）——神一开口，「应」就变成了「交易」 |

## 四、写作约束

1. 写「收」，不写「显灵」：香火戏的重点在收了没回，不在回了多神。
2. 不要写神被打动：受祭是账，不是情感。
3. 沉默要写足：上供的人等了一年，什么也没等到，第二年照样上供——**这才是香火最真实的部分**。
4. 凡人视角优先：神在本书里很少出面，受祭几乎全靠凡人和祭司的嘴来体现。

## 五、关系

- 对家：[[香火]]（预收）、[[愿力]]（空口承诺，与受祭同源但方向相反）
- 归口：[[考功]]（核「收得多、回得少」）、[[册府]]（记香火与受祭两栏）
- 执行者：[[土地]]、[[城隍]]、[[山神河伯]]（护佑这一种只能由他们落地）
- 对照：[[功德]]（已签收的收款）——受祭是「还没交货」，功德是「货已到」
- 人物：[[汤]]（收祭但不回应的典型：祷了三天，雨按簿下）

## 未定稿问题

- [ ] U-565 香火与受祭两栏，天庭什么时候开始对着核？
  - A 第五元会之后：`行雨定额` 上线，香火被迫纳入核数，两栏才开始并排
  - B 一直就核：只是早年核得松，「收得多回得少」不算错，算常态
  - C 只在出事时核：平时不查，一旦某地出了乱子，就把这一位的两栏翻出来当罪状
- [ ] U-566 沉默到底算不算履约？
  - A 算：神不能改变什么，沉默就是他能给的全部——「不添乱」本身就是护佑
  - B 不算：账上永远挂着一笔，所以天庭的神大多「欠着」，这才是天庭真正的常态
  - C 看地方：山野小神算履约（他们真的没别的事可做），大位上的不算（他们本来能做更多）
- [ ] U-567 有没有神主动退回香火？
  - A 有，极少：退香火等于自请下调，从此再没人给他上供——有神这么干过，名字被人记住了
  - B 没有：香火是册上的数，退不了；能做的只有「少收」
  - C 有，但不叫退：叫「分给别处」——把这一带的香火过给邻位的庙，账面看不出是退
