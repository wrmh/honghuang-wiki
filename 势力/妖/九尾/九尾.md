# 九尾

> 一句话：编不进别人秩序里的人，最后只剩下一种本事——**变成别人**。

## 是什么
妖族的一支。巫妖量劫后，天庭塌了、星君散了、有战力的都被清算干净，九尾这一支剩下的只有「变」。

不是幻术，是**替身**：它们能变成任何在秩序里有位置的东西——人、仙、贵人、神。变了之后，秩序就认它。

## 内部结构

```
九尾（一族说法）
  └─ 轩辕坟三妖（另立条目）
       └─ 与青丘传说并行（本库采「无族」）
```

它最像一段传说，最不像一个族群：**本库不设「九尾一族」，只设九尾**。

## 死穴

1. **本库不设九尾一族**，避免给传说补家谱。
2. **它是被用的**，不是主谋。
3. **入宫之后两种说法并存**，正文只写「各有各的说法」。

## 为什么是「变」
| 结构类型 | 靠什么活 | 九尾有没有 |
|---|---|---|
| 血脉（巫族） | 天生能打 | 没有 |
| 编制（妖族天庭） | 有位置 | 位置没了 |
| 传承（人族） | 有方法 | 学不会（它们不是人） |
| **替身（九尾）** | 变成有位置的东西 | **只剩这个** |

所以「变化」对九尾不是本事，是**唯一剩下的活法**：它们不能赢，只能进去。

## 散入人间
巫妖劫后，九尾一族散入 [[人族]] 诸部。它们不侵略、不统治，只做一件事：**找一个人，变成他该有的样子**。

这也解释了它们为什么后来总出现在王朝的边上——**王朝是洪荒里位置最密的地方**，位置越密，替身越有用。

## 最后一次下注：轩辕坟三妖
[[封神量劫]] 里，九尾一族把最后的筹码全压了一次：三妖入朝歌（妲己为其一），试图在人间最大的一个「位置」上换一次命运。

结局：输了，而且输得比巫妖劫更彻底——**巫妖劫里它们是被打散的，这一次它们是被点名的**。三妖上了清算名单，九尾一族从此在本书里不再有政治动作，只剩个体。

## 与「编制」主题的关系
九尾是全书里「编制」这条线最锋利的一刀：

- 巫族：不能进编制，就死。
- 妖族天庭：有编制，编制一塌就全塌。
- 人族：自己造了一套不分血统的编制（[[人族]] 年表）。
- **九尾：进不去，就变成能进去的样子。**

四劫讲的是账，九尾讲的是**账外的人怎么活**——靠伪装进账，然后被账清算。

## 写作约束
- **不写成祸水**。它们不是「美女乱国」，是「没有位置的人用替身进入秩序」，这是结构问题不是道德问题。
- **不给它们翻盘**。封神之后只有个体，没有一族。
- **不写成可怜**。它们每次都是自己选的。
