# 香火院

> 一句话：**佛门不收「祭」，只收「供」——香火进的是寺院的账，不是佛的账。佛不签字，所以这笔记不上天。**

## 一、它是什么

天庭那一侧，香火是一笔账：神收了，要回；回不了，账挂着，`考功` 会来问（见 `受祭`）。

佛门这一侧，香火进的是**寺院**。

- 供的人说「供佛」，其实供的是僧团：灯油、米粮、修缮、印经。
- 寺里管账的叫人「知事僧」，他不问「佛应了没有」，只问「今年够不够」。
- 佛不下场。佛像受了香，不动、不说、不记事——**这不是失职，是佛门本来就不认这笔账。**

## 二、为什么佛门能这么办

因为 `愿力` 与 `香火` 是两种东西：

| | 天庭的神 | 佛门 |
|---|---|---|
| 收的是什么 | 香火（预收的账） | 供养（已经交出去的东西） |
| 谁在记账 | `册府`：谁的庙、多少香 | 寺院自己：收支两栏，不外报 |
| 回不回 | 必须回（`受祭`：护佑换差事／沉默挂账） | 不回：佛不承诺具体事，只承诺「有人替你说」 |
| 出了问题 | `考功` 来核 | 僧团自查：破戒另收（见 `戒`） |

关键一句：**天庭的神欠账，是因为他收了；佛门的佛不欠账，是因为他不认收。** 供的是僧，不是佛——所以账落在僧团身上，而僧团只受戒律管，不受 `考功` 管。

## 三、它真正在管什么

- **它给佛门一个稳定的、不在册府账上的进项。** 五部洲的寺院加起来，每年收的灯油与米粮是个不小的数，可这些数从来不出现在天庭的三本主册里——**因为收的是「物」，不是「份」**（对比 `水部圭` 量的「份」）。
- **它把「信」变成可延续的东西。** 一户人家供一年，是自家的事；一座寺院收一百年，就有了「这一带自古信佛」的说法——而这个说法是不需要册子承认的（`天命` 的传播环节同理）。
- **它是佛门唯一「不记账」的地方，也是最容易被查的地方。** 不记账意味着没有凭证，一旦有人问「这些油去哪了」，答不上来；所以佛门宁可让院小、僧少，也不肯把账记太细——**账太细，就等于承认这账该被核。**
- **天庭从没问过要账。** 水部核雨那年顺手问过一句口径，佛门答「那是供僧的，不是供天的」，此后没人再提——不是不敢问，是问不出：寺院的账本不在 `册府` 那三本里，所以它跟 `柳庭` 一样，被算作「**不在册的地方**」。
- **进项一半给僧团、一半上缴灵山。** 僧团那一半有知事僧记，灵山那一半没有账可查——**佛门内部也说不清那本账在哪**。所以香火院既是佛门最实在的一笔进项，也是唯一没人能对账的一笔。

## 四、三条硬规矩

| 规矩 | 破了会怎样 |
|---|---|
| 不说「佛应了」 | 一说，这笔供就成了愿力的兑现，佛门立刻进了天庭那套账——`授记` 的「谁有权开口」就废了 |
| 不记「谁的香」 | 记了就成了册籍：谁供得多谁排前面，寺院立刻变成第二个 `城隍` |
| 收物不收「份」 | 一收「份」（定额、配额），就落进了 `水部圭` 那套量法，天庭随时可以来核 |

## 五、写作约束

1. 不写佛像显灵、不写香灰变色：佛门的力量在「有人来了、有人留下、有人一直供」，不在奇迹。
2. 知事僧是主角：写他算米、补瓦、挡人，不写他修行。
3. 供的人写具体的物：一篮米、两斤油、半匹布——**不写「虔诚」这种词**。
4. 寺再穷也不写「香火断了佛就生气」：佛不生气，是僧人发愁。
