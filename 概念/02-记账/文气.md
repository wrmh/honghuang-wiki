# 文气

> 一句话：**武人的力是别人的兵，文人的力是别人的信——信的人越多，他一句话越重。**

## 一、它是什么

[[龙气]] 是「多少人愿意让你替他做决定」；文气是「多少人愿意**按你说的活**」。

差别只有一句：**龙气要一个位置，文气只要一句话。**

修的不是法术，是**诸子百家之一**（见 [[百家]]）：你立一句能被复述的话，照着做的人多了，那句话就有了重量。所以本库说：**文人不是修出来的，是被信出来的。**

## 二、三源：气从哪来

| 源 | 具体是什么 | 上限贡献 |
|---|---|---|
| **立说** | 写下一句能被复述的话（不是你想了句好话，是别人能替你讲） | 40% |
| **从者** | 真有人照它活（不是赞同，是改变行为） | 40% |
| **传习** | 隔代仍有人教、有人考、有人引 | 20% |

三源缺一条，气就上不去：**立说而不行＝空谈（天仙档）**；**行而无说＝乡约（金仙档）**；**说与行都在，但传不下去＝一时之风（太乙～大罗档）**。

## 三、档位：最高到准圣

| 档 | 什么情况 | 战力 |
|---|---|---|
| 未立说 | 只会引用别人的话 | 凡人 |
| 立说而未行 | 有人赞，没人做 | 天仙档 |
| 行于百人 | 一门一乡照它活 | 金仙档 |
| 行于一方 | 一州一国之政教 | 太乙档 |
| 行于一洲 | 天下皆引其说 | 大罗档 |
| **百家争鸣、诸国皆用** | 一洲之上无一家能绕开它 | **准圣档（顶）** |

**硬顶写死：文气最高准圣，不能到圣人。** 理由不是不强，是**圣位只有那几位**（README 第 2 条）——文气可以推翻一个王朝，改不了天道签过字的名单。

## 四、最弱的准圣：为什么他仍是准圣

这是本库特意留下的一处不体面：

**他确实是准圣，但他是最差的那一个。** 四条原因：

1. **肉身是凡人**：一拳打中就死，不需要法术，不需要法宝。
2. **起手要开口**：他的力在「说」，被打断就没了；偷袭者永远占先。
3. **一言说完即落**：一句话的力量在说完那一刻到顶，之后就走下坡。
4. **无信则无效**：对不信的人，他就是一个念书的。

但「准圣也是圣」这句也必须写实：

> **准圣与大罗之间差的不是力，是「位」——大罗还在别人给的位里，准圣已经立了一条自己的规则。文人的规则是「话」。**

所以他能**压制大部分大罗**：大罗听得懂人话，一旦被那句说住了，就动不了（不是被打败，是「被说住了」）。**大罗输的不是拳头，是他自己也认那句话。**

## 五、与武将（士气准圣）正好互补

| | 文人（文气） | 武将（士气） |
|---|---|---|
| 力的来源 | 一洲的人信他 | 身后那群人跟他 |
| 最强的地方 | **一对一**：能压大罗 | **阵上**：一冲即决 |
| 最弱的地方 | 阵上几乎无用（一万人听不清一句话） | 单挑最弱（离开阵就掉档） |
| 怎么掉 | 被驳、被禁、从者散 | 兵溃即归零 |
| 能不能持久 | 一句话说完即落 | 一场到顶要歇一个冬天 |

一句总结：**文人压得住一个高手，压不住一支军队；武将冲得开一支军队，压不住一个讲道理的人。**

## 六、气怎么掉

1. **被驳**：出现成体系的反对（不是骂，是能自洽的另一套话）。
2. **被禁**：律令不许教、不许考、不许引。
3. **从者散**：照它活的人活不下去了（这一条最狠，也最常见）。
4. **自己推翻自己**：同一个人前后改口，气掉得比被驳更快。

## 七、与既有词边界

| 词 | 记什么 | 与文气的区别 |
|---|---|---|
| [[龙气]] | 多少人愿意让你替他决定 | 龙气要有位，文气只要一句话 |
| [[功德]] | 你做成了什么 | 文气不看做成，看有人照做 |
| [[愿力]] | 别人替你许的愿 | 愿力是许诺，文气是**有人已经照做了** |
| [[气运]] | 个人余量 | 文气是**别人的行为汇到你这句话上** |

## 八、写作约束

1. 文人出场先写「他的话有没有人在做」，再写他多能说。
2. **不许让文气动手**：它没有形状、没有声响、不能挡刀；它只让对手「动不了」或「不敢动」。
3. 准圣文人被打死的写法要保留：他挡不住一支箭，这在库内是硬设定。
4. 不许把文气写成「嘴炮无敌」：对不信的人、对听不懂的人、对妖兽，**无效**。
5. 掉气要写具体：谁不教了、哪条律禁了、哪个国不用了。
