# 十二品功德金莲

> 一句话：它记功，不产功。坐在上面的人显得很有德，是因为**德先有了**，不是莲给的。

## 是什么

[[混沌青莲]] 的一枚莲子所长，十二品、四十六道禁制、极品混沌灵宝。金色，端严，坐下即稳。

它和 [[十二品灭世黑莲]] 是同一枚莲蓬上下来的两朵，方向完全相反：一朵记功、一朵记罪；一朵护身、一朵污人；一朵不伤人、一朵不硬碰。

## 为什么在佛门手里

因为它**只承载、不生产**。

功德金莲不会给人加功德。它只是把已有的功德显出来、稳住、别散掉。这一点正好对上佛门的位置：[[罗睺]] 毁了西方灵脉之后，西方最缺的是「资源」，最不缺的是「道理」——而金莲恰恰是「道理可视化」的工具。

所以佛门拿着它，不是因为它能打，是因为**它能让别人看见佛门有德**。这是西方在贫瘠之地唯一能拿出来的资本。

## 代价

- **不能伤人**。它一件攻击手段都没有。坐在上面的人必须另有战力，否则就是个好看的靶子。
- **德散则莲暗**。功德一旦被耗（替人担因果、出手救不该救的人），金莲的光会暗下去；暗到一定程度会掉品。所以持莲者比谁都怕「做亏本的好事」。

## 与黑莲的镜像

| | 功德金莲 | 灭世黑莲 |
|---|---|---|
| 管什么 | 功德（正账） | 污秽（气运，负账） |
| 表现 | 稳住已有的 | 让对手开始倒霉 |
| 弱在哪 | 不能打 | 污不动气运满的人 |

两朵出自同一处，决定了它们永远不可能被同一个人同时持有一一账本的正反两面，不认一个主人。
