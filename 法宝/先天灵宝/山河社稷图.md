# 山河社稷图

> 一句话：**它不是把敌人关起来的牢，是把「外面」画没了的画——进去的人不是被困住，是「这里就是全部」。**

## 一、档位与来历

| 项 | 值 |
|---|---|
| 品阶 | [[先天灵宝]]（42 道极品） |
| 系列 | 先天 |
| 来历 | [[混沌青莲]] 解体时的**莲瓣**之一 |
| 现主 | [[女娲]] |

莲瓣这一批里，[[河图洛书]] 管「算得出」，[[七宝妙树]] 管「刷得掉」，[[红云]] 的葫芦管「收得走」，**它是唯一一件管「画得出」的**。

## 二、能力：把世界画成一张画

- 展开之后，一片山水自成天地：有山有水有日有月，**但它只有这么大**。
- 进入画中的人会发现：走不出去，不是因为有墙，而是**再往前就还是画**。
- 更狠的一点：**画里的时间是画的人定的**。所以在画里待了很久，外面可能只过一瞬——反之亦然。

### 为什么这不是「结界」

| 手段 | 机制 | 被破的方式 |
|---|---|---|
| 结界／禁制 | 挡住 | 打碎它 |
| 困阵 | 困住 | 破阵眼 |
| **山河社稷图** | **替换掉「哪边是外面」** | 想不起外面还有什么 |

它伤人不在皮肉，在**「把参照系换掉」**。从画里出来的人常常先问一句「我进去多久了」——因为他在里面算不出来。

## 三、女娲为什么用它

女娲手里的活全是「收拾残局」：造人（给一个标准）、补天（把破的那一块垫回去）。

[[女娲补天]] 之后天带只垫回八成，**剩下两成永远歪着**。这件事没法靠力气解决，只能让它不再恶化——山河社稷图在她手里的用法是：

> 把某一块坏掉的地方「画进去」，让它在图上维持原样，外面按新的规矩继续过。

所以它不是她的武器，是她的**封存手段**。

## 四、代价与限制

| 限制 | 说明 |
|---|---|
| 只收「地方」，收不了「人」 | 人进去可以，但收的是他所在的那片地方 |
| 画里的人会老 | 不是时间停止，是时间**换了算法** |
| 必须展开 | 收起时只是一卷画，什么都护不住 |
| 对「不可分的整体」无效 | 同 [[界柳]] 的软肋：一整块的东西画不进去 |
| 认主 | 别人抢去也能用，但画出来的山水会「不像」——一眼看得出不是原主 |

## 五、写作约束

1. **不许用它当牢房**：它是画，不是监狱。
2. **不许写「里面过了千年外面只一瞬」的爽文用法**：它的时间差是**折磨**，不是福利。
3. **不许别人用它困住圣人**：圣人不在「有参照系」这个层级上。
4. 出场只写「展开」「卷起」「看看画里现在是什么季节」。
