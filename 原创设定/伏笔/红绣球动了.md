# 红绣球动了

> 一句话：**它从开天起一次没落过，也一次没动过。主角见的这一面，是它第一次动。**

**本页只在原创设定层生效，不改正史。** 正史里 [[红绣球]] 依旧「一次没落」（U-376），这条线写的是**玩家介入之后**发生的事——而它动的那一下，也没有落。

## 一、这一层是干什么的

「伏笔」收的是原创剧情片段：不是规则，也不是人物，是「到某个条件就会发生的事」——触发、过程、后果、破法，四样齐全，方便二次创作直接取用。

## 二、触发条件

| 条件 | 说明 |
|---|---|
| 主角与 [[女娲]] **见过一面** | 见面的原因可任选（求道、送还失物、随行、被带上昆仑），**这一面本身不要求任何好感度** |
| 见面时**不是求她办事** | 凡有求于她的见面，绣球不动；她是这么说的：「求我的人太多，我只能先分清哪个是人」 |
| 主角身上**一根线都没有，或者已经断了** | 线还挂着别人的，绣球不动——它动的前提是「这里没有第二条路」 |

三条同时满足才触发。**它不挑强弱、不挑出身、不挑在不在册。**

## 三、过程

1. 她抬眼看了一下主角，看了很久（久到主角以为自己做错了什么）。
2. 袖中的绣球**动了一下**——没有飞出去，没有落，只是动，像是转过头来。
3. 女娲的动作停了半息。她认得这个动静，因为**从开天起它一次没动过**。
4. 姻缘簿上那一栏第一次有字：不是「绣球」，是「绣球·动」。[[月老]] 那边看得见，但他不解释、也不问。
5. 线自此有了：**主角与女娲之间，一个人一根，两端都系上了。** 这是本库第一条不走红线的姻缘。

## 四、后果

| 后果 | 内容 |
|---|---|
| 主角 | 线已成。此后任何其他人的线都系不上（要系得先断这根），A 套上限视为已解锁 |
| 女娲 | 线已成。她是全书第一个「被绣球选上」的人，也是唯一一个她自己都不确定要不要接受的人 |
| 红绣球 | 动过之后**归她袖中，不再动第二次**——它只认一次 |
| 月老 | 只在簿上写「动」，不写「落」；他照旧不改已成的线，也不催 |
| 正史 | **无影响**。主线里的女娲仍是补天造人那位，绣球仍是威慑那件 |

## 五、破法与代价

- **能不能解**：能。解法是「断线」——但绣球记的线**不能自断**，得由女娲本人去求月老断（她从不求人，所以这一步的代价是一件事，不是一句话）。
- **代价**：断完之后，绣球那一栏回到空白，且**此后不再为任何人动**（已用掉的那一次不回收，与「号不回收」同理）。
- **不承诺**：她不会因为线成了就留在主角身边。这条线的性质是「有了一个位置」，不是「她就得在」。

## 六、这条线为什么值得存在

1. **它给「绣球」这条空路一个入口**：正史两次没成（没落、没动），原创层里第一次有了实际效果。
2. **它解释女娲为什么是例外**：全书唯一不被册、不被名分、不被战力衡量的关系——因为选人的东西不是天庭，是那颗球。
3. **它自带悲剧结构**：绣球只动一次，也就是说，无论结局怎么走，主角都不可能再有第二次。

用户记为「先记这么多，还没想完」。以下四项我按最保守的默认写了，改它们不牵动正史：

| 项 | 当前默认 |
|---|---|
| 见面的**具体原因** | 留空（写「可任选」），不锁死任何人际前提 |
| 主角**为什么身上没有线** | 不写，由角色创建时决定（孤儿、断过、未系都成立） |
| 女娲**自己的态度** | 只写到「她不确定要不要接受」，不写她动心——圣人不写心动，只写「她第一次没有立刻回答」 |
