# 天地玄黄玲珑宝塔

> 一句话：**它不挡，它让攻击「打不到你身上」——立于不败之地。**
> 一件**先天功德至宝**：没有炼制，只有"开天那一刻剩下的东西"。

## 一、档位与来历

| 项 | 值 |
|---|---|
| 品阶 | [[后天至宝]]（49 道；类别＝功德至宝，出身仍是先天） |
| 特殊类别 | **先天功德至宝**（见 [[后天至宝]] 末节） |
| 材料 | [[玄黄之气]] 中的**大道玄黄之气** |
| 功德来源 | [[盘古]] 开天功德（三清是盘古所化，故能分到） |
| 现主 | [[太上老君]] |

它跳过了"炼制 42 道 → 功德顶到 49"这条路：**材料本身是开天的产物，功德本身也是开天的功德，两者同源**，所以在开天之际直接凝成 49 道。

## 为什么收在「后天至宝」目录

它的出身是**先天**（材料是开天那一刻的[[玄黄之气]]，功德是[[开天功德]]），但归档按**类别**：凡是[[功德至宝]]，一律归 `法宝/后天至宝/`——因为「后天至宝」这一档的另一个名字就是功德至宝。

所以这一条有两个标签同时成立：**系列＝先天**（出身），**品阶＝后天至宝**（类别与归档）。校验器对带 `先天功德至宝` 标签的条目豁免「系列与品阶不符」这条检查。

## 二、核心：立于不败之地

- 一旦祭出，**无视绝大多数攻击**；诸邪避乱、万法不侵。
- 但它不反击。它解决的是"你会不会死"，不解决"对方会不会死"。

这一点决定了老子的战斗方式：**他能永远不输，也因此从不赢。**（与[[太极图]]"只分不合"是同一件事的两面——他手里全是"守"与"分"，没有"立"与"行"。）

## 三、与其它防御手段的差别

| 手段 | 原理 | 弱点 |
|---|---|---|
| 硬挡（护体、金身） | 承受 | 总有一个上限 |
| 躲（挪移、空间） | 不在一处 | 被钉住就完了（见 [[帝江]]） |
| **玄黄宝塔** | **让这一击在因果上不算打到** | 只保护"本人"，护不住别人 |

所以它护不住身边的人：老子在封神里能保自己，保不了截教那些人——**这件宝塔从来不是"救人"的东西。**

## 四、写作约束

1. **不许它被破**：全书没有一次它被打破；它只能在"来不及祭出"时失效。
2. **不许它攻击**：一旦写成能打人，老子"不立规矩"的人物逻辑就全塌了。
3. **不许别人用**：它认主，且只认"分到那两股气的人"。
4. 出场只写"祭出/收起"两个动作，不写光效。
