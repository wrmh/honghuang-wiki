# 散仙

> 一句话：散仙不是「不入流」，是**「不在任何一本册子上、但活得下来」**——
> 全书只有这一种人证明了：不进编制也能活，代价是永远不被承认。

## 是什么

四本册子（[[封神榜]]、[[生死簿]]、[[天庭历法]]、族谱）一本都不记他，这就是散仙的定义。
不是「没人管」，是**「管不到」**——两件事完全不同：没人管的人随时会被想起来，管不到的人连被想起来都难。

| 项 | 编制内 | 散仙 |
|---|---|---|
| 位置 | 有（名在册） | 无 |
| 资源 | 定额 | 自己找 |
| 上限 | 到顶就停（位置固定） | 无上限，也无保障 |
| 死法 | 有名有姓（榜上或册上） | 死了没人知道 |

## 为什么能活

因为他们**不占位置**，所以不触发清算；因为他们**不结大因果**，所以不招圣人。
[[陆压道人]] 是唯一被点名的例子：有债无被告、帮赢的那一边、打完就走。

**代价是三条，条条都硬**：不能被救（没有位置可换命）、不能收徒立派（一旦成形就要登记）、不能被记（做了大事也不进账）。

## 与其它「走法」的对照

| 走法 | 换掉了什么 | 例子 |
|---|---|---|
| 进编制 | 自由 | [[妖族天庭]] 星君、[[地府]] 阴差 |
| 换名字（归西） | 名字 | [[长耳定光仙]]、[[三千红尘客]] |
| 换身份（变成别人） | 身份 | [[九尾]] 一族 |
| 换自由（被打服） | 名分 | [[孔宣]] |
| **做散仙** | **承认** | [[陆压道人]] |

**五种走法都换掉了一样东西，散仙换掉的是「被承认」**——这一条最轻也最重：轻在不用交人，重在永远不算数。

## 三条硬性质

1. **不能成群**：散仙一抱团就变成势力，势力就要登记。所以「散仙联盟」不存在，只有临时搭手。
2. **不能成圣**：圣位要账要名，散仙两样都没有（走 [[愿力]] 也没用——愿力要有人信，散仙没人信）。
3. **活得久但不出名**：全书散仙的死法一律写得含混（「此后不闻」），因为他们本来就没被记。

## 写作约束

1. 不许把散仙写成「隐世高人」（那是另一种套路：其实很强只是不管事）——散仙的核心是**没身份**，不是藏起来。
2. 不许让散仙在关键战役里改变结局（他们不进场）。
3. 写散仙只写「他来过、他走了、没人记他」，不写他的师承与来历。
4. 不许用它当解围工具（「恰好有个散仙路过」这种写法一律不用）。

## 关系

- 例子：[[陆压道人]]（唯一点名）、[[云霄]]（失败的另一种）
- 对照：[[封神榜]]（有名有位置）、[[天庭历法]]（排班的人）、[[生死簿]]（记死的人）
- 相关：[[妖族天庭]]（编制）、[[九尾]]（宁可变成别人也不当散仙）
