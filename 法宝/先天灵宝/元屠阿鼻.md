# 元屠阿鼻

> 一句话：它们不杀「人」，它们**结账**。

## 是什么

[[冥河]] 的一对佩剑，各 36 道禁制（[[先天灵宝]]·上品），血海自生。

两把剑的分工是这对法宝唯一重要的事：

| | 元屠 | 阿鼻 |
|---|---|---|
| 斩什么 | **有形的**：肉身、法体、残魂 | **留名的**：名字、记录、在册的位置 |
| 效果 | 断了就是断了，无法再生 | 从账上划掉，无人记得曾经有过 |
| 谁最怕它 | 肉身强横者 | **有编制者** |

## 为什么杀人不沾因果

因果是账，血海是账的终点。东西到了这里，账就结了——所以剑不欠账，它只是**把账送到终点**。

这也解释了它们为什么杀人不沾因果：不是剑特殊，是**它们从来不在账内动手**。

## 阿鼻为什么可怕

[[冥河]] 之所以没人敢请下场，不是因为元屠。

是因为阿鼻能划名字。而洪荒此后的秩序全部建立在「名字在册」上——

- [[封神榜]] 是名册；
- [[天庭历法]] 是名册；
- [[六道轮回]] 是名册；
- 连 [[九尾]] 拼命要混进去的，也是一个名册。

**一把能划名字的剑，等于一个能拆编制的按钮。** 所以四劫里没有一方提过要借它——提了就等于承认自己的名册可以被撕。

## 与诛仙四剑的对照

[[诛仙四剑]] 立在规则上：斩谁由规则定，规则不变。
元屠阿鼻立在账外：斩谁由持剑人定，没有规则。

一个在制度内，一个在制度外——这也是 [[冥河]] 与 [[鸿钧]] 的关系：一个往里走，一个往外站。

## 写作约束

- **不写双剑合璧的绝招**。它们不是一套武功，是两种账务处理。
- **不让它们离开血海**。一出海，账就乱了。
- **阿鼻的斩名必须罕见**：全书最多一次，且斩完要有人发现「少了一个名字」。
