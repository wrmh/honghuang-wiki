# 嫦娥

> 一句话：**她这一生做的事只有一件——把话说对。**

## 是什么

天庭在册的女仙，隶属太阴星一侧，却在天庭领一份职。洪荒里极少有这种两头都站着的人：**册是[[册府]]发的，事是月亮交办的。**

她的位子不是荣耀，是补缝。

## 为什么需要她

[[太阴星君|太阴星]]与[[太阳星君|太阳星]]都不入天庭的册：

- [[常羲]]开门不交权，能通问，但不接天庭的使；
- [[羲和]]三次不开门，天庭连话都递不进去。

可这两颗星是天庭**离不开**的东西：历法靠它们、农时靠它们、[[周天星斗大阵]]的边也压在它们身上。制度上必须有一条线，能说「问过了」，又不能是「管住了」。

于是有了她。

## 一个位子，两套规矩

| | 太阴这一侧 | 太阳那一侧 |
|---|---|---|
| 她去做什么 | 替天庭把话问清 | 顺带把话带到 |
| 对方怎么对她 | 收留她，像收留一个肯听的人 | 不理她，但不赶她 |
| 能不能答 | 能答，答完就完 | 答不答看那天热不热 |
| 她回天庭怎么说 | 照原话 | 照原话，一个字不加 |

**关键：她是「信使」，不是「代表」。** 她从不替两星做承诺——这一点是[[常羲]]收她时唯一的条件：「你不用替我说月亮的话，你只要把话带对。」

## 一趟话怎么走

1. **接**：天庭有文，落在她手上；她只接**说得清的**，说不清的退回——「话不通，就不必走这一趟」。
2. **走**：夜里动身。两星之间的路很窄，只有天黑那段能过。
3. **到**：进太阴星不敲门；进太阳星先在门外站一会儿，等热散了才开口。
4. **听**：听完就记，不辩、不问第二遍、不替对方圆场。
5. **回**：原话带回，连语气都照搬；被人追问「她是不是不高兴」，只答「她没说不高兴」。

## 「大羿之妻」这个说法

本库**不采用**。理由三条：

1. [[大羿]]是巫族大巫。若给她一个巫族的丈夫，月宫这条线就被扯进巫妖血债里，她那个「往来于两星之间的信使」的位子立刻站不住；
2. 巫妖血债的债主是[[帝俊]]那套编制，不是月亮。她若嫁给射日的人，就成了债的一部分——她这辈子做的事恰好是**不让任何一方把话搅浑**；
3. 这个故事在她身上最没用的地方，是把一个**跑腿的、专业的、把话带对的人**，写成了「一个等人的女人」。

她在人间被传成望夫、被传成偷药、被传成悔——都是后来的话。她自己只说过一句：「**我不是在等人，我是在等天亮了好把话带回去。**」

## 外貌

### 一、头面

脸是清瘦的瓜子脸，颧骨略高，下颌线清楚；皮肤白而干，是常年夜里在外走的那种白。眉是细长的远山眉，几乎不描；眼睛是深褐带一点灰，眼尾略垂，看人时眼神很稳，不闪。

鼻梁直，鼻头略尖；唇薄，唇色偏淡，常抿着。

头发是黑的，梳成**单髻**，用一根素白玉簪别住——不解开，也不加饰。散下来能到腰下，夜里走路时会用一条素带束在颈后。

### 二、身形

身高 **168 cm**，身量清瘦，肩窄腰细，走路时略微前倾——**常年赶夜路的人都不自觉地这样走**。

三围 **86 / 60 / 88**。手指细长，指甲剪得很短；手背有一层薄茧，是常年提灯磨出来的。

### 三、服饰与妆造

**衣服**：内里是月白的天庭制式宫装（交领、窄袖、素色缘边），外头披一条**太阴星赐的霜色披帛**。

两样都穿，是有意的：宫装说明她受天庭管，披帛说明月亮认她。**她不换衣服，也不把两样混成一色。**

脚下是素色软底履，走路没声。

**随身**：一盏**不点的小灯笼**，提在手里。她说点了会招人，亮处看不清路；也有人说她只是舍不得用月亮给的火。

**妆造**：只在鬓边压一点薄粉，唇上不施红。她说过：「夜里涂得艳，是给谁看。」

### 四、特殊标记

- 左腕一圈细银链，链上缀**三颗小珠**：一颗是[[常羲]]给的，一颗是天庭发的，第三颗是她自己留的空位——没说过要放什么。
- 身上常年有一点凉，靠得太近会觉得像站在井边。
- 眼睛在极黑的地方会反出一点光，很淡；她夜里看东西比常人清楚。

### 五、气质与神态

**她的话是照着别人的话说的。**

- 开口前先复述对方的话，确认没听错，再答。
- 不说重话，也不说软话；评价谁都是事实判断，不加态度。
- 从不在人背后改口；当着人怎么说，回去就怎么说。
- 走路很轻，坐下时会先把裙摆收好；别人说话时她不打断，只在必要处接一句「我记下了」。
- 一年里有一半的夜在路上。别人问她孤不孤，她答「路上有月亮」。

### 六、写作忌处

1. 不许写「望夫」「偷药」「悔恨」这一类——本库不采用那套故事。
2. 不许让她替两星做主：她只带话，不带条件。
3. 不许把她写成弱者：她不强，但从不含糊。
4. 不许让她和[[大羿]]有私情——哪怕一句暗示，都会破坏她「谁的话都带得对」的位子。

## 关系

| 对象 | 关系 | 备注 |
|---|---|---|
| [[常羲]] | 收留她的人 | 条件只有一个：把话带对，别替月亮开口 |
| [[羲和]] | 说得上话 | 不理天庭，但不赶她；热天让她在门外多站一会儿 |
| [[天庭]] | 在册任职 | 唯一一条通天庭与两星的线 |
| [[册府]] | 记她的名 | 她这一格写的是「通问使」，不是「月宫之主」 |
| [[大羿]] | 无私人关系 | 本库不采用「夫妻」说法 |

## 写作约束

1. 她出场必须带一件在做的具体事：接话、走路、听、记。
2. 写她就写「话怎么被带过去」；不写她思念谁。
3. 她与两星的关系，永远是**事情关系**，不是情感关系。
