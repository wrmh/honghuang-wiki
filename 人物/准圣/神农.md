# 神农

> 一句话：他把自己的身体当成了实验记录本。

## 是什么

人族三皇之二（[[伏羲]]、神农、[[轩辕]]）。[[伏羲]] 算的是「变化」，神农定的是「可用」——洪荒里什么东西能吃、能治、能种。

## 尝百草：一次人与物的对账

洪荒的草木各有归属：有的补气运、有的伤魂魄、有的只是毒。这些知识原本只在天道那本账上写着，谁也不知道。

他做的事很笨：**一样一样吃下去，看身体怎么反应。**

| 他得到的 | 他付掉的 |
|---|---|
| 每一种草木的「归属」 | 一份不可逆的身体损耗 |
| 可传授的用药之法 | 他的五脏变成透明的（传说里「肝肠可见」） |
| 一套「什么能吃」的公共知识 | 他自己成了这套知识的第一份代价 |

**这是人族第一次用「重复试验」换知识**——不是天启，不是神通，是拿命试。

## 与伏羲的分工

| | 伏羲 | 神农 |
|---|---|---|
| 对象 | 时间与变化 | 物与身体 |
| 方法 | 演算 | 试验 |
| 产物 | 卦（可算的符号） | 本草（可查的清单） |
| 共同点 | **都可传授、可验证** | 同左 |

人族能活下来，靠的不是谁更强，是**这两套东西都能传给下一代**。

## 与五谷、与息壤

他要种东西，就得有能长东西的土——[[九天息壤]] 是昆仑山下那层「能增量的土」，与他这一条直接接上：**神农不造土，他只是第一个知道该往哪儿种的人。**

## 结局：他最后不再尝了

不写死法。没有断肠草、没有七窍流血、没有葬在哪里。只写一句：某一天他放下草，不再尝了。

这是「把人当试验记录本」这条线唯一的收尾——代价不是一次性的死，是**能尝的器官先一步用完**。人族后来给他立庙，庙里供的不是「尝过百草的人」，是「一开始不认得草的人」。

## 本草去哪了：被仙门收走

百草的知识没有留在人族手里。大部分被仙门收走，成了**丹药体系的底子**——[[玄都大法师]] 那座丹炉里烧的方子，最早的一批就是从这里来的。

这是本库最冷的一处：救人最多的知识，最后归了最不需要它的人。人族只剩「知道哪些草能吃」，不知道「为什么能」。
## 写作约束

- **不写成神医**。他常常判断错，错了就是一条命。
- **不写他百毒不侵**。他的强在于敢试，不在于不会死。
- **保留「笨」**。他的方法是全书最不玄的一个，也正因此最有效。
