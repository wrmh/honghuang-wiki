# 劫会

> **每一会一场小劫。** 一元会十二会，前十一会各结一次小账（就是它），第十二会才是量劫。名字叫「会」不叫「战」，因为它本来就排在「会」这个账期上。

## 一、它是什么

| 项 | 值 |
|---|---|
| 频次 | **每一会一次**（10800 年）；一元会十二会 → 前十一会各一场，第十二会是量劫 |
| 性质 | 局部、有胜负、**可以不去**；死的是各地的小账，不是整本册子 |
| 与量劫的关系 | **量劫的预演，也是分摊**：账提前结掉一部分，第十二会手上就轻了（见 [[量劫]]、[[元会]]） |
| 谁在打 | 各势力自己打；天庭只派 `雷部`／`水部` 这类「按条款执行」的人核数，不点名 |
| 打完了记什么 | 各地自己记；要上 `册府` 的只有「位」的变动（谁死了、谁补谁） |

## 二、为什么分成十二段

龙汉、巫妖两次都是「一元会算一次总账」，一次算得太狠：三族尽伤、灵脉断两千七百年、巫族散场。后人把账拆成十二份，第十二份才是总账——**同一笔账，拆开就不至于把人一次杀光**（见 [[元会]] 第三节）。

所以「劫会」不是新发明的战争，是**把量劫的手续提前了**。

## 三、游戏映射（玩法层的话，正史里不出现）

- **一个月办一期**，一周年正好十二期 → 第十二期就是量劫。
- 每一期的胜负只影响下一期的起手（地盘、人数、账），不影响整本册子。
- 允许缺席：不打就是「这一会你不在」，不影响下一期能不能进。

## 四、群体好感度的两个入口（见 [[好感度]] 第七节）

| 入口 | 条件 | 结果 |
|---|---|---|
| 随行 | 群体好感到 **+L（归心）** | 可以跟着这个群体去打，**但他们不会主动邀请你**——去了有风险，赢了也不算你的人情 |
| 被盯 | 群体好感到 **-L（死敌）** | 这一场里该群体会**专门盯着你打**，且不掩饰 |

中间八档没有入口：**劫会不是社交场**，它只认两端。

## 五、暂不写（占位）

1. 赛制（几轮、怎么算赢）。
2. 结算与奖励（赢了给什么、输了扣什么）。
3. 死亡是否上 `册府`（现在只记位的变动）。
4. 与第十二会量劫撞在同一年时怎么开。
