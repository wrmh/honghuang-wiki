# 东岳大帝

> 一句话：**他是天庭派到轮回门口的签字人——只签「这个人确实到期了」，签不了地府内部的账。**

## 一、他为什么在这里

天庭管的是**活人有多少、活多久**；轮回是活人变成死人的**最大分流口**。

如果这个口子上没有人核一遍，就会出现最麻烦的一种错：**册子上记着某人还在世，人却已经投了胎。** 一旦发生，天庭历法与地府名册就对不上，往后所有账期都会歪。

所以天庭在这里设一个常驻的签字位，由东岳坐镇泰山——泰山是人间与幽冥之间的那道门在图上的位置（见 [[幽冥]]）。

## 二、他能签什么、不能签什么

| 事项 | 能不能 |
|---|---|
| 核「某人的寿数是否到期」 | **能**，且这是他的核心职权 |
| 核「来的是不是这个人」 | 能（对册，不对人） |
| 决定某人该去哪一殿 | **不能** |
| 改生死簿上的任何一笔 | **不能**（生死簿执笔的是判官，见 [[四大判官]]） |
| 命令十殿阎罗 | **不能** |
| 放人回阳 | 不能 |

一句话：**他是门房，不是审判官。** 门房能拦住不该进的，决定不了进去以后怎么处置。

## 三、与另外三位的关系

| 谁 | 来源 | 管什么 | 与东岳的接口 |
|---|---|---|---|
| [[后土]] | 本源 | 轮回盘，只在转不动时出面 | 几乎不接触（层级不同） |
| [[酆都大帝]] | 地府自身 | 行政、审判、执行 | 每天打交道的上级 |
| [[地藏]] | 佛门派驻 | 劝、听、记 | 互不统属，偶尔在门口遇见 |
| **东岳大帝** | **天庭派驻** | **生死交界处的核验** | —— |

这四个人**没有一个能命令下一个**（见 [[地府]]）。地府之所以既打不起来也独立不了，就是因为门口坐着的是别人家的官。

## 四、他的位置为什么稳

天庭换过几次主，地府换过几次帝，**东岳这个位子一直没换过人**。

原因不是他强，是**换掉他不划算**：新人来要重新认一遍册子、重新跟判官对一遍口径，这中间的错账没人赔。所以他成了三界里少见的「位置比人稳」的神职。

## 五、写作约束

1. **不许他下场战斗**：他是签字的人，不是打仗的人。
2. **不许他与地藏争权**：两家的活儿不重叠，争起来就没有真正的矛盾可写。
3. **不许他救人**：他放不了人，这是他与佛门最大的区别（佛门也只救下一世）。
4. 出场只写「核册」「落印」「让路」三个动作。
