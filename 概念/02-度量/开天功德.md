# 开天功德

> 一句话：它是洪荒的**第一笔账**——在它之前没有「该不该」，在它之后，一切都可以被拿来算。

## 是什么

[[盘古]] 开天这一件事本身，在 [[天道]] 那里记下的第一笔。本库按既有裁决只做定性，**不给数值**：

> 开天功德＝洪荒气运账簿上的第一行，从此之后所有气运都在这本账里流转（见 [[气运]]）。

## 为什么它不能有数值

这是本库刻意的一条写作约束，理由有三个：

1. **数值会引出兑换率**：一旦说「开天功德＝三万」，立刻就要回答「一分功德能换多少气运」，那整套体系就变成一个游戏数值表。
2. **它要能"被认领"而不是"被分配"**：功德的特点是谁认领谁背账（见 [[女娲]] 造人、[[鸿钧]] 立道），如果它是一个数，就变成可以分的。
3. **它必须足够大到"分不完"**：分得完，四劫就不成立——**账之所以能一劫一劫地算下去，是因为这笔本金永远结不清。**

## 它落到谁身上

| 承接者 | 拿到的是 | 代价 |
|---|---|---|
| [[盘古]] | 开天这件事本身 | 身殒，化生万物（见 [[开天辟地]] 的化生清单） |
| [[三清]] | 元神三分（一部分功德的继承权） | 三份遗嘱，谁都不算正主（见 [[三清]]） |
| [[巫族]]（祖巫与大巫） | 精血一支（肉身与血脉的继承） | 只继承身体，不继承「道」 |
| [[女娲]] | 造人＝把这笔账**认领**成自己的 | 气运清零（见 [[女娲补天]]） |
| [[鸿钧]] | 立道、定序＝把账**制度化** | 合道，从此不能下场 |

关键点：**开天功德不是"盘古留下的遗产"，是一笔"还没被认领的债"。** 谁认领谁就背上「洪荒该怎么运行」这个责任——这也解释了为什么六圣成圣的条件是「认领一笔没人认的账」（见 [[故事线]] 4.5）。

## 与「功德」的一般关系

一般意义上的 [[功德]] 是行为的结果（造人、补天、治水）；开天功德是**这笔账的本金**。两者关系像：

| | 开天功德 | 一般功德 |
|---|---|---|
| 性质 | 本金 | 利息／还款 |
| 会不会耗尽 | 不会 | 会（用掉要记「已用」） |
| 能不能抵因果 | 能（这是它能抵的原因） | 能，但有限 |
| 谁管 | 天道本身 | 天道、册子、圣人 |

## 为什么它是四劫的根

| 劫 | 与这笔账的关系 |
|---|---|
| [[龙汉初劫]] | 三族争「开天功德」的分配权——它们都觉得自己该继承一份 |
| [[巫妖量劫]] | 巫族主张血统继承（精血一支），妖族主张编制继承（秩序一支），**两种继承法打架** |
| [[封神量劫]] | 不再争继承，改用「签押摊账」（见 [[封神量劫]]） |
| [[西游量劫]] | 账已经摊完，只剩欠款要走程序还（见 [[西游量劫]]） |

一句话总结本库对四劫的理解：**四劫是同一笔本金，四种结账方式。**

## 写作约束

1. **不给数值、不给兑换率。**
2. **不写「功德可以攒」**：它只会被认领、被用掉、被记上「已用」。
3. **不写任何人「拿到了开天功德」**：他们拿到的是**责任**，不是财产。
4. 任何提到它的段落，都要落到「谁背了什么账」，不要落到「谁变强了」。
