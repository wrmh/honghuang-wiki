# 天庭

> 一句话：**它不是[[妖族天庭]]的延续，是它的接手人**——同一份岗位表，换了主人，也换了性质。
> 这一条先定**框架**（谁在哪一层、权力从哪来、不管什么），没定的都进末尾的「未定稿问题」。

## 〇、先分清两个「天庭」

全书最容易写混的一处，先把两张表摆开：

| | [[妖族天庭]]（帝俊的） | **天庭**（昊天的） |
|---|---|---|
| 本体 | 血缘王朝 | **程序官僚** |
| 谁是主 | [[帝俊]]／[[太一]] | [[昊天上帝]] |
| 位置怎么来 | 血统给的（365 星君＝365 阵位） | 册子给的（[[封神榜]] 上榜即归位） |
| 人能不能换 | **不能**（位置挂在人身上） | **能**（位置在，人可换） |
| 兵源 | 妖族全族 | 三教死者的名字 |
| 命门 | 血缘不可补，少一个就崩 | **缺编**：没人上班，规矩就执行不了 |
| 结局 | 倾覆（巫妖量劫） | 满编（封神之后），此后长期在场 |

一句话记：**妖族天庭是「一群有血缘的强者占住了岗位」，天庭是「一套岗位找人来坐」。**

它从妖族天庭手里只接了一样东西：那张 **365 星位的岗位表**（见 [[妖族天庭]]「政权即阵法」一节）。不接人、不接血脉、不接旧主。而这张表自带一个难题——**编制不满，天庭就运转不了**，这正是 [[封神量劫]] 的直接起因。

## 一、框架总图（六层・顶层是「六御」）

```
【0 主位】  昊天金阙玉皇大帝（[[昊天上帝]]）
              │ 并列：[[瑶池金母]]（王母｜女仙与蟠桃，不管编制）
【1 中枢】   ┌───┴────┐
           星部（历）   册府（名册）
              │
【2 五辅御】 ┌────┼─────┬──────┬──────┐
          [[紫薇大帝]]  [[勾陈大帝]]  南极长生  东极青华  [[后土]]
        （中天·坐标）（军职）（定数）（救苦）（幽冥·实独立）
              │   ← 主位＋这五位＝「六御」（见 [[六御]]；后土只挂尊号，不上朝）
【3 职能六部】斗  雷  火  水  太岁  财
              │   ← 六部全立（斗/雷/火/水/太岁/财），全是上榜的死名字
【4 地方末梢】[[城隍]]（城）  ｜  [[山神河伯]]（山河）
              │     └ [[土地]]（乡野，按地界挂在山河口下）
              │   ← 三套并行，互不隶属（城隍不是土地的上级）
【5 派驻与外部】[[东岳大帝]]（地府门口签字）  [[太白金星]]（传旨）  [[四大天师]]（文书）
```

**读法**：上面三层（0–2）**定规矩**，下面三层（3–5）**办规矩**。天庭的毛病是——定规矩的人多，办规矩的人不够用。

**还有一层「文官」**：星部、册府、四大天师这一路，都是不作战、只管账的**文官**。它们不是单独一层，而是散在 1、5 两层里——**天庭的骨是文官，皮是武职**。

## 二、六层各是什么

| 层 | 谁 | 管什么 | 权力从哪来 | 命门 |
|---|---|---|---|---|
| 0 主位 | [[昊天上帝]]＋[[瑶池金母]] | 发位置、批文书、定名分；金母管女仙与蟠桃 | 天道授权（鸿钧合道后规矩自己办） | **没有战斗力**：他一动手，天庭就变成「能打的势力」，而它是机构 |
| 1 中枢 | 星部／[[册府]] | 星部校 [[天庭历法]]（时间）；册府管名册（位置） | 编制内、可替换 | 星部一停日子就漂；册府一漏名字就错 |
| 2 五辅御 | [[紫薇大帝]]／[[勾陈大帝]]／[[后土]]／[[南极长生]]／[[东极青华]] | 坐标／军职／幽冥／定数／救苦 | 册子给的位置 | 五位里有三位是妖族天庭的旧编制，混着坐；后土不上朝 |
| 3 职能六部 | 斗／雷／火／水／太岁／财 | 兵、刑、火、雨、年运、赐福 | [[封神榜]] 上榜归位 | 全是「死人的名字」，**只会按册办事，不会变通** |
| 4 地方末梢 | [[城隍]]／[[山神河伯]]／[[土地]]（土地挂在山河口下） | 收香火、报账、管一地 | [[册封]] 给的承认 | 城隍独立、山神河伯与城隍并行、**土地日常归山神河伯按地界管**（U-449 B，收窄 441B）；靠 [[香火]] 养 |
| 5 派驻与外部 | [[东岳大帝]]／[[太白金星]]／[[四大天师]] | 地府门口签字、传旨、管文书 | 昊天直接派 | 派驻的人**只签一头**，签不了别人的账 |

### 曾经「两头当差」的那几个人（U-436 B）

天庭接手岗位表时，**有几个旧星君没死透**：他们被收编了，但**名字被重写过**——旧名留在妖族天庭的册子上，新名进了封神榜。

- 这样的人**极少**，且天庭从不公开承认；
- 他们最危险的地方不是战力，是**记得旧天庭怎么运转**（知道哪个位置可以互相替代、哪一段可以空着）；
- 写作上只许出现「某位神对旧制熟得不像新来的」这种暗示，**不许点名**。

## 三、它靠什么活着：不生产，只分配

天庭不产气运、不产功德，它**分配**三样东西：

| 卖什么 | 怎么卖 | 谁记账 |
|---|---|---|
| **位置** | [[封神榜]] 上榜即归位；散仙给名不给册 | 册府 |
| **日子** | [[天庭历法]] 定节气、行雨、巡狩 | 星部 |
| **名分** | [[册封]] 只给承认，不给权力 | 昊天亲批 |

香火是人间的记账动作，经它核过（见 [[香火]] 四种收法）；功德它年年刮一笔，还握着「这笔记给谁」的分配权（见 [[功德]]）。

所以它穷到要刮香火，却谁也不敢得罪它——**不是因为强，是因为它在册子那一头。**

## 三之二、朝廷不是机器

把人间的朝堂写成一台只会按条款运转的机器，是最好写也最假的一种写法。天庭跟人间的朝堂一样，三种人同时在里头：

| 人 | 长什么样 | 例子 |
|---|---|---|
| **一心为公的** | 宁可什么都不做，也不越权；宁可自己背骂名，也不改一个字 | `雷部巡检` 停手回报、`水部量水` 定位不到就全体减 |
| **只想着自己的** | 把差事当生意：刮来的功德先留一手，能拖的账拖着换人情，能卖的面子卖一次 | 五部里那些还没立条的中层 |
| **按规矩混日子的** | 大多数：条款怎么写他怎么填，出事就说「我是照册办的」 | [[城隍]]、[[土地]]、各路末梢 |

条款管得住第三类，管不住前两类。所以天庭真正靠的不是条款，是**权衡**——让前两类互相牵制，让第三类照章办事。[[昊天上帝]] 的本事正在这里：他不是没有私心，他是把私心办成了公事的形状。

**钱也这么走**：天庭不生产，靠刮功德的分配权、各方岁贡与公器产出来活着（见 [[功德]]）；大头入总账由帝支配，其余折成份例发下去（见 [[份例]]）。**每年这份账怎么分，就是朝堂里最大的那件事。**

写作口径：写天庭的每一件事，都要能回答一句「**这件事里谁得了什么**」。没有人得利的事，在天庭是办不成的。

## 四、它不管什么（四条最容易被写错）

1. **不管生死**：生死归 [[生死簿]] 与 [[地府]]，它只在门口签「确实到期」。
2. **不管轮回**：[[六道轮回]] 归天道直辖，[[后土]] 只维护不使用；天庭连边都摸不着。
3. **不管修行**：境界是人自己修出来的（见 [[修行境界]]），天庭只发「金仙以上」那种**位置**。
4. **不判对错**：它执行规矩，不裁定规矩。规矩在鸿钧合道之后**自动运行**（见 [[天道]]），但**执行的是人**——同一条规矩，谁去办、办几步、办偏一点，全看人情与位置。

## 五、命门与三步解法（它的力量曲线）

**缺编**是结构性弱点。三步解法一步比一步被动：

1. **封神**：用位置换命，把死者的名字填进岗位（[[封神量劫]]）；
2. **关门**：[[绝地天通]] 一断，人上不来，只能靠册子招人；
3. **走程序**：到 [[西游量劫]] 连「派人」都做不到，只能**出文书**——文牒一批，剩下靠佛门自己走（见 [[八十一难]] 二组「官面」）。

**从「缺人就补」到「只能批条子」，这就是它全书的力量曲线。**

## 六、写作约束

1. **不许它有战斗力。** 它没有能打的人，只有能签的字。
2. **不许两朝的人混用。** [[帝俊]]、[[太一]]、[[白泽]] 属妖族天庭；[[昊天上帝]]、[[东岳大帝]]、星部属天庭。
3. **不许[[昊天上帝]]出手。** 他的权力形状是「签字」，不是「斗法」。
4. **补编只能靠 [[封神榜]]。** 不许用别的东西填天庭的位置。
5. **不许写成暴政，也不许写成圣人。** 它不压迫，它**办事慢**——慢才是它可怕的地方；但它也不清白，它要好处。
6. **不许让职能部「灵活处理」。** 上榜的神是按册办事的死人，越灵活越不像天庭——**灵活留在人情那一层**（中层、地方、帝自己），不在条款那一层。
8. **不许把天庭写成无人的制度机器。** 制度是给人用的：每一道命令背后，都有一个人在算自己的账。
7. **没立条的位置不许加双链。** 六部里的具体职司（斗姆、雷祖、二十四天君等）还没立条，正文里只写纯文本；已立条的（[[册府]]、[[星部]]、[[三官大帝]]、[[六御]]、[[太白金星]]、[[四大天师]]、[[南极长生]]、[[东极青华]]、[[瑶池金母]]、[[城隍]]、[[土地]]、[[山神河伯]]）可以正常链接。

## 已定（2026-11-15 裁决）

- **文官层（U-435 A）**：有。星部、册府、四大天师这一路都是不作战只管账的文官；它们不单列一层，散在第 1 与第 5 层。
- **两头当差（U-436 B）**：有极少数旧星君残部被收编，**名字重写过**；天庭从不公开承认，写作只许暗示「某位神对旧制熟得不像新来的」，不许点名。
- **主位是两位（U-437 A）**：昊天金阙玉皇大帝与瑶池金母**并列**——一个管神道名册与位置（[[昊天上帝]]），一个管女仙与蟠桃（[[瑶池金母]]）；编制归昊天，女仙与宴不归他管。
- **册府立条（U-438 A）**：已立 [[册府]]，是天庭的人事处，与星部（历）对称。
- **顶层叫「六御」（U-439）**：主位＋五位辅御＝六御（见 [[六御]]）；其中 [[紫薇大帝]]（中天）、[[勾陈大帝]]、[[后土]] 三位是妖族天庭旧编制，[[南极长生]] 与 [[东极青华]] 是新立的。**后土只挂六御尊号，不上朝、不列班**（她身化[[六道轮回]]，位在地府一侧）。
- **六部全立（U-440 A）**：斗部／雷部／火部／水部／太岁部／财部各一条，上榜者的去处自此具体。
- **地方的层级（U-441 B＋U-449 B）**：[[城隍]]（城）与 [[山神河伯]]（山河）**并行互不隶属**；[[土地]]（乡野）**日常归山神河伯按地界管**，但册封仍直通天庭——所以土地对上游是「业务归山河、名分归天庭」两头挂。城隍始终不给任何人转公文；地方上「事办得慢」的制度原因就在这套双轨里。
- **派驻立条（U-442）**：[[太白金星]] 与 [[四大天师]] 都立条；使者管「话有没有到」，天师管「文书有没有走完」，两条合起来解释天庭为什么慢。
- **南极与东岳分工（U-443 A）**：[[南极长生]] 掌「**该给多少**」（定数），[[东岳大帝]] 掌「**是不是到期**」（核数）；一个定，一个核，谁也不能替对方改。
- **没有储君（U-444 A）**：天庭是机构，位置不是血统传的。**「谁接班」这个问题在天庭是不成立的**——它最怕被人看出它也想有个血统继承。
