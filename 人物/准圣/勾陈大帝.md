# 勾陈大帝

> 一句话：**他管天下所有「该动兵」的事，却一个兵都调不动——因为他管的是「该不该打」，不是「谁去打」。**

## 一、他在六御里的位置

| 项 | 内容 |
|---|---|
| 排行 | 六御之三 |
| 尊号 | 勾陈上宫天皇大帝 |
| 管什么 | 统御万雷、兵戈战事：什么时候算「兵革之事」、该由哪一套办 |
| 权力从哪来 | 榜上给的一格（`封神榜`），与紫薇同批 |
| 命门 | **只有裁断权，没有调兵权**：兵在 [[斗部]]，令在 [[火部令|火部]]那类公器，他能定「该打」，动不了具体的人 |

所以天庭里最常出现的一幕是：**他说该动兵，然后看别人肯不肯动。** 他签的那一笔是「这事算兵革」，剩下的排队、点兵、发令全在六部手里。

## 二、帝与「位」的区别（最容易混的一处）

| | [[勾陈位|勾陈]]（星位） | 勾陈大帝（人物） |
|---|---|---|
| 是什么 | **职能位**：编制里专门留给「打」的那一个格 | **守着这一格的人** |
| 在哪 | `概念/04-星位` | `人物/准圣` |
| 缺了会怎样 | 打得赢也没人去打（妖庭的死穴） | 该动兵的事没人认这一笔，全推回给 `册府` |
| 是不是「最强的那个」 | 不是，它是位不是人 | 也不是，他的分量在裁断 |

一句话记法：**位是「该有人去打」，帝是「谁说这算该打」。**

## 三、他与妖族天庭、斗部的关系

- **旧编制**：勾陈位在 [[妖族天庭]] 是唯一作战位，[[太一]] 一人兼着（`东皇钟` 在他手上）。这件事就是妖庭的死穴：**武力是一件单件装备**，他一被钉住，政权的「打」整个停摆。
- **接手**：天庭照收这一格（见 `封神榜签押`），但**兵权拆了**——训练、点兵、调度归 [[斗部]]，那是 U-248 定的方向：与其留一个专属武力位，不如把功能拆给机构。
- **于是有了那口气**：斗部与勾陈抢「军职」的名义（见 [[斗部]]）——真正办事的是斗部，真正签「这算兵革」的是勾陈。**名实在两边，谁也吃不掉谁。**

## 四、怎么写他

- **他最常见的样子是「批一个字」**：不是点将，是在一道公文上认下「兵革」两个字。
- **他不点兵、不训兵、不上阵**：点兵的是斗部（`斗部点兵`「位全，能战者半」就是他批下来的那种局面）。
- **与大羿射日那次的关系**：那件事在**第三元会**，那时这个位子还是 [[勾陈位|勾陈]]，坐的人是 [[太一]]——**大帝一职是封神之榜才立的，中间隔了一个元会**。他见过那一卷：后人问「该不该动兵」，答案被记在天规那一侧，他认这个结论，但他本人不在场。
- **不写他征战**：写征战要写斗部、写雷部、写火部；他只在开头与结尾出现。


## 外貌

### 一、头面

四十上下的方脸，眉很浓，**且修得能看出是修过的**（他不掩饰这一点）。眼不大，看人时先看对方的肩与腰——判断能不能动兵。唇线紧抿，几乎不笑。

### 二、身形

身高 **186 cm**，肩宽背厚，腰背笔直；走路只在方寸之间，不是不快，是每一步都按「该走多远」走。虎口宽，右手有握剑磨出的薄茧。

### 三、服饰与妆造

- **常服**：朱红底墨金云雷纹武袍，束墨色革带；**腰横一柄剑**，剑鞘上有封条，多年没拆。
- **朝会**：加玄色披风，只到肩，不罩全身。
- 从不穿甲：他不是上阵的人。

### 四、特殊标记

**右手虎口薄茧却没有裂口**（握而不战）。**剑鞘封条上盖的是天庭的印**，不是他自己的——「这口剑不是我的，是这个位子的」。

### 五、气质与神态

说话只说「该不该」，从不说「能不能」。被问具体怎么打，他把话交回 [[斗部]]；被问该不该打，绝不含糊。发火不提高声音，只是把话说完就起身。

### 六、写作忌处

- 不许让他亲手开战或亲自上阵。
- 不许写成莽将：他的力气全在「定性」上。
- 不许让他与 [[斗部]] 抢同一个动作。

## 五、写作约束

1. **不许写他亲自出手**：他要是动手，就说明制度那一侧全废了。
2. **不许把他写成好战**：他管的是「兵革的边界」，越界他反而最紧张。
3. **不许写他调动军队**：调不动是设定，不是失误。
4. 他出场必须有**一份东西等他签**，与紫薇同一写法。
