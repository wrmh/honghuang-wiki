# 天竺佛门

> 一句话：**它不翻译——它只把原话念给你听。听不懂是你的问题，不是话的问题。**

## 它是什么：一条不能跳的次第
天竺佛门不是「更正统的那一支」，是「没有改过口的那一支」。它教的是一套次第：

| 步 | 做什么 | 跳过去的后果 |
|---|---|---|
| 戒 | 先把自己能做的事减少 | 没有戒的定，是把自己练得更硬 |
| 定 | 再让心停在一处 | 没有定的慧，是聪明 |
| 慧 | 最后才看得见「为什么苦」 | 没有慧的戒，是规矩的奴隶 |

**本库最看重的是「不能跳」这一条**：天竺佛门认为三学是阶梯，不是三样工具；
你想先要慧，就等于想只要结果、不要过程——这是本库认定的**最危险的一种聪明**。

## 沿革

| 时间 | 变了什么 | 为什么变 |
|---|---|---|
| 第二元会末 | 立教即以原话为法 | 接引只把话念出来，不解释 |
| 第四元会第 11 会起 | 佛指骨入法门寺 | 经可以被重讲，骨不能——最硬的凭据是实物 |
| 第五元会 | 译本之争白热化 | 格义那一支把词换掉了，两支第一次正面撞上 |

## 内部结构

```
戒师（受戒年月只在戒师手里）
  └─ 梵行僧团（依戒次第，不依境界）
       └─ 受戒者（账上只有一行：受戒年月）
```

它最像一条传承链，最不像一个组织：**没有中枢，只有戒**。

## 力从哪来

| 层 | 管什么 | 权力从哪来 | 命门 |
|---|---|---|---|
| 戒 | 能不能算佛门的人 | 戒师付法 | 戒师死则断一代 |
| 定 | 能不能坐得住 | 自己练 | 没有戒的定是把自己练得更硬 |
| 慧 | 能不能看破 | 自己证 | 没有慧的戒是规矩的奴隶 |

## 死穴

1. **不翻译就学不会**：不肯翻译的学问只能等人来学它的语言，而这一洲的人没有那个时间。
2. **凭据是实物**：骨在则正统在，骨失则无凭。
3. **账只有一行**：受戒年月，多一个字都不记。

## 编目控制

- **判断依据**：通行说法（西天取经、梵文原典）＋本库新立（三学次第的三种错法、法门寺佛指骨作为凭据）
- **异说登记**：见 `## 版本差异`
- **最后校订**：第五元会（2026-11-22）

## 它的规矩：音译不意译
这是两支真正的分界线，也是最好写的一处：

- 涅槃就叫**涅槃**，不叫「无为」；
- 般若就叫**般若**，不叫「智慧」；
- 禅那就叫**禅那**，不叫「坐忘」。

理由一句话：**一意译，它就落进南赡部洲本来有的那个词里，从此讲的是那个词，不是这件事。**
所以天竺佛门宁可让人听不懂，也不肯让人「听懂了一个别的」。

## 账怎么记：只有一行
灵山给这一支记的账，全库只有一行——**受戒年月**。

- 这一行**不由本人报**，由戒师填；
- 它不问你会什么、讲过几场、度了几个人；
- 它只回答一件事：**你从哪一天起，算这屋里的人。**

对照 `[[果位]]`：果位排座次，受戒年月排先后——两本账，不能互换。

## 命门
**它保住了原意，所以它学不会。**
一门不肯翻译的学问，只能等别人来学它的语言；而南赡部洲的人没有那个时间。
于是它人少、位高、不出山——**它不扩张，不是不想，是不能。**

## 与另一支的边界
- 与 `[[格义佛门]]`：那一支管「怎么讲」，这一支管「讲的是什么」；**两支不互相贬低**（见格义佛门第六节）。
- 与 `[[佛门]]`：佛门是整体，这一支是它的一条口。
- 与 `[[灵山]]`：灵山是治所，不属于任何一支——治所要是归了某一支，另一支就不来了。
- 与 `[[度牒]]`：度牒认「你是佛门的人」，受戒年月认「你从哪天起算」；**两样都要**。

## 写作忌处
1. **不许把它写成「正统」**——本库两支都真，只是话不同。
2. 不许让它用道门的词解释自己（一用就成了另一支）。
3. 不许安排它「终于想通了去翻译」——它的价值恰恰在于不翻。
4. 写它的人说话要少：一句顶别人三句，且不解释。
5. 不许把「听不懂」写成傲慢，那是它的成本，不是它的姿态。
