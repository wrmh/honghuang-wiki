# 孔宣

> 一句话：书的半程里没有一个人打得过他——**因为他的本事不是修炼来的，是从娘胎里带的。**

## 是什么

[[凤族]] 旁支，元凤直系（见 [[元凤]]、[[凤族]]），本相孔雀。五色神光在手，封神前半段把阐教诸仙刷了一遍。

他的位置很尴尬，本库把他写成一类人的代表：**血统上够，名分上不够。**

| 他有的 | 他没有的 |
|---|---|
| 元凤直系的血脉 | 凤族的族籍：他入不了族（见 [[凤族]] 的「涅槃一次损一脉」） |
| 一身没人能破的本事 | 一个位置：截教不要他，阐教收不了他 |
| 天下最强的「不接受」 | 任何可以交易的东西 |

所以他不站队不是清高，是**没有队可站**。

## 五色神光：一种无法被「破」的东西

它的强不在威力，在**性质**：

| 对上什么 | 结果 |
|---|---|
| 法宝、兵器 | 一刷即落（不问来历） |
| 神通、法门 | 一刷即散 |
| 阵法 | 刷不散，但阵里的人会被刷出来 |
| 讲道理 | 无效：它不讲道理，它只收 |

本库的定性：**五色神光是「构成」，不是「规则」**——所以它对 [[诛仙四剑]] 那种判决类的东西没用，但对付一切「有形有样」的东西几乎无解（单独立条见 [[五色神光]]）。

## 为什么只有 [[七宝妙树]] 能刷他

这是全书一处刻意对称：

> 五色神光是**天生的**，七宝妙树刷的正是**天生**的东西（见 [[七宝妙树]]）。

所以那一场不是斗法，是**同源相克**：一个是「我生来如此」，一个是「我让你不如此」。青莲的瓣压得住孔雀的光，理由不在禁制多四道，在**来路更早**。

## 被收之后

他一战之后归了西方（[[接引]] 那一路），后世称「孔雀明王」。

本库对这段的处理很冷：**他不是被度化，是被收编。** 西方要的不是他的道，是他的**光**——一件能刷落一切构成的兵器，对「没有粮只有嘴」的西方来说，比一个圣人门徒值钱得多。

也因为他归了西方，[[西游量劫]] 里那条路上再没人敢拦——**拦路的那个已经在这条路的股东名单上了。**

## 人物要素

### 一、基础标识
孔宣｜男｜第二元会末生（凤族血脉）｜出身凤族｜现居 金鸡岭（后归佛门）｜族属 妖族（孔雀）

### 二、外貌体征
186cm 肩窄腰细、重心偏一侧，眼底五色在缓慢地流，耳后一小片细羽（详见 `## 外貌` 六节）。

### 三、性格气质
眼睛长在头顶上，却从不自称第一；骄傲是「不必跟人解释」，不是「我看不起你」。

### 四、身份背景
凤族血脉，五色神光之主，截教之外的一支；封神时无人能破其神光，最后被佛门收走——有座次，无佛位。

### 五、能力喜好
五色神光可刷万物，唯不可分之物不可刷；爱好整理尾屏；价值观：本事在身上，不必挂在册上。

### 六、言行特征
说话慢、眼睛不看你；口头禅「你也配」很少出口，多半只是那一眼；从不主动出手。

### 七、状态与关系
与 `如来` 地位相当而无佛位；与 `凤族` 有一层说不清的亲；诉求：不必进任何一本册子。

### 八、补充标签
- 闪光点：输也只输给比自己更不讲道理的东西。
- 缺点：太相信自己的光，忘了光是刷不动整体的。
- 标志性事件：封神战场上无人可破，最后被收进佛门，名号在而位置不在。

## 外貌

### 一、头面

二十岁上下的脸，漂亮到让人先记住脸、后记住话；眉细长入鬓，眼尾上挑，瞳色不是一种——**近看是五色在缓慢地流**（青赤黄白黑，每一色都在走）；眼白极净，睫毛长而密；唇薄而上翘，笑起来像在讥人（他其实没那个意思）。

耳后贴近发根处有一小片极细的羽——本相残留，他自己拔过，又长出来。

### 二、身形

身高 **186 cm**，肩窄腰细，四肢长。站立时重心偏一侧，下巴微抬——不是傲慢，是**从没学过低头**。

### 三、服饰与妆造

外面一件素白广袖，里面衬着五色织的羽衣——那不是染的，是他自己褪下来的羽织成的，**别人穿不了**（穿上去像裹了一块死羽）。束发用一枚孔雀羽管，本相的东西，从不离身。

### 四、特殊标记

手背上有一层极薄的彩，像油膜浮在水面，光一照才看得见——那是神光留下的痕。

后颈正中有一小块皮肤永远比别处凉。

### 五、气质与神态

- 说话带刺，但刺是往外撒的，不挑人；被反驳时会先愣一下，然后笑得更好看。
- 打起来极兴奋，眼睛会亮成一片——**那是他唯一像妖的时候**。
- 被收之后，那层亮再没出现过。

### 六、写作忌处

1. 不许写他自己认「凤族正统」：他知道自己是旁支，**正因为知道才更恨**。
2. 不许写五色神光被随便破掉：全书只有 [[七宝妙树]] 能刷他（见该条）。
3. 不许写他哭、不许写他跪下求饶：他败了也只是不再说话。

## 妖身

| 项 | 内容 |
|---|---|
| 形态 | **五色孔雀**。五色不是染的，是羽面在光里过一遍留下的痕 |
| 尺寸 | 收尾约八丈；开屏时尾屏近十丈 |
| 状态 | 大体完好，唯**尾屏正中缺三根**——被 [[七宝妙树]] 刷断的，长不回来。被西方收走之后，本相再也没有现过 |
| 要害 | 尾屏正中；[[五色神光]] 就是从那里出去的 |

他是「血脉上够、名分上不够」的那一类，本相把这件事写得很直白：**毛色够正，尾巴有缺**。开屏时那三根空着的位置最显眼，他从不背对光站着。

**写作用法**：不许写尾屏圆满（缺三根是定死的）；不许写他化形骗人；他若现形，先写光，再写羽——**五色先到，鸟后到**。

## 关系

- [[元凤]]：血脉上的母亲一辈，但凤族不认他（见 [[凤族]]）。
- [[准提]]：收他的人。两人此后再无对话记录——收编不需要谈话。
- [[接引]]：真正的接收方。他接的是「一件东西」，不是一个人。
- [[陆压道人]]：同为「血脉上的余孤」，一个归隐、一个被收，本库两人全书无照面。

## 版本差异

| 说法 | 内容 | 本书 |
|---|---|---|
| A | 孔宣是凤凰之子，天生神通 | **采用**：并且加一条「血脉够、名分不够」，用来解释他不站队 |
| B | 孔宣后来成佛，地位极高 | 部分采用：位置很高，但写成「被供起来的兵器」，不是觉悟者 |
| C | 五色神光可以刷落任何法宝 | 不采用：对判决类（[[诛仙四剑]]）与账外之物（[[无相面]]）无效 |

## 写作约束

1. **不写他被「打败」**：他是被同源的东西收走的，不是被打服的。
2. **不写他悟道。** 他一辈子没有过「想通了」这种时刻。
3. **不写他与 [[天吴]] 的风对刷**——风没有形，神光刷不动，撞上只会两散（可作留白）。
4. 他的台词少，且都是短句：**他不解释自己。**

## 已定（2026-11-15 裁决）

- **U-259**：算。只是被供起来，偶尔出手。他的本相还在，只是不再属于自己。
- **U-260**：没有交集。两条线不交叉：一个被收编，一个自己跑过去，前后差着几百年。

## 已定（2026-11-15 裁决）

- **U-431 B**：大鹏是他的**亲弟弟**。兄弟两个后来的去处不一样——他守着佛门的门面，大鹏成了佛门的兵。这是「收编一族」最省事也最狠的做法：**不用灭族，把他们拆到不同位置就行。**
