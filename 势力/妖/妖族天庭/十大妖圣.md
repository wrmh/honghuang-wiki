# 十大妖圣

> 一句话：**妖庭的中层不是官职，是十张脸——名册上有十个位置，能当场报出名号的始终不到七个。**

## 一、星君是「位」，妖圣是「名」

[[妖族天庭]] 的 365 星君是**阵位**：一位对一颗星，战时就是阵里的一个格子，可值可替、死了能补（补上来的不一定是原来那个）。

妖圣不是格子，**是名字**：

| | 365 星君 | 十大妖圣 |
|---|---|---|
| 靠什么进 | 位（阵里缺一格） | 名（洪荒里有人记得他） |
| 能不能换 | 能，位不认人 | 不能，换个人就不是那个名号 |
| 战时做什么 | 站进阵里 | **自己冲出去** |
| 死后 | 位补上，阵照转 | 名号空着，没人敢接 |

所以妖庭打仗时有两套东西同时在动：**星君是把阵撑住，妖圣是把人心里那点「我们会赢」撑住。**

## 二、十个名号

| 名号 | 管什么 | 在阵里做什么 |
|---|---|---|
| 白泽 | 知——知道对方是谁、从哪来 | 不说话，只在前一夜把答案递给帝俊 |
| 计蒙 | 雨 | 让战场先湿，甲重三分 |
| 英招 | 巡 | 绕着阵走，谁掉队谁被捡回来（或被处理掉） |
| 鬼车 | 夜 | 把夜拉长一刻 |
| 九婴 | 水火 | 两边一起用，所以两边都不够 |
| 穷奇 | 兽 | 把散兵聚成一群 |
| 饕餮 | 食 | 吃阵里掉下来的东西，包括自己人 |
| 混沌 | 乱 | 让对面认不出自己人 |
| 梼杌 | 顽 | 打不退——不是强，是不懂退 |
| 毕方 | 火 | 火烧完之后那一段，归他 |

**十位不是十个高手，是十种「战场之外的东西」**：知、雨、巡、夜、水火、兽、食、乱、顽、火。所以妖庭的强不在谁最能打，在**它能把天气、时间、人心一起拿来用**。

## 三、中层为什么一直是空的

因为妖圣**不入册**。

`册府` 的三本主册只写「人」与「位」（见 [[册府]]）：有格子、有份例、可罚可削。妖圣两头都不占——他们有名号没有位置，也没有份例，赏赐是当场给的（一次给完，不进账）。

结果就是：**妖庭有一层人，从来没被任何册子记过。** 天庭接手妖庭时，星君照着阵位一个一个收了，妖圣**一个都没收**——不是不收，是单子上根本没有他们。

与 [[不在册]] 是同一个形状：不在册不是身份，是一种状态。区别是妖圣**自己知道**，而且他们是自愿的——有位置就要听调度，有名号才冲得出去。

## 四、巫妖量劫：死得最多的那一层

十位里活下来的不到三位。

原因很实在：**星君不会自己冲出去，妖圣会。** 星君是位，位不动；妖圣是名，名要靠「我去了」来维持。所以越是打不动的时候，他们越要出去——**不出去，名号就淡了；淡了，就没人记得妖庭还有这一层。**

这也是 [[北海]] 那批残部为什么只剩「同乡」而没有「号令」：**中层全死在了出发的那一次。**

## 五、四条写作约束

1. **不许写他们开会、不许写他们上朝**——他们不是官，只在「要出去」的时候出现。
2. **不许十个同时出场**——同时出现三个以上，就说明妖庭已经到最后一战；那是 `巫妖量劫` 后段，不能提前用。
3. **不许写他们归顺天庭**——天庭的名册上从来没有他们的格子，归顺无处可归。
4. **写「出面」不写「出力」**——他们的作用是让人相信能赢，不是把谁打死。
