# 凌霄宝殿

> 一句话：**它不是一座宫殿，是一个麦克风——进了这道门，说出口的每一句都会变成册子上的一行。**

## 一、它是什么

天庭正殿，`昊天` 坐的位置所在。殿不高，也不长；台阶比殿身更占地方——**位置比建筑重要，这是它的设计原则。**

进了这道门，话就不再是话：

| 在门外 | 在门内 |
| --- | --- |
| 试探 | 表态 |
| 商量 | 决议 |
| 「我看可以」 | 「准」 |

同一句话，进来前后是两件事。所以天庭的人在这里说话极慢——**慢是因为每一句都要被写下来。**

## 二、为什么它必须「入档」

天庭只分配三样东西：位置、日子、名分。三样都不能私下给：私下给的东西，收不回来。

于是需要一个**公开的、有记录的、当众的**地方。凌霄宝殿就是那个地方：

- 位置在这里给（所以 `封神榜签押` 之后要在这里宣读）；
- 日子在这里定（`行雨定额`、`考功` 的期都在这里排）；
- 名分在这里落（谁是谁的部属，进这道门才算）。

**它不做好事、不判对错、不改账**——它只让「已经定下来的事」变成当众发生过的事。

## 三、朝会怎么开

三步，从不多一步：

1. **报**：该报的由 `星部`／`册府`／六部报上来，一句一件事，不解释；
2. **问**：只问「有没有不认的」，不问「好不好」；
3. **定**：定了就写，写了就散。

散会之后殿门关着，谁也不在里面议事——**议事的场合在别处，入档的场合只有这一处。**

## 四、三条硬规矩

| 规矩 | 破了会怎样 |
| --- | --- |
| 说出口就入档：出了这道门不能改口 | 能改口的地方就不是决议，天庭立刻退回人情秩序 |
| 不在这里议事，只在这里定 | 一旦议事，殿就成了内阁，公开性反过来变成密谋 |
| 位置在先、人在后：位子空着，会照开 | 一旦等人，所有议程都要为一个不在的人停 |

第三条是结构性的：**天庭不为人停。** 这也是它冷的地方——会开完了，那个人可能永远不会来了。

## 五、写作约束

1. 不写金碧辉煌、不写仙乐祥云：**写空、写高、写台阶多**。
2. 朝会场面只写三步（报、问、定），不写争吵、不写私下递眼色——**这里没有回合，只有宣布**。
3. 不写昊天在会上长篇讲话：他说的都是短的，且都是能入档的。
4. 写到「定了」之后要给一句「殿门关上了」，别写余音。
5. 不写有人在这里痛哭、求情、喊冤：求情有别的门，这里只收决议。

## 未定稿问题

- [ ] U-548 殿上有没有「不开口的人」的位子？
  - A 有：末席留一排空位，是给「该到而没到」的——空着也算一种出席
  - B 没有：位子只给能开口的；不开口的人在这里没有位置
  - C 有过：某一位从不开口，但位子一直留着，后来没人敢撤——成了惯例
- [ ] U-549 决议能不能在这里被推翻？
  - A 不能：定了就是定了，要改只能在下一件事上改回来（所以天庭常「将错就错」）
  - B 能，但要当众：推翻必须在同一道门里、同一批人在场，否则不改
  - C 能，且有过一次：那一次之后，殿上添了一条「不复议」的规矩
