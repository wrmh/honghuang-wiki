# 地府

> 一句话：**它不是"阴间的朝廷"，是轮回这台机器的运维班子——有编制、有分工、没有主权。**
> 后土不在这里当判官；她只在机器要停的时候出现。

## 一、它是什么

[[后土]] 化[[六道轮回]]之后，洪荒有了「死后的去处」。但一台机器立起来只是开始：**谁分流、谁记账、谁维持秩序**——这些活要有人干。

地府就是干这些活的组织。三条性质定死：

1. **归天道直辖，不进天庭编制**：天庭管活人，地府管死者，两套册子互不隶属（见 [[天庭历法]] 的"登记的 vs 天赋的"）；
2. **没有主权**：地府不拥有轮回，只维护它。幽冥的地界也不是它的领土，是它**守着的地方**（见 [[幽冥]]）；
3. **只结算，不审判**：判官判的是"这一笔账该送到哪一道"，不是"这个人是好是坏"（见 [[因果]]）。

## 二、组织（十殿与判官）

| 层 | 谁 | 干什么 | 关键限制 |
|---|---|---|---|
| 最高 | **[[后土]]** | 只在**轮回运转受影响**时出面 | 不做判官、不日常理政、不管具体某个人 |
| 主事 | **十殿阎罗** | 分掌十殿，各领一类死者的分流与秩序 | 各殿之间互不统属，事涉轮回才合议 |
| 执行 | **判官** | 执笔登记、核对[[生死簿]] | **判官是人做的**，不是后土，也不是神职 |
| 差役 | 鬼卒、牛头马面等 | 押送、看守、传令 | 不入册、不可升迁 |
| 特殊 | [[巫咸]] 一类"记忆携带者" | 记录不该断的东西 | 不在编制内，靠口传 |

**十殿阎罗的写法**：他们不是"十个坏人头子"，是**十个部门的负责人**。每殿都有自己的册子与辖区，谁也不能替别殿签字——这一点与天庭的"名在册即有位"完全同构。

## 三、后土与地府的关系（最容易写错的地方）

| 错写法 | 本书写法 |
|---|---|
| 后土坐殿审案 | 后土不在殿上，她在盘边 |
| 后土是地府之主 | 地府是天道直辖，她只是轮回的持有人 |
| 判官听后土的话 | 判官按册子办事，册子才是权威 |
| 后土慈悲，所以宽赦 | 轮回不讲宽赦，只讲账期 |

**她出面的唯一条件**：轮回**转不动了**。这时候她会到场，且只做一件事——让它重新转起来。做完就走。

## 四、与其它势力的关系

| 对象 | 关系 |
|---|---|
| [[天庭]] | 互不隶属。天庭要人（封神）时，是**两个系统在换账**，不是上下级 |
| [[巫族]] | 后土本是祖巫，她这一走等于否定了全族的路线（见 [[巫族]]） |
| [[佛门]] | 地藏一系进入幽冥属"外来驻点"，不是地府编制（见未定稿） |
| [[鸿钧]] / [[天道]] | 地府的合法性来自天道，不来自任何一位圣人 |

## 五、写作约束

1. **不写"地府开会决定谁死"**：死亡是账，不是决议。
2. **不写后土下命令**：她的存在是"最后一个闸"，不是"最高领导"。
3. **不写十殿阎罗有野心**：他们没有可争的东西——位置不是资源，是职责。
4. 不写地府豪华或阴森：写成**办公场所**，最准。
