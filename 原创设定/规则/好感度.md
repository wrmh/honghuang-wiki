# 好感度

> 一个 NPC 对某一个人的态度，记成一个数。**这个数只决定「他愿不愿意」，不决定「他做不做得到」。**

## 一、底盘

| 项 | 值 |
|---|---|
| 区间 | **-100 ~ +100** |
| 初始 | **0**（被天赋改写，见 `万人迷` 的 20、`万人迷？` 的 50） |
| 方向 | **单向**：A 对 B 与 B 对 A 是两条独立的数 |
| 存储 | 记在 NPC 名下，不记在当事人身上 |
| 变动来源 | 三类：互动、事件、天赋 |

## 二、读法（不是阈值）

| 数值 | 这个人心里在说 |
|---|---|
| -100 | 这事只能用命抵 |
| -60 ~ -99 | 见一次坏一次 |
| -30 ~ -59 | 会找你麻烦 |
| -10 ~ -29 | 不想跟你说话 |
| -9 ~ +9 | 你是路人 |
| +10 ~ +29 | 记得你这个人 |
| +30 ~ +59 | 愿意帮你一次 |
| +60 ~ +79 | 愿意替你担一次 |
| +80 ~ +99 | 愿意跟你一起死 |
| +100 | 不再算账 |

**真正的门槛不在这张表里，在 [[亲密关系]] 表里**——关系档位决定「能要求什么」，好感度只决定「够不够」。

## 三、变动口径

| 来源 | 变动 | 说明 |
|---|---|---|
| 普通互动（一次帮忙、一次冒犯） | **±2** | 同一件事只算一次，重复刷无效 |
| 重大事件（救命、背叛、当众羞辱） | **±10 ~ ±30** | 由事件本身定，不叠加 |
| 一次性事件 | **只改一次** | 同一件事不因为被反复提起而反复加分 |
| 时间衰减 | 每 30 天向 **0** 回落 **1 点** | 正负都回落；不回落到越过 0 |
| 公开表态 | **±10** | 公开 > 私下；私下道歉只算 +2 |

## 四、几个必须记住的判定

1. **倍率只乘变动量，不乘阈值**。「增长变快」不会让关系更早建立，只让你更快到那儿。
2. **衰减与倍率不互乘**：先算衰减，再算天赋倍率。
3. **好感度可回复**，三条路：时间（慢）、实事（一次性 +5）、当面承认（一次 +10）。
4. **不可回复的例外**：**血债**——数值可以回，标记不消（标记见 [[亲密关系]] 的负向档）。
5. **群体是自己的一笔账**：「天庭」「妖族」这类复合体**没有单条好感度，但有「群体好感度」**——它不是一个人的态度，是所有成员对你的数加起来的总和（见第六节）。天赋对群体无效（`万人迷` 不能让一整个族喜欢你），群体只认总和。

## 五、与天赋的接口（三个钩子）

| 钩子 | 作用时点 | 谁在用 |
|---|---|---|
| 初始值 | 第一次见面，在 0 之上改写 | [[万人迷]]（20）、[[万人迷？]]（50） |
| 增速 | 每次变动之后乘倍率 | [[万人迷]]（正 ×1.5）、[[万人迷？]]（负 ×0.5） |
| 事件改写 | 触发条件成立时直接赋值 | [[慎议者]]（拉到 -10 或维系最低值） |

## 六、群体好感度

> 一个人的态度记成 -100~+100；**一个群体对你的态度，是所有这些人数加起来的总和**。个人好感决定「他愿不愿意」，群体好感决定「**他敢不敢、能不能**」。

### 1. 怎么算

| 项 | 值 |
|---|---|
| 定义 | **该群体每个成员对你好感度的总和**（负的照加） |
| 例 | 你在妖族有 10 个朋友，每人 30 → 群体好感度 **300** |
| 上限 | **+3000 封顶**：超过 3000 的部分**收益归零**（数照记，效果不再增加） |
| 下限 | **-3000 封底**：比 -3000 更负**不会再有额外 debuff** |
| 变动 | **不能单独加减**，只随成员变动；成员死了／离群，他那份从总和里移除 |
| 血债 | 成员欠你的血债标记**不因他死或离群而消失** |
| 谁有群体好感 | 只有**大势力级**群体有（天庭／妖族／巫族／佛门／龙族／阐教／截教／人族）；「六部」「十殿」这类下属单元不单独算，算在它的上级里 |

**为什么正好是 3000**：3000 ＝ 三十个人全满（30 × 100），是一个**中小群体「全员极好」**的量级。像妖族这种上万人的群体凑到 3000 反而更容易（人多），所以封顶限制的是「能不能继续换东西」，不是「有多难」。

### 2. 它怎么影响个人好感（三种，不得混用）

| 作用 | 规则 |
|---|---|
| **起手** | 你第一次见到该群体成员，他先按群体档位给你一个修正（见下表「初始」），**再**叠加天赋 |
| **增速** | 与该成员的**正向变动**乘档位倍率；**负向不变**——群体的好抵不了他个人的一次冒犯 |
| **天花板** | 他愿意为你做的事，**不超过群体档位允许的范围**：个人好感 80 也顶不过一个「见疑」的群体；反过来，群体再高也替不了他那 30 分 |

**旁观传导（可选细则）**：同群体两人都在场时，你与其中一人的互动会给另一人 **±1** 的旁观修正（最多 ±3，人再多也不叠加）——群体好，你当众做的每件事都被放大一点；群体差，你私下做的每件事都会被传歪一点。

### 3. 九档（专属奖励位留空，等内容定了再填）

| 档位 | 区间 | 初始修正 | 正向倍率 | 群体对这个人的行动许可 | 专属 |
|---|---|---|---|---|---|
| **归心** | **+3000（封顶）** | **+10** | **×1.5** | 群体可为你出面一次（每元会一次）；内部场合随意进出 | **专属奖励（待定）** |
| 同气 | +1800 ~ +2999 | +6 | ×1.3 | 可请一名成员代办一次；可列席内部议事 | — |
| 贴近 | +900 ~ +1799 | +4 | ×1.2 | 进内部场合需有人带；可求一次通融 | — |
| 相识 | +200 ~ +899 | +2 | ×1.1 | 可托一件公事（按规矩走，不破例） | — |
| 平常 | -199 ~ +199 | 0 | ×1.0 | 一切按规矩 | — |
| 有嫌 | -200 ~ -899 | -2 | ×0.9 | 不接受你主持的事；公事须第三人陪 | — |
| 见疑 | -900 ~ -1799 | -6 | ×0.8 | 进门要报备；不许单独见他的人 | — |
| 敌视 | -1800 ~ -2999 | -10 | ×0.6 | 见面即动手（不致命）；不能交易 | — |
| **死敌** | **-3000（封底）** | **-20** | **×0.5** | 见面即敌；只认命或功德 | — |

### 4. 三条容易搞错的

1. **群体好感不是平均值**：10 个人里 9 个爱你、1 个恨你，总和仍然很高——**群体记总账，不记口碑**。
2. **封顶与封底都是硬线**：+3000 之后再加人也不会更「归心」，-3000 之后再加仇也不会更「死敌」；多的部分只是**记着**。
3. **群体档位不能替代关系档位**：群体「归心」也不会让一个只有「面熟」的人替你去死（见 [[亲密关系]]）。
