# 三生石

> 一句话：**它不是预言石，是一份账目摘要——石上刻的不是「你下一世是什么」，是三笔已经发生过的账，对得上就亮，对不上就空着。**

## 一、它是什么

忘川岸上的一块石。不高，过人胸口，表面是平的，没有任何图案；靠着它看，才看得清上面的字。

它记三世：前世、今生、下一世。

前两世是**已经记完的账**，刻得明明白白。第三世的位置是空的——不是因为还没到，是因为**未发生的不入账**。

## 二、对上才亮

石上的字不是自己长出来的，是「对」出来的：

| 状态 | 石面 | 原因 |
| --- | --- | --- |
| 三笔都对得上 | 字迹清楚，第三世的位置透出一点光 | 账在 `轮回台` 那边已经算完 |
| 只对上前两笔 | 前两世清楚，第三世全黑 | 还没轮到 |
| 一笔都对不上 | 整块石面是灰的，像没刻过 | 此人的账不在这一本上（见 `不在册`） |

「灰的」这一种最容易被忽略：**不是每个人都有资格被这块石头条陈**。石上没字的人照样要过桥、照样要上轮回台，只是没有摘要可看。

灰石的人往下走不了那么快：先送**枉死城**挂起，等对得上再来。所以枉死城里那些「账没结清」的人，有一部分就是从这块石头前被领过去的——**不是他们不认账，是账还没长出来。**

## 三、它不回答什么

三生石最要紧的一条是它**不回答**的问题：

- 不回答「我下一世能不能好一点」——它只显示已经算完的，不预测。
- 不回答「我这一世做错了什么」——它写的是账，不是评语；要评语得去 [[孽镜台]]。
- 不回答「我能不能改」——石是死的，改账的地方在 `册府`，不在这里。

**三生石让人看见的只有一件事：你的一生，在账上是什么形状。**

## 四、三条硬规矩

| 规矩 | 破了会怎样 |
| --- | --- |
| 摸不到：手伸过去会穿过去 | 摸到就等于「拿走」，而摘要不能拿走 |
| 靠得越近看得越清，但只能看清自己那一段 | 别人的字对你是灰的——不是藏，是**不在同一本账上** |
| 同一个人的两世都经过这里，刻痕会自己改 | 改的不是旧账，是「摘要跟着新账走」；石没有记忆，它只是显示 |

## 五、写作约束

1. 不写石上出现预言、不写有人照着石上的字去找下一世的亲人——**石只朝后看**。
2. 不写「石认人」：它不认人，它认账。所以一个改过名、换过籍的人，在石上也可能什么都看不见。
3. 石面文字只给形状和修辞，不给完整句子：写「刻着他的名字，后面跟着一件他从不承认的事」，不写那件事是什么。
4. 出现三生石，就不要再写孽镜台的细节（一个给摘要，一个给回放，同时写会互相吃掉）。
5. 不许出现「把石上的字刮掉」——能改账的地方在册府，不在石头。

## 六、关系

- 位置：[[忘川]] 岸上（与 [[奈何桥]] 同在中段）
- 上游：`册府`（账在那边算完，石只是显示）
- 对照：[[孽镜台]]（回放一生细节，不给摘要）
- 下游：[[望乡台]] → [[轮回台]]
- 记账：石本身不记账，它显示 `功德`／`因果`／`气运` 三笔的对账结果

- **U-532** 石面是给谁看的——只有亡魂，还是判官也读它？ → 只给亡魂看。判官看的是册子，石头是给「自己」的——所以它没有解释、没有解说员，看见什么就是什么。
