# 十二祖巫

> 一句话：**盘古的尸体分出来的十二个股东**。他们不是「反派」，是唯一有资格说「这天地本来就是我家的」的一方——而这句话，正是他们必须被清算的原因。

## 是什么

[[盘古]] 精血所化的十二位祖巫，巫族的顶点与全部。血脉直系，肉身成圣，**不修元神**。

「不修元神」这五个字决定了巫族的一切：

| 不修元神的后果 | 具体表现 |
|---|---|
| 无法使用法宝 | 法宝需以元神御使，巫族只能靠肉身 |
| 无法理解阵法结构 | 所以他们的阵是「合体」而非「布阵」 |
| 无法合道、无法成圣 | 圣位属于元神体系，巫族结构上被排除在外 |
| 寿元有尽 | 肉身再强也会老死，除非不断以血脉续命 |

**这解释了 [[龙汉初劫]] 分宝为什么可以不给巫族**：不是歧视，是制度性排除——他们根本用不了。但「用不了」和「不给」是两回事，巫族听懂的是后者。

## 成员

十二祖巫各掌一种力量，名单**全部写实**（裁决 2026-11-13：写全，不留「其余八位」）。写全是刻意的——[[都天神煞大阵]] 的强度直接挂在「十二个位置缺一即崩」上，名字不全是那座阵就写不实。

| # | 祖巫 | 所掌 | 在本书里的位置 |
|---|---|---|---|
| 一 | [[帝江]] | 空间 / 速度 | 巫妖劫实际统帅，与 [[太一]] 单挑过一次（太一胜，但没杀成） |
| 二 | 句芒 | 木 | 主生发，负责巫族在洪荒的据点经营；巫族「能长住」靠他 |
| 三 | 蓐收 | 金 | 主杀伐，巫族兵器与刑律出自他；撞山之后第一个战死 |
| 四 | [[共工]] | 水 | 怒触 [[不周山]]，撞折天柱 |
| 五 | [[祝融]] | 火 | 与共工长期对立，水火之争贯穿巫族内部 |
| 六 | 烛九阴 | 时间（昼夜之转） | 与妖族 [[周天星斗大阵]] 的「定序」正面相冲，是两阵对撞时最先被耗掉的一位 |
| 七 | 天吴 | 风 | 巫族的「腿」，侦察与突进都靠他 |
| 八 | 玄冥 | 雨 / 寒 | 与共工同为水系，但主「降」不主「流」；两水不合，是巫族内部第二大裂 |
| 九 | 强良 | 雷 | 唯一的远程打击；肉身打法里最像「术」的一个 |
| 十 | 翕兹 | 电 | 与强良成对，雷生电、电引雷；两人合击是巫族唯一的「配合技」 |
| 十一 | 奢比尸 | 天候 / 毒 | 巫族最不受欢迎的一位：他管的是「让人慢慢地死」 |
| 十二 | [[后土]] | 土 / 生死 | 化六道轮回，本族命运的转折点 |

补一条结构观察：这十二位里，**只有帝江、烛九阴、强良、翕兹四个的能力是「非肉身」的**。也就是说巫族自认「只靠肉身」，其实并不成立——他们最强的四位里有三位靠的是规则性的力量。这件事巫族自己不愿承认，也解释了为什么 [[都天神煞大阵]] 合体之后能召出 [[盘古]] 真身：合的本质不是「肉身叠加」，是**十二种规则拼回一个完整的人**。

## 立场与诉求

- 要什么：**承认**。不是要天庭的位子，是要「这天地是父神身躯所化，我们天然有份」这句话被承认。
- 怕什么：被当成「不需要法宝的野蛮人」。他们的诉求从来是法理，不是资源。
- 与谁对立：[[妖族天庭]]（占天）、[[鸿钧]]（立序而未问过他们）、[[天道]]（把他们排除在体系外的那套规则）。

## 在量劫中的作为

- **拒认天道**：不拜鸿钧，不敬天庭。不是傲慢，是逻辑：凭什么一群后来者给父神的天地定规矩。
- **攻天庭**：由 [[帝江]] 率众，以肉身硬穿星斗防线。第一次让妖族发现「星君虽多，能打的没几个」。
- **布 [[都天神煞大阵]]**：十二人合体，召盘古真身。这是巫族唯一的「阵法」，本质是血脉回溯，不是术数。
- **[[后土]] 离阵**：为救洪荒亡魂，立誓化六道轮回。**都天神煞残缺一角，盘古真身差最后一臂**——巫族从均势转为劣势，转折点就在这一走。
- **[[共工]] 撞山**：败局已定后怒触不周山，天柱折，天倾西北。这一撞不是战术，是「既然我们得不到，那谁都别想要」的最终表达。

## 为什么巫族必须退出舞台

三层原因，从浅到深：

1. **战力结构单一**：只有肉身，遇上有准备的对手就没有变化余地
2. **无法传承**：不修元神意味着经验、道法、组织能力都无法沉淀，一代死完就归零
3. **法理失效**：他们的合法性建立在「盘古后裔」上，而 [[女娲补天]] 之后天地的合法性改由「功德」提供——**旧法理被新法理取代**，这是结构性淘汰

第 3 条是本书的重点：巫族不是被打败的，是**他们主张的那套道理过期了**。

## 关系

**与 [[混沌魔神]] 有无接触：无**（裁决 2026-11-13）。巫族是盘古精血所化，魔神是被盘古删掉的那一批；时间上错开，立场上相反，全书没有任何一次照面。这条定死是为了挡住「巫族求助于魔神」这类写法——巫族一旦有外援，他们的死就不再是「主张的道理过期」，而只是「打输了」，全书最重要的那层意思会塌掉。

| 对象 | 关系 | 备注 |
|---|---|---|
| [[盘古]] | 血缘父神 | 全部合法性的来源，也是全部局限的来源 |
| [[妖族天庭]] | 死敌 | 结构性矛盾，无谈判空间 |
| [[鸿钧]] | 拒认 | 不承认其立序资格 |
| [[后土]] | 内部异类 | 她选了「填规则」而不是「争主权」，等于否定了全族的路线 |
| [[共工]] / [[祝融]] | 内部对立 | 水火之争消耗了本族最后的余力 |
