# 紫霄宫讲道

> 一句话：洪荒第一次「上课」，也是最后一次「公开分配资格」。

## 起因

龙汉的账刚结完：[[罗睺]] 死了，西方灵脉毁了，[[鸿钧]] 手里握着一堆没人认领的东西——修行法门没有统一说法、谁能走到哪一步没人定、分宝怎么分也没规矩。

讲道的动机不是慈悲，是**制度需要在场者同意**。鸿钧要立的不是教派，是「洪荒从此有公认的标准」。

## 经过（三次讲道，层层递进）

### 第一次：修行的门槛

面向最广的一次，讲的是大罗金仙这一层的修行法门——怎么筑基、怎么避开自己道上的坑、为什么有的人永远卡在同一处。

- 听的人最多，记下来的人最少（不落文字，靠各人自己领悟，见下「不落文字」）。
- 这一次真正的成果不是法门，是**「修行这件事第一次有了共识」**：此前各家各法，此后至少能互相听懂。
- 副作用：听过课的人开始有「同门」的错觉，这正是后来三教都能自称正统的底气（见 [[三教]]）。

### 第二次：斩三尸

核心是「斩三尸」的证道之法——[[修行境界]] 里「大罗金仙 → 准圣」那道坎的真正内容。

- 三尸不是三个敌人，是**三笔拖住你的旧账**：善、恶、执。斩不是杀掉，是不再被它们记账。
- 这一次讲完，洪荒才出现「准圣」这个说法——此前只有「很强的大罗金仙」。
- 与本书的口径接得上：准圣之所以还成不了圣，是因为**账还没认领**（见 [[鸿蒙紫气]]）。

### 第三次：圣人之道

层次最高的一次，也是唯一一次讲「成圣」本身。

- 讲完当场做三件事：**收徒**（三清为亲传，女娲、接引、准提各记名分）、**分 [[鸿蒙紫气]]**（六道）、**定六席**（见 [[蒲团之争]]）。
- 第三次讲道结束后不久，鸿钧分宝、合道、闭宫。紫霄宫从此不再开讲。

## 不落文字

三次讲道**没有留下经书**（本库口径）：

- 不是不想留，是**留不住**——圣人之道一旦落成文字，就不再是道，而是一部可以被引用、被曲解、被拿去争正统的书。
- 后果一：所有「得道者」的记忆各不相同，六圣后来各有各的说法（见 [[故事线]] 六圣成圣一节的「顺序争议」）。
- 后果二：洪荒此后再没有第二个公共的知识来源，一切传承都退化为**师徒私授**——这直接决定了 [[巫族]] 没有培养体系、[[妖族天庭]] 只能靠编制、而人族必须自己发明「可重复、可传授、可验证」的东西（见 [[伏羲]]）。

## 后果

| 层 | 后果 |
|---|---|
| 规则层 | 修行有了公共标准；「准圣」「斩三尸」成为通用词 |
| 名额层 | 六道紫气、六个席位——**成圣从开放变成定额** |
| 势力层 | 三清、女娲、西方二圣各有名分；巫族一件未得（见 [[鸿钧]]：分宝排除巫族） |
| 长期 | 知识不再公共 → 一切靠私授 → 人族被迫发明制度（这是人族真正的起点） |

## 写作约束

- **不写讲道原文**。可以写「他讲了什么主题」，不写「他说了什么话」。
- **不写听众顿悟的场面**。顿悟是个人的事，写多了就成了集体鼓掌。
- **不写鸿钧的表情、语气、慈悲心**。他是执行者，不是导师。
- **不写第四次讲道**。宫门闭了就是闭了。
