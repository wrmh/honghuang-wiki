# 孔宣

> 一句话：书的半程里没有一个人打得过他——**因为他的本事不是修炼来的，是从娘胎里带的。**

## 是什么

[[凤族]] 旁支，元凤直系（见 [[元凤]]、[[凤族]]），本相孔雀。五色神光在手，封神前半段把阐教诸仙刷了一遍。

他的位置很尴尬，本库把他写成一类人的代表：**血统上够，名分上不够。**

| 他有的 | 他没有的 |
|---|---|
| 元凤直系的血脉 | 凤族的族籍：他入不了族（见 [[凤族]] 的「涅槃一次损一脉」） |
| 一身没人能破的本事 | 一个位置：截教不要他，阐教收不了他 |
| 天下最强的「不接受」 | 任何可以交易的东西 |

所以他不站队不是清高，是**没有队可站**。

## 五色神光：一种无法被「破」的东西

它的强不在威力，在**性质**：

| 对上什么 | 结果 |
|---|---|
| 法宝、兵器 | 一刷即落（不问来历） |
| 神通、法门 | 一刷即散 |
| 阵法 | 刷不散，但阵里的人会被刷出来 |
| 讲道理 | 无效：它不讲道理，它只收 |

本库的定性：**五色神光是「构成」，不是「规则」**——所以它对 [[诛仙四剑]] 那种判决类的东西没用，但对付一切「有形有样」的东西几乎无解。

## 为什么只有 [[七宝妙树]] 能刷他

这是全书一处刻意对称：

> 五色神光是**天生的**，七宝妙树刷的正是**天生**的东西（见 [[七宝妙树]]）。

所以那一场不是斗法，是**同源相克**：一个是「我生来如此」，一个是「我让你不如此」。青莲的瓣压得住孔雀的光，理由不在禁制多四道，在**来路更早**。

## 被收之后

他一战之后归了西方（[[接引]] 那一路），后世称「孔雀明王」。

本库对这段的处理很冷：**他不是被度化，是被收编。** 西方要的不是他的道，是他的**光**——一件能刷落一切构成的兵器，对「没有粮只有嘴」的西方来说，比一个圣人门徒值钱得多。

也因为他归了西方，[[西游量劫]] 里那条路上再没人敢拦——**拦路的那个已经在这条路的股东名单上了。**

## 关系

- [[元凤]]：血脉上的母亲一辈，但凤族不认他（见 [[凤族]]）。
- [[准提]]：收他的人。两人此后再无对话记录——收编不需要谈话。
- [[接引]]：真正的接收方。他接的是「一件东西」，不是一个人。
- [[陆压道人]]：同为「血脉上的余孤」，一个归隐、一个被收，本库两人全书无照面。

## 版本差异

| 说法 | 内容 | 本书 |
|---|---|---|
| A | 孔宣是凤凰之子，天生神通 | **采用**：并且加一条「血脉够、名分不够」，用来解释他不站队 |
| B | 孔宣后来成佛，地位极高 | 部分采用：位置很高，但写成「被供起来的兵器」，不是觉悟者 |
| C | 五色神光可以刷落任何法宝 | 不采用：对判决类（[[诛仙四剑]]）与账外之物（[[无相面]]）无效 |

## 写作约束

1. **不写他被「打败」**：他是被同源的东西收走的，不是被打服的。
2. **不写他悟道。** 他一辈子没有过「想通了」这种时刻。
3. **不写他与 [[天吴]] 的风对刷**——风没有形，神光刷不动，撞上只会两散（可作留白）。
4. 他的台词少，且都是短句：**他不解释自己。**

## 未定稿问题

- [ ] U-259 他归西方之后还算不算「活着」
  - A 算：只是被供起来，偶尔出手（最省，也最符合「兵器被保养」的写法）
  - B 不算：本相被镇在西方，世上只剩一个名号（更狠，但会削弱西游那段）
  - C 留白：只写「此后无人再见过他的本相」
- [ ] U-260 他与 [[长耳定光仙]] 有没有交集
  - A 有：两个「从东方过去的人」，见面彼此不认得（可写成一次沉默的对视）
  - B 没有：一个被收编，一个自己跑过去，两条线不交叉
  - C 只留一句「西方殿上有个不说话的人」——不点名，留读者自己接
