# 灵山

> 一句话：灵山不是「圣地」，是**佛门的治所**——
> 一座山、一座寺、一张名单；山是地，寺是衙，名单才是它真正的东西。

## 一、位置与为什么在这里

| 项 | 值 |
|---|---|
| 位置 | 西牛贺洲极西端，紧贴 [[罗睺]] 毁掉的西方灵脉焦土带东缘 |
| 为什么选这里 | **因为这里最穷** |
| 与焦土带的关系 | 一步之隔：占着「离废墟最近的高地」 |

选址的理由是全书的结构性理由：佛门不能在中土立治所——那里有天庭的册子；也不能退回域外——那里没人是活的。**它只能贴着废墟站**，因为废墟以东就是它的客源（活人），废墟本身是它「贫瘠」的证明（所以要东进）。

**这是本书对「西天」的处理：不是彼岸，是边境。**

## 二、山的三层

| 层 | 是什么 | 谁在这 |
|---|---|---|
| 山脚 | 俗世：香客、商道、检验文书的关卡 | 凡人、护法 |
| 山腰 | 教团：经堂、戒堂、译场 | 罗汉、菩萨、比丘 |
| 山顶 | 大雷音寺：**议事的地方，不是神龛** | [[接引]]、[[准提]]、诸佛 |

山顶那一层刻意不写成「神光万丈的宝殿」：它是**一间很大的厅**，中间空着，四周坐着人——因为佛门的权力形态是「凑够人才算数」（见 [[佛门]]）。

## 三、它真正的资产：名单

灵山最有价值的东西不是经，是**名册**：

- 谁在册、谁不在册（对照 [[封神榜]]、[[生死簿]]）。
- 册上的人是「下一世有着落」的人——这是佛门跟天庭、地府抢的不是活人也不是死人，是**还没出生的人**。
- 所以灵山最忙的地方是**译场与名录房**，不是大殿。经要译成能听懂的话（[[观音]] 跑外勤也是这个道理），名字要写进能查到的册子。

## 四、与别处的关系

| 地方 | 关系 |
|---|---|
| [[紫霄宫]] | 对照：紫霄宫在域外、不归任何一界；灵山在人间、紧贴废墟——**一个在天外立法，一个在边境收人** |
| [[昆仑]] | 对照：昆仑是「根」（道门的源头）；灵山是「口」（收人的地方） |
| [[幽冥]] | 分工：地府管死人去哪，灵山管下一世是谁 |
| 西方焦土带 | 依存：它是灵山「必须东进」的理由（见 [[西游量劫]]） |

## 五、三条写作约束

1. **不写「佛光普照」**：灵山是行政机关，写得越像衙门越对。
2. **不许灵山被攻破**：全书没有一次兵临灵山；它的安全不靠战力，靠「打它等于承认自己也要收人」。
3. **不许写成净土**：山脚的关卡会验文书、会收钱、会拒人。

## 已定（2026-11-15 裁决）

- **U-428（大厅座位）**＝**按果位排**：佛在前、菩萨次之，一眼看出编制。理由：灵山是治所不是道场，治所当然要让人一眼看明白自己坐哪——「排得出座次的地方，才管得住人」。
- **U-429（山脚关卡）**＝**两种都认，两种都要**：天庭的通关文牒要，佛门自己的度牒也要。理由：它两头都欠着——天庭那边要认它的合法过境，佛门这边要认来人的资格；**缺一样都不放行**，这也正是佛门「两边都不得罪、也两边都不自由」的具体形状。
