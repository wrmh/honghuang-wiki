# 罗睺

> 一句话：他不是「反对天道的人」，是**唯一看懂了天道结算机制并试图劫持它的人**。他的失败不在战力，在于他把自己也算进了那笔账。

## 来历

[[混沌魔神]] 被 [[盘古]] 诛杀后，残念散入天地。「拒绝被排序」这个念头没有随肉身消亡，最终聚合为罗睺。

所以他是**第二次尝试**，不是第一代。第一代魔神正面反对秩序，全灭；罗睺改了打法——承认秩序，然后寄生在秩序的结算环节上。

## 立场与诉求

- 要什么：不是毁灭天地，是**成为清算本身**。天道要平账，他就要做那本账。
- 怕什么：被排除在账外。一个不被结算的存在，等于不存在——这是他最深的不安，也是他和鸿钧真正的分歧。
- 与谁对立：[[鸿钧]]。两人抢的是同一个职位：谁来执行清算。

## 在量劫中的作为

- **立魔道**：把「反抗」重新定义为「利用」。魔道不是混乱，是**有组织的反向寄生**——借天道的规则对付天道认可的人。
- **布诛仙阵**：四门四剑，阵内自成一方天地，外界规则不通行。这是洪荒第一次「在天道眼皮底下开小天道」。
- **败于自耗**：鸿钧不攻，等他自己的阵把气运吞干。他输在自己的机制上——**一个靠吞噬维持的阵法，最终会吞掉布阵者**。
- **毁西方灵脉**：败局已定时引爆，制造了一个持续三劫的后果（见下）。
- **身死，魔道不灭**：残部退入天地背面。这一条是关键——**龙汉初劫没有消灭魔道，只是把战场从正面挪到了背面**。

## 他留下的那笔账：西方贫瘠

这是全书最长的一条因果链，写洪荒时最容易漏掉：

```
罗睺毁西方灵脉
  → 西方寸草不生，气运总量恒定故别处溢出
  → 溢出部分引发新的清算（巫妖量劫）
  → 西方长期贫瘠，养不起强大教派
  → 三劫之后佛门必须东渐求供养
  → 西游量劫
```

**所以西游不是佛道之争，是资源驱动**。佛门东渐的根本原因，是自家地里的灵脉被一个死在第一劫的人炸了。这条链把四个量劫串成一条线，是本书与常见写法的最大差别。

## 为什么他必须输

不是战力差距。真正的原因是**逻辑闭环**：

- 他要成为清算本身，就必须让所有存在（包括自己）都进账
- 一旦自己进账，他就必须被清算
- 所以他赢了也是输，输了更是输——**这是一个自毁结构，不是一场战役**

鸿钧看穿了这一点，所以不攻。全书对罗睺的定性也因此不是「邪不胜正」，而是「一个聪明人给自己设计了一个必死的局」。

**① 弑神枪与十二品灭世黑莲各自立条**（裁决 2026-11-13），见 [[弑神枪]]、[[十二品灭世黑莲]]。

**② 魔魂入轮回**（裁决 2026-11-13）：**入**。这一条比看上去更狠——罗睺设计的死局是「让所有存在都进账」，而轮回本身就是账本。他炸了西方灵脉、逼出了轮回的必要性；最后自己的魔魂也被这套账收了进去，成了六道里最不情愿的那一批。魔道说「我们不受清算」，天道用一次投胎回答了他。

**③ 术语对齐**：「背面」是称谓，「[[域外]]」是地方。魔道余部退入域外，那里不归任何一界管——他们要的不是黑暗，是「不被记账」。
