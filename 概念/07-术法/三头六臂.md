# 三头六臂

> 一句话：**它不是长出三个头，是同一时刻办三件事——多出来的不是手，是「同时」。**

## 一、它是什么

形变的一种，也是这一类里最不神秘的一种。

三头：**三个方向都看得见**；六臂：**三件事同时做**。头不是装饰，是「不用转身就看得见背后」；手也不是装饰，是「一件还没完，另一件已经动上了」。

所以它真正改的是**并发**，不是体型。

**可以只变出一部分**：多一双手是最常用的用法，三头才少见——所以世人多称「六臂」，少称「三头」。整副齐出是决战里的动作，平日里用不着，也招眼。

## 二、形变三件的分工

本书的形变类神通有三条，容易写混，这里一次划清：

| 神通 | 改的是什么 | 一句话 |
| --- | --- | --- |
| [[法天象地]] | 改**尺子** | 把「一个人」按「一座山」来量 |
| [[袖里乾坤]] | 改**位置** | 把人从这一页挪走 |
| 三头六臂 | 改**并发** | 三件事同一时刻办 |

三条里只有这一条**不动别人，只动自己**——所以它最不像神通，最像一种手艺。

## 三、代价：三份在意

这不是体力问题：

| 一般人以为的代价 | 实际的代价 |
| --- | --- |
| 累、耗力、撑不住 | **办三件事，就得有三份「在意」** |
| 用完会虚脱 | 用完会**记不清自己刚做了什么**——三份注意力收不回来 |

所以用过的人事后常常讲不清经过：不是装，是那一段的记忆是分三份存的，收拢时总会丢掉一路。

**写到「累」，要给他的是「记不清」，不是「喘」。**

**留下的不是痕迹，是习惯**：此后做事总想「另一只手也能同时动」，于是常常一只手空着等。别人看不出异样，只有自己知道那只手在等什么。

## 四、为什么战场上其实不多用

并行不等于配合：

- 三个方向看得到，但**一颗心只能决定一件**——另外两路是按刚才的决定在动。
- 所以真正的用法不是「同时打三个人」，是「一只手挡、一只手抓、一只手取物」。
- 对手只要挑**最弱的那一路**打，三路就会一起乱——因为三路共用同一个判断。

这也是为什么它常出现在**做事的场面**而不是决战：搬、拆、扶、接，才是它最像样的地方。

## 五、三条硬规矩

| 规矩 | 破了会怎样 |
| --- | --- |
| 不是三个人：还是一颗心、一个人 | 写成「三个分身各打各的」，这条神通就降级成分身术 |
| 不能同时说两种话：张嘴只有一个 | 说了就破——同一时刻只有一个「说」的念头 |
| 收得回来：结束时要收回，收不回就散在那里 | 收不回的代价是「多出来的那两路留在原地」，成为别人看得见的东西 |
| 留下的痕迹是习惯，不是伤 | 写成「肩上一道疤」，就把这条神通写成了外功——它没有外伤 |

第三条是这本书对形变类神通的统一约束：**变化有回声**。

## 六、写作约束

1. 不写「三头六臂大战三百回合」的堆叠爽感——**它的价值在不多打，在同时办**。
2. 具体到动作：一只手在扶、一只手在拆、一只手在接，写动作不写光环。
3. 不写「三个头各说一句话」——一条硬规矩不能破。
4. 写完这场要留一句「他后来记不清」，不要写「他筋疲力尽」。
5. 不把它写成谁独有的绝技：它是一种**通用形变**，会的人不少，用得好的少。

## 七、关系

- 同门：[[法天象地]]（换尺子）、[[袖里乾坤]]（挪位置）
- 使用面：做事、拆解、救人；不是决战
- 记账：不产生功德、不产生因果（改的是自己，不是别人）
- 对照：[[袖里乾坤]]（那一条不产生因果是因为「挪走的那一段不存在」；这一条不产生因果是因为「动的只有自己」）
