# 五行轮

> 一句话：它不是五行之力——它是**五行的次序**。

## 是什么

一只轮，五个格。转一格，次序就换一次：木生火、火生土……全都可以反着来。

**注意边界**：它换的是*次序*，不是*量*。所以它不能让水变成土，只能让「土生金」这一段倒着走。

## 为什么这件最危险

洪荒一切的稳定都建立在五行次序上（见 [[先天灵宝]] 与 [[天庭历法]]）：次序一乱，阵会自己崩、丹会自己毒、地脉会自己改道。

所以五行老祖在 [[诛仙阵]] 之后把它藏了，而不是带走。他的理由后来被记下来：**「次序不是武器，次序是所有人共同在用的东西。」**

## 与巫族的关系

[[都天神煞大阵]] 唤出的盘古真身按五行成形；若次序被换，真身会散。这一条从没有人验证过——因为没有人找得到这轮。

## 写作约束

1. 不写它被任何人重新找到并使用。
2. 不写它违背「只换次序不换量」。
