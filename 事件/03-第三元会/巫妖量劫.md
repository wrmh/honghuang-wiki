# 巫妖量劫

> 一句话：天地初分后的第二次大清算。掌星空的妖族与掌山川的巫族争气运，同归于尽，把洪荒的正中央空出来给了人族。

## 事件要素

### 一、时间
第三元会，劫序第二。以五场战役为主干，结算在战役之后；「改册」由天道自结，后人补记。

### 二、地点
洪荒全境：天界、四部洲、不周山、四海沿岸、幽冥（血海一带）；量劫按「你在不在这一片」计算，不按名单。

### 三、主体
巫族、妖族（两造）；天道（结算者，无执行人）；六部（后世的执行者，此时尚不存在）。

### 四、事由
前债累积到无法单笔核对：气运、血债、名分三条同时到期。

### 五、经过
五步：积累（数万年小冲突）→ 触发（射日）→ 清算（五场战役）→ 余数（未清的部分留给下一劫）→ 改册（天道自结，后人补记为「谁最后拿到了记这笔账的资格」）。

### 六、结果
巫族散、妖族塌；余数未清；册（`册府`）尚不存在，故这一劫的账没有经手人。

### 七、影响
短期：洪荒进入「无人主劫」的状态。长期：`封神量劫` 的机制（榜、册、条款）正是为「不再靠天道自结」而立；`量劫` 一词的「结算」含义由此确立。连锁：`共工` 触山 → `女娲补天`。

### 八、史料备注
本节依「量劫＝结算」的设定（`概念/01-规则/量劫.md`）。异说：巫妖之战是否算「劫」，有「是劫」与「只是战争」两说，本书取**是劫**（有账要改）；改册者，本书取**天道自结、后人补记**（因册府未立）。

### 九、定性
战争（量劫级）。

### 十、关联
并行：`女娲补天`（收拾残局）。接续：`封神量劫`（第四元会）。

## 起因

龙汉初劫之后，鸿钧合道，道魔之争落幕。但「天地归谁管」这件事，其实一个字都没定下来。秩序缺的那个口子，被两个种族同时伸手去堵。

- **妖族**：帝俊、太一于三十三重天立天庭，收拢洪荒散修，封周天三百六十五位星君，以星辰为纲统御万灵。这是第一次有人把「天」变成一个有编制的机构。
- **巫族**：盘古精血化生十二祖巫（祖巫之下还有大巫、巫师、巫民三档，全族按血脉浓度分层），肉身成圣，不修元神，只看血脉。不敬天道，不拜鸿钧，只拜盘古。占据大地山川地脉，认为天地本就是父神身躯所化，凭什么让一群飞禽走兽来管。

巫族这边也不是铁板一块：**祖巫、大巫、巫师、巫民四档**，力量全挂在血脉浓度上（见 [[巫族]]）。祖巫十二位就是全部，死了没有补位——这一档结构后来成了他们真正的死因，但在本劫开头，它是优势：**十二个不可替代的人，比三百六十五个可替换的位置更集中**。

**矛盾的结构性原因**：气运是恒量。妖族封星君，等于把「天」这一半的气运全部锁进天庭；巫族只剩「地」这一半，而地脉供养不起十二位祖巫。这不是脾气不合，是账算不平——一方多一分，另一方必然少一分。谈判在结构上就没有空间。

**但账之外还有一层：名分。** 巫族的名分立在一滴血上——十二祖巫是[[盘古]]精血直系；妖族没有那滴血。[[帝俊]]的做法是把「遗物」说成「血脉」：日月是盘古的双眼、他是太阳星上孕育的三足金乌、日月之主是他的妻（后一层是假的，见 [[帝俊]] 的「名分战」）。巫族的回答是那句最刻薄的话：「你们连血都没有，只能借眼睛。」

所以这一场是**两条线同时打**：一条是气运的账，一条是「谁有资格自称盘古之后」的名分。前者决定谁缺资源，后者决定谁连说话的位置都没有。

## 经过

### 一、立天庭，定星斗

帝俊以[[河图洛书]]推演周天，定星官、排斗宿，把散落洪荒的星辰秩序化。[[太一]]持[[东皇钟]]镇守天门。天庭初立时，巫族并未立即动手——他们在等，等妖族把摊子铺大到收不回去。

### 二、开源：夸父逐日 → 大羿射日

正规战之前，先有两件"边境尺度"的死亡（裁决 2026-11-14）：

1. 帝俊命十子同出以示妖族之盛 → 地上大旱 → [[夸父逐日]]，巫族死了第一个大巫；
2. [[大羿]] 弯弓，射落九只 → 妖族失去九个继承人。

**先死一个人，再断一代人。** 到这一步，两边都已经没有台阶——帝江点兵用的就是这个理由。争端的起因不是「意见不合」，是血债。

### 三、祖巫反扑

[[帝江]]（空间祖巫）率众攻天庭。巫族不擅阵法、不擅法宝，靠的是肉身与血脉之力，硬生生把天庭外层的星斗防线打穿。妖族第一次发现：星君虽多，能打的没几个。

### 四、两阵对撞

这是整场量劫的胜负手。

- 妖族布**[[周天星斗大阵]]**：借三百六十五星辰之力，帝俊主阵，河图洛书定方位，东皇钟镇阵眼。
- 巫族布**[[都天神煞大阵]]**：十二祖巫合力，召盘古真身，以血脉回溯父神之躯。

按设定，二阵同阶，胜负在阵外。转折点是[[后土]]——她见族人死伤枕藉，又见洪荒亡魂无处可去、尽数消散，遂立誓化六道轮回。**后土离阵，都天神煞大阵残缺一角，盘古真身差了最后一臂。** 巫族从此由均势转为劣势。

### 五、天柱折

巫族败局已定。[[共工]]（水之祖巫）不甘，怒触[[不周山]]。不周山是天柱，一折，天倾西北、地陷东南，天河之水倒灌洪荒。

[[女娲]]炼五色石补天，断鳌足以立四极。补天耗尽了她最后的气运存量，也耗尽了妖族残存的立身之本——严格说，妖族不是被巫族打死的，是在这一补之后彻底失去了在天道的账面上的位置。

## 结局

- **妖族**：天庭倾覆，[[帝俊]]、[[太一]]陨落，星君星散。残部退入北俱芦洲与各方妖域，从「统御者」降为「散修」。
- **巫族**：十二祖巫十不存一，后土永镇幽冥，共工身死。残余退守幽冥与人迹不至的绝地，从「大地的所有者」降为「边地居民」。
- **天地规则**：天柱既折，洪荒不再是一整块平地，气运流向由「天地二分」改为「三方并立」——天（残存神道）、地（幽冥轮回）、人（新生）。
- **人族**：在两大族腾出的正中央开始繁衍。这一条不是顺带写的，它是整场量劫真正的产出。

### 四条定死的事（裁决 2026-11-13）

**① [[东皇钟]]封存**。太一陨落后，钟随其本体坠入东海海眼，妖族残部以最后的气运作封，此后**封神、西游两劫都不再出现**，只余「东海有异响」的传闻。这条一次定死：后面任何词条都不得写「东皇钟已毁」，也不得写「东皇钟在某人手中」。

**② [[河图洛书]]借给 [[伏羲]]**。巫妖劫结束后 [[女娲]] 接任妖族之主，她把本宝**借**给伏羲使用——是借不是赠。宝属妖族、人属人族，这层「借用」正是巫妖→封神那道接口。伏羲身后本宝归还妖族，随女娲隐于三十三天外，封神劫不再出现（本书自定）。

**③ 妖族残部**。白泽一脉归隐，不入封神战场；九尾一族走另一条路——封神劫里以「轩辕坟三妖」出场，[[九尾]] 即妲己。这是妖族最后一次以群体身份出手，失败后彻底散入山林人间。到西游时，妖族已不是政治实体，只剩零散妖魔——**西游的妖怪都是个体户，没有一个是「妖族派来的」**。

**④ 十二祖巫名单写全**。全部十二位有名有姓有所掌，见 [[巫族]]。写全是刻意的：[[都天神煞大阵]] 的强度挂在「十二个位置缺一即崩」上，名单不齐，这座阵就写不实。

## 因果链

- 帝俊命十子同出 → 十日并出、地上大旱 → [[夸父逐日]]（死第一个大巫）→ [[大羿射日]]（断妖族一代）→ 血债成立 → [[帝江]] 点兵
- 妖族独揽天之气运 → 巫族地脉不足以供养十二祖巫 → 争
- 后土见亡魂无归 → 化六道轮回 → 巫族阵营少一位祖巫 → 都天神煞不全 → 巫族败
- 巫族败 → 共工撞折不周山 → 天倾西北 / 地陷东南 → 女娲补天
- 女娲补天耗尽气运 → 妖族失去天道账面位置 → 人族趁空而起
- 人族兴 → 人皇更替有了意义 → 封神量劫的舞台成立

## 关键人物

- [[帝俊]]：天庭之主，主阵者。他的失败不在战力，在于把「天」做成了封闭机构，没给巫族留任何位置。
- [[太一]]：天庭武力上限，东皇钟持有者。定海神针式的存在，倒得越晚，妖族败得越彻底。
- [[后土]]：整场量劫的转折点。她不在阵里，胜负就定了。
- [[共工]]：把战争升级成天地灾变的人。他的动机只有「不甘」两个字，但后果由整个洪荒承担。
- [[女娲]]：收拾残局者，也是妖族气运的终结者。
- [[夸父]] / [[大羿]]：巫族两个大巫，争端的开端就是这两条命——**先死一个人，再断一代人**。他们不在"关键"里排前面，但在因果上排最前面。
- [[帝江]]：实际统帅。他要的不是赢，是让天上那位承认巫族有份。

## 关键阵法与法宝

- [[周天星斗大阵]]：妖族国本。缺点是需要「天」的完整秩序，天庭一散，此阵再没人能布全。
- [[都天神煞大阵]]：巫族底牌。强在血脉同源，弱在必须十二人齐——所以它注定被一次缺席击穿。
- [[东皇钟]]：先天至宝，镇天庭气运。
- [[河图洛书]]：推演之用。这一劫后流入人族，成为[[伏羲]]演卦的源头。

## 与其它量劫的接口

- **上游（[[龙汉初劫]]）**：鸿钧分宝，妖族得重器而巫族一无所获。分宝的那一刻，巫妖之争就已经开始了。
- **下游（[[封神量劫]]）**：天柱折、人族兴，才有「人皇更替、三教签榜」的舞台。同时天庭神位在巫妖劫后长期空缺，这是封神榜必须补人的直接原因——**封神不是突然要打，是天庭缺编缺了整整一劫。**
