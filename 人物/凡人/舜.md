# 舜

> 一句话：**他是被「考察」出来的人——不是被选出来的，是被用出来的。**

## 一、他与尧的不同

| | [[尧]] | **舜** |
|---|---|---|
| 怎么上位 | 交出去（禅让者） | **被交进来**（受禅者） |
| 凭什么 | 会算账 | 被派去办事，一件件办成 |
| 留给后世的 | 「位置可以交出去」 | 「上位之前得先被用过」 |

**舜的意义不在他做了什么，而在他证明了一件事：位置可以先试用，再交。**

## 二、他经手的几件事

- **历法**：接尧的表继续校（人族第一次「两代人守同一张表」）；
- **治水换人**：鲧不成，换禹——这次换人建立了一条规矩：**工程失败换人，不换目标**；
- **巡狩**：他到四方去，不是打仗，是**核对各地的账**（谁在报、报得对不对）。

## 三、他为什么没有变成「第二个尧」

尧交得干脆，是因为他只有一个人要交；舜交的时候，人族已经**有班子了**——禹那一代人手里有队伍、有工程、有记录。

**班子一旦成型，位置就开始往「能继承的人」身上走。** 这是 [[启]] 能改掉禅让的真正前因：不是启抢，是结构变了。

## 四、写作约束

1. 不许写他孝顺的传说细节（那是后世的演义，不写实）。
2. 不许写他与禹争：他们的关系是**交接人**，不是对手。
3. 他的所有功绩都要落在「核账」这件事上，不落在神通上。
