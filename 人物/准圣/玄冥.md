# 玄冥

> 一句话：共工让水去不该去的地方，**玄冥让水停住**——同一个族里最深的裂，就从这两句话开始。

## 是什么

[[巫族]] 十二祖巫之一，掌雨与寒。在 [[都天神煞大阵]] 里占「雨寒」之位。

她的能力只有一种形态，而且比共工更窄：**她不能让水做什么，只能让水不做。** 雨落下来，她能叫它停；河要决，她能叫它不决；大水漫过来，她能叫它结住。

| 能做 | 不能做 |
|---|---|
| 冻结、止住、减缓 | 造水、运水、改河道 |
| 护住一段防线 | 攻击：她没有任何直接的杀伐手段 |
| 拖住时间 | 赢：她只能让事情慢下来 |

## 与 [[共工]] 的分裂

巫族内部最硬的裂不是「谁当首领」，是**对同一件事的两种本能**：

| | [[共工]] | 玄冥 |
|---|---|---|
| 对水 | 让它去它不该去的地方 | 让它停在该停的地方 |
| 相应性格 | 不服、要冲出去 | 守住、不许多走一步 |
| 在阵里的角色 | 前锋 | 底盘 |
| 各自最怕 | 被拦住 | 拦不住 |

被撞倒的不周山那一次之前，两人已经吵过很多次——不是私人恩怨，**是两个祖巫对「水该怎么用」的根本分歧**。所以 [[共工]] 撞山那一撞，在巫族内部不是意外，是这条路线的最后一次发言。

## 她的死，与后来那场洪水

[[巫妖量劫]] 决战，十二祖巫全部入阵，玄冥阵亡：她那一角塌下去之后，**洪荒就再没有「让水停」的人了**。

这不是顺手一句——它直接接上后面两件事：

1. **[[女娲补天]] 时洪水无人可止**：所以女娲只能用五色石去垫、去堵、去撑，而不是叫它停。**洪荒最会治水的那个人已经死了。**
2. **人族后来自己治水**：大禹那一套不是法术，是工程——**制度补上了能力留下的空缺**（见 [[人族]] 年表）。

本库对这条线的定性：**玄冥的死是「治水」这件事从能力变成工程的那一天。**


## 外貌

### 一、头面

极白，不是苍白，是**水底那种白**：透着一点青，像泡了很久，脸上几乎没有血色。眼窝略深，眼下有一层淡淡的青影（不是没睡，是本来就这样），所以她的美里总带着一点**倦**。

眼睛是浅灰蓝，虹膜外缘还有一圈更深的环，瞳孔散得慢，看久了让人想起很深的水。眉淡，眉形偏平，眉尾散；鼻梁细，鼻尖微翘——这一处让她看起来年岁很小。唇常年偏紫，像刚从冷水里出来，唇纹很清楚。

头发黑而极直，到腰；湿的时候像水草，干的时候像墨线。她几乎不盘发，只用一根素簪别住一侧。

### 二、身形

身高 **166 cm**，三围约 **86 / 62 / 90 cm**。整体是「海的形状」：没有棱角，全是流动的线。肩窄，腰长，四肢偏长；手腕极细，指节却清楚。

她站着的时候重心很轻，像随时会浮起来；走路几乎没有声音，裙下摆不扬。

### 三、服饰与妆造

**衣服**：素白的单衣，交领，料子极薄（鲛绡一类，水浸不湿），外面罩一层半透明的青灰纱；衣摆很长，拖在地上也不脏——水汽重的地方，土落不下来。腰上不系带，只用一根银线松松一挽。

**妆造**：只点一点唇——紫调的暗色，薄薄一层，不描边；眉完全不画，任它淡着；脸上不施粉。发间一根素银簪，簪头是一小片冻住的冰，永远不化。

**佩饰**：左手腕一串**水精珠**（十二颗，颗颗不同色，从浅到深），是她自己凝的。

### 四、特殊标记

- 颈侧至锁骨一道浅银的水线纹，平时极淡，**「让水停」的那一瞬会亮起来**。
- 指尖常年比周围低两度，碰过的铜器会起一层白霜；她递东西给人，从来是放在桌上让人自己拿。
- 呼吸极轻，近身才看得见胸口起伏。

### 五、气质与神态

**安静到让人不敢大声。**她站着不动时，连周围的空气都像停了——不是威严，是「这里的水不想动」。

- 说话很少，句子常常只剩半句；她更常用「看」和「等」。
- 她不催人，也不等人；她自己就是那个「不发生」。
- 偶尔会盯着水看很久，眼神放空；被叫住时会慢半拍才回头，那半拍是她唯一显得「年轻」的地方。
- 声音很轻，略沙，像隔着水说话。

### 六、写作忌处

1. 不许写成冷艳强势：她的冷是「淡」，不是「硬」。
2. 不许写她大笑、大声、或热闹场合里的中心。
3. 不许把倦写成病弱：她不虚弱，只是不热。

## 关系

- [[共工]]：同族、最深的路线对立，且从不互相下死手（因为谁也替代不了谁）。
- [[后土]]：她是最早支持后土化轮回的人之一——理由很冷：**她见惯了水停下来的样子，知道「让东西有去处」有多要紧。**
- [[帝江]]：她服从调令，但从不认他的「快」——她的道是慢。
- [[天吴]]（风）：风与水最容易配合，也最容易互相甩锅。

## 写作约束

1. **不写她主动进攻。** 她的每一次出手都是「让某事不发生」。
2. **不写她与共工动手。** 两人只吵，不动手。
3. **不让她活过巫妖劫**：她死在阵里是后面洪水那条线的前提。
4. 她说话少、且句子短——**她的语言和她的道一样，是「停」的**。

## 已定（2026-11-15 裁决）

- **U-241**：靠后。她撑到最后，是被围死的——这样「洪荒再没有让水停的人」这句话才成立在最需要它的时候，洪水那条线也才接得上。
- **U-242**：没有。她的能力是天生的，教不了。人族后来治水只能做工程，正因为法术这条路从一开始就不通。
