# 不周山

> 一句话：它不是一座山，是**天地之间唯一那根柱子**。折了它，洪荒从「一整块」变成「倾斜的一块」——所有后来的地理、气运、势力格局，都建立在这个倾斜之上。

## 它是什么

[[盘古]] 脊梁所化（来历见 [[开天辟地]]），立于洪荒正中，上接天、下接地。天地初分时并未定型，靠盘古撑了一万八千年才稳住；稳住之后，**这根柱子就是稳定的物理保证**。

它的性质有三条，每条都有具体后果：

| 性质 | 后果 |
|---|---|
| 无主 | 谁都不能「占有」它，所以谁都可以「破坏」它——没有主人就没有人为它而战 |
| 唯一 | 没有备用的第二根柱子。这是洪荒最脆弱的单点 |
| 通天 | 是天地的通道。折了之后，天地隔绝，上下不再往来 |

第三条常被忽略，但它才是 [[封神量劫]] 里「天庭必须靠封神榜补人」的物理原因：**通道断了，人上不去，只能靠册封**。

## 为什么巫族要撞它

[[共工]] 撞山不是发疯，是三层动机叠在一起：

1. **战术上**：败局已定，唯一能造成「妖族也得不到」的手段
2. **法理上**：这山是父神的脊梁——**巫族撞的是自己家的东西**，他们有权处置
3. **情绪上**：既然「盘古后裔」这个身份不再被承认，那这根柱子也就没有存在的意义了

第 2 条是本书的关键处理：**这不是破坏公物，是一个族群在法理失效后的自毁式抗议**。共工撞的不是山，是「你们不认我们」这件事。

## 折了之后

| 层面 | 变化 |
|---|---|
| 物理 | 天倾西北、地陷东南。日月星辰西行、江河东流，全部由此而来 |
| 气运 | 天河之水倒灌洪荒，淹死无数生灵 → [[女娲]] 必须补天 |
| 势力 | 妖族在补天中耗尽最后气运（见 [[女娲补天]]），巫族败亡，正中央空出 → 人族兴起 |
| 规则 | 天地通道断绝，洪荒从「天地二分」变为「三方并立」（天、地/幽冥、人） |

**这一撞是全书最大的单点变化**：四个量劫里有三个的格局，都是在这根柱子倒了之后才成立的。

## 作为材料：算「先天灵宝级」

盘古的脊梁，是开天时最硬的一段——**它算先天灵宝级的材料**，这一点与 [[先天灵宝]] 的口径对齐：材料属先天，成品要炼。

由此推出三件事：

1. **天柱碎片是后世法宝的一个来源**。不周山折了之后，碎块散落洪荒，捡到的人可以炼，炼出来的东西天然带「柱」的属性（稳、承重、镇物）。
2. **但不等于能炼出至宝**。材料是先天，成品仍要看禁制道数——碎片最多炼到极品（37–48 道），到不了至宝。
3. **最硬的那一块不在任何人手里**。女娲补天用的是剩下的、够得着的那部分；真正的主干碎在哪里，本书不写——这是留给后文的钩子。

## 与女娲补天的关系

补天不是把柱子接回去。**柱子是接不回去的**——盘古的脊梁只有一根，人死不能复生。

女娲做的是另一件事：用五色石补住天的**裂口**，断鳌足立四极把倾斜的天**撑住**。等于承认「永远歪着」，只是不让它继续塌。

这个区别决定了洪荒的整个后期格局：**洪荒是一个歪着的世界，所有人都在歪着的世界里争位置。** 那些「本该如此」的秩序，从这一刻起就不存在了。
