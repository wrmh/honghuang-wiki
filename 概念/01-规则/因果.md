# 因果

> 一句话：因果不是报应，是**账期**——你做了什么，就会被记在某个地方，等有一天有人来要。

## 是什么

[[天道]] 四层里的第三层（物理／数术／**因果**／秩序，见 [[天道]]）。它不管对错，只管「连得上」：

| 你做的事 | 它记什么 |
|---|---|
| 借了东西没还 | 欠一笔（见 [[河图洛书]] 的借约） |
| 杀了人 | 血债（见 [[大羿射日]]、[[红云之死]]） |
| 用了不该用的力量 | 透支（见 [[射日神弓]] 每次拉弓都降血脉浓度） |
| 替别人挡了 | 代偿（见 [[女娲补天]]、[[封神榜]]） |

它的关键性质有三条：

1. **不消失，只转移。** 债可以被人扛、被制度摊、被功德抵，但不会凭「算了」而消失。
2. **只认「连得上」。** 因果不是道德判断，是连接判断——所以才有「杀人不沾因果」这种说法（见 [[元屠阿鼻]]：它们在账外动手）。
3. **可以被记账工具管理。** [[生死簿]] 记死、[[封神榜]] 记位、[[地书]] 记地脉流水、[[天庭历法]] 记时——四本册子都是因果层的账房。

## 圣人也躲不开

这是本库一条硬口径（来自既有裁决）：

> **圣人受因果层约束：可代偿，不可抹除。**

| 做法 | 允许 | 说明 |
|---|---|---|
| 替弟子挡一刀 | ✅ | 代偿：账转到他身上 |
| 把一笔血债「取消」 | ❌ | 抹除：因果层不提供这个功能 |
| 用功德抵 | ✅ | 但功德是另一本账，抵完要记「已用」 |
| 把整件事挪到别人头上 | ✅ 但记两笔 | 一笔原债、一笔「谁挪的」 |

所以封神里圣人能做的只有一件事：**签字**。三教签押（见 [[封神量劫]]）的本质就是「我们同意由这套机制来摊这笔账」——签完之后，连他们自己也不能反悔。

## 与「气运」的区别

两个概念最常被混，本库严格分开：

| | [[气运]] | 因果 |
|---|---|---|
| 是什么 | 你能**调动**多少 | 你**欠**多少 |
| 会不会自动变 | 会（会流向有位置的人） | 不会（只会被转移） |
| 谁能管 | 有位置的人、有法宝的人 | 天道、四本册子 |
| 典型表现 | 妖族有东皇钟仍败（宝只锁气运不产气运） | 罗睺毁西方灵脉，账记到佛门东渐上（见 [[西游量劫]]） |

一句话记法：**气运是余额，因果是欠条。**

## 为什么它是四劫的真正发动机

四劫都不是「谁想打谁」，而是**账平不了**：

- 开天 → 分「有/无」留下的第一笔债（见 [[开天功德]]）；
- 龙汉 → 三族互断灵脉，天道替它们立约清账（见 [[龙汉初劫]]）；
- 巫妖 → 血债 + 法理过期，两头都结不清（见 [[巫妖量劫]]）；
- 封神 → 用「位置」换「命」，把散账收进册子（见 [[封神量劫]]）；
- 西游 → 欠款方必须走程序把钱挣回来（见 [[西游量劫]]）。

## 写作约束

1. **不写「因果报应」的道德剧**：因果只认连接，不认善恶。
2. **不让任何人「消除」因果**（包括鸿钧）——他合的是条文，条文里没有「删除」这个动作。
3. **不写因果自动生效**：它需要有人来收（天道、册子、或某个肯动手的人）。

## 已定（2026-11-15 裁决）

- **U-251**：有，但只对凡人有效。修行者的账不随时间淡化：凡人一世不平就并进下一次量劫，修行者的欠条没有期限。
- **U-252**：只有账外之物能做到（元屠阿鼻、无相面这一类）。位置再高也免不了，圣人同样只能代偿。
