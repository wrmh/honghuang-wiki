# 紫薇大帝

> 一句话：**他不是星星，是「按星星排班」这件事的签字人——天上那个位子是坐标，他是守着坐标的那一格人。**

## 一、他在六御里的位置

| 项 | 内容 |
|---|---|
| 排行 | 六御之二（主位是 [[昊天上帝]]） |
| 尊号 | 中天紫薇北极太帝 |
| 管什么 | 统御万星：日月星辰的排班、四时气候的节点 |
| 权力从哪来 | 榜上给的一格（`封神榜`），不是修行来的 |
| 命门 | **他只能「放行」，不能「加人」**：星位是阵画的，不是他排的 |

他不决定谁强、谁该得什么位置——那是 [[册府]] 的事；他只管**这些位置什么时候动、按哪一天动**。所以天庭的星辰排班有两道：先由他这一侧放行，再由 [[星部]] 对表发符（见 [[星命]]）。

## 二、帝与「位」的区别（最容易混的一处）

| | [[紫薇位|紫薇]]（星位） | 紫薇大帝（人物） |
|---|---|---|
| 是什么 | **坐标**：三百六十五个星位按它定方位 | **守着坐标的那一格人** |
| 在哪 | `概念/04-星位` | `人物/准圣` |
| 缺了会怎样 | 全阵散（原点走了） | 星位照在，但没人放行、没人担这一笔 |
| 能不能换 | **不能**：换人即换坐标系 | **能**：榜定，死了补 |
| 有没有性格 | 没有 | 有：极省事、极不表态 |

一句话记法：**位是尺子，帝是拿尺子的手。**

## 三、他与妖族天庭的关系

紫薇位原本是 [[妖族天庭]] 的阵心，[[帝俊]] 自立其上。巫妖量劫里他去前线那一夜，原点走了，阵散了半边——**那一夜之后这个位子空了整整一个元会**。

天庭立起来时把这格照收（`封神榜签押` 定的），但性质变了：从「君位即阵心」变成「册上的一格」。所以紫薇大帝这一位在制度上有个别扭处——**他守着一个已经不成阵的坐标**：星星还在，阵再没摆过。

## 四、怎么写他

- **他是「不表态」的那一类**：六御之间从不议事（见 [[六御]]），他尤其不说话；要他开口，得先有一份要签的东西。
- **他不管人间的事**：求他不如求 `城隍`；他只对星辰历数负责。
- **上元天官那一层**：他在监察侧的化身是上元天官（见 [[三官大帝]]）——**同一个人，两个册子上的位置**。
- **不写他出手、不写他上阵、不写他教训谁**：他一动，历法就要重校。


## 人物要素

### 一、基础标识
紫薇大帝｜男｜封神之榜后受职｜出身（位子造的，不是人修的）｜现居 紫薇天｜族属 神

### 二、外貌体征
182cm 长脸灰瞳，紫黑无纹冕服，冕上九旒不绣纹，腰间一枚素银刻度环（详见 `## 外貌` 六节）。

### 三、性格气质
沉，极沉；不表态的时候最多；一句话说完不再补。

### 四、身份背景
六御之二、中天紫薇北极太帝：管「按星星排班」这件事的签字人；只能放行，不能加人。

### 五、能力喜好
认得所有星位（阵画的），能签也能空着；爱好一个人看那张已经不成阵的图；价值观：位子比人久。

### 六、言行特征
说话只给结论；口头禅「这个位有人了」；从不解释为什么不加人。

### 七、状态与关系
与 `勾陈大帝` 同列不同司；与 `妖族天庭` 抄来的那张格有旧账；诉求：让「位」不被当成「人情」。

### 八、补充标签
- 闪光点：宁可让位子空着，也不拿它做人情。
- 缺点：守着一张早已不成阵的图，明知已无意义仍不肯改。
- 标志性事件：封神后接过星位册，从未签过一个「加人」。

## 外貌

### 一、头面

五十上下的男子脸，高鼻深目，**瞳色淡到近乎灰**——看人时像在看编号。上髭修得极整齐，一根不歪；下颌无须。整张脸的美感来自对称，对称得有点不像人。

### 二、身形

身高 **182 cm**，高瘦，肩背极正，站姿像一把竖着的尺子；重心落在正中，从不单脚受力。手指长而白，指甲修得极短。

### 三、服饰与妆造

- **常服**：紫黑冕服，滚金边，**不绣任何纹样**（「不替谁记花纹」）；腰束玉带。
- **大朝会**：加九旒（比 [[昊天上帝]] 少三旒）。
- **日常**：换一件深紫素袍，仍旧束带。

### 四、特殊标记

**右手无名指上有一枚素银环**，无纹无字，是当年排布星位时套上去的刻度环，此后没摘下。说话时手不摆动。

### 五、气质与神态

极静，一句说完就停；听完不答只是「记了」。不轻易下座，下座必为「有人错排了位」。对错他不争论，他在册上改。

### 六、写作忌处

- 不许让他亲临一线动手（他的权在放行，不在杀）。
- 不许写成冷酷无人味：他只是把「表情」也算在「要报上去的东西」里。
- 不许写他加人加位——星位是阵画的，他只能放行。

## 五、写作约束

1. **不许写他跟谁争位**：位是榜定的，争不了；六御里没有第二个人想要星辰这一摊。
2. **不许给他写战功**：帝级人物的分量在「签不签」，不在打。
3. **不许写他下凡**：下凡的是他的化身体系（上元天官），不是他。
4. 需要他出场时，写**一份等他签的东西**，不写他本人的情绪。
