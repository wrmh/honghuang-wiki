# 九色鹿

> 一句话：**它救人不要报，所以这笔账记不上**——功德要「做成的事」，它连名字都不留。

## 是什么

身有九色，角白如雪，走起来不响。它不吃人，也不避人；有人落水，它会下水去驮。

它的规矩只有一条：**不许提它。**

## 它与「功德」的分别

| | 功德 | 九色鹿做的事 |
|---|---|---|
| 谁记 | `册府` 记、`考功` 核 | 没人记 |
| 能不能换 | 能换份例／名分／寿数 | **换不了任何东西** |
| 为什么 | 做成了、有人看见、有人签收 | 它不许人说 |

一句话：**功德是已签收的收款，它这笔连收款单都不开。**

## 第一元会：那个回头的人

第一元会，它从河里驮起一个落水的巫民，放在岸上，只看了他一眼就走了。

那人后来带了一队人来猎它——因为他答应了别人「我知道它在哪儿」。那时天地间还没有人族，这些人也都是巫民。

鹿没有报复。它走进林子，从此再没出来。

那个人此后每夜都听见水声。不是天罚，也没有谁来找他——**是他自己身上多了一道没人能擦掉的记号**（见 [[阴德]]）。

## 写作约束

1. **不许写成报应爽文**：不写猎人们遭殃，不写鹿回头惩罚。
2. **不许鹿开口说话**：它只用「看」与「走」表达；想让它表态，就写它把角低下去。
3. 救人那段必须写**它自己也怕**：下水时腿在抖，只是没停。
4. 鹿消失之后不许再出现，包括「后来有人又见过一次」。

## 关联

- [[阴德]]：记在地下、没人看见的那本账，第一笔就来自这里。
- [[功德]]：它的反面对照——做了好事但拒绝被记。
- [[名声]]：那个人得到的不是恶名，是「没人知道，只有他自己知道」。
