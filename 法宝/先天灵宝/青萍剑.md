# 青萍剑

> 一句话：它不斩人，它**评**人——评完，那人就不必再被斩了。

## 来历

先天灵宝，[[通天教主]] 随身佩剑：**截教的「截」字有一半在它身上**。

## 能力与代价

- 能做到：截：拦腰截断一个「正在成形」的东西——术法、阵法、道统，只要能「成形」就截得断。
- 代价 / 克制：只能截「还在成形」的；**已成形的截不断**，所以它在 [[万仙阵]] 会输（对面已经立住了）。

### 完残与来由

完好。剑身有一处细缺口，是万仙阵那一次磕的。

## 战史

- [[万仙阵]]：通天持此剑，被四圣合围，输在「阵已成」。

## 流转

先天 → [[通天教主]]（不传弟子）。

## 相关

- 持有者：[[通天教主]]
- 相关：[[诛仙四剑]]（布阵）、[[万仙阵]]

## 是什么

[[先天灵宝]]，40 道极品。由 [[混沌青莲]] 的**叶**所化，现主 [[通天教主]]。

叶在植物上是做一件事的东西：**把光变成活的东西**。所以这一件的能力不是杀伐，是「**量**」——量一个人的根行、量一件事该不该成、量这一场到底算不算。

| 用法 | 效果 |
|---|---|
| 平举（不出鞘） | 评：对方自己就退了，因为被量完之后知道自己差多少 |
| 出鞘一划 | 把「够格」与「不够格」分开——**分完两边都还在**，只是从此不同路 |
| 刺出 | 极少见。通天用它刺的时候，是这件事已经不打算再讲道理了 |

本库的定性：**青萍剑是全书唯一一件「不以杀人为目的的剑」**。[[诛仙四剑]] 是判决书，它是一杆秤。

## 为什么它在万仙阵会输

万仙阵里，[[准提]] 用 [[七宝妙树]] 把青萍剑刷落了。本库给的理由是结构性的，不是失手：

> 叶与瓣同株。**瓣在下、叶在上，所以瓣刷得落叶。**

具体机制：七宝妙树刷的是「构成」，而青萍剑的构成就是那株青莲的一部分——同源之物对它天然有支配关系（见 [[七宝妙树]]）。这不是强弱问题：**只要它的来历还是「莲叶」，它就一定被莲瓣克。**

换句话说：**通天输在自己那把剑的出身，不在自己的本事。**

## 与 [[诛仙四剑]] 的分工

同属截教，一杆秤与一套判决书：

| | [[诛仙四剑]] | 青萍剑 |
|---|---|---|
| 性质 | 规则（断道/形/神/传） | 度量（够不够格） |
| 用的人 | 要多人同时立四条 | 一人可用 |
| 对敌人 | 判死 | 判「不必再争」 |
| 失效 | 被「先立」的规则压过 | 被同源之物刷落 |
| 下落 | 万仙阵后鸿钧连图收走 | 被刷落后随通天入紫霄宫 |

两件都落在鸿钧手里，一件是「规则必须被保管」，一件是「秤不该留在人间」。

## 现主与流转

- 分宝岩上归 [[通天教主]]（见 [[紫霄宫讲道]] 分宝表）；
- 万仙阵被 [[七宝妙树]] 刷落，随通天被带走（见 [[封神量劫]]）；
- 此后不出。**不是丢了，是收在紫霄宫里**——与四剑同一处保管。

## 写作约束

1. **不写它一次杀很多人。** 它杀人极不合算：评一个人要花时间。
2. **不让它与 [[七宝妙树]] 二次交手。** 一次就够，结论已定。
3. **不写它为别人所用。** 它的使用前提是「有资格量别人」——这资格来自位置，不来自法宝。
4. 与 [[元屠阿鼻]] 严格区分：那两把在账外动手，青萍剑只在账内评。

## 已定（2026-11-15 裁决）

- **U-237**：无损。只是脱手，剑身完好——七宝妙树只刷资格不毁物。通天的颓不在剑上，在他的道被证明「出身不够早」。
- **U-238**：没评过。通天只在万仙阵真正用它，之前一直平举不出鞘——他一生只量过一次，量的还是自己门下的结局。
