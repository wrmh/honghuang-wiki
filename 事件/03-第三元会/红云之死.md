# 红云之死

> 一句话：它分两次——第一次没杀成，第二次成了；中间隔着的，是**三清成圣**。

## 第一次：讲道散场之后（未成）

紫霄宫门外。听完讲道的 [[鲲鹏]] 与 [[冥河]] 第一次堵住 [[红云]]。

- 鲲鹏要的是**那一让**的账；
- 冥河要的是**那道没用掉的东西**（见 [[鸿蒙紫气]]）。
- 但 [[镇元子]] 在场——他没有动手打，只做了一件更有效的事：**站到红云侧前半步**。

红云被护住了。两人退走（此后不复往来）。

这一段的意义不是「打了一架」，是**让鲲鹏明白：只要镇元子在，这条路走不通。**

## 中间：三清成圣

[[紫霄宫讲道]] 之后，三清先后成圣（见 [[故事线]] 第 4 段）。

对鲲鹏来说，这一下把「账」变成了「恨」：**位置上的人已经成圣了，而他连位置都没有。** 他愤怒的不是红云一个人，是那一夜所有人都不替他说话。

## 第二次：三清成圣之后（成）

他再来时带了 [[冥河]]。

- **鲲鹏围**：他的本事是速度与风，把红云的路一段一段封掉——不是一击致命，是**不给出口**。
- **冥河收**：他不动手则已，动手只有一下；血海的东西收的是「还没来得及用掉的部分」。

红云死在这里。两人**没有成为同伙**：一个回北冥，一个回血海，此后不再往来。

## 后果

| 层面 | 后果 |
|---|---|
| 规则层 | 那道紫气**悬空**——气认位不认人，主人一死它就落不下来（见 [[鸿蒙紫气]]） |
| 器物层 | 随身的 [[九九红云散魄葫芦]] 不见了，成为全书唯一「下落成线索」的法宝 |
| 势力层 | [[镇元子]] 与鲲鹏、冥河结仇，且**从不交手**（结下了、永不结清） |
| 叙事层 | 「让」这条路被堵死：此后没人再敢用让位换人情 |

## 为什么要分两次

一次的写法只能给出「他死了」；两次才给出三件事：
1. 他本来**可以不死**（有人护得住他）；
2. 真正的转折不是那一夜，是**三清成圣**——它把「失位」变成了「永远失位」；
3. 鲲鹏的第二次不是算计，是**发作**。

## 写作约束

1. 第一次堵截不要写成大战，写成「半步」与「退走」。
2. 第二次要写实，但不要写成势均力敌——红云从头到尾没打算杀回去。
3. 镇元子第二次不在场（若在场，红云就不会死，这与「镇元子的恨」直接相关）。
4. 冥河一生只此一次亲自上门。

## 镇元子为什么第二次不在场（已定 2026-11-14）

不是被支开，也不是被算过。

**红云在外游历，镇元子曾经让他待在自己的道场里，他闲不住。**等镇元子察觉不对，他在地脉这一头，红云在那头——**赶不上**。

这一条把「镇元子的恨」定死了：他恨的不是自己没本事，是**那个人从来不肯被护住**。
