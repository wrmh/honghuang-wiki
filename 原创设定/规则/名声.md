# 名声

> **名声 = 一个数 + 一张表。**
> 数是你在这个群体里被怎么想的（−100 ~ +100）；表是你对这些**每一个群体**各有一个数。
> 它的用处只有一件：**别人在没跟你打过交道之前，先怎么想你说的那句话。**

## 一、它是什么，不是什么

| | 名声 | [[好感度]] | [[亲密关系]] |
|---|---|---|---|
| 记在哪 | 某群体对你的印象 | 某一个人对你的态度 | 你与某人之间已成立的关系 |
| 谁在记 | 一群人，各自记 | 一个人，单独记 | 双方，各记一份 |
| 变化快慢 | 慢，且会被传 | 中，一次互动 ±2 | 极慢，要靠认定事件 |
| 能不能操纵 | **能**（造谣、吹捧） | 只能影响，不能直接改 | 不能 |
| 一句话 | 「听说他」 | 「我对他」 | 「我们」 |

三条界线：

1. **名声不改事实，只改效率。** 名声 +80 的庸医还是庸医，只是他开口时没人先怀疑。
2. **名声是分的，不是总的。** 天庭里名声 −60 的人，在妖族营里可能是 +50。**没有「全天下统一的名声」**。
3. **名声不回传正史。** 正史写「他在封神榜上无名」，原创层写「所以他在天庭的名声上限被压到 +60」。

## 二、数值底盘

| 项 | 值 |
|---|---|
| 区间 | **−100 ~ +100**（+100 与 −100 都是可达到的） |
| 初始 | **0**（新到一个群体＝没人认识你） |
| 记账单位 | **一人 × 一群体 = 一格** |
| 谁有 | 有名字、被人说得上的人才有；**不在册且没人传的人永远 0** |
| 群体粒度 | 用 `势力` 里的大势力（天庭／妖族／巫族／佛门／阐教／截教／龙族／人族……） |

区间含义（两端是**质变**，不是「更好一点」）：

| 值 | 这个群体怎么对你 |
|---|---|
| +100 | **不用查也知道你**——报名字即通行，担保人都不必 |
| +60 ~ +99 | **先给机会**——求见不挡、交易折价一成、他说的话默认当真的 |
| +20 ~ +59 | 客气，仍要按程序走 |
| −19 ~ +19 | 没人先入为主 |
| −20 ~ −59 | 多问一句、要担保、私下打听你 |
| −60 ~ −99 | **先怀疑**——你说的每件事都要有人作证 |
| −100 | **说什么都不信**——你报了真事，他们也会去找别的解释 |

## 三、传播：名声怎么从一个人手里到一群人手里

一件事发生之后，名声的变动要**乘以下面四个系数**——这就是「为什么同样一件事，在这里传得开、在那里没人知道」。

| 要素 | 档 | 系数 |
|---|---|---|
| **距离** | 同城／同门／同部 | ×1.0 |
| | 邻州／邻部 | ×0.6 |
| | 隔洲 | ×0.3 |
| | 域外、他界、绝地 | ×0.1 |
| **接触频率** | 该群体每 30 天与你有一回往来 | 每回 **+10%**（上限 +50%） |
| **群体大小** | 万人以下 | **当天传遍**（无延迟） |
| | 一万 ~ 十万 | 七天内 |
| | 十万 ~ 百万 | 一个月内 |
| | 百万以上 | **必须有一次公开事件**，否则不传 |
| **身份权重** | 有位、有名、在册者 | ×1.5 |
| | 寻常 | ×1.0 |
| | 无名、不在册 | ×0.6 |
| **事件性质** | 公开场合、当众 | ×2.0 |
| | 半公开（有第三人在场） | ×1.0 |
| | 私下、只两人知道 | ×0.5 |

乘法顺序固定：**先算基数，再乘事件性质，再乘距离，最后乘身份权重**；接触频率是**加在结果上的百分比**。
（写死这个顺序是为了两次读书能得到同一个数。）

## 四、升降表（常用行为）

| 行为 | 名声变动 | 附带 |
|---|---|---|
| 当众布施、救急、修桥铺路 | **+5** | 若被受益人当众道谢，再 +3 |
| 救回一条命 | **+20** | 受助者本人对你的[[好感度]] **+30** |
| 替人担责（明知要背下来） | **+10** | 只在**知情的那群人**里算 |
| 讲别人的好话 | +2 | 被讲的人若在场，他对你 +5 |
| 当众揭人丑事 | **−8** | **被揭者对你 −15**，且此后永不主动往来 |
| 毁约（有据可查） | **−12** | 该群体此后对你的一切承诺打折 |
| 杀有罪且有据之人 | 0 ~ −5 | 视该群体是否认这条罪 |
| **杀无罪的** | **−30** | 若对方有名，再减 10 |
| 传谣（被证伪） | **−15** | 你自己同时被记「会造谣」，见第六节 |

## 五、动态：它会自己掉，也会被新事压掉

1. **回落**：每 30 天向 0 落 1 点——**前提是这一格上「没有正在流通的事迹」**。有事实在传，就不掉；事实被忘掉了，才开始掉。
2. **覆盖**：新事迹不是简单相加，而是**取「更极端的那个」**。
   - 例：名声 +40，杀了一个人（−30）→ 不是 +10，而是**变成 −20 上下**，因为「他杀过人」会盖住「他给过钱」。
   - 口诀：**极端值覆盖中间值，近事覆盖旧事。**
3. **换群体**：到新地方从 **0** 起，但旧名声会按距离系数渗过来（隔洲 ×0.3，域外 ×0.1），且**渗得慢**（每 30 天渗一次）。

## 六、操纵：谣言、吹捧、洗白

| 手段 | 成功率 | 效果 | 被戳穿 |
|---|---|---|---|
| **散布谣言** | `50% + 目标名声绝对值 ÷ 2 − 你在该群体的名声 ÷ 2`（上限 90%，下限 10%） | 目标 **−10 ~ −25** | **你 −20**，并记「会造谣」标记（此后你的谣言成功率减半） |
| **吹捧** | 不需要成功率，只看有没有人愿意传 | 目标 **+3 ~ +8**，持续 90 天 | 被吹的事一旦证伪：目标 **−15**、**你 −10** |
| **洗白** | 只在「新事迹与旧事迹同类相反」时有满额效果 | 例：从前杀无辜，如今救无辜 | 否则只按普通升降算 |

**每个群体信什么**（决定谣言在哪儿跑得快、在哪儿跑不动）：

| 群体 | 信 | 谣言效果 |
|---|---|---|
| 天庭 | 册、文书、留档 | 差（要么有据，要么没人信） |
| 妖族 | 名、谁去了 | 好（说得响就有人传） |
| 巫族 | 血、族里的口传 | 中（族内极快，族外极慢） |
| 人族 | 口碑、赶集时听来的 | **最好**（一条街一个月走遍全城） |
| 佛门 | 行、有没有做过 | 差（只看做过什么） |
| 龙族 | 约、守没守 | 中（只信两家以上的说法） |

## 七、与好感度、亲密关系的接口

1. **名声是修正值，不是加数。** 同一次互动的基础值仍是 ±2（大事 ±10 ~ ±30），名声只加**一个修正**：

   | 该群体里你的名声 | 修正 |
   |---|---|
   | +60 以上 | 正向互动 **+1**、负向 **−1**（别人更容易往好里想） |
   | −60 以下 | 正向互动 **−1**、负向 **+1** |

   **修正不改变正负号**：名声再好，你做了坏事，好感一样掉。
2. **名声卡门槛**：建立结构性关系（师徒／盟友／君臣）时，若你在**对方所属群体**的名声 < 0，必须有**第三个人担保**才能建立。
3. **名声卡流程**：< −60 时求见要担保、交易加价；> +60 时先给机会、可先办事后补手续（对天庭这类群体无效——它只认册）。
4. **名声 ≠ 好感**：一个人可以在群体里名声极好、却没有任何一个人对你好感过 +30——**名声是别人替你做的广告，好感是你自己谈的**。

## 八、写作与使用时怎么落

- 每次要写「这个人办事顺不顺」，先问三句：**在哪个群体？那个群体信什么？他这一格是多少？**
- 名声变动一律**写出系数**（例：「同城 ×1，当众 ×2，在册 ×1.5 → 那条 −8 的谣言，他实掉 24」），不要只写「他的名声坏了」。
- 反派**不要用名声当唯一武器**：名声只能让人「先怀疑」，真正动手的仍是制度（见第 10 条硬规矩：制度不是无人的机器）。

## 九、写作约束

1. **不许写成天下统一的名声**——一定分群体。
2. **不许让名声代替好感**（不能因为名声 +100 就写「所有人都喜欢他」）。
3. **不许让名声直接改结果**：它只能改「别人先怎么想」「要不要多问一句」。
4. **造谣必须有代价**：被戳穿的反噬是硬规矩，不许写成「造谣没成本」。
5. **数字在交付里要算给读者看**，不许只给结论。
