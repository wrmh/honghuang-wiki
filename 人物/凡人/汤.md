# 汤

> 一句话：**他是第一个把「受命」当成一件可以做的事的人——不是等天给，是自己去接。**

## 一、他是谁

商的开国者，伐夏之君。人族第三位共主级人物（[[尧]]、[[舜]] 之后），**不是修行者**：没有神通、没有师承、寿数按人算。

他做的事没有一件超出人的手段：结盟、迁都、打仗、立说法。

## 二、他真正开创的东西：把天命变成行动

`天命` 有三个环节：**结算、解释、传播**。前两个都在天上，第三个在人间——**他做的是第三个**。

| 他做的三件事 | 从制度看是什么 |
|---|---|
| 伐桀 | 换册：旧账清掉，新账立起来 |
| 迁亳 | 挪中心：让「谁的话算数」跟着换地方 |
| 作诰 | 立说法：把「换代」讲成「天的意思」 |

**伐桀是他自己判的。** 先动手，事后补说法——次序不能倒过来写：祭司的话是事后才齐的，`天命` 的解释权就是在这一次里落到人手里的。所以后世的「奉天命讨罪」都只是把这一步重演一遍，差别只在于谁先动的手。

所以后人说「汤武革命」，说的是同一件事：**换代要被讲成受命，才不叫篡。**

## 三、两个被误读最深的场面

**网开三面。** 田野里有人张四面网捕禽兽，他命去掉三面。这不是仁慈的即兴，是**示范**：诸侯看见「他连禽兽都留一路」，就明白自己对百姓留路的分寸该有多少。**这是一次公开的政治表演，做给活人看的。**

**桑林祷雨。** 大旱，他以身为祷。要紧的不是他祷得多诚恳，是**这一年天庭已经有 `行雨定额`**：雨按簿下，与他祷不祷无关（见 [[行雨定额]]）。

于是这个场面在本书里最好的写法是：**他祷了，雨也下了，但两者不是一件事**——史官把两段写在一起，后人就以为是因果。

按裁决写成：**雨按簿下了，时辰、份量都对，与他祷不祷无关。** 他在雨里站了三天，那三天正好是这一带该下雨的三天——商初的史官不会算这笔账，只看见「祷了，下了」，就写成了「祷而有应」。

## 四、三条硬规矩

| 规矩 | 破了会怎样 |
|---|---|
| 不给他神通：他不能呼风唤雨 | 一给他法力，`行雨定额` 那条制度线就废了——凡人能改天，制度就没有意义 |
| 不写天回应他 | 天不答，这是 `天命` 与 `绝地天通` 的硬约束 |
| 祷雨必须写「按簿」 | 写成「因他感动而下」，等于承认人间可以绕过簿子 |

## 五、写作约束

1. 写**做事**，不写感天动地：写他站在雨里、写诏、数人。
2. 网开三面的重点在旁观者，不在禽兽。
3. 不写他晚年求仙、长生、得道——他没有这条路。
4. 与 [[大禹]] 对照着写：禹是「把水治好的人」，汤是「把说法立起来的人」；前者动地，后者动册。
5. 他不与神仙对话；若必须同场，让神先开口，他只答人事。

## 六、关系

- 前代：[[尧]] → [[舜]] → [[大禹]]（禅让线）→ 汤（**革命线**：从这一位起，「换人」不再靠让）
- 承接：[[天命]]（解释权在人）、[[九州鼎]]（受命信物）、[[封禅]]（他之后才成惯例，见该条未定稿）
- 对照：[[武王伐纣]]（周人把「受命」讲得比商更圆）
- 制度后果：`人间自记` 的远因——账本下放之前，说法已经先下放了

## 已定（2026-11-18 裁决）

- **556A** 桑林祷雨那一次，雨到底下了没有？
  - 定：按簿下了，与他无关：时辰份量都对，他站的那三天正好是该下雨的三天；史官把两段写在一起，才成了「祷而有应」。
- **557A** 他伐桀，是奉天命还是自己判的？
  - 定：自己判的：先动手，事后补说法；`天命` 的解释权就是这一次落到人手里的，后世「奉天命讨罪」都只是重演。
