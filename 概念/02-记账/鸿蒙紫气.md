# 鸿蒙紫气

> 一句话：紫气不是力量，是**资格**——它证明你有位置，不代表你已经坐了。

## 是什么

混沌未分时的一缕本源之气，共**六道**。[[鸿钧]] 合道前后，把它们分给紫霄宫最前方六席上的人（见 [[蒲团之争]]）。

六道之外没有第七道。这件事本身就是全书最重要的一条名额制度：**成圣不是开放的，是有定额的。**

## 它和「认领一笔账」是什么关系

本库有两套关于成圣的说法，看起来像两套机制，其实是**一件事的两半**：

| | 紫气 | 认领一笔账 |
|---|---|---|
| 作用 | 给你**资格**（可以成圣） | 让你**到位**（真的成为圣人） |
| 谁给 | 鸿钧（分配） | 无人给，自己接（见 [[修行境界]]） |
| 能否被夺 | 能（人死了，气就悬了） | 不能（账已经记在你名下） |
| 缺了会怎样 | 修到顶也只是准圣 | 有资格也永远是个「候选」 |

所以：**紫气是准考证，账是答卷。** 六个人拿到准考证，六个人都答了卷——这是洪荒唯一一次「名额」和「成圣」严丝合缝对上的时候。

## 红云那一道：全书最重要的一个意外

[[红云]] 是六席之一，也是唯一一个**拿到资格却没走到终点**的人。他被 [[鲲鹏]] 与 [[冥河]] 合力击杀（见 [[红云]]），于是出现了一个此前没人想过的问题：

> 一道已经发出去的紫气，主人死了，它归谁？

这件事的后果比红云本人的死重要得多：

1. **紫气不是永久的**。它可以被「悬空」——这说明资格能被打破，所以六圣此后一直在防同类的事（这也是 [[封神量劫]] 三教签押的心理底色）。
2. **鸿钧没有收回**。他闭宫不出，等于默认「气在外面」。从此洪荒多了一件没有主人、也没人敢认的东西。
3. **镇元子的仇不是私怨**。[[镇元子]] 与红云是至交，红云死后他与鲲鹏、冥河结仇——按他自己的说法，他恨的不是杀人，是**「他们杀了一个还没到期的人」**。

## 常见误解（写作时不要写错）

- **不是能量**。不能炼、不能发射、不能当法宝打人。
- **不产气运**。它和 [[先天灵宝]] 一样只锁不加：有气的人不会自动变强，只会「被允许」。
- **不等于圣位**。六圣成圣靠的是各自接下的账，紫气只是让他们有资格去接。
- **不认主人**。气跟着「位置」走，不跟着血脉、师承、功德走——所以它能被悬空。
- **没有第七道**。任何「又一道紫气现世」的写法都在拆本书的定额制度。

## 已定：红云那一道去哪了

**被封存了。**

[[镇元子]] 把它收进与 [[地书]] 相关的一处所在——不炼、不用、不给任何人看。理由只有一句：**替朋友保管一张没交出去的准考证。**

- 没散回混沌，所以理论上洪荒还有第七个成圣的可能；
- 但它在镇元子手里，这个可能**永远不会被兑现**；
- 这也解释了他为什么不打听 [[九九红云散魄葫芦]] 的下落：他要的是**资格**，不是**证据**。

## 已定：鸿钧有没有说清「气会用掉」

**没说。**

分气时他只给了六道气，没讲用法，也没讲「主人死了气会悬空」。六个人各自摸索，红云到死都不知道自己让出去的是什么。这是道祖式的做法：**给条件，不给说明书。**
