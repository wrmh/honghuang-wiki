# 公器

> 一句话：**公器不是法器，是职务的延长——它认位置，不认人。**

## 一、它是什么

同一件东西，在私人手里叫法宝，在位置上叫公器。

判据只有一条：**交位的时候交不交它。** 交的，是公器；不交的，是私器。

| | 私器 | 公器 |
|---|---|---|
| 来历 | 谁炼的、谁抢的、谁赐的 | 天庭制的（或妖族天庭留下、天庭重制的） |
| 认谁 | 认人：认气息、认道、认因果 | 认位置：位上有名，器就热；位上无人，器就冷 |
| 能否赠人 | 能 | 不能。赠＝把公物变成私物，等同于贪墨 |
| 能否随葬 | 能 | 不能。人死了器留下，等下一个上位的人 |
| 坏了怎么办 | 修、补、重炼 | **不修，报**——册府记一行「器损」，由天庭重制 |

## 二、三件代表

| 公器 | 归哪 | 它真正在管什么 | 用错的样子 |
|---|---|---|---|
| **雷部锤** | 雷部 | 打不打：落下之前的那一下决定 | 打「不该打的」——锤会照打，因为锤不判断 |
| **水部圭** | 水部 | 量：一寸一分到底是多少 | 量「不该量的」——把私田量进了公册 |
| **火部令** | 火部 | 划界：烧到哪一行为止 | 划「不该划的」——把不在册的宅子划进界线内 |

三件都不是战力问题。**公器问的永远是「谁有资格」，不是「谁打得过」。**

## 三、三条硬规矩

| 规矩 | 破了会怎样 |
|---|---|
| 公器不入私产 | 一旦写进谁的私产，它就成了一件「能传给儿孙的宝贝」，制度立刻退化成人情 |
| 不能借 | 借出去的那一刻，位置就被借出去了——六部从不为「借一下」开会，因为它们知道借了就不回来 |
| 器冷之后只有原位上的人能唤醒 | 别人拿了也能用，但用一次要付一次代价（雷部锤会先打持锤的人） |

## 四、写作约束

1. 写「交」不写「夺」：公器的故事发生在交接那一刻，不在抢夺那一刻。
2. 不写器灵、不写器会说话：公器冷，冷在它不挑人也不认人。
3. 三件里只写一两件，不要凑齐——凑齐就变成「三神器」的套路。
4. 器物出场的动作要具体：放上案、擦一遍、报一句「器在」。

## 未定稿问题

- [ ] U-562 公器的「冷」是天生还是后来变冷的？
  - A 天生：造出来就是给位置的，天道在兵器里留了一道「不认人」的禁制
  - B 后来变冷：先是人的东西，被反复移交之后才磨掉了认人的那部分
  - C 看炼制者：妖族天庭那几件有认人的旧习，天庭重制的才是天生冷
- [ ] U-563 位上有名但人不在（缺员、兼位），公器算谁的？
  - A 算位置：器热着，谁拿都能用，用完放回去——这就是兼位的人能同时管两件的原因
  - B 算没人：器冷，必须等正式补位那天
  - C 分器而论：锤认位、圭认簿、令认界，三件各有各的算法
- [ ] U-564 公器损毁，天庭重制时照原样重做，还是趁机改一改？
  - A 照原样：改了就等于承认上一件做错了，而天庭从不承认这种错
  - B 趁机改：制度就是在一次次「重制」里悄悄改完的，改的时候没人留档
  - C 一半一半：外形照旧、内里的禁制加一道——所以老器看起来一样，用起来不一样
