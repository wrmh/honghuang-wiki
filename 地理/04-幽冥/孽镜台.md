# 孽镜台

> 一句话：**它不判，只让人自己看见——而且照的不是「你记得的样子」，是「别人眼里的样子」。**

## 一、它是什么

酆都城一侧的一座台，台上立着一面镜。镜面朝下，斜对着地面，所以人得站在它下边仰头看。

它是十二站里最安静的一站：没有问话、没有判决、没有判官在旁。

## 二、照的是什么

照一生，但换了一个视角：

| 一般以为的镜子 | 孽镜台 |
| --- | --- |
| 照出你的脸 | 照出你**做过的事在别人那里是什么样子** |
| 你自己记得的那个角度 | 你不记得、或不愿意记得的那个角度 |
| 会给你评价 | 只回放，没有评语、没有声音 |

所以最狠的地方不在「看见了」，在**看见的是自己一直不承认的那一面**。

镜里那个人，是**他自己的一个样子**：长着他自己的脸，做着他做过的事，只是从对面看过来。人站在台下仰头，认的是自己——不是受害者，不是别人。这一条不能写错：写成「看见受害者」，这一站就变成了审判；写成「看见自己」，它才只是自省。

有人站上去看见的是一碗没喝完的汤；有人看见的是一句没说出口的话；有人从头到尾什么都没看见——**孽镜台对空手的人是空的**。

## 三、为什么它不判

判要在第一殿、十殿里做，那里有册子、有条款、有记账的地方。

孽镜台没有这些。它不写、不记、不留档——**照完就散，第二次上来照不到同样的东西**。

这条设计的作用只有一个：**让人在「被分类」之前，先自己看清一次。** 看清了还照旧，那就照旧；看不清，后面也没人替他说。

判官在场也不催——催了就成「判」了。

## 四、三条硬规矩

| 规矩 | 破了会怎样 |
| --- | --- |
| 镜不给人看未来，只给过去 | 一旦能看未来，幽冥立刻变成可以「提前改账」的地方 |
| 照不出别人的一生：想看别人，镜面是黑的 | 「查别人的账」这件事只归 `册府`，不归一面镜子 |
| 不留档：照过之后册上不写「曾照」 | 若留下这一行，人就会为「照过」而不是为「做过」争辩 |

第三条与 `望乡台` 正好相反：那边要留一行「曾看」，这边一行都不留——**看阳间是手续，看自己是自省**，自省不进账。

还有一类人在这里照不出任何东西：**天上有职司的**。镜只照「会死的东西」的一生，神仙不在这一本账上，站上去镜面就是灰的。所以他们照不出，也无从自省——**这一条让他们比凡人更难看清自己**，而他们又恰恰是掌握别人的账的人。

## 五、写作约束

1. 不写镜中出现对话、不写镜中有人说话——**它是回放，不是招魂**。
2. 镜中所见只写「别人看见的样子」，不写「他做这件事的动机」——动机是给自己留的，镜子里没有。
3. 不写有人照完当场悔悟、痛哭改过——**幽冥不设悔悟这一段**；改写账要去 `册府`，不在镜前。
4. 同一个角色只能照一次；第二次上到台前，镜面是空的（不是罚，是「已经照过了」）。
5. 不写镜上有字、有血、有裂——**它干净得让人不舒服**。
