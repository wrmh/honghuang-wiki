# 巨鳌

> 一句话：全书唯一一个**用身体去补一个不归它管的地方**的东西——它没有立场，只是「沉下去了」。

## 是什么

极大。大到人站在它背上会以为那是一座岛：背上有苔、有树、有溪，还有一群从来不知道自己在活物身上的鸟。

它不叫，不动，不浮上来换气。**它不是不会动，是不必动。**

「巨鳌」不是它的名字。没人知道它叫什么——因为**没人在它活着的时候和它说过话**。

## 它管的那一件事：承

天地初成，水是散的。海没有边缘，也没有底——水往低处走，低处却一直往下漏。

它自己沉了下去，顶住那处漏。**从此海水有了「不散」的理由。**

| | 它做的 | 不是它做的 |
|---|---|---|
| 海水 | 不一味往下漏 | 不调潮汐（那是后来的 [[龙族]]） |
| 地 | 托住最底的一层 | 不造山、不定位置（那是 [[乾坤老祖]]） |
| 四极 | 后来被断去四足、立成四极 | 不是它自己的选择 |

一句话：**它不是「神兽」，它是一块会呼吸的地基。**

## 第一元会：海底那一声闷响

第一元会之初，海还不稳。有几天里，海水整片往下退，露出大片光底的泥。

三族都以为是雷。后来知道不是——**那一响是它沉下去时背壳碰到地脉的声音。**

它沉下去之后再没动过。第一元会剩下的十一会，它一直在那里；谁也不知道底下有个活物，只当那里水浅、礁多、船不好走。

这也是本库唯一一次「灵兽救了所有人，但没有人知道」。**记住这件事的人，一个元会之后才出现**——是 [[女娲补天]] 时去找它的那个。

## 后来：四足与海眼

[[女娲补天]] 时天柱折、四极不稳，女娲去找的正是它。

她借了四足，立成四极。它**没有反抗也没有死**——四足断了之后沉入东海，压住了海眼。此后海眼的「封」，一直是它。

（详见 [[女娲补天]] 与 [[东海]]。这一节不在本书展开，因为**它一生只有两次出场：沉下去，被借走。**）

## 写作约束

1. **不许说话、不许托梦、不许回应**：它一生没有交流；想表现它的态度，只能写「它没有动」。
2. **不许把它写成坐骑或岛**：有人误当它是岛可以写，把它当岛搬走、当坐骑骑不许写。
3. **它不能用来打**：它不攻击、不碾压、不撞人；它的存在只解释「水为什么不漏」「海眼为什么封着」。
4. **只写两次**：第一元会沉下去一次、补天借足一次。第二次之后按「它在那里」处理，不再给高光。
5. **它与 [[夔牛]] 的那一声要分清**：夔牛是「响」，它是「闷响」；后人常把两件事混成一件，本库要求写清楚「不是同一声」。
