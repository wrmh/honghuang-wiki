# 授记

> 一句话：**授记不是封官，是当众说出「这个人将来会到哪一步」——说完就算数。**
> [[度牒]] 证明你是谁，授记决定你排在哪。

## 一、它补的是哪一段

佛门这条链原来两头都有、中间是空的：

```
度牒（你是佛门的人） → ？ → 果位（你排在座次表哪一格）
                        ↑
                      就是这里
```

授记就是那一段：**从「是佛门的人」到「有座次」，中间必须有人当众开口。**

## 二、三道条件（缺一不成）

| 条件 | 内容 | 谁看 |
|---|---|---|
| 有人背书 | 得有一位在册的佛或菩萨愿意说这句话 | 教团层 |
| 一笔已做成的功德 | 不是打算做，是已经做成（[[功德]] 只认做成） | [[八宝功德池]] 换算 |
| 排得进座次 | 座次表上没有空位，就得等 | [[果位]] 表 |

第三条最容易被忽略：**佛门的果位不是按需要增加的**。位置不够，功德再厚也只能等。

## 三、它做什么、不做什么

- **做**：把一个人的名字，正式写进座次表的某一格。
- **不做**：不给权力（果位只排座次不发命令，见 [[果位]]）、不豁免债务（[[因果]] 照旧）、不能撤销（说了就到那一步，除非他自己退）。

## 四、为什么是「当众说」

私下承诺在佛门不算数——因为愿力（[[愿力]]）的记账对象是「信的人」，人越多，账越硬。

所以授记必须有人听：听的人越多，这句话越难反悔。**佛门用「公开」来替代「担保」。**

## 五、写作约束

1. 不写授记有法力灌顶：它是当众说一句话 + 记一笔账。
2. 不写随便谁都能授记：背书人必须在册上。
3. 不写授记能加速：条件三不满足就是等，等到位置空出来。
4. 不写佛门内部靠授记拉帮结派成功——公开这一条正是防这个的。
