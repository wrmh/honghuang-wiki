# 八十一难（总目）

> 一句话：八十一难不是八十一场打斗，是**八十一次签收**。
> 每难都要有地方、有人、有个官面上的名目；打完了得有人在纸上承认「这里结过账」。

原件太长，按《西游记》原著逐条点名后**拆成五卷**（每卷一个词条，见下表）。本页只放总口径与目录，具体难写在卷里：
**不重要的难一事一句（200 字内），重要的难单独一节细写（500 字内）。**

## 一、为什么必须是「八十一」

| 项 | 含义 |
|---|---|
| 九九 | 极数相乘，表示「这一趟要走到不能再走」 |
| 八十一 | 每难一次签收，凑齐才算手续完备 |
| 缺一难 | 手续不完备，份额不能落定——**所以末难在经书已到手之后** |

**难的数量是文书要求，不是难度要求。** 一碗饭的难和灭国的难，在账上是同等的。

## 三、写作约束

1. **不写连续打斗**：一难一个画面，重点写「谁签了字」，不写招式。
2. **不许难数被加减**：八十一就是八十一；末难是补手续，不是凑数。
3. **不许妖魔成为主角**：妖王是「地方上的办事阻碍」，不是反派。
4. **长度按重要性分档**：不重要的难一律一句；只有重点章回才展开，且不超过 500 字。

## 未定稿问题

- [ ] U-430 第 1–4 难（金蝉遭贬、出胎几杀、满月抛江、寻亲报冤）不在路上、不结账，与「八十一难＝沿途八十一次签收」冲突，怎么处理？
  - A 照原著保留，但注明它们「记在佛门自己的账上」，不计入沿途签收
  - B 压成一句「出发前已有四难」，不展开，也不占序号
  - C 这四难改记到 [[金蝉子]] 名下，取经这一段从「出城逢虎」算第一难
- [ ] U-431 第 61–62 难的大鹏，与已被 [[准提]] 收编的 [[孔宣]] 同出一脉，两者怎么并存？
  - A 大鹏是旁支，不入佛门册子，被主人收走后此后不出现
  - B 大鹏是孔宣之弟，被收编后成为佛门护法之一——正是「孔宣一族被拆着用」的证据
  - C 大鹏与孔宣无关，只是同色的鸟：不做血缘联想，避免佛门势力过强
- [ ] U-434 正文说「只有妖王那一卷是打，其余是办手续」，但金兜山、狮驼岭、小雷音都是硬仗，要不要改口径？
  - A 改成「打是手段、手续是目的」：所有难最终都必须落到「谁签字」上
  - B 保留原口径，把硬仗解释成「手续办不下去时才会动手」
  - C 承认配比：约三分之一打、三分之二办手续
- [ ] U-433 第 80 难凌云渡脱胎之后，唐僧还是不是「凡人」？
  - A 是：脱掉的是旧身，他从此不是凡人也不是仙，是「一个被承认的人」
  - B 不是：到灵山时他已不是凡人，「无文」那件事另有原因
  - C 不写清楚：只写「他没有回头」，把身份问题留给 [[唐僧]] 条目
