# 观音

## 导语

佛门最会跟人打交道的那一位。**她一直是女子**——在阐教时扮男相，只因册上的座次、执事、应劫名单全按男身排；入佛门才卸下这层。

## 人物要素

### 一、基础标识
- **姓名**：观音（前身 慈航道人）｜**性别**：女（**一直是女子**）
- **生辰**：不记年（阐教弟子时就在）｜**出身**：人道修士 → 阐教 → 佛门
- **现居**：落伽山（一年待不满一个月）｜**族属**：佛门

### 二、外貌体征
174cm，三围 86 / 60 / 89。细部见 `## 外貌`。

### 三、性格气质
温、稳、能听。处事：先听完，再决定要不要说。情绪极稳。气场：让人愿意把话说下去。

### 四、身份背景
佛门菩萨（**没有开口权**）、天庭与太阴星的桥梁。家庭：无。关键经历：慈航 → 扮男相入阐教 → 入佛门 → 落伽山成为地址。

### 五、能力喜好
擅长听、变、度。爱好：听人把话说完。习惯：垂眼。价值观：把话带对。好恶：厌被人替她说。

### 六、言行特征
慢，从不打断。口头禅「你说」。肢体：说话时拇指捻珠。行为模式：先问「你要我带到哪」。

### 七、状态与关系
当下：在册上无名。关系：如来、落伽山那户人家、[[嫦娥]]。诉求：把每一句带到。

### 八、补充标签
- **闪光点**：能听。
- **缺点**：不肯替自己争。
- **标志性事件**：落伽山从一个错误的地方长成地址。

## 外貌

### 一、头面

脸是长圆的脸，下颌的线收得柔，颧骨很低——**这是一张不设防的脸**，所以谁都能对她把话说完。肤色是极浅的暖白，不施粉也透着一层薄红。

眉是远山眉，弯而长，眉尾几乎不必画；眼睛是浅褐色的，眼白干净，上眼睑压得低一点，看人的时候像垂着眼——**她其实一直在看，只是不抬眼**。鼻梁细，鼻头小而圆；唇薄，唇色是天然的淡粉，说话时几乎不见唇形变化。

耳朵比常人略大一点，耳廓上多一道浅浅的折——**这是她身上最像「她」的地方**：菩萨听人说话，不是用眼睛。

**头发**：黑，中分，极顺，发质细而软，梳得一丝不乱；挽一个**松而低的髻**，用一根素木簪别住，簪子从右向左穿，簪尾只露半寸。鬓边总有一缕不肯服帖，风一吹就散到脸侧，她不拢。在落伽山岛上不戴冠，长发用一条**旧布带**松松束在颈后（布带是那户老妇给的，洗得发白）；扮男相那段年月则是束发戴冠、把发际线压平——**同一头发，两种束法**，改的是冠，不是发。

### 二、身形

身高 **174 cm**，三围约 **86 / 60 / 89 cm**。极瘦，肩窄，脖子长，锁骨清得像两道细线；手长，指细，指甲修得短而圆。

她站着的时候重心很稳，背略向前倾一点——那是常年「往前递东西」的姿势：递一句话、递一个人、递到门口。

### 三、服饰与妆造

**衣服**：月白的交领长衣，料子软而垂，走动时下摆不起风；外罩一件**旧的青灰褙子**——那是阐教时的旧物，边角磨白了也不换，她说「穿着顺手」。

腰上不佩玉，只挂一枚**竹牌**，牌上刻着「落伽山」三个字，磨得发亮：**那是她的地址，也是她的凭信**。

**妆造**：几乎没有妆。眉不描，唇不点，脸上一层极淡的香粉（闻不出来，只在近身时有一点点）。发间只有那根素木簪，不加珠花。

**礼佛时的换法**：外面加一件灰褐的缦衣，袖口收窄；手里托一只**净白的小瓶**，插一枝鲜杨柳——柳是每天现折的，枯了就换，不供着。

**阐教时期的那一身（已脱下的）**：青灰道袍、玄色束带、束发玉冠，里面用一条布带把胸束平，肩上垫两层衬——**为的是在册子上像「一个少年道人」**。她不贴假须，宁可被当成年纪小；说话时刻意慢半拍、把尾音压下去。**那件旧褙子就是那时留下的**，所以袖子磨白了也不换——脱得下男装，脱不下这一件。

### 四、特殊标记

左手腕内侧有一道极浅的旧痕，像被什么勒过很久，颜色比周围淡一点——是当年握剑握出来的，入了佛门也没消。

右耳后有一粒极小的朱砂痣，她自己不知道；靠得极近的人才看得见。

### 五、气质与神态

**「听」是她的本能，也是她的武器。**

- 别人说话时，她会微微侧头，把那一侧的耳朵递过去——这个动作她做得很自然，被看的人会不自觉把话说深一点。
- 说话极慢，句子软，常用「嗯」「是这样」接住；**她从不答应什么**，也从不拒绝，只把人送到门口。
- 她笑的时候眼睛几乎不动，只是眼尾软下来一点；真被问住了会先低头看自己的手。
- 走路的步子轻，进门前会先停一下——不是犹豫，是听里面有没有人。
- 身上没有香火气，只有一点皂角和旧布的味道。

### 六、写作忌处

1. 不许写她「显灵」「度化」「金光万丈」：她的作用是**把路指出来**，不是替人走。
2. 不许写成慈眉善目的老太太，也不许写成冷面菩萨：她是**温和但有距离**。
3. 不许让她承诺任何事——她的台词里不该出现「我会帮你」。
4. **不许写「男变女」**：她一直是女子，只在阐教扮过男相。禁止变形、换身、身体改造，也禁止写「其实是男人」——这是本书的死线。

## 与既有词条的边界

- **严禁写成「男变女」**：她本来就是女子。
- **不许写她求人**。
- **不许写她显神通压人**。
