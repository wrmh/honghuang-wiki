# 洪荒世界观百科 · 词库

**日与月的两个主人，以及一个跑腿的人。**

## 这是一本什么书

**一部从「开天辟地」写起的洪荒百科全书，重心放在五大量劫。**

不是只写四场劫难的故事集。洪荒之所以能自成一个体系，靠的是劫与劫之间的**因果结算**——气运怎么转移、法宝怎么易主、势力怎么涨落。所以词条按类型分（人物、法宝、势力、阵法、地理、功法、事件、概念），但**每一条词条的写法都要求交代它和量劫的关系**：它在这场结算里是债主、是抵押物，还是被清掉的账。

写作顺序：开天（纪元）→ 龙汉初劫 → 巫妖量劫 → 封神量劫 → 西游量劫。前四篇是骨架，其余词条挂在这根骨头上。

## 一句话方案

**Markdown 正文 + YAML 头信息（front matter）作为唯一真源**，索引表、静态网页、EPUB 全部由它生成。

不要另外维护一份 Word / Excel 版本。一份真源是这个方案能跑三年的前提；两份就等于两份都会过期。

## 为什么不用别的格式

| 要求 | Markdown + Git | .docx | .xlsx | 单文件 HTML | 在线笔记 |
|---|---|---|---|---|---|
| 交叉引用 | `[[双链]]` 自动解析 + 反向链接 | 无，靠手工书签，改名即断 | 无 | 锚点手写，改标题就断 | 有，但导出后失效 |
| 全文检索 | 秒级，含表格内文字 | 慢，跨文档搜不到 | 弱 | 需自带搜索脚本 | 有，但离线不可用 |
| 改一处不漏改 | 脚本可查断链 / 重名 / 缺字段 | 全靠人眼 | 全靠人眼 | 靠人眼 | 部分可查 |
| 版本 diff | 逐行，能看清改了哪句设定 | 二进制，看不了改了啥 | 二进制 | 尚可 | 基本没有 |
| 数值表（气运 / 品阶） | 正文表格或独立 CSV 再渲染 | 能排，难算 | 强 | 弱 | 中 |
| 排版精修 | 靠主题，写的时候不用管 | 强 | 弱 | 强 | 弱 |
| 手机上随手查 | 发布成网页即可 | 要装 Office | 要装 Office | 可以 | 可以 |

结论：**写作期要「好改、能查错、能回溯」，发布期才需要「好看」**。这两件事交给两个工具，硬塞进一个格式必然两头都不讨好。

- 写作用 **Obsidian**（把 `F:\世界观设定` 当 vault 打开：双链、反向链接、关系图、全文检索全都有）
- 发布用 **GitHub Pages + MkDocs Material / Quartz**（生成可搜索的静态站）
- 需要电子书再用 **pandoc** 从 Markdown 转 EPUB / PDF

### 两级目录怎么套

`法宝`、`人物`、`事件`、`地理`、`概念` 是**两级目录**（类型 / 档位）；`原创设定` 也是两级（类型 / 原创层：总览·规则·天赋·关系·玩法·伏笔）；`势力` 是**按组织分层的两级目录**（类型 / 大势力），而且**大势力本体也在这第二层里**，详见下一节。其余类型仍是一级。

| 类型 | 二级目录 | 对应字段 | 枚举 |
|---|---|---|---|
| 法宝 | 品阶档 | `品阶` | 混沌至宝 / 混沌灵宝 / 先天至宝 / 先天灵宝 / 功德灵宝 / 后天至宝 / 后天灵宝（带 `先天功德至宝` 标签者豁免「系列与品阶相符」校验） |
| 人物 | 境界档 | `境界` | 凡人 / 引气入体 / 炼气化神 / 炼神返虚 / 炼虚合道 / 地仙 / 天仙 / 玄仙 / 金仙 / 太乙金仙 / 大罗金仙 / 准圣 / 圣人（＋特例「混沌」） |
| 事件 | 元会档 | `元会` | 第零元会 / 第一元会 … 第六元会（目录名带 `00-`…`06-` 排序前缀，脚本去掉前缀再比对） |
| 地理 | 空间层档 | `空间层` | 总目 / 天上 / 陆地 / 海域 / 幽冥 / 域外（目录名带 `00-`…`05-` 排序前缀） |
| 概念 | 门类档 | `门类` | 规则 / 记账 / 制度 / 星位 / 神通 / 总览（目录名带 `01-`…`06-` 排序前缀） |

脚本会查三件事：文件在不在档位子目录里、档位目录名在不在枚举内、**`品阶`/`境界`/`元会`/`空间层`/`门类` 字段值与所在子目录是否一致**。三者任一不符都是 E 级阻塞。

### 事件怎么定档：按元会

一元 = 12 会 = 129600 年，**元会是天道对账的周期**（见 [故事线](概念/06-总览/故事线.md)）。事件不按时代名分（不写"巫妖时期"那种含糊标签），一律落到一个元会里：

| 元会 | 目录 | 这一元会发生的事 |
|---|---|---|
| 第零元会 | `事件\00-第零元会\` | **只有开天辟地这一刻**：本体 `开天辟地.md` ＋它的分卷子条目（`开天辟地\混沌纪.md`…，写 `归属: 开天辟地`）；开完天才进入第一元会 |
| 第一元会 | `事件\01-第一元会\` | [[洪荒初生]]：唯一没有量劫的元会（无册、无位、无欠条）；凶兽横行、灵兽镇地、三族各自成形 |
| 第二元会 | `事件\02-第二元会\` | [[龙汉初劫]]（`劫序: 1`）＋**龙汉末期**的[[紫霄宫讲道]]、[[蒲团之争]]、[[红云之死]] |
| 第三元会 | `事件\03-第三元会\` | [[巫妖量劫]]（`劫序: 2`，接着龙汉）＋夸父逐日、大羿射日、女娲补天、公器移交 |
| 第四元会 | `事件\04-第四元会\` | [[封神量劫]]（`劫序: 3`）＋大禹治水（收口） |
| 第五元会 | `事件\05-第五元会\` | [[西游量劫]]（`劫序: 4`） |
| 第六元会 | `事件\06-第六元会\` | [[人间自记]]：册子没人来领，从此账由人自己写；[[最后的土地]]：下面那一头怎么退场 |

两条硬规矩：

1. **一条事件只归一个元会**——按"它在哪一元会结算"定，不按"它从哪开始"。跨元会的事件写在**结束**的那一元会里，`时间锚点` 字段里注明跨期。典型例子：紫霄宫三次讲道＋六圣成圣发生在**龙汉末期**，所以它们归第二元会，不单占一个元会；龙汉与巫妖是**前后脚**，巫妖落第三元会。
2. **量劫也在 `事件\` 里**：量劫不再是单独的类型／目录，它是一条事件，用 `劫序: 1-4` 标出是第几劫（开天辟地是纪元，不写劫序）。所以事件目录里两类并存：带 `劫序` 的是量劫本体，不带的是量劫里的具体一幕（写"大羿射日"，不写"巫妖大战"那种与量劫同义的重条）。

### 一条事件太长怎么办：拆卷（第三层）

判据只有一条：**正文超过约 200 行、或要按组分开讲，就拆卷**。写法与势力那套一致——本体住进自己的目录，分卷挂在下面，最多三层：

```
事件\<元会>\<大事件>\<大事件>.md         本体（不写 归属）
事件\<元会>\<大事件>\<大事件>-卷一-….md   分卷（front matter 写 归属: <大事件>）
```

目前只有 [[八十一难]] 拆了卷（卷零前缘 1–4／卷一大唐境内 5–13／卷二境外 14–60／卷三天竺境内 61–79／卷四灵山脚下与归途 80–81），因为它是 81 条账，塞一条里没法读。分卷按**地理**（谁的册子在管这一段）而不是按性质。

**拆卷后的长度档（硬规矩，所有"清单型事件"通用）**：

| 分量 | 写法 | 字数 |
|---|---|---|
| 不重要的一条 | 总表一行，一句带过 | ≤ 200 字 |
| 重点一条 | 独立小节细写（机制、后果、与既有设定的接口） | ≤ 500 字 |

脚本会查三件事：本体必须在同名分卷目录里、分卷的 `归属` 必须等于所在目录、分卷的父本体必须先立条。


### 地理怎么定层：按空间层

地理不按"谁的地盘"分，按**它在哪一层空间**分——因为同一块地方会反复易主，层不会。六个层：

| 层 | 目录 | 放什么 | 为什么是这一层 |
|---|---|---|---|
| 总目 | `地理\00-总目\` | `00-地图变迁`（跨层总览 + AI 生图提示词） | 它是**全图的读法**，不属于任何一层，故给独立层和 `00-` 前缀 |
| 天上 | `地理\01-天上\` | 三十三天、天河、星辰 | 天界自成一套秩序（重数、封条、编制），与地面是两种物理 |
| 陆地 | `地理\02-陆地\` | 四部洲、昆仑、不周山、五行山 | 生灵默认所在的一层 |
| 海域 | `地理\03-海域\` | 东海（海眼、蓬莱三岛）、西海、南海、北海、落伽山 | **海眼是龙族岗位、用盟约管理**，这一层的组织方式与陆地根本不同，塞进陆地会丢掉"守"这条线 |
| 幽冥 | `地理\04-幽冥\` | 幽冥（十二站）、鬼门关、枉死城、忘川、奈何桥、孟婆亭、三生石、孽镜台、望乡台、轮回台、血海 | 归天道直辖的结算空间，不归任何势力 |
| 域外 | `地理\05-域外\` | 域外、紫霄宫 | 开天时没分出去的那部分，不归洪荒任何一界 |

两条硬规矩：

1. **层看"它在哪一层"，不看"它是谁的"**——昆仑归三清，但它是陆地，不是"三清层"。势力归属写在词条的「归属势力」里，不进目录。
2. **一层只写一层的事**：跨层的写进**总目**那张图里，不再单开词条（否则「不周山折了之后水往哪流」会既在陆地又在幽冥，两处对不上）。

### 概念怎么定门类：按「它是哪一种东西」

概念是最容易被写成大杂烩的一栏，所以二级按**门类**分——看它是哪一种东西，不看它讲的是哪件事、哪个时代。六个门类：

| 门类 | 目录 | 放什么 | 一句话 |
|---|---|---|---|
| 规则 | `概念\01-规则\` | 天道、因果、气运、气数、天命、量劫、六道轮回、不在册、斩三尸 | 世界自己怎么运转（不以谁的意志为转移） |
| 记账 | `概念\02-记账\` | 功德、开天功德、玄黄之气、鸿蒙紫气、功德至宝、香火、受祭、愿力、阴德、余荫 | **可被结算、可被转移的账与气** |
| 制度 | `概念\03-制度\` | 天庭历法、修行境界 | 人（或曾经的人）造出来、用来管人的秩序 |
| 星位 | `概念\04-星位\` | 紫薇、勾陈、北斗、太阳星君、太阴星君 | 编制上的**位置**——人换了位置还在 |
| 神通 | `概念\05-神通\` | 五色神光、袖里乾坤、法天象地 | 一个存在**本身的能力**，不靠器物不靠位置 |
| 总览 | `概念\06-总览\` | 故事线、未定稿问题 | 跨条目的骨架页；`未定稿问题` 是脚本自动生成的 |

两条硬规矩：

1. **门类看"它是哪一种东西"，不看题材**——「功德」不进「规则」而进「记账」，因为它是能算、能顶档、能代偿的一笔账；「巫妖量劫」那种讲事件的不进概念，它是 `事件\`。
2. **概念只做两级、不再往下套**——门类下面就是词条。真需要分组（比如星位再分吉凶）时，写进词条的 `标签`，不要加第三层目录。

### 势力怎么分类：先分「类」，再分「大势力」

**第一层问「它是哪一类」，第二层问「它是哪一个」，第三层才是本体文件。**

| 类 | 收什么 | 现在有 |
|---|---|---|
| **人** | 以人族为主体、靠组织而非血脉延续的 | 人族 |
| **妖** | 血脉成族、有本相、不入人道编制的 | 妖族天庭、凤族、龙族、麒麟族、九尾、洪荒凶兽 |
| **仙** | 教门／道统（收徒、论道、立榜的那一路） | 阐教、截教、三教 |
| **神** | 有编制、有册子、有岗位的 | 天庭 |
| **巫** | 血脉即名分（祖巫—大巫—巫师—巫民） | 巫族 |
| **佛** | 以果位与愿力结账的 | 佛门 |
| **鬼** | 幽冥、清算、轮回这一侧 | 地府 |
| **先天** | 开天之前就在、或天生地养的 | 混沌魔神、先天灵兽 |

- **判据一句话**：先看它靠什么立身——**血（妖／巫）、册（神／鬼／佛）、道统（仙）、还是人（人）**；开天之前就在的，进「先天」。
- **三族（龙／凤／麒麟）在「妖」下**，尽管他们已经退场：他们的盟约是后两劫的法理背景，类别仍按「血脉成族」算。
- **`妖族天庭` 与 `天庭` 分在两类**（妖／神），这正是「两朝两物」在目录上的落实：一个靠血统立朝，一个靠编制立朝。
- 新增一个大势力时，先想「它落哪一类」，落不进这八类就先别立条——**落不进类，多半是结构还不够**。

### 势力怎么定条：只有「大势力」才单独成条

**一条势力词条 = 一个金字塔结构完整的组织。** 判断标准只有一条：它有没有**三层以上**的结构（决策层 / 中层 / 执行层），并且这三层不是同一种人。

不够三层的一律不单独成条，挂到它所属的大势力下。**大势力自己的词条也住进它自己的目录**（第二层），这样"一个势力"在文件树上就是一个文件夹，进去先看到它自己，再看到它的组成部分：

```
势力\鬼\地府\地府.md          ← 类 \ 大势力 \ 本体（第三层）：顶层（后土/东岳/地藏/酆都）、中层（十殿/五方鬼帝）、执行层（属官/差役）
势力\鬼\地府\阴差\四大判官.md ← 组成部分，front matter 写 `归属: 地府`
势力\妖\妖族天庭\妖兵.md      ← 组可省，直接挂
势力\妖\九尾\九尾.md → 势力\妖\九尾\轩辕坟三妖.md    ← 归属: 九尾
势力\佛\佛门\佛门.md → 势力\佛\佛门\三千红尘客.md    ← 归属: 佛门
```

脚本会查六件事：① 势力第一层必须是**类**（`人/妖/仙/神/巫/佛/鬼/先天`，别的名字直接报错）；② 本体必须在**同名目录**里（`势力\<类>\<名>\<名>.md`，放开在 `势力\` 根上直接报错）；③ 大势力本体**不许**写 `归属`；④ 子条目 `归属` 必须等于所在大势力目录；⑤ 大势力本体必须先立条（`势力\<类>\<父>\<父>.md` 存在）；⑥ 势力最多三层目录。另外，大势力本体**少于 3 个 `##` 小节**会给一条提示（结构可能不足以单独成条）。

### 人物怎么定档：一条阶梯，一个字段

境界阶梯（用户 2026-11-14 定稿，从低到高）：

**凡人 → 引气入体 → 炼气化神 → 炼神返虚 → 炼虚合道 → 地仙 → 天仙 → 玄仙 → 金仙 → 太乙金仙 → 大罗金仙 → 准圣 → 圣人**

规矩三条：

1. **`境界` 只写阶梯上的名字**，一个字都不许多——`境界: 太乙金仙`，不是「太乙金仙（近大罗）」。
2. **目录 = 境界**。写 `人物\太乙金仙\孙悟空.md`，就得 `境界: 太乙金仙`，库存脚本会比对，不符是 E 级。
3. 说不清的那些余量（祖巫肉身成圣、合道、天生石猴、修道四十年未成仙）写进 **`境界备注`**，那是自由文本，不参与分档。

另有一个 `境界序`（整数）跟着 `境界` 走：凡人 1 … 圣人 13，`混沌` 是 0（盘古、混沌魔神，排在阶梯之前——他们不是「境界更高」，是**在境界这套尺子之前**）。它存在的唯一理由：让 Dataview 能按真实次序排，而不是按拼音。脚本会校验 `境界序` 与 `境界` 是否对得上。

**法宝有六档是因为「系列 × 禁制」两把尺子；人物有十四档是因为只有一把尺子——阶梯本身就是目录。**

### 法宝怎么定档：系列 × 禁制

两把尺子一起用，缺一不可（口径见 [先天灵宝](法宝/先天灵宝/先天灵宝.md)）：

| 系列 | 出生 | 谁有 | 特点 |
|---|---|---|---|
| 混沌 | 开天之前，未被分离 | 盘古、三千混沌魔神 | 同禁制数比先天更硬、更难祭炼；不可再生 |
| 先天 | 开天瞬间成形 | 天生地养，无主后归人 | 可被人夺、可被封 |
| 后天 | 开天后炼制 | 各教、各族自炼 | 可量产，威力最弱 |

| 禁制道数 | 品级 | 对应档位 |
|---|---|---|
| 49 | 至宝 | 先天至宝 / 后天至宝（开天后能存在的上限） |
| 43–48 | 功德灵宝 | **仅后天**：后天炼制经功德部分承认（会掉回 42） |
| 50 | 至宝 | 只有混沌至宝（开天前的大道全数，开天后存不住） |
| 37–42 | 极品灵宝 | 混沌灵宝 / 先天灵宝 / 后天灵宝（后天到此为炼制上限） |
| 25–36 | 上品灵宝 | 同上 |
| 13–24 | 中品灵宝 | 同上 |
| 1–12 | 下品灵宝 | 同上 |

法宝 front matter 必须有四个字段：`品阶`（＝六档之一）、`系列`（混沌/先天/后天）、`禁制`（1–49 整数）、`品级`（下品/中品/上品/极品/至宝）。

三条推论，写新法宝前先想清楚：

- **系列看材不看威力**：一件后天灵宝炼到 48 道，也压不过 48 道的混沌灵宝。
- **只有两个至宝值：50 与 49**。50 道＝大道全数，只在开天之前成立；开天后天意不容，存留的至宝只能 49 道——49 不是练到顶，是被削到能活。至宝定规则，灵宝只是执行，差一道就是差一个层级，补不上。
- **碎片即降档**：至宝碎了就只是同系列的灵宝，至宝位随碎而失（开天神斧 → 东皇钟等，见 [混沌至宝](法宝/混沌至宝/混沌至宝.md)）。

分类条目（如 [先天灵宝](法宝/先天灵宝/先天灵宝.md)）自己不是某一件法宝，打 `分类条目` 标签，豁免三字段校验。

### 排序前缀

文件名允许 `NN-` 前缀（`00-地图变迁.md`），用来把它钉在目录最上方。此时 `词条` 字段写**带前缀的全名**（`00-地图变迁`），这样 `[[00-地图变迁]]` 才接得上；自检两种写法都认。

## 十三条硬规矩

1. **一个词条 = 一个文件，文件名 = 词条名**。写 `帝俊.md`，不要写 `妖族老大.md`，这样 `[[帝俊]]` 永远接得上。
2. **目录看类型，再看档位；不看时代，也不看归属**。`帝俊` 是人物就放 `人物\准圣\`，不管他属不属于巫妖劫；`东皇钟` 是法宝就放 `法宝\先天灵宝\`，哪怕它首次登场在巫妖。同一个词条只有一处正文，跨劫提到只写 `[[链接]]` 链回去。
3. **设定分歧写进「版本差异」一节，不混进正文**。洪荒流没有官方正典，冲突是常态。正文只写「本书采用」的那一版，其他版本记在末尾——日后改设定有据可查，也不会读着读着自相矛盾。
4. **别名只用来检索，正文双链一律写词条名**。`妖族天庭` 的别名里有「天庭」，但正文必须写 `[[妖族天庭|天庭]]`，不能写 `[[天庭]]`——用别名当链接目标，Obsidian 的未解析计数、导出与第三方工具都会判成空链（`检查.py` 现在直接把这种写法报成 E 级）。同时 front matter 要**两个键都写**：`别名: [...]` 给人看，`aliases: [...]` 给 Obsidian 认（它只认英文键，只写中文键时别名检索不生效）。

> 这条规矩是被你点出来的：库里曾经有 18 处「用别名当链接」的写法（`天庭` ×11、`玲珑宝塔` ×2、四把剑各 1、`十二祖巫` ×1），在新开的窗口里全是空链。现在全部改成「真词条名 + 显示文本」，Obsidian 的未解析链接已归零，并由脚本守死。
5. **同名不同物必须分两条，别拿别名硬塞**。典型的例子就是你点出来的 `妖族天庭`（帝俊、太一那一朝，血缘王朝）和 `天庭`（昊天那一朝，程序官僚）：它们只共用一张岗位表，不是同一个东西。所以 `天庭` 是独立词条，`妖族天庭` 的别名里**不再留「天庭」**——别名一旦撞上另一个词条的正式名，`[[天庭]]` 会悄悄落到错的那一个身上。`检查.py` 现在双管：① 别名被两个词条占用 → E 级；② 别名撞上另一个词条的正式名 → E 级。全库曾一次性查出 10 处这类撞名（`酆都`／`玉虚宫`／`金蝉子`／`夸父逐日`／`轩辕坟三妖`／`地府`／`气数`／`先天至宝`／`阿鼻`／`后天功德至宝`），已逐条清掉。

6. **制度只写在它成立之后，早于它的事只能写「后来的人这样叫」**。册子、位置、份例、考功、城隍、地府这一整套都是有起点的：`册府` 要等天庭立起、地府要等 `后土` 身化轮回、`考功` 要等三本主册齐。所以写龙汉、巫妖那些年，不许让人「去册府查一查」「拿阴德换寿数」——那时候连这个词都没有，只有「冥冥之中有所察觉」。判断办法：**先问这套东西什么时候才有，再决定那个时代的人能用哪几个词。** 具体边界见 `阴德`／`余荫`／`不在册`／`量劫` 各自的「时序」一节。

7. **每个「人物」词条必须带 `时间线` 字段，写清「生 → 关键节点 → 终」**。格式固定为一条用 `→` 串起来的链，节点必须带元会（`第一元会生`、`第三元会初射十乌`、`第四元会初涿鹿`、`至今`）：

   ```yaml
   时间线: 第二元会初诞生 → 第三元会初射杀十乌 → 触怒妖族后战死
   ```

   这条规矩是补一类真出过的错：`勾陈大帝` 是**封神之后**才立的帝位，正文却写成他在**第三元会**大羿射日那次「站在天规那一侧」——两个不同元会的人被写进了同一场戏。有了 `时间线` 就能一眼比对：链条上没有的时段，正文里不许让他到场。`检查.py` 现在把「类型＝人物但没有 `时间线`」报成 E 级，链里没有 `→` 也报 E 级；新增人物时照 `_模板\人物.md` 填。

8. **人物还要带「三视角评价 + 人物标签 + 器物人我」这十个字段，字段必须在、内容可以空**。`外貌` 与 `外貌标签` 写一句总括（供 Dataview 一眼扫），正文另有 `## 外貌` 六节：**头面／身形／服饰与妆造／特殊标记／气质与神态／写作忌处**（有第二形态的另加一节，如女娲蛇形、元凤凤凰形）；身高与三围一律用现代单位（cm），三围写「胸／腰／臀」三个数，不写「三维」；女性角色 T0 必写服饰与妆造（料子、颜色、部件、场合替换），男性 T1 可略；标签从外貌里提炼 2–3 个，顿号分隔；`评价自视`／`评价亲近`／`评价旁人` 各写一句话——**他自己怎么看自己、最亲近的人怎么看他、旁人怎么看他**，三句话必须互相不完全一致，否则说明还没写进去；`人物标签` 从这三种评价里提炼 1–3 个，顿号分隔，`检查.py` 卡「最多三个」与「不能空」；`法宝` 要带类型占位（`番天印（类型：待定）`，类型枚举——刀剑戟枪棍棒锤鞭锏钩叉……——同样等定稿；旧的 `本命法宝` 字段已并入这一项，再出现就是 E 级）；`功法`／`神通`／`亲近之人`／`仇视之人` 有就写、没有留空，不许为了填满硬编。

   ```yaml
   外貌: {{一句总括：脸型、眼、标志物、气质}}
   外貌标签: {{2–3 个，顿号分隔}}
   评价自视: 我只认该不该，不管能不能
   评价亲近: 他不好打交道，但不糊弄你
   评价旁人: 问了他也白问，他只说你该不该
   人物标签: 裁断、不点兵、只讲该不该
   法宝:
   功法:
   神通:
   亲近之人:
   仇视之人:
   ```

   为什么单列规矩：这三个视角是**同一件事的三种记法**，写在一起才能看出「他以为的自己」和「别人眼里的他」差在哪——这个差就是人物能立住的缝隙。

9. **`原创设定\` 这一层只写「规则与数值」，不改正史**。它是二次创作（游戏／跑团／二创小说）用的：天赋、好感度、关系档位都在这里，写清**生效对象／触发条件／数值效果／可回复性／破法**五项，不许只给形容词。与正史冲突时正史优先——天赋能让所有人一见面就喜欢你，不能让量劫不来。

10. **制度不是无人的机器——写制度，必须同时写「谁在用它、谁在留余地、谁在拿好处」**。天庭跟人间的朝堂一样：有一心为公的，有只想着自己的，有按规矩混日子的。`昊天上帝` 的位置是鸿钧给的，他自己也想坐，坐上去就要好处（每年刮来的功德拿大头、四时供奉、名分），所以他办事不是只有程序——**程序给下面人用，权衡给自己用**。判词只写「不得做什么」、不写「当如何」，就是留余地的形状；上司的亲戚犯了事，办的人若一点活路不给，以后没法在官场混。判断办法：写完一条制度，追问一句「**这件事里谁得了什么**」——答不出来，说明写成了机器，不是朝堂。具体见 `天庭` 的《朝廷不是机器》、`昊天上帝` 的《权衡之术》。
11. **人物必须写「人物要素」八项**——基础标识／外貌体征／性格气质／身份背景／能力喜好／言行特征／状态与关系／补充标签。`## 人物要素` 一出现就必须写满八节，缺项按 E 级报；外貌体征只写一句总述，细部写进 `## 外貌` 六节；不知道的写「待定」，但标题必须都在。**101 篇人物已全部补齐（2026-11-20）**：15 位女性＋86 篇男性与群像条目。
