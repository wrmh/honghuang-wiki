# 落伽山

> 一句话：它不是一个道场，是**一个收件地址**。

## 它是什么

南海东部一座小岛。山不高，没有灵脉，没有矿，没有洞府——岛上只有三间屋、一片竹、一口井，和一条从滩头上来的石阶。

按灵气的标准衡量，这是四海里最不值钱的一块地。`南海` 里比它肥的礁有几百处。

## 为什么它不是道场

[[观音]] 一年在这里待不满一个月（U-427 已定）。她本来就没有固定的地方——`灵山` 是治所，落伽山不是。

所以「岛是真的，常住是假的」。真要按道场的标准算，这里连门都没有：没有山门、没有知客、没有护法。

## 它真正的作用：收信

洪荒所有要送到观音手上的东西——求告、文书、一支香、一句传话——都往这座岛上送。

原因很朴素：**她本来没有地址，可总得有一个地址。** 神佛与人之间的距离，最后落成一个具体的门牌。

收信的不是修行人，是一个凡人的老妇。她不懂经文，也不问来处，做的事只有一件：**把送来的东西放进屋里，告诉他「送到了」。**

| | 一般道场 | 落伽山 |
|---|---|---|
| 收什么 | 香火、供奉、弟子 | **信** |
| 谁在 | 门人、护法 | 一户凡人 |
| 有没有回音 | 有（显灵） | **基本没有** |
| 归谁管 | 本门 | 龙族送补给，佛门不认领 |

## 龙族在这里唯一的一笔支出

岛不在龙族册上（见 `南海`），但龙族每年往岛上送一次补给——米、盐、灯油。

理由不是慈悲，是账：**「免得岛上没人，信就落进海里。」** 一封信落海，此后就要有人来解释它为什么没送到。

所以这是龙族在南海北部唯一一笔不算亏的支出：一年一次船，换一年不用解释。

## 写作约束

1. 不写观音在岛上显灵。她可以来，但不在这里办事——办事在`灵山`，在路上，在别人家里。
2. 不写宝殿、法会、香火鼎盛。这里一旦热闹起来，「没有固定地方」这条设定就塌了。
3. 写落伽山一律用三个动词：**送到、收到、没有回音**。
4. 岛上那户人家不修行、不求什么，也不因此得道——他们的作用是让「送到」这件事有个落点。
