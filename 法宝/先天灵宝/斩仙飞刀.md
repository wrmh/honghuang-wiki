# 斩仙飞刀

> 一句话：它不和人打——它只请人「转身」。

## 来历

先天灵宝，[[陆压道人]] 之物。**它不是刀，是一句必杀的话**：喊出名字，头就落。

## 能力与代价

- 能做到：必杀：对上了名字的人，一刀落下即斩，不问修为。
- 代价 / 克制：使用条件四条缺一不可（见正文）：名字、正身、无他人护持、持刀人在场。**四缺一即落空**。

### 完残与来由

完好。刀身有三处旧卷刃，都是「落空」那几次留下的。

## 战史

- 封神：斩过数位截教门人，**每一次都只斩一个**。
- [[钉头七箭书]] 那一役：未出手。

## 流转

先天 → [[陆压道人]]（不借）。

## 相关

- 持有者：[[陆压道人]]
- 对照：[[钉头七箭书]]（拜，不是斩）

## 是什么

一只葫芦。葫芦里不是刀，是一道**白光**；白光里有一个七寸高的小人，有眉有眼，眼中射出两道白光。

用的时候只需三步：**钉住泥丸宫**（让人元神不起作用）→ 报出对方名字 → 小人鞠一躬。头就落下来了。

关键在于：**它不经过「打」这个环节。**它不问对方有多强、有什么护身法宝，只问「泥丸宫钉不钉得住」。

## 为什么它属于先天灵宝

- 它是**开天之后成形的东西**（不是混沌里带来的），所以不属混沌系列。
- 40 道禁制、极品，不到至宝：因为它只能「斩有名字的东西」——无名者、不在册者，它没有下手的地方（对照 [[元屠阿鼻]] 的「斩留名的」）。
- 它不产气运、不锁气运，只是一把工具（见 [[先天灵宝]]）。

## 使用条件（四条，缺一不可）

| 条件 | 说明 |
|---|---|
| 钉住泥丸宫 | 需对方元神离体或被制；对纯肉身者（如巫族祖巫）无效 |
| 知道名字 | 名字是下手的位置；化名、无名、被抹去名字的人斩不了 |
| 施法时间 | 不是瞬发，要几息；故 [[陆压道人]] 每逢硬手先走 |
| 葫芦在手 | 葫芦失则刀散 |

## 战史（本库口径）

- 破**烈焰阵**：他凭本体是火里的东西（见 [[陆压道人]]），在阵中毫发无伤，从容祭出飞刀，斩阵主白礼。
- 封神末：他把葫芦**赠给 [[姜子牙]]**，此后不再出现。赠这一手不是慷慨，是**退出**——把最后一件能让他被找上门的东西交出去。

## 与其它法宝的分工

| 法宝 | 下手方式 | 边界 |
|---|---|---|
| 斩仙飞刀 | 钉元神 + 报名字 | 只斩有名字者 |
| [[钉头七箭书]] | 草人 + 二十一日 | 慢、阴，只能一次 |
| [[诛仙四剑]] | 按规则断道/形/神/传 | 需成套布阵 |
| [[元屠阿鼻]] | 斩有形 / 斩留名 | 杀人不沾因果 |

## 写作约束

1. 不写「随手一挥万人死」——它有施法时间，这一点决定了他为什么总在跑。
2. 不写它斩过圣人；也不写它斩不了圣人（留白）。
3. 赠姜子牙之后不许再出场。

## 已定（2026-11-14）：姜子牙用过几次

**一次也没用。**

他把它挂在车上，从头挂到尾。不是不想用，是**用不了**——飞刀要钉住泥丸宫、要报名字，[[姜子牙]] 一辈子没有那个本事把谁钉住。

这也让 [[陆压道人]] 的赠予更像一次**交割**：把一件自己再也不打算碰的东西，交给一个不会用它的人。
