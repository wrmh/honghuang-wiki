# 天庭

> 一句话：**它不是[[妖族天庭]]的延续，是它的接手人**——同一份岗位表，换了主人，也换了性质。

## 一、两个「天庭」不是一回事

这是全书最容易写混的一处，先把两张表摆开：

| | [[妖族天庭]]（帝俊的） | **天庭**（昊天的） |
|---|---|---|
| 本体 | 血缘王朝 | **程序官僚** |
| 谁是主 | [[帝俊]]／[[太一]] | [[昊天上帝]] |
| 位置怎么来 | 血统给的（365 星君＝365 阵位） | 册子给的（[[封神榜]] 上榜即归位） |
| 人能不能换 | **不能**（位置挂在人身上） | **能**（位置在，人可换） |
| 兵源 | 妖族全族 | 三教死者的名字 |
| 命门 | 血缘不可补，少一个就崩 | **缺编**：没人上班，规矩就执行不了 |
| 结局 | 倾覆（巫妖量劫） | 满编（封神之后），此后长期在场 |

一句话记：**妖族天庭是「一群有血缘的强者占住了岗位」，天庭是「一套岗位找人来坐」。**

## 二、它从妖族天庭手里只接了一样东西

不是势力、不是血脉、不是旧主，是那张**岗位表**。

妖族天庭把星空的自然秩序改成行政秩序（见 [[妖族天庭]] 的「政权即阵法」），设下 365 个星君职位。它塌了，那张表没塌——[[昊天上帝]] 接手时接的就是这张表，以及表上那个难题：**编制不满，天庭就运转不了。**

这正是 [[封神量劫]] 的直接起因：**缺编缺了整整一劫**，只能去三教那里要人。

## 三、结构：一个只会签字的头，加一堆可替换的岗

| 层 | 谁 | 干什么 | 为什么是这个形状 |
|---|---|---|---|
| 主 | [[昊天上帝]] | 发位置、批文书、定名分 | **有编制权，没有战斗力**——他一出手，天庭就变成「能打的势力」，而它的本质是机构 |
| 中枢 | **星部** | 校订 [[天庭历法]] | 编制内、可替换，谁上谁下都不影响历法本身 |
| 职能神 | 斗部、雷部、火部、水部等 | 按册执行天条 | 一个职能一个岗，**岗在人不在**（见 [[勾陈]] 从武力位变成军职岗） |
| 地方 | 城隍、土地、山神 | 收香火、报账 | 这是它伸到人间的末梢（见 [[香火]]） |
| 派驻 | [[东岳大帝]] | 在地府门口签字 | 天庭管「活人多少活多久」，轮回是最大分流口，必须有人在门口核「确实到期」 |

它管的三样东西：**位置**（[[封神榜]]）、**日子**（[[天庭历法]]）、**名分**（[[册封]]）。三样都不是生产力，都是**承认**。

## 四、它靠什么活着：不生产，只分配

天庭不产气运、不产功德，它**分配**：

- 香火是人间记的账，经它核过（见 [[香火]] 的四条收法）；
- 功德它年年刮一笔，还握着「这笔功德记给谁」的分配权（见 [[功德]]）；
- 卖的是「承认」：给散仙一个不算数的名，给势力一个合法，给人族一个「天命在此」。

所以它穷得要刮香火，却谁也不敢得罪它——**不是因为强，是因为它在册子那一头。**

## 五、命门与它的解法

**缺编**是它的结构性弱点。它的解法有三步，一步比一步被动：

1. **封神**：用位置换命，把死者的名字填进岗位（见 [[封神量劫]]）；
2. **关门**：[[绝地天通]]，通道一断，人上不来，它只能靠册子招人；
3. **走程序**：到了 [[西游量劫]]，它连「派人」都做不到，只能**出文书**——取经文牒一批，剩下的靠佛门自己走（见 [[八十一难]] 二组「官面」）。

**从「缺人就补」到「只能批条子」，这就是它全书的力量曲线。**

## 六、写作约束

1. **不许它有战斗力。** 它没有能打的人，只有能签的字；一旦写成能打，封神与西游两劫的因果全塌。
2. **不许把两个天庭的人混用。** [[帝俊]]、[[太一]]、[[白泽]] 属妖族天庭；[[昊天上帝]]、[[东岳大帝]]、星部属天庭。同名不同物。
3. **不许[[昊天上帝]]出手。** 他的权力形状是「签字」，不是「斗法」。
4. **不许用别的东西补编。** 补天庭编制的只有 [[封神榜]]；其他任何「又招了一批人」的写法都要先有一本册子。
5. **不许写成暴政。** 它不压迫，它**办事慢**——慢才是它的可怕之处。

## 关系

- 前身／接手对象：[[妖族天庭]]（只接了岗位表）
- 主：[[昊天上帝]]；派驻：[[东岳大帝]]
- 册子：[[封神榜]]（位置）、[[天庭历法]]（时间）、[[册封]]（名分）、[[香火]]（收入）
- 治所：[[三十三天]] 第三十二重·玉京
- 对手／合作方：[[三教]]、[[佛门]]、[[地府]]、[[人族]]
- 因果：[[封神量劫]] → [[绝地天通]] → [[西游量劫]]
