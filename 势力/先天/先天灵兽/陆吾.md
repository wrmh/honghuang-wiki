# 陆吾

> 一句话：**它守的是门与时节，不是人**。

## 是什么

虎身而九尾，人面而虎爪。古籍说它「司天之九部及帝之囿时」——**管天界的九个区界，也管天帝园圃的时节**。

注意它管的两样东西：**界**与**时**。都是「到哪里为止」，不是「谁归谁管」。

## 它与「南天门」的分别

| | 陆吾 | [[南天门]] |
|---|---|---|
| 守什么 | 九道界、园圃时节 | 一道门、一份凭信 |
| 凭什么拦 | 到了界就不许再走 | 凭信对不上就不许进 |
| 拦的是谁 | 所有会走的东西 | 有名字的东西 |

一句话：**陆吾守的是「界」，南天门守的是「名分」。**

## 第一元会：九道界

第一元会，昆仑还没有名字，山上只有石与雪。它绕着山走了九圈，每一圈停一次，脚印落在哪儿，哪儿就是一条界。

那九道界不是墙，也不是线，是**「到这儿为止」**——走过去不会撞到什么，只是会在某一刻忽然不想再往前。

后来天庭建南天门，学的就是这九圈里的第一圈：**先有界，才有门。**

## 写作约束

1. **不许写它说话**：人面不等于会说话。它表达只用三样——停、转身、把尾巴收起来。
2. **不许把它写成守卫队长**：它不巡逻、不换班、不抓人，只在界上「在」。
3. **界不能破，只能绕**：写谁硬闯，结局是「过去了，但从此回不来」，不是被打退。
4. 九道界只用一次，别在别的故事里再画一遍。

## 关联

- [[南天门]]：门禁制度的祖先。
- [[昆仑]]：九道界都画在这座山上。
- [[绝地天通]]：把「能上去」这件事关掉，与界是两回事——界管「到哪儿为止」，绝地天通管「还上不上得去」。
