# 红绣球

> 一句话：**它只有一个用法：扔。扔出去，必中；中了，必结束。**

## 一、档位与来历

| 项 | 值 |
|---|---|
| 品阶 | [[先天灵宝]]（32 道上品） |
| 系列 | 先天 |
| 来历 | [[混沌青莲]] 解体时的**莲瓣**之一（与 [[山河社稷图]]、[[河图洛书]] 同批） |
| 现主 | [[女娲]] |

同一批莲瓣里，它是**禁制最少、用途最窄**的一件。这不代表它弱——代表它**只做一件事**。

## 二、能力：一次落点

- 出手方式只有一种：**抛**。
- 抛出去之后**不追、不拐、不连击**——它落下的那一点，就是它要结束的那一点。
- 被它落中的人：**当场结束**，没有「重伤」这一档。
- 它**只落一次**，落完回到主人手里。所以它没法被躲第二遍，也没法连用。

### 为什么这样设计才合理

一件「必杀」的东西如果还能连发，这本书里所有战斗都失去意义。所以：

| 约束 | 后果 |
|---|---|
| 只落一次 | 用它的人必须先选对目标 |
| 不追不拐 | 躲得开的只有「不在那一点上」的人 |
| 落点由主人定 | 用它的关键在于**判断**，不在于力量 |
| 用完即收 | 一场仗只能用一次，第二次要等下一次机会 |

**它考验的是「你知不知道该结束谁」，不是「你打不打得过谁」。**

## 三、女娲为什么需要它

女娲一生只做两件事：造人（立标准）、补天（垫残局）。她几乎没有「必须杀掉谁」的场合。

所以红绣球在她手里的意义是**威慑**：她自己从不出手，但所有人都知道她手里有一个「只落一次、落了就结束」的东西。**一个从不使用的东西，比使用过的东西更有分量。**

## 四、为什么它只有 32 道

莲瓣系列的禁制分布是刻意的：

| 法宝 | 禁制 | 它管的事有多大 |
|---|---|---|
| [[七宝妙树]] | 44 | 刷掉「构成」 |
| [[河图洛书]] | 40 | 算出「结构」 |
| **红绣球** | **32** | **结束「一个点」** |

**管的面越窄，道数越少。** 它不参与规则、不改名分、不动因果——它只负责让某件事在此刻停下来。这种「窄」正是它 32 道的原因。

## 五、写作约束

1. **全书不许它落空**：它不是会失手的法宝，落空就等于破设定。
2. **不许连用**：一场只有一次。
3. **不许别人用出第二种用法**：抢去也只能扔。
4. 出场不写光效与轨迹，只写「她一抬手」「那一点就结束了」。
