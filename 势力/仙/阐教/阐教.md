# 阐教

> 一句话：**它只收「查得清来历」的人——所以它赢下了名分，也只赢下了名分。**

## 一、是什么

[[元始天尊]] 在昆仑玉虚宫立的教派，[[三教]] 之一。核心主张一句话：

> **资格从根行来——可查、可考、可举证。**

这条主张在当时是**革命性的**：巫族凭血统（不可查）、妖族凭编制（可查但不可增）、阐教凭**根行**（可查且可增）。它是洪荒第一个「凭证据取人」的组织。

## 二、三层结构

| 层 | 谁 | 干什么 |
|---|---|---|
| 教主层 | [[元始天尊]] | 立规矩、择人而授（盘古幡只立不执行，见 [[盘古幡]]） |
| 门人层 | [[十二金仙]]、[[姜子牙]]、[[申公豹]] | 撑门面、执行规矩 |
| 底层 | 记名弟子、玉虚宫执事 | 跑腿、记事、传话 |

## 三、它的强处与死穴

| 强处 | 死穴 |
|---|---|
| 可查证 → 规矩能被守 | 可查证 → 门人必须有「出身」，收不了没出身的人 |
| 择人而授 → 不出叛徒 | 择人而授 → **人太少**，一代只有十二个 |
| 讲根行 → 名声最正 | 名声最正 → 出事时最不能退 |

**十二金仙被打落境界那一次（见 [[混元金斗]]），阐教等于被削掉了整个中层。** 一个靠「门人撑门面」的教派，中层一空就再也补不回来——因为新人要重新查根行、重新认师承，而封神之后没人肯再查。

## 四、封神里的位置

- 主张：补编要人，阐教按规矩出人
- 签押：换名分（见 [[三教]] 三教签押表）
- 战场：主力（姜子牙执榜、十二金仙出战）
- 代价：赢了名分，输了元气，**五百年不复**

## 五、封神之后

| 项 | 状态 |
|---|---|
| 玉虚宫 | 还在，且更清静（[[元始天尊]] 封神后不再管阐教事务） |
| 门人 | 十二金仙五百年重修，回不到原来那一档 |
| 新收弟子 | 基本停了——收人就要往榜上填，谁也不肯再开这个口 |
| 影响力 | 名声最大，实际最弱 |

**阐教赢了「谁说了算」，输掉了「还有谁在」。**

## 六、写作约束

1. **不许写成正义一方**：它赢在可查证，不在更正确（见 [[三教]]）。
2. **不许它与人教、截教联手**：联手等于承认谁都不是正主。
3. **不许它封神后扩张**：元气一空，扩张就是找死。
4. 阐教的冲突一律落到**「谁有资格被写进册子」**，不落到个人恩怨。
