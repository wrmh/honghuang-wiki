# 鬼门关

> 一句话：**它不拦人，它换账本——过了这道关，你就不再是谁家的人，而是「册子上的一行」。**

## 一、它是什么

阴阳之间的那道界。不是一座门楼，也不是两扇门板：是一条线，线上立着关，关不闭。

活着的人从来看不见它；死了的人一下子就站在它这一侧——**没有「走过去」这个动作，是「已经到了」**。

过了它，才归册子管。

## 二、关不筛人

这是最容易写错的一处：鬼门关**不审判、不筛选、不问来历**。

| 以为的 | 实际 |
| --- | --- |
| 关上有差役把守，查身份 | 关上没有人常在；查身份在第一殿，不在关 |
| 恶人过不去、善人过得去 | 都过得去——**关不判善恶，它只换账本** |
| 需要凭证 | 不需要：册子上那一行在过来的那一刻自己就写上了 |

所以「过了鬼门关」在本书里不是一个可怕的场面，而是一件**手续已经发生**的事实：你从此在阳间那一本册子上，只剩一个「已故」。

## 三、为什么是「关」不是「门」

门可以关、可以锁、可以有人守着；关是一段界线，只分内外。

这个差别决定了三件事：

1. **没有人能替你过关**——界线不认代理人；
2. **没有人能在关外讨价还价**——关外还是阳间的事，关内已经换了一本账；
3. **关不能封**——一旦封上，幽冥就成了某个势力的辖区；它是天道直辖的，所以它永远不闭。

第三条是硬约束：**鬼门关没有守将**。谁想在那儿设卡，谁就是在夺幽冥的主权。

## 四、三条硬规矩

| 规矩 | 破了会怎样 |
| --- | --- |
| 过来就不能回去：回头＝还在阳间算，账立刻退回没结的状态 | 「回去一次」的先例一开，所有死都变成可以商量的 |
| 关不查身份：不管生前是谁 | 一旦查，幽冥就成了审判机关，而审判在十殿 |
| 关永远不闭：任何势力不得设卡 | 封关＝夺主权，轮回立刻失去意义 |

## 五、写作约束

1. 不写关楼、不写匾额、不写阴兵列队——**它越像一道界线越好**。
2. 不写「他舍不得走，在关前徘徊」：徘徊发生在这边，不在关前；关前没有「还来得及」这回事。
3. 不写有人被押着过关：过关没有押送，也没有仪式。
4. 不给关任何称呼上的威严：全书只叫「鬼门关」三个字，不加「森严」「阴风」这类形容。
5. 不写关上的对话——**这一站没有人说话**。

## 六、关系

- 上游：人间（`城隍` 那边划册，人间的账在阳间那一侧就断了）
- 下游：[[黄泉路]]（过关之后才开始走）
- 记账：过来那一刻，册上先写一行「到此」
- 记账人：`册府` 派人在关内那一侧抄（会抄漏，抄漏的就是 `不在册` 的一条来处）
- 对照：[[南天门]]（那边认凭信，这边不认任何东西）
