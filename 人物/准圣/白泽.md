# 白泽

> 一句话：全书唯一一个「知道所有答案，所以什么也做不了」的人。

## 是什么

妖族天庭的谋主。本相是兽，通人言，**知万物之情**——洪荒所有东西的名字、来历、弱点，他都能叫得出来。

这份能力在本书里不是「智慧」，而是一种**检索**：他不会算出别人算不出的东西，他只是**从来不需要查**。

## 他给妖族的每一条建议都是对的

这是本库对白泽最重要的定性：**他的建议从没出过错，所以妖族输得更彻底。**

| 局面 | 白泽的建议 | 结果 |
|---|---|---|
| 三族刚打完、罗睺起事 | 不掺和，先整编 | 对：妖族因此全须全尾地进了第二劫 |
| 巫族成形、血脉四级 | 早打，别等他们炼成都天神煞 | 对：帝俊没听（觉得十个太阳够用） |
| 十日同出、地上大旱 | 收一个回来 | 对，但晚了：[[夸父逐日]] 已经死了 |
| 大羿射日之后 | 立刻收兵，认这笔血债 | 对：帝俊与太一在帐里吵了一夜，最后没听 |
| 十二祖巫开始结阵 | 散阵，别跟阵法拼 | 对：帝俊算的是「谁能赢」，白泽要的是「别用阵法去打」 |

**五次全对，五次都没被采纳。** 这不是他无能，是**血缘型组织不需要参谋**：[[巫族]] 与 [[妖族天庭]] 都是「谁的血更浓谁说话」，一个靠检索的人在这里永远只是客人。

第三次之后，他就不劝了。

## 为什么归隐

[[巫妖量劫]] 收场时，他是少数几个「既没死也没被清算」的妖族。他不留天庭（天庭已经空了），不投人族（人族有自己的路），也不去 [[域外]]。

本库的处理是：**他不是逃，是「该说的都说完了」。**

他归隐之后只做一件事：**给东西起名字。** 后世 [[人族]] 那些最早的名物之辨（草木、禽兽、器物各叫什么），按本库版本都有一条暗线——来自一个不肯说出自己是谁的老者。

## 与 [[九尾]] 的对照

两人都是「不被秩序接住」的妖族，走了相反的路：

| | 白泽 | [[九尾]] |
|---|---|---|
| 本钱 | 知道一切 | 能变成任何样子 |
| 活法 | 退出去，只说话 | 挤进去，换身份 |
| 结局 | 无人知道他在哪 | 假身被斩、真身不知去向 |
| 共同点 | **都不在册上**（见 [[封神榜]]、[[生死簿]]） | 同 |

## 妖身

| 项 | 内容 |
|---|---|
| 形态 | **白身狮形，额生独角**，通体雪白无杂毛 |
| 尺寸 | 长约两丈；独角约三尺 |
| 状态 | 完好。但他极少现形——**现形就是开口**（见「他给妖族的每一条建议都是对的」） |
| 要害 | 角。角一断，他就只剩「知道」，说不清 |

**族**：白泽一族早就散了，如今**只剩他一个名字**，所以不单独立条（见 [[妖族天庭]]：妖圣是「名」不是「位」）。凡间偶有白泽的传说，说的都是他讲过的话，不是他的样子。

**写作用法**：不许写他战斗（他从不上阵）；不许写他现形后被人降住；他开口时要点明代价——**说出来的人，要担说出来的后果**。

## 关系

- [[帝俊]]：君臣，也是全书最典型的一次「对的人遇上不需要对的答案的人」。
- [[太一]]：太一从不与他说话——太一信的是钟，不是检索。
- [[巫族]]：他从不评巫族的人，只说「那个阵，别碰」。
- [[人族]]：唯一给过他善终的地方，虽然人族自己不知道。

## 版本差异

| 说法 | 内容 | 本书 |
|---|---|---|
| A | 白泽献《白泽图》，把天下精怪的名字都写下来 | 部分采用：他确实在给人族「起名字」，但不写成一部书——**写下来就变成册子，册子就归天庭管了** |
| B | 白泽是妖族第一战力 | 不采用：他的强在「不用查」，不在打 |
| C | 白泽在封神或西游出场 | 不采用：他不该再出现，出现就等于给读者一个「他其实在暗中操纵」的错误暗示 |

## 写作约束

1. **不给预言式剧透。** 他能叫出名字，不能说出结局。
2. **不写他后悔。** 他劝过五次，没被采纳，他不怨。
3. **不让他在封神与西游里露面**，最多留一句「有人说那老者什么都知道」。
4. **不解释他的境界来源**：他不在修行阶梯的常规路径上（与 [[大羿]] 同类，境界只作战力刻度）。

## 已定（2026-11-15 裁决）

- **U-229**：只留暗线，不点名。人族的名物之辨是人族自己长出来的；白泽只作为「有个什么都知道的老者」被提一句，不与人族文明源头挂钩。
- **U-230**：不知。连「知万物之情」都检索不到他——这是全书唯一一次检索彻底空转，用来立住「无相魔神确实在账外」。
