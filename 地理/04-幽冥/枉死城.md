# 枉死城

> 一句话：**它不是监狱，是候账区——里面的人不是有罪，是缺一个格子，账写不进去。**

## 一、它是什么

[[黄泉路]] 走到尽头，大路偏侧的一座城。城不高，墙也矮得近乎没有——**从里面能看见外面，从外面也看得见里面。**

城门口不站人。进去的人不用登记，出来的人也没有手续：能出去，只是出不去太远。

收的是「账没结清」的那一类：**暂不审判**。

## 二、谁会被收进来

| 来处 | 为什么进这里 |
| --- | --- |
| 判词还没落下 | 十殿那边还没轮到，先在这儿等着（不是罚，只是等） |
| 账还没长出来 | `三生石` 上照出来是灰的那一类（未发生的不入账，所以无从判起） |
| 账对不上 | 两本册子上写的东西不一致，得等 `册府` 核完 |
| 死得太早 | 阳间那边的账还在动（寿数之外的事还没结），于是先挂着 |

这四种有一点共同：**没有一种是因为「他坏」。**

所以在枉死城里，「好人」「坏人」这两个词没有用；唯一有用的问句是「他那一笔结了没有」。

## 三、城里不许忘

这是它与 [[忘川]] 最要紧的反差：

- 过了忘川的人，记忆被挪到不能回头看的地方；
- 在枉死城里的人，**记忆不能动**——因为要等账长出来，账要靠记忆对上。

所以枉死城是全幽冥唯一「人人都记得清清楚楚」的地方：记得自己怎么死的、记得谁欠他、记得死前那一刻的每一件事。

这也解释了它为什么安静得那么难受：**一群人，各自把同一件事想了很久。**

## 四、三条硬规矩

| 规矩 | 破了会怎样 |
| --- | --- |
| 不审判：进来只是挂着，不判、不罚、不上刑 | 一旦判了，这里就成了第二座十殿，而账还没结清的人不该被判决 |
| 不许忘：记忆不得被挪走、不得被兑掉 | 忘了就再也对不上账——**这一条把城和忘川划成了两件事** |
| 不锁门：能出去，只是出不去太远 | 锁门就等于「有罪」；这里的人还没到那一步 |

第三条要写清楚分寸：**不是被关住，是被「挂住」**——脚能走，走不远，因为册上那笔还挂在原地。

## 五、写作约束

1. 不写牢房、不写刑具、不写鬼卒看守——**它更像一座等消息的客栈**。
2. 不写城里的人互相诉苦、不写结拜、不写闹事：**他们各自等各自的一笔**。
3. 不写有人在城里修炼、变强、悟道——**没有进账的地方，也没有长进**。
4. 写这座城一定要写到「他记得」：记得越清楚，等得越久。
5. 不许出现「从枉死城逃出去」：能走，只是走不远，这一点不许被写成越狱。

## 六、关系

- 位置：[[黄泉路]] 尽头偏侧（见 [[幽冥]] 上段）
- 上游：[[黄泉路]]、[[鬼门关]]（都是「还没到审判」的那一段）
- 下游：十殿（见 [[地府]]）——账结清之后才走
- 常客：[[三生石]] 上照出灰的那一类
- 对照：[[忘川]]（那边忘，这边不许忘）

- **U-542** 城里的人等了很久之后，会不会「淡」下去？ → 会淡到只剩名字。记忆不许动，但情绪磨没了，久了连自己为什么等都不记得——**城里最老的那一批，只剩一个名字挂在那里**，判官翻到时也只剩一句「尚在」。

- **U-543** 有没有人替他把账补上？ → 有：阳间还有人替他烧、替他做、替他结，账就能长出来。所以这座城与阳间一直连着——**城里人等的不是判官，是阳间最后一个还记得他的人**。
