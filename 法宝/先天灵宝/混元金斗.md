# 混元金斗

> 一句话：**它不杀人，它把人「打回原形」——一身修为被削掉，人还是活的。**

## 一、档位与来历

| 项 | 值 |
|---|---|
| 品阶 | [[先天灵宝]]（40 道极品） |
| 系列 | 先天 |
| 来历 | 开天后第一次沉降成形的先天之物（不在青莲那批里） |
| 现主 | 三霄（[[云霄]]、琼霄、碧霄 三人共持，云霄主导） |

## 二、能力：削，不是杀

被金斗晃过，会发生的顺序是：

1. **顶上三花削落**（修出来的那三层先没了）
2. **胸中五气消散**（气运与内息被抽走）
3. **境界跌落**（跌到哪一档看被削的程度，不封顶也不保底）
4. **人还活着**

它的可怕不在死，在**「一夜之间变回凡人」**：有一身本事的人被打回原状，剩下的日子全部要按凡人的活法过。

### 它与阿鼻的分工

| 法宝 | 削掉什么 | 结果 |
|---|---|---|
| [[阿鼻]] | 名字 | 人活着，册上没有他 |
| **混元金斗** | 修为 | 人在册上，什么都做不了 |
| [[红绣球]] | 一整个落点 | 直接结束 |

**三件合起来才是完整的「怎么让人消失」：从册上抹掉、从境界上打落、从物理上直接终结。**

## 三、封神里的那一场

三霄为兄（赵公明，见 [[赵公明]]）出头，摆九曲黄河阵，用金斗连削十二金仙——**这是全书唯一一次「阐教被打到集体掉档」**。

后果有三层：

- 十二金仙被削，修为回不来（封神之后五百年重修，见 [[封神量劫]]）
- 阐教从此元气大伤，封神之后无力再撑门面（见 [[三教]]）
- 三霄自己招来圣人下场：削人修为这件事，触到的是**圣人也不能不管的那条线**

## 四、限制

| 限制 | 说明 |
|---|---|
| 只对「有修为可削」的人有效 | 对凡人、对没有三花五气者无效 |
| 削不彻底 | 削到哪一档不确定，看对方根基 |
| 逆不了 | 被削掉的修为**不能收回来**（谁捡都一样） |
| 圣人免疫 | 圣人不在这套「修出来的东西」上 |
| 用完要静置 | 一次削太多，斗本身也会「空」一阵 |

## 五、写作约束

1. **不许把它写成杀人法宝**：它的价值全在「不杀」。
2. **不许被削的人轻松恢复**：修回去要走五百年，且回不到原来那一档（见 [[修行境界]] 的断层）。
3. **不许再出现第二件同类法宝**：全书只有这一件能削，削这件事因此不可复制。
4. 出场只写「晃了一下」「三花落了几朵」。
