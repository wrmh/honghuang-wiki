# 五庄观

> 一句话：**它不是一座道观，是一个不接客的地方——门开着，是因为没有门；人来了，是因为没人拦。**

## 一、它是什么

万寿山里的一座观。没有山门、没有牌匾、没有知客。

| | 一般道场 | 五庄观 |
|---|---|---|
| 门 | 有山门，有人守 | 没有门：山径直接通到院子 |
| 客 | 报帖、通名、候见 | 不来人；来了自己找地方坐 |
| 主人 | 常在 | 常在，但多半在后山，不来前院 |
| 属于谁 | 属于门派 | 只属于它自己：不归天庭、不归三教（`地仙一脉` 名单上最长的一笔） |

观里最出名的不是殿，是那棵树。

## 二、它真正在管什么

它是 `地仙一脉` 的**事实中心**，但不是它的衙门。

- **它是名单上最长的那一笔。** 谁家山上有难，最先到的往往是这一带的人；他们从这儿得到消息，也从这儿知道「哪座山最近不对劲」。
- **它不议事。** 镇元子从不召集；来的人自己在前院坐一会儿，说几句，走。**这个观的作用是「让人有个地方说」，不是「让人有个地方定」。**
- **它替这一脉挡着两件事。** 天庭来问「你们归谁」，答案是「不归谁」；三教来请，答案是「不去」——两句话都由这一座观说出口，说完就没有下文，也没有人再问第二遍。
- **树下埋着这一脉最早的名单。** 写在石上，谁也没看过——观里人守的从来不是树，是那块石；而「没看过」才是它还能算数的原因（看过就得有人对它负责）。
- **天庭只派人来过一次。** 来的是 `太白金星`，把「请」字说完就走，此后再没来。所以此后天庭对万寿山的态度是「知道有这么个地方，但不登记」——与 `香火院` 同类，都是在册之外的地。

## 三、它不做什么（比做什么重要）

| 不做的 | 为什么 |
|---|---|
| 不设山门与守门人 | 一设门就有「谁能进」，一有「谁能进」就有名册 |
| 不接天庭的册封 | 一受封，山归天庭管，`地仙一脉` 的邻山就再也不会来（那条名单会短一大截） |
| 不参与量劫 | 按 `量劫` 的范围算，山在范围里一样被扫；去争反而把「不归谁」这句话说破了 |
| 不留客人过夜 | 留一夜是情分，留一月就是「依附」 |

## 四、写作约束

1. 不写仙气缭绕、不写异香满院：写石阶、写落叶、写没人扫。
2. 前院的戏最多：来的人坐着，主人不来，茶自己凉。
3. 镇元子的出场方式是「在后山」，不是「端坐殿上」。
4. 不写它被围攻、被夺：这座观的价值就在「没人来动它」，动了这一脉就散了。
