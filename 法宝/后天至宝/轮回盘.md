# 轮回盘

> 一句话：**它不是武器，是把「人死了去哪」这件事做成了一件能转的东西。**
> 后土不做判官——判官是人做的；她只负责**这台机器还在转**。

## 一、档位

| 项 | 值 |
|---|---|
| 品阶 | [[后天至宝]]（49 道） |
| 类别 | [[功德至宝]] |
| 来历 | [[后土]] 化[[六道轮回]]时，那笔功德凝成的实物 |
| 现主 | **后土**（她持有，但她不管它怎么判） |
| 归档 | `法宝/后天至宝/` |

它是功德至宝里唯一**"做出来的"**那一种：不是挣来的（[[屠巫剑]]），也不是剩下的（[[天地玄黄玲珑宝塔]]），是**拿一整个祖巫位格换出来的一件东西**。

## 二、它到底在做什么

轮回不是报应，是**结算**（见 [[因果]]：气运是余额，因果是欠条）。

轮回盘做的只有一件事：**把「该结的账」送到该去的地方**。

| 它负责 | 它不负责 |
|---|---|
| 魂魄进场、分流、重入六道 | 判谁该去哪个道 |
| 保证分流之后还能回到总账 | 记住谁是谁 |
| 在运转受影响时自保（这是后土出面的时刻） | 惩罚、奖励、审判 |

**关键分工（写死）：判官是地府的官，不是后土。** 后土只在**轮回运转本身受威胁**时才出面——她不是司法者，她是**运维者**。

## 三、为什么它是至宝而不是灵宝

因为它动的是**规则层**：一个人的死有没有"去处"，取决于这东西在不在转。

- 灵宝能伤人、能护身、能锁气运；
- 轮回盘一动，**全洪荒的生死就同时改了一次价**。

这也是它不需要"打"的原因：谁威胁轮回，等于威胁所有人的"死后"，不用后土动手，天道自己会清算。

## 四、写作约束

1. **不写后土坐在殿上审判**：她在盘边，不在案后。
2. **不写轮回盘能被抢走**：能拿它的人必须先能承担"所有死者无处可去"这件事。
3. **不写它显示画面、回放人生**：它不记录，只分流。
4. 每次出场只写"在转/停了一瞬/又转起来"，不写光华。

## 已定（2026-11-15 裁决）

- **U-310（停转一次要不要写）**：**不写**。从立起就没停过，停不下来本身就是设定。这条不松动，「后土只在转不动时出面」才成立——她一次都没被叫来过。
- **U-311（她能不能用它做别的事）**：**不能**。只能维护，不能使用——这才是她的代价。捞人这件事全书没人做到过，包括她。
