# 慎议者

> 他只有一个规矩：**话要么当面说，要么别说。**

## 一、三条原则

1. **不参与任何「当事人不在场」的议论**——评价人、传话、听闲话，全都算参与。
2. **要议论就当面**：他会把「你刚才说的那个人」当场叫来，或者直接把话原样递过去。
3. **他自己从不背后议论人**：不是不说，是**只当众说**——所以他骂人也骂得很响，很多人喜欢他这一点，也怕他这一点。

## 二、判定表（什么算「背后」）

| 情境 | 算不算背后议论他 | 后果 |
|---|---|---|
| 你与第三人在他不在场时议论他 | **算** | 触发，见第三节 |
| 你只是听，什么也没说 | **算**（听着也是参与） | 触发 |
| 你当着他的面说他 | 不算 | 正常互动；说得难听反而加分（+2 而不是 -2） |
| 你当着他面议论第三人 | 不算「背后议论他」，但他会当场叫那人来 | 对你 -5，并且他真的会去叫 |
| 你传话：「某某说你……」 | **算**（传话也是背后） | 触发，并且他会去找那个某某当面问 |
| 你在朝会上当众议人 | **算**——但他会在开口之前把当事人叫来 | 见第四节「公事」 |

## 三、后果（数值）

| 当前状态 | 后果 |
|---|---|
| 好感度 > -10 | 直接**拉到 -10** |
| 好感度 ≤ -10 | 再 **-10**（不覆盖为 -10，只能往下） |
| 已建立 [[亲密关系]] | 降到**该关系能维系的最低值**（表见 [[亲密关系]]） |
| 同一件事 | 只算一次；**新的**背后议论每次都算 |

好感度可回复（见 [[好感度]] 第三节），但**「背地里说过我」这个标记不消失**，除非你当着他的面承认一次。

## 四、核心玩法：二选一（自爆步兵）

你与 NPC-A 议论过慎议者。现在你有两条路，**没有第三条**：

| | 路线甲：公开告诉他 | 路线乙：私下告诉他 |
|---|---|---|
| 形式 | 当着 A 的面说，或在公开场合说 | 单独找他，A 不在场 |
| 他的判定 | **当面**，不算背后 | **当事人 A 不在场**，这就是在跟他议论 A |
| 慎议者对你 | **+10**（你敢当面说） | **-10**，或降到维系最低值 |
| 慎议者对 A | **-30**，并记 A 为「背后议论我的人」 | 无变化 |
| A 对你 | **-20**（你把他卖了） | 无变化 |
| 后续 | A 与慎议者从此不合；你少一个朋友 | 你会被记「会背地里说人」，此后与任何人议论第三人都触发 |

**设计意图**：这不是道德陷阱，是**信息税**。想让他知道你站他这边，就必须把说话的人交出去；想保住那个人，就必须让自己变成他讨厌的那种人。

## 五、谁会利用他

- **挑拨者**：把话递给他，他就替你去当面对质——他没被利用的感觉，因为他本来就打算去。
- **想甩锅的人**：让他当传声筒，事后可以说「是他说的」。
- **真正能留住他的人**：只有**当着他的面说难听话**的人。所以他的朋友少，但都极牢。

## 六、公事那块（我替你拍的板，你可改）

在朝会、评议、考功这种**制度允许议人**的场合，他照样认为「背后」，但他会做一件事：**发言之前把当事人叫来**。这就是他在天庭人缘差的原因——他不是不讲理，他是把「理」讲得太到位。

## 七、写法约束

1. 不许写成道德楷模：他不是好人，他是**受不了话被稀释**。
2. 不许写他放水、睁一只眼闭一只眼——那是没有这个天赋的人。
3. 不许写他背后报复：他只会当面问你一句「你那天说的是不是这个意思」。
4. 他生气的时候不吼，是**把话说得比平时更慢、更清楚**。
