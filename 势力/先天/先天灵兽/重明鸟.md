# 重明鸟

> 一句话：**它不来的时候，人自己刻一只**——「信」的第一个形状，不在鸟身上，在门口那个东西上。

## 是什么

状如鸡，鸣似凤，**两眼各有两瞳**（故名「重明／双睛」）。时常解落毛羽，光着翅肉也能飞。能搏逐猛兽虎狼，凡妖灾群恶，见它便退。

古籍说它「或一岁数来，或数岁不至」——**它来不来，没有规律**。

## 它与「名声」的分别

| | 重明鸟 | [[名声]] |
|---|---|---|
| 谁在替你说 | 你自己在场 | 别人在背后 |
| 靠什么起作用 | 它真的来过 | 有人真的信 |
| 失效方式 | 它不来了 | 事迹被新事覆盖 |

## 第一元会末：门口那只木鸟

第一元会末，它落在一个刚被凶兽清空的**巫民聚落**（那时还没有人族）。停了一夜，叫了一声，走了。此后再没来过。

聚落里的人做了两件事：

1. 刻了一只木鸟，挂在门上；
2. 开始对着木鸟说话。

木鸟不挡风雨，不治病，也不回话。可那之后，再没有东西进过那片聚落——**因为它开始有「里面」了**。

这是天地间第一件「没有用的东西」：它唯一的作用是让人知道**这里住着人**。后来人族学去，成了门上的木牌。

## 写作约束

1. **不许写它显灵**：它只出现一次，且不解释自己为什么来。
2. **不许写它被谁豢养**：可以是「它愿意停在你屋檐上」，不能是「你养了它」。
3. 木鸟这一段必须写**笨**：刻得丑、挂得歪、被人笑过。
4. 它的效用一律写成「没有东西进来」，不写成「打退了什么」。
