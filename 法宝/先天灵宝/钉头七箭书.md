# 钉头七箭书

> 一句话：全书唯一一件**打赢了也不好看的**法宝。

## 怎么用

筑一台高台 → 扎一个草人 → 写上目标姓名 → **一日三次，连续二十一日**拜祭 → 最后以箭射草人。

二十一日之内，目标会逐日恍惚、神魂渐散；到第二十一日，**魂魄散尽，无声无息地死**。

## 它为什么比 [[斩仙飞刀]] 更可怕

| | 斩仙飞刀 | 钉头七箭书 |
|---|---|---|
| 时间 | 几息 | 二十一日 |
| 见证 | 当场有人看着 | 无人看见，只是「他一天比一天不对劲」 |
| 反抗 | 可以躲、可以挡 | **不知道在被咒，就无从反抗** |
| 代价 | 葫芦在手 | 施术者二十一日不能离开高台 |

所以它的可怕不在威力，在**它把「杀人」变成一件不需要在场的事**。

## 战史（本库口径）

用于 **[[赵公明]]**：赵公明手持 [[定海珠]]、缚龙索，连败阐教十二金仙，燃灯道人也奈何不得。[[陆压道人]] 献书，[[姜子牙]] 依计行事——**一位准圣级别的强敌，就这样在二十一天里被咒死**。此后再未使用。

## 为什么只用一次

- 二十一日不能动，等于把自己钉在原地；封神战场上没人给他这个空档。
- 用它就要写清「谁在数日子」，这件事脏，脏在**它不给你一个可以还手的人**。

## 写作约束

1. 不写它咒过圣人。
2. 不写「咒错人」这种桥段（那是爽文写法，与本书「账要结清」的调性不合）。
3. 二十一天要写出「渐渐不对」的过程，不能一句带过。
