# 紫微

> 一句话：它是「所有位子中间的那个位子」——所以它从来不决定事情，它只是**让别的位置有中心可依**。

## 是什么

[[周天星斗大阵]] 的核心位。在 [[妖族天庭]] 的编制里，它不是一个战力岗，是一个**坐标**：三百六十五个星位全部按它定方位，它一动，全阵重排。

| 时期 | 谁在紫微位上 | 性质 |
|---|---|---|
| 妖族天庭全盛 | [[帝俊]] 自立 | 君位即阵心：他自己就是坐标系的原点 |
| 巫妖量劫之后 | 空 | 坐标没了，满天星位仍在，但不再成阵 |
| 封神之后 | 由榜定（本库不点名） | 从「人坐的位置」变成「册上的一格」 |

## 为什么它不能由战力决定

紫微的用处是**定方位**，不是打人。这意味着一个反直觉的结论：

> 坐紫微的人不必最强，但必须**最不会动**。

妖族天庭之所以能撑住，靠的正是帝俊从头到尾没离开过紫微位（见 [[妖族天庭]] 的「政权即阵法」）；而 [[巫妖量劫]] 里他去前线那一夜，阵就散了半边——不是被打散的，是**原点走了**。

## 与「太阳位」的区别

两个位子最容易被混为一谈，本库严格分开：

| | [[太阳星君]] | 紫微 |
|---|---|---|
| 数量 | 曾是十个，后压缩为一个 | 始终一个 |
| 作用 | 提供**光**（物理必需） | 提供**方位**（结构必需） |
| 缺了会怎样 | 天不能没有太阳 | 阵不能没有中心 |
| 可否由人替换 | 可以（排班） | **不可以**：换人即换坐标系，全阵要重排 |

所以封神里「榜定紫微」这件事比「榜定太阳」重得多：**它意味着天道认可了一个新的原点。**

## 写作约束

1. **不写紫微位的人亲自下场作战**（下场即失位）。
2. **不把它写成「最高权力」**：它是坐标，权力来自「别人要按你定方位」，不来自你能命令谁。
3. 封神后谁坐紫微**一律留白**，只说「榜上有这一格」。

## 已定（2026-11-15 裁决）

- **U-255**：留白。只说「榜上有这一格」，坐的人不重要——它是坐标，不是首领。
- **U-256**：没人守。阵心空着，这就是妖族崩得那么快的原因：不是被打散的，是原点走了。
